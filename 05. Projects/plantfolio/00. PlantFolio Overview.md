# 00 · PlantFolio: Project Overview

> [!abstract] Map of Content
> This is the **home page for the notes** of PlantFolio. Every lesson, summary and weekly progress note is reachable from here.
> The project's front page, with the goal, plan and log, is [[PlantFolio - Project Home]].

## Project details
| Item | Detail |
|---|---|
| What | A mobile-responsive platform to keep a profile for every plant, track its health, swap plants and diagnose problems from a photo |
| Brief | Plant Care & Exchange Community: group coursework, B.Sc. (Hons) Computer Science, Wayamba University of Sri Lanka |
| Stack | Plain PHP 8, hand-written CSS, vanilla JavaScript, MySQL through PDO, XAMPP; a Flask and Keras service for the two ML features |
| Roadmap | Five stages over about 16 weeks: 0 planning · F frontend with mock data · B backend · M machine learning · D testing and delivery |
| Code | `C:\xampp\htdocs\plantfolio` · <https://github.com/rSith/plantfolio> |
| How the notes are split | **Lessons** explain what you need to know. **Week notes** record what you actually did. |

## Suggested study order
1. **Now (weeks 1–4):** lesson 00, then lesson 01. Read [[00.04 Output Escaping in PHP]] and [[00.07 Mock Data Shaped Like Database Rows]] first: the whole frontend stage depends on those two habits.
2. **Before week 5:** [[02.01 Progressive Enhancement and Script Organisation]], which sets the rules for all the JavaScript that follows.
3. **Before week 8:** all of lesson 03. Its seven notes are the security rules of `CLAUDE.md`, and they are the most likely viva questions.
4. **Just in time** for everything else: read a topic note when its task starts.
5. **After each stage:** read that lesson's summary (`NN.99`) and answer its "Exam and viva focus" points aloud.
6. **Before the viva:** the seven summaries, the work logs of your week notes, and [[06.02 Security Review of a PHP Application]].
