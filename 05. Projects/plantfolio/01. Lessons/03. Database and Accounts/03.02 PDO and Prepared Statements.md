# 03.02 · PDO and Prepared Statements

> [!info] [[03.00 Database and Accounts|Lesson 3]] · Week 8 · Task CORE-03 · Priority 🔴 Core
> **Parent concept:** [[13.03 SQL Injection]], which explains the attack. Compare with [[06.03 SQLAlchemy]], the same idea in Python.
> **Used for:** `includes/db.php` and every query in the project.

## 1. Definitions
> [!note] PDO
> **PDO** (PHP Data Objects) is PHP's built-in way to connect to a database and run SQL. One interface works with MySQL, MariaDB, PostgreSQL, SQLite and others.

> [!note] Prepared statement
> A **prepared statement** is a query sent to the database in two parts: first the SQL text with **placeholders**, then the values. The database never mixes the two, so a value can never be read as SQL.

## 2. Why it is used
The first security rule in `CLAUDE.md`: *"PDO prepared statements only, `ATTR_EMULATE_PREPARES` off, exceptions on. Never build SQL by concatenating input."*

```php
// DANGEROUS: the value becomes part of the SQL text
$sql = "SELECT * FROM users WHERE email = '" . $_POST['email'] . "'";
```
Someone types `' OR '1'='1` as their email, and the query becomes
```sql
SELECT * FROM users WHERE email = '' OR '1'='1'
```
which matches every user. Other inputs can read or delete whole tables. A prepared statement makes this impossible, not merely unlikely.

## 3. How it works
```text
1. prepare   "SELECT * FROM users WHERE email = :email"   → the database parses and plans the SQL
2. execute   [':email' => "' OR '1'='1"]                  → the value is sent separately, as data
3. fetch     the result rows
```
Because the SQL was already understood in step 1, the value in step 2 can only ever be compared as text. It has no way to change the query's structure.

## 4. The connection
One way to write `includes/db.php`, matching the task's three requirements:

```php
<?php
// includes/db.php: one shared database connection (CORE-03)

function db(): PDO
{
    static $pdo = null;                       // created once per request, then reused

    if ($pdo === null) {
        $dsn = 'mysql:host=' . config('db_host') . ';dbname=' . config('db_name') . ';charset=utf8mb4';

        $pdo = new PDO($dsn, config('db_user'), config('db_pass'), [
            PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,   // errors become exceptions
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,         // rows as ['column' => value]
            PDO::ATTR_EMULATE_PREPARES   => false,                    // real prepared statements
        ]);
    }

    return $pdo;
}
```
| Option | Why |
|---|---|
| `charset=utf8mb4` in the DSN | The connection uses the same character set as the tables |
| `ERRMODE_EXCEPTION` | A failed query stops the code loudly. It cannot be silently ignored. |
| `FETCH_ASSOC` | Rows arrive as associative arrays, the exact shape of the mock data |
| `EMULATE_PREPARES => false` | The database itself prepares the statement. With emulation on, PHP pastes the values into the SQL before sending it. |

The DSN is the same for MariaDB, which XAMPP installs.

## 5. Syntax
```php
<?php
$pdo = db();

// SELECT several rows
$stmt = $pdo->prepare('SELECT id, nickname FROM plants WHERE user_id = :user_id ORDER BY nickname');
$stmt->execute(['user_id' => $user_id]);
$plants = $stmt->fetchAll();                 // an array of rows; [] if none

// SELECT one row
$stmt = $pdo->prepare('SELECT * FROM users WHERE email = :email');
$stmt->execute(['email' => $email]);
$user = $stmt->fetch();                      // one row, or false if none

// SELECT one value
$stmt = $pdo->prepare('SELECT COUNT(*) FROM plants WHERE user_id = :user_id');
$stmt->execute(['user_id' => $user_id]);
$total = (int) $stmt->fetchColumn();

// INSERT
$stmt = $pdo->prepare('INSERT INTO collections (user_id, name, is_public) VALUES (:user_id, :name, :is_public)');
$stmt->execute(['user_id' => $user_id, 'name' => $name, 'is_public' => 1]);
$new_id = (int) $pdo->lastInsertId();

// UPDATE and DELETE: rowCount() says how many rows changed
$stmt = $pdo->prepare('UPDATE collections SET name = :name WHERE id = :id AND user_id = :user_id');
$stmt->execute(['name' => $name, 'id' => $id, 'user_id' => $user_id]);
$changed = $stmt->rowCount();
```
`:name` is a **named placeholder**. `?` is a positional one; values are then given in order.

## 6. Three things a placeholder cannot do
| Need | Why a placeholder fails | Do this |
|---|---|---|
| A **column or table name**, or `ASC` / `DESC` | Placeholders stand for values only | Choose from a **whitelist** in PHP |
| **`LIMIT` and `OFFSET`** | They must be integers | `bindValue(':limit', $n, PDO::PARAM_INT)` |
| A **list** for `IN (…)` | One placeholder is one value | One placeholder per item |

```php
<?php
// Whitelist for ORDER BY
$orders = ['newest' => 'created_at DESC', 'title' => 'title ASC'];
$order_sql = $orders[$sort] ?? $orders['newest'];        // an unknown value falls back

$stmt = db()->prepare("SELECT id, title FROM exchange_listings WHERE status = :status
                       ORDER BY $order_sql LIMIT :limit OFFSET :offset");
$stmt->bindValue(':status', 'open');
$stmt->bindValue(':limit', 12, PDO::PARAM_INT);
$stmt->bindValue(':offset', $offset, PDO::PARAM_INT);
$stmt->execute();
```
`$order_sql` is safe to place in the string only because it can be nothing but one of the two texts written in the code.

## 7. Example: a transaction
Some actions need several queries that must **all** succeed or **all** be undone. Creating a plant and its default reminder is one.

```php
<?php
$pdo = db();

try {
    $pdo->beginTransaction();

    $stmt = $pdo->prepare('INSERT INTO plants (user_id, nickname, health_status) VALUES (:user_id, :nickname, :status)');
    $stmt->execute(['user_id' => $user_id, 'nickname' => $nickname, 'status' => 'stable']);
    $plant_id = (int) $pdo->lastInsertId();

    $stmt = $pdo->prepare('INSERT INTO care_reminders (plant_id, task, interval_days, last_done, next_due)
                           VALUES (:plant_id, :task, :days, :today, DATE_ADD(:today2, INTERVAL :days2 DAY))');
    $stmt->execute(['plant_id' => $plant_id, 'task' => 'water', 'days' => 7, 'today' => $today,
                    'today2' => $today, 'days2' => 7]);

    $pdo->commit();                          // make both permanent
} catch (Throwable $error) {
    $pdo->rollBack();                        // undo everything since beginTransaction
    throw $error;
}
```
Without the transaction, a failure in the second insert would leave a plant with no reminder.

> [!warning] A named placeholder can be used only once per query
> With real (non-emulated) prepared statements, `:today` may not appear twice. That is why the example has `:today` and `:today2`. Reusing a name gives "Invalid parameter number".

## 8. When a query fails
- In development, the exception shows the SQL error. Read it.
- In production, the visitor sees a plain "Something went wrong" page and the details go to a log. An SQL error shown to a visitor reveals table and column names: [[06.03 Production Configuration and Release]].
- A **duplicate** on a `UNIQUE` column raises an exception with code `23000`. Catch that one where it is expected (registration) and show a normal form error.

## 9. Common mistakes
- **Putting a variable into the SQL string.** Even a number, even "just this once".
- **Using `query()` with input.** `query()` is for SQL with no parameters at all.
- **Thinking escaping is as good.** Functions such as `addslashes` are not a defence. Placeholders are.
- **Emulated prepares left on.**
- **`fetch()` treated as always returning a row.** It returns `false` when nothing matches. Check before using it.
- **A new connection in every function.** One per request.
- **`SELECT *` in pages.** Name the columns: the row then has exactly the shape the page expects.
- **`%` inside the SQL of a `LIKE`.** The wildcard belongs in the value: [[04.04 Search, Filters and Pagination]].
- **Catching an exception and doing nothing.**
- **Printing the error to the visitor.**
- **Forgetting the owner condition** (`AND user_id = :user_id`). The query is injection-proof and still lets anyone edit anything: [[03.07 Access Control and Ownership Checks]].
