# 01.99 · Lesson Summary: Building Pages

> [!abstract] Back to [[01.00 Building Pages]] · Progress: [[PlantFolio Week 02 - Pages A First Impressions]] · [[PlantFolio Week 03 - Pages B My Plants]] · [[PlantFolio Week 04 - Pages C Community]]

## Must know
- **Page pattern:** helpers → data → `$page_title` → `header.php` → HTML → `footer.php`. Logic at the top, HTML below.
- **`header.php` opens** `<html>`, `<head>`, `<body>`, `<main>`; **`footer.php` closes** them and loads scripts with `defer`.
- **The head needs** `lang`, `charset`, the **viewport** tag, a unique `<title>`, and stylesheet links built with `url()`.
- **Active link:** compare `basename($_SERVER['SCRIPT_NAME'])` with the link's file and set **`aria-current="page"`**; style that attribute.
- **Nothing may be output before a redirect or a session start.** That is why logic comes first.
- **Card grid:** `repeat(auto-fill, minmax(210px, 1fr))` gives 1 to 4 columns with no media query.
- **Photos:** `aspect-ratio: 4 / 3` with `object-fit: cover`; meaningful `alt`; `loading="lazy"`.
- **Clickable card:** one real link on the title; its `::after` covers the card.
- **`margin-top: auto`** in a flex column pushes a row to the bottom. **`position: sticky; bottom: 0`** keeps the save bar in view.
- **Query string:** `?name=value&name=value`, read through `$_GET`. Every value is a string, may be missing, and may be anything.
- **Validate:** `filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT)` for IDs; trim and limit text; a whitelist for choices.
- **Not found → `http_response_code(404)`.**
- **`http_build_query()` encodes for the URL; `e()` escapes for the page.**
- **GET reads, POST changes.**
- **States:** name each condition once at the top (`$has_plants`, `$is_owner`), branch in the HTML.
- **An empty state** says what is happening and offers one next step.
- **Hiding a control is not security.** The server checks ownership. **Never send data that should stay hidden.**

## Key code
```php
<?php
$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);
$q  = mb_substr(trim((string) ($_GET['q'] ?? '')), 0, 100);
$is_owner = $plant['user_id'] === $current_user['id'];
?>
<a href="<?= e(url('explore.php?' . http_build_query(['q' => $q]))) ?>">Search again</a>
```
```css
.card-grid { display: grid; gap: var(--space-16); grid-template-columns: repeat(auto-fill, minmax(210px, 1fr)); }
.card-media img { width: 100%; aspect-ratio: 4 / 3; object-fit: cover; display: block; }
.card { position: relative; }
.card-link::after { content: ""; position: absolute; inset: 0; }
.save-bar { position: sticky; bottom: 0; }
.nav-link[aria-current="page"] { font-weight: var(--weight-semibold); }
```

## Important comparisons
| GET | POST |
|---|---|
| Data in the address | Data in the body |
| Read, search, filter | Create, edit, delete |
| Can be bookmarked | Cannot |

| `auto-fill` | `auto-fit` |
|---|---|
| Keeps empty tracks | Collapses them; few items stretch |

| `object-fit: cover` | `contain` |
|---|---|
| Fills the box, crops | Shows all, leaves bands |

| `sticky` | `fixed` |
|---|---|
| Stays in the flow and its container | Floats over the page |

| Hiding a control | Checking on the server |
|---|---|
| Tidies the interface | Is the actual protection |

| URL encoding | HTML escaping |
|---|---|
| Makes a value safe inside a URL | Makes a value safe inside HTML |
