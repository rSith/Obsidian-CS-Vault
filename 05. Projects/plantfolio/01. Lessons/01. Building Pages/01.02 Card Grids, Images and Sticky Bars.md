# 01.02 · Card Grids, Images and Sticky Bars

> [!info] [[01.00 Building Pages|Lesson 1]] · Weeks 2–4 · Priority 🔴 Core
> **Builds on:** [[07.01 CSS Layout with Flexbox and Grid]], which explains flexbox and grid themselves. This note covers the four layout patterns PlantFolio uses most.
> **Used for:** My Garden, Explore, Exchange, Public Profile (card grids) and Add / Edit Plant (sticky save bar).

## 1. Definitions
| Term | Meaning |
|---|---|
| **Card** | A box that summarises one item (a plant, a listing) and links to its page |
| **Aspect ratio** | The proportion of width to height, such as 4 : 3 |
| **Intrinsic size** | The real pixel size of an image file |
| **Sticky positioning** | An element scrolls with the page until it reaches an edge, then stays there |

## 2. Why it is used
- Members upload photos of every shape. Without rules, cards in a row would all be different heights and the grid would look broken.
- The grid must go from one column on a phone to three or four on a desktop **without a media query for every step**.
- On the long Add Plant form, the Save button must stay reachable without scrolling to the bottom.

## 3. Pattern 1: a grid that chooses its own number of columns
```css
.card-grid {
  display: grid;
  gap: var(--space-16);
  grid-template-columns: repeat(auto-fill, minmax(210px, 1fr));
}
```
Read `repeat(auto-fill, minmax(210px, 1fr))` as: *"make as many columns as fit, each at least 210 px wide, and share the leftover space equally."*

| Screen | Result |
|---|---|
| 375 px phone | 1 column |
| 768 px tablet | 2 or 3 columns, depending on the padding around the grid |
| 1040 px content area | 4 columns |

The style guide uses exactly this for plant cards, and `minmax(270px, 1fr)` for the wider listing cards.

| `auto-fill` | `auto-fit` |
|---|---|
| Keeps empty column tracks when there are few cards | Collapses empty tracks, so few cards stretch wide |
| Two cards stay card-sized | Two cards each take half the row |

`auto-fill` suits a garden with only one or two plants: the cards do not balloon.

## 4. Pattern 2: every photo the same shape
```css
.card-media img {
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
  display: block;
}
```
- **`aspect-ratio: 4 / 3`** fixes the box's proportion, whatever the photo's real shape.
- **`object-fit: cover`** fills that box by **cropping** the photo. Without it the photo would be stretched or squashed.
- **`display: block`** removes the small gap that inline images leave underneath.

| `object-fit` | Result |
|---|---|
| `fill` (default) | Stretched to fit; distorted |
| `cover` | Fills the box; edges cropped |
| `contain` | Whole image visible; empty bands at the sides |

The design system asks for 4 : 3 on cards and 1 : 1 on thumbnails.

```php
<img src="<?= e(photo_url($plant['photo'])) ?>" alt="Photo of <?= e($plant['nickname']) ?>" loading="lazy">
```
- **`alt`** describes the image for people who cannot see it. A purely decorative image gets `alt=""`, as the avatar partial does.
- **`loading="lazy"`** delays images below the screen until the visitor scrolls near them. A garden of 40 plants then loads quickly.

## 5. Pattern 3: a whole card that is clickable, with one link
Wrapping the entire card in an `<a>` makes a screen reader read every word of the card as the link's name, and forbids other links inside. The project's approach:

```css
.card {
  position: relative;                 /* the anchor for the stretched link */
}

.card-link::after {
  content: "";
  position: absolute;
  inset: 0;                           /* cover the whole card */
}
```
```php
<h3 class="plant-card-name">
  <a class="card-link" href="<?= e(url('plant.php?id=' . $plant['id'])) ?>"><?= e($plant['nickname']) ?></a>
</h3>
```
There is **one real link**, on the title, with a clear name ("Monty"). Its invisible `::after` covers the card, so a click anywhere follows it.

## 6. Pattern 4: lining up the bottoms of cards
Cards in a row have text of different lengths. To keep the last row of each card (the owner and rating) at the same height:

```css
.card-body {
  display: flex;
  flex-direction: column;
  flex: 1;                            /* fill the card's height */
}

.listing-card-owner {
  margin-top: auto;                   /* push this row to the bottom */
}
```
In a flex column, `margin-top: auto` takes up all the spare space above the element.

## 7. Pattern 5: a save bar that stays in view
```css
.save-bar {
  position: sticky;
  bottom: 0;
  display: flex;
  justify-content: flex-end;
  gap: var(--space-12);
  padding: var(--space-12) var(--space-16);
  background: var(--color-white);
  border-top: 1px solid var(--color-line);
}
```
| | `sticky` | `fixed` |
|---|---|---|
| Takes up space in the page | Yes | No; it floats over the content |
| Stays within its container | Yes | No; relative to the screen |
| Content can hide behind it | No | Yes, unless padding is added |

`sticky` is the safer choice for a bar that belongs to one form.

## 8. Example: the page container
```css
.container {
  max-width: var(--content-width);          /* 1040px */
  margin-inline: auto;                      /* centre it */
  padding-inline: var(--space-16);          /* breathing room on a phone */
}

@media (min-width: 768px) {
  .container { padding-inline: var(--gutter); }
}
```
```php
<div class="container">
  <div class="card-grid">
    <?php foreach ($plants as $plant): ?>
      <?php partial('plant-card', ['plant' => $plant]); ?>
    <?php endforeach; ?>
  </div>
</div>
```
`margin-inline` and `padding-inline` mean "left and right".

## 9. Common mistakes
- **Horizontal scrolling on a phone.** Usually one element with a fixed width, or a long word. A grid or flex child may also refuse to shrink below its content: give it `min-width: 0`.
- **Stretched photos:** `width` and `height` set with no `object-fit`.
- **A fixed pixel height on a card.** Longer text overflows. Let content set the height.
- **A media query for every column count,** when `auto-fill` with `minmax` does it.
- **No `alt`,** or an `alt` that says "image". Write what the image shows.
- **`alt` text on a decorative image,** which a screen reader then reads aloud for nothing.
- **Wrapping the whole card in a link.**
- **`position: sticky` that does nothing.** It needs `top` or `bottom`, and no ancestor with `overflow: hidden`.
- **Large original photos in a small card.** Stage B resizes uploads to 1600 px: [[04.02 Secure File Uploads in PHP]].
