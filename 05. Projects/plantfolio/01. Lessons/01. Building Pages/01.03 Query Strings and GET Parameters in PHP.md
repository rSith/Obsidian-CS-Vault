# 01.03 · Query Strings and GET Parameters in PHP

> [!info] [[01.00 Building Pages|Lesson 1]] · Weeks 3–4 · Priority 🔴 Core
> **Builds on:** [[02.03 URL Structure and Domains]] · [[02.04 HTTP Protocol]] · [[00.02 PHP Basics for Templates]]
> **Used for:** `plant.php?id=42`, `listing.php?id=7`, `user.php?u=nimali.grows`, `explore.php?q=pothos`.

## 1. Definitions
> [!note] Query string
> The **query string** is the part of a URL after the `?`. It carries named values to the page: `explore.php?q=pothos&type=swap`.

| Term | Meaning |
|---|---|
| **Parameter** | One `name=value` pair. Pairs are joined with `&`. |
| **`$_GET`** | PHP's array of the parameters in the address |
| **URL encoding** | Replacing characters that are not allowed in a URL with codes: a space becomes `%20` or `+` |
| **Whitelist** | A fixed list of the values you accept |

## 2. Why it is used
One file serves many pages. `plant.php` shows Monty for `?id=42` and Goldie for `?id=43`. Search and filters live in the address too, which the wireframes require: a filtered page can be **bookmarked, shared and reloaded** and still shows the same results.

## 3. How it works
```text
http://localhost/plantfolio/public/explore.php?q=golden+pothos&type=swap
                                               └────────── query string ─┘

$_GET = ['q' => 'golden pothos', 'type' => 'swap']
```
Three facts to hold on to:
1. **Every value is a string.** `?id=42` gives `'42'`, not the number 42.
2. **Any value can be missing.** Reading a key that is not there gives a warning.
3. **Anyone can type anything.** The address bar is user input. `?id=abc`, `?id=-1` and `?id=999999` will all arrive one day.

## 4. Syntax
```php
<?php
// An integer ID: null if missing, false if not a whole number
$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);

// A search text: always a string, trimmed, with a length limit
$q = trim((string) ($_GET['q'] ?? ''));
$q = mb_substr($q, 0, 100);

// A choice from a fixed list: fall back to a default
$sort = $_GET['sort'] ?? 'newest';
if (!in_array($sort, ['newest', 'nearest', 'rating'], true)) {
    $sort = 'newest';
}
```

| Kind of value | Read it with | Reject or replace when |
|---|---|---|
| ID | `filter_input(…, FILTER_VALIDATE_INT)` | Not an integer, or below 1 |
| Free text | `trim`, `mb_substr` | Longer than the limit |
| One of a few options | `in_array(…, true)` against a whitelist | Not in the list |
| Yes or no | `isset($_GET['public'])` | |

The third argument `true` makes `in_array` compare strictly.

## 5. Example: `plant.php?id=42` with mock data
```php
<?php
require_once __DIR__ . '/../includes/helpers.php';
require_once __DIR__ . '/../includes/mock-data.php';

$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);

// Find the row with that id
$plant = null;
foreach ($mock_plants as $row) {
    if ($row['id'] === $id) {
        $plant = $row;
        break;
    }
}

// Nothing found: answer with a real 404, not an empty page
if ($plant === null) {
    http_response_code(404);
    $page_title = 'Plant not found';
    include __DIR__ . '/../includes/header.php';
    echo '<p>We could not find that plant.</p>';
    include __DIR__ . '/../includes/footer.php';
    exit;
}

$page_title = $plant['nickname'];
include __DIR__ . '/../includes/header.php';
?>
<h1><?= e($plant['nickname']) ?></h1>
<?php include __DIR__ . '/../includes/footer.php'; ?>
```
- A missing, invalid or unknown ID all end in the same place: **404 Not Found**.
- `http_response_code(404)` sets the status, so browsers and search engines know the page does not exist. It must run before any output.
- In stage B the `foreach` becomes one query with a prepared statement. The rest stays.

## 6. Building links
```php
<?php
$params = ['q' => $q, 'type' => 'swap', 'page' => 2];
$link = url('explore.php?' . http_build_query($params));
// …/explore.php?q=golden+pothos&type=swap&page=2
?>
<a href="<?= e($link) ?>">Next page</a>
<input type="search" name="q" value="<?= e($q) ?>">
```
- **`http_build_query()`** encodes each value for a URL. A search for `ferns & mosses` would otherwise break the address at the `&`.
- **`e()`** then escapes the finished URL for HTML. Two different jobs: encoding for the URL, escaping for the page.
- The search box is filled with what the user typed, escaped, so they can see and edit their search.

A plain HTML form with `method="get"` builds the query string by itself:
```php
<form method="get" action="<?= e(url('explore.php')) ?>">
  <label for="q">Search plants or @usernames</label>
  <input id="q" type="search" name="q" value="<?= e($q) ?>">
  <button class="btn btn-primary" type="submit">Search</button>
</form>
```
Filters work this way first, with no JavaScript: [[02.04 URLSearchParams and Shareable Filter URLs]].

## 7. GET or POST?
| | **GET** | **POST** |
|---|---|---|
| Data travels in | The address | The request body |
| Bookmark, share, reload | Yes | No |
| Use for | **Reading:** view, search, filter, sort, page number | **Changing:** create, edit, delete, log in |
| Safe to repeat | Yes | No |

A link such as `delete.php?id=42` is a mistake: a browser, a search engine or a tricked user can follow it. Anything that changes data is a POST form with a CSRF token: [[03.05 CSRF Tokens]].

## 8. Common mistakes
- **Trusting the value.** Validate every parameter, every time.
- **Printing it without `e()`:** `You searched for <?= $_GET['q'] ?>` is the textbook XSS hole.
- **Comparing `'42' === 42`.** A string is never identical to an integer. Convert first.
- **`(int) $_GET['id']` alone.** It turns `'abc'` into `0` and `'42abc'` into `42` without complaint. `filter_input` rejects both.
- **No handling for "not found".** The page then crashes with "Trying to access array offset on null".
- **Returning status 200 with a "not found" message.**
- **Putting the value straight into SQL** in stage B. Prepared statements only: [[03.02 PDO and Prepared Statements]].
- **Passwords or private data in the address.** URLs are stored in history and server logs.
- **Using GET for an action** that changes something.
- **Assuming "the page has no link to it" means nobody can open it.** Anyone can type `?id=45`. Ownership is checked on the server: [[03.07 Access Control and Ownership Checks]].
