## What this lesson is about
The database and login exist. These two weeks **wire every page** to real data: collections, plants with photos, the health story, reminders, search, the exchange marketplace and ratings. At the end the nine core features work end to end and the project could be submitted.

The pages were built in stage F, so this is not page-building. For each feature the work is:
1. write the query that returns **the same shape as the mock array**;
2. swap it into the page;
3. make the forms save, with every security check;
4. delete the mock array;
5. run the Test Plan cases, then try the wrong inputs.

## Two things to settle before this stage
> [!warning] Image resizing needs a PHP extension that is switched off on this computer
> On 8 Oct 2026 the XAMPP install here had `;extension=gd` in `C:\xampp\php\php.ini`, which means the GD image library is **not loaded**. Resizing uploads to 1600 px (CORE-17) needs it. Remove the semicolon and restart Apache. Every teammate's XAMPP needs the same change, so it belongs in the README's setup steps.

> [!note] Where do query functions live?
> The folder structure is locked, and `CLAUDE.md` lists the files of `includes/`. It does not say where functions such as "get the plants of a user" go. That is a convention for `docs/conventions.md` (task DES-11) to settle before week 9.
