# 05.03 · Convolutional Neural Networks

> [!info] [[05.00 Machine Learning Service|Lesson 5]] · Week 12 · Task ML-04 · Priority 🟡 Supporting
> **Parent concepts:** [[Neural Network]] · [[Deep Learning]] · [[Classification]]. Read those first for neurons, layers, weights and training. This note covers what makes a network *convolutional*.
> **Used for:** the baseline disease model built from scratch, and for understanding MobileNetV2.

## 1. Definitions
> [!note] Convolutional neural network (CNN)
> A **CNN** is a neural network designed for images. Its first layers do not look at the whole picture at once. They slide small pattern detectors, called **filters**, across it.

| Term | Meaning |
|---|---|
| **Filter** (kernel) | A small grid of weights, often 3 × 3, that responds to one pattern |
| **Convolution** | Sliding a filter over the image and computing one number at each position |
| **Feature map** | The grid of numbers one filter produces: where its pattern was found |
| **Stride** | How many pixels the filter moves at each step |
| **Padding** | Extra border pixels added so the filter can reach the edges |
| **Pooling** | Shrinking a feature map by keeping one value from each small block |
| **Softmax** | The last step: turns scores into probabilities that sum to 1 |

## 2. Why it is used
A photo for the model is $224 \times 224$ pixels with 3 colour values each: $224 \times 224 \times 3 = 150{,}528$ numbers. An ordinary (fully connected) layer of 1,000 neurons on top would need about **150 million weights**. That is too many to learn from a few thousand photos, and it has a second flaw: it treats a leaf spot at the top-left and the same spot at the bottom-right as unrelated.

A CNN fixes both:
- **Few weights.** A 3 × 3 filter has 9 weights per input channel, reused at every position.
- **Position does not matter.** The same filter finds the same pattern wherever it appears.

## 3. How it works: one convolution
A filter is laid over a patch of the image. Matching positions are multiplied and the products added. That sum is one number of the feature map. Then the filter moves on.

**Worked example.** A filter that detects a vertical edge (bright on the left, dark on the right):

$$\text{filter} = \begin{bmatrix} 1 & 0 & -1 \\ 1 & 0 & -1 \\ 1 & 0 & -1 \end{bmatrix}$$

| Patch of the image | Calculation | Result |
|---|---|---|
| $\begin{bmatrix} 9 & 9 & 0 \\ 9 & 9 & 0 \\ 9 & 9 & 0 \end{bmatrix}$ bright left, dark right | $3 \times (9 \cdot 1 + 9 \cdot 0 + 0 \cdot (-1))$ | **27**: edge found |
| $\begin{bmatrix} 9 & 9 & 9 \\ 9 & 9 & 9 \\ 9 & 9 & 9 \end{bmatrix}$ flat | $3 \times (9 - 9)$ | **0**: nothing here |

Nobody writes these filters. **Training finds them.** The network starts with random filters and adjusts them until the ones that help tell diseases apart remain.

### Sizes
$$\text{output size} = \frac{W - F + 2P}{S} + 1$$

$W$ = input width, $F$ = filter width, $P$ = padding, $S$ = stride. A 224-pixel image with a 3 × 3 filter, no padding and stride 1 gives $(224 - 3 + 0)/1 + 1 = 222$.

$$\text{weights in a layer} = (F \times F \times C_{\text{in}} + 1) \times C_{\text{out}}$$

32 filters of 3 × 3 on a colour image: $(3 \times 3 \times 3 + 1) \times 32 = 896$ weights. Compare that with 150 million.

## 4. The layers of a CNN
```text
photo ─▶ [Conv → ReLU → Pool] ─▶ [Conv → ReLU → Pool] ─▶ [Conv → ReLU → Pool] ─▶ pool everything ─▶ Dense ─▶ softmax
          edges, colours          textures, spots          leaf-level patterns                          one score per class
```
| Layer | Does |
|---|---|
| **Convolution** | Finds patterns; each filter gives one feature map |
| **ReLU** | Replaces negative values with 0, which lets the network learn non-linear patterns |
| **Max pooling** (2 × 2) | Keeps the largest of each 2 × 2 block: half the width and height, small shifts ignored |
| **Global average pooling** | Averages each feature map to one number |
| **Dense + softmax** | Combines the features into one probability per class |

Early layers learn simple things (edges, blobs of colour). Later layers combine them into complex ones (a ring-shaped spot with a yellow halo). That hierarchy is why a network trained on one set of images can be reused for another: [[05.04 Transfer Learning with MobileNetV2]].

## 5. The output and the loss
**Softmax** turns the final scores $z_1 \dots z_K$ into probabilities:

$$p_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$$

For three classes with scores 2.0, 1.0 and 0.1 the result is about 0.66, 0.24 and 0.10. The largest is the prediction.

Training minimises **cross-entropy**: $L = -\log(p_{\text{correct class}})$. If the model gives the right class 0.9, the loss is 0.105. If it gives it 0.1, the loss is 2.3. Being confidently wrong is punished hardest.

## 6. Example: the baseline CNN (task ML-04)
```python
import tensorflow as tf
from tensorflow.keras import layers

num_classes = 38

model = tf.keras.Sequential([
    tf.keras.Input(shape=(224, 224, 3)),
    layers.Rescaling(1 / 255),                       # pixels 0-255 → 0-1

    layers.Conv2D(32, 3, activation="relu"),
    layers.MaxPooling2D(),
    layers.Conv2D(64, 3, activation="relu"),
    layers.MaxPooling2D(),
    layers.Conv2D(128, 3, activation="relu"),
    layers.MaxPooling2D(),

    layers.GlobalAveragePooling2D(),
    layers.Dropout(0.3),                             # randomly switches off 30 % of values while training
    layers.Dense(num_classes, activation="softmax"),
])

model.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
model.summary()
```
**Why build a baseline at all?** For the same reason a forecast needs one: to have something to compare with. "MobileNetV2 reached 96 %" means more beside "a small CNN from scratch reached 85 %". It also proves you can explain a CNN layer by layer, which you cannot do as easily for a 150-layer pretrained model.

## 7. Overfitting
| Sign | Meaning |
|---|---|
| Training accuracy keeps rising while validation accuracy stops or falls | The model is memorising the training photos |

| Remedy | How |
|---|---|
| More varied data | Augmentation: [[05.05 Image Datasets - Splits, Augmentation and Domain Shift]] |
| Dropout | Switches off random values during training, so no single feature is relied on |
| Early stopping | Stop when validation loss stops improving |
| A smaller model, or a pretrained one | Fewer weights to fit to noise |

## 8. Common mistakes
- **Judging by training accuracy.** Only validation and test accuracy say anything about new photos.
- **No scaling of pixel values,** or scaling twice.
- **The wrong loss for the labels:** `sparse_categorical_crossentropy` for integer labels (0, 1, 2 …); `categorical_crossentropy` for one-hot labels.
- **A softmax layer with the wrong number of outputs.**
- **Thinking a deeper network is always better.** With little data it overfits.
- **Calling softmax output "the probability the plant is sick".** It is the model's confidence among the classes it knows: [[05.07 Confidence Thresholds and Honest AI Results]].
- **Training on a laptop CPU for hours.** Use a GPU on Google Colab.
- **Comparing the baseline and the final model on different test images.**
