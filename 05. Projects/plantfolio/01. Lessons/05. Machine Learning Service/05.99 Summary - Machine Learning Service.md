# 05.99 · Lesson Summary: Machine Learning Service

> [!abstract] Back to [[05.00 Machine Learning Service]] · Progress: [[PlantFolio Week 11 - ML Service Skeleton]] · [[PlantFolio Week 12 - Training the Models]] · [[PlantFolio Week 13 - Prediction Endpoints]] · [[PlantFolio Week 14 - AI in the App and Gate 3]]

## Must know
- **Architecture:** browser → PHP → (cURL, multipart, 10 s timeout) → Flask on `127.0.0.1:5000` → JSON back. **The browser never calls Flask.**
- **The site must never break because of ML.** One function returns the result or `null`; `null` means the manual form.
- **PHP validates the reply** and logs every call in `ml_predictions` with the `model_version`.
- **Flask:** load the model **once** at start-up; `/health`, `/predict/species`, `/predict/disease`; errors as JSON with 400, 415, 503.
- **Serving must preprocess exactly like training.** The pixel scaling is a layer inside the model. The class-name list is saved with the model.
- **CNN:** small filters slide over the image; each gives a feature map; pooling shrinks; softmax gives one score per class. Few weights, and position does not matter.
- **Output size** $= (W - F + 2P)/S + 1$. **Weights** $= (F \cdot F \cdot C_{\text{in}} + 1) \cdot C_{\text{out}}$.
- **Transfer learning:** start from MobileNetV2 trained on ImageNet. **Phase 1** freeze the base, train a new head. **Phase 2** unfreeze the last layers and fine-tune with a learning rate about 100 times smaller. Compile again after changing `trainable`.
- **A baseline CNN from scratch** gives the final number something to be compared with.
- **PlantVillage:** about 54,000 photos, 38 classes, 14 **food crops**, single leaves on plain backgrounds.
- **Split 70/15/15:** train to learn, validate to choose, **test once**. Split before augmenting; stratify; fix the seed.
- **Augmentation** only on training images, and only changes that keep the answer true.
- **Domain shift:** test-set accuracy says little about phone photos. Measure on 20–30 real ones and report both.
- **Evaluation:** accuracy, **top-3** for the identifier, the confusion matrix, per-class precision and recall. **Sick called healthy** is the costly error.
- **A softmax score is not the probability of being right.** A model always answers, even for a photo of a cat.
- **Fixed words, decided in PHP from the rounded percentage:** High ≥ 80 · Medium 60–79 · Not sure < 60. Below 60 it is never shown as an answer.
- **AI suggests, the user decides.** Nothing is saved until Save.
- **Gate 3:** ≥ 90 % test accuracy, top-3 measured, offline fallback verified.

## Key formulas
$$p_k = \frac{e^{z_k}}{\sum_j e^{z_j}} \qquad \text{Accuracy} = \frac{\text{correct}}{\text{all}} \qquad \text{Precision}_X = \frac{\text{correct } X}{\text{predicted } X} \qquad \text{Recall}_X = \frac{\text{correct } X}{\text{actual } X}$$

## Important comparisons
| Training | Inference |
|---|---|
| Weights change | Weights fixed; predictions only |

| Feature extraction | Fine-tuning |
|---|---|
| Base frozen; head trains | Top of the base trains too, gently |

| Fully connected layer | Convolutional layer |
|---|---|
| A weight for every pixel | A small filter reused everywhere |

| Validation set | Test set |
|---|---|
| For choosing | For the final number, once |

| Top-1 accuracy | Top-3 accuracy |
|---|---|
| First choice correct | Correct class among three |

| Overfitting | Domain shift |
|---|---|
| Memorised the training photos | Real photos differ from all the training photos |

| Confidence score | Probability of being correct |
|---|---|
| Preference among known classes | Only equal if the model is calibrated |
