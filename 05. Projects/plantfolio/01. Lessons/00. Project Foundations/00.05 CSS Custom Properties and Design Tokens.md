# 00.05 · CSS Custom Properties and Design Tokens

> [!info] [[00.00 Project Foundations|Lesson 0]] · Week 1 · Task CORE-04 · Priority 🔴 Core
> **Builds on:** [[00.07 CSS Fundamentals]] · [[00.08 CSS Selectors, Pseudo-classes and the Cascade]]
> **Used for:** `public/assets/css/variables.css`, the single file that holds every colour, font, size and spacing value.

## 1. Definitions
> [!note] CSS custom property
> A **custom property** (often called a CSS variable) is a value you name yourself, written with two dashes: `--color-leaf: #4A7043;`. Other rules read it with `var(--color-leaf)`.

> [!note] Design token
> A **design token** is one named design decision: a colour, a font size, a spacing step. Tokens are the design system written down in a form that code can use.

In PlantFolio every design token is stored as a custom property.

## 2. Why it is used
- **One place to change.** If the primary green changes, one line changes and every button, link and bar follows.
- **Consistency.** A component can only pick from the agreed values, so spacing and colours cannot drift from page to page.
- **Readable CSS.** `var(--status-sick-text)` says what it is. `#9A3524` does not.
- **It matches the wireframes.** The tokens are wireframe p6, copied into code.
- **No build tool needed.** Custom properties are plain CSS, which fits the project's rule of no frameworks.

## 3. How it works
```css
:root {
  --color-leaf: #4A7043;       /* declare */
}

.btn-primary {
  background: var(--color-leaf);   /* use */
}
```

- **`:root`** is the top element of the page. A property declared there is **inherited** by every element, so it is available everywhere.
- **`var(--name)`** is replaced by the value when the browser works out the style.
- **`var(--name, fallback)`** uses the fallback if the property is not defined.
- A custom property can be **redefined lower down**. Elements inside then see the new value.

```css
.card-dark {
  --color-ink: #FFFFFF;      /* only inside .card-dark */
}
```

## 4. The project's tokens
| Group | Examples | Rule |
|---|---|---|
| Brand palette | `--color-forest`, `--color-leaf`, `--color-sage`, `--color-cream`, `--color-terracotta`, `--color-ink`, `--color-muted`, `--color-line` | From wireframe p6 |
| Health status | `--status-thriving-text`, `--status-thriving-bg`, … `--status-sick-bg` | Named after the **database values** |
| Danger | `--color-danger: var(--status-sick-text)` | A token can point to another token |
| Fonts | `--font-display` (Lora), `--font-body` (Poppins) | Fallback fonts are listed after the first |
| Type scale | `--text-h1: 2rem` … `--text-label: 0.75rem` | In `rem` |
| Spacing | `--space-4` … `--space-48` | 8-point scale, named by pixel value |
| Corners | `--radius-input`, `--radius-card`, `--radius-pill` | |
| Layout | `--content-width: 1040px`, `--gutter: 24px` | |

## 5. Example: one status, three places that agree
```css
:root {
  --status-needs-attention-text: #8A5A0B;
  --status-needs-attention-bg: #FBEFD5;
}

.badge-needs-attention {
  color: var(--status-needs-attention-text);
  background: var(--status-needs-attention-bg);
}
```
```php
<span class="badge badge-<?= e(str_replace('_', '-', $status)) ?>"><?= e(health_label($status)) ?></span>
```
The database stores `needs_attention`. The class is `badge-needs-attention`. The tokens are `--status-needs-attention-*`. One name runs through the database, the PHP and the CSS, so nothing has to be translated or remembered.

## 6. Units: `rem` and `px`
| Unit | Relative to | Used for |
|---|---|---|
| `px` | Nothing; a fixed size | Spacing, corner radii, borders |
| `rem` | The root font size, 16 px by default | **Text sizes** |
| `em` | The font size of the element itself | Icon sizes, so an icon scales with its text |
| `%`, `fr` | The container | Widths and grid tracks |

Text is in `rem` so that a visitor who sets a larger default font in their browser gets larger text. That is an accessibility requirement, not a style choice.

## 7. Two limits to know
> [!warning] `var()` does not work in a media query condition
> `@media (min-width: var(--bp-tablet))` is invalid. The breakpoints are therefore typed as numbers: `@media (min-width: 768px)` and `@media (min-width: 1024px)`. The file records them in a comment so they are still written down in one place.

> [!warning] A misspelt name fails silently
> `var(--colour-leaf)` is not an error. The property is simply treated as unset and the element falls back to an inherited or default value. If something is unexpectedly black or unstyled, check the spelling.

## 8. Contrast is part of a colour token
The file notes `5.7:1 with white` beside Leaf. That is the **contrast ratio** between the text and its background. WCAG level AA asks for at least **4.5 : 1** for normal text. One token in the file exists for this reason only: Muted on the neutral background reached 4.3 : 1, so a darker `--color-neutral-text` was added.

## 9. Common mistakes
- **A hex code written in a component.** The project's rule is: never. Add a token, or use an existing one.
- **Inventing a value** that is "almost" a token (`15px` beside `--space-16`).
- **Misspelling a property name.**
- **Using `var()` inside `@media`.**
- **Forgetting to load `variables.css`** on a page. Every `var()` then resolves to nothing.
- **Naming a token after its look** (`--green-dark`) instead of its role (`--color-forest`, `--color-danger`). Role names survive a redesign.
- **Text sizes in `px`.**
- **A token for everything.** A value used once does not need a name.

## 10. Exam and viva focus
- **What is a CSS custom property?** Syntax for declaring and using one.
- **Why declare on `:root`?** Inherited by every element.
- **Advantages:** maintainability, consistency, readability, theming.
- **Custom properties vs preprocessor variables (Sass):** custom properties exist in the browser, inherit and can change at run time; Sass variables are replaced when the CSS is built.
- **Absolute vs relative units:** `px` vs `rem`, `em`, `%`.
- **What is a design system?** Shared colours, type, spacing and components with rules for their use.
- **Viva:** "Why are there no hex codes in `components.css`?" · "Why are the health-status tokens named after database values?" · "Why are the breakpoints not tokens?"
