## What this lesson is about
Before the first real page, a set of shared pieces has to exist, and you need to understand how a PHP site works at all. This lesson covers:
1. **How a page reaches the browser:** Apache, PHP, the web root, and why some folders are locked.
2. **Enough PHP to write a template:** variables, arrays, loops, includes.
3. **The one rule for printing data:** escape everything with `e()`.
4. **The design system in code:** tokens in `variables.css`, components in `components.css`, the style guide.
5. **Mock data** that has the shape of the future database rows.
6. **How the team works in Git:** branches, commit messages, pull requests.
