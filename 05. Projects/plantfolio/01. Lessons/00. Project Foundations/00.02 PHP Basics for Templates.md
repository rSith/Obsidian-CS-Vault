# 00.02 · PHP Basics for Templates

> [!info] [[00.00 Project Foundations|Lesson 0]] · Week 1 · Priority 🔴 Core
> **Builds on:** [[02.02 Web Languages - HTML CSS JavaScript PHP]] · [[00.01 How a PHP Page Is Served]]
> **Used for:** every page. Stage F needs only this much PHP: hold data in arrays, loop over it, print it into HTML.

## 1. Definitions
| Term | Meaning |
|---|---|
| **Template** | An HTML file with small pieces of PHP that fill in the data |
| **Variable** | A named value. In PHP every variable starts with `$`. |
| **Array** | One variable that holds many values |
| **Associative array** | An array whose values are reached by **name** (a key), not by position |
| **Loop** | Code that repeats once for each item |

## 2. Why it is used
A page such as My Garden shows the same card for every plant. Writing the card six times by hand would have to be redone whenever a plant changes. With PHP you write the card **once** and loop over the data. The same template later works with data from the database.

## 3. How it works: the tags
PHP code lives between tags. Everything outside them is sent to the browser unchanged.

| Tag | Does | Use for |
|---|---|---|
| `<?php … ?>` | Runs the code inside | Logic: loops, conditions, loading data |
| `<?= … ?>` | Runs the code and **prints** the result | Showing one value |

`<?= $x ?>` is short for `<?php echo $x; ?>`.

## 4. Syntax
```php
<?php
// Variables and types
$nickname = 'Monty';          // string
$interval_days = 7;           // integer
$rating_avg = 4.9;            // float
$is_public = true;            // boolean
$phone = null;                // "no value"

// Strings: join with a dot
$title = $nickname . ' · PlantFolio';
$text = "Water every $interval_days days";   // double quotes fill in variables

// Associative array: one row
$plant = [
    'id'            => 42,
    'nickname'      => 'Monty',
    'health_status' => 'thriving',
];
$name = $plant['nickname'];                   // read a value by its key

// A list of rows
$plants = [$plant, ['id' => 43, 'nickname' => 'Goldie', 'health_status' => 'needs_attention']];
$total = count($plants);                      // 2

// A value that may be missing: ?? gives a fallback
$collection = $plant['collection_name'] ?? 'No collection';

// A function
function plural($count, $word)
{
    return $count . ' ' . $word . ($count === 1 ? '' : 's');
}
```

| Operator | Meaning |
|---|---|
| `=` | Assign a value |
| `==` | Equal after converting types (`'5' == 5` is true) |
| `===` | Equal **and** the same type (`'5' === 5` is false). Prefer this one. |
| `!==` | Not identical |
| `&&` `\|\|` `!` | and, or, not |
| `??` | Use the right side if the left is missing or `null` |
| `.` | Join strings |

## 5. Templates use the "alternative syntax"
Inside HTML, PHP offers a form of `if` and `foreach` that ends with a word instead of a brace. It is far easier to read among tags.

```php
<?php if ($total === 0): ?>
  <p>Your garden is empty.</p>
<?php else: ?>
  <p>You have <?= e(plural($total, 'plant')) ?>.</p>
<?php endif; ?>

<ul>
<?php foreach ($plants as $plant): ?>
  <li><?= e($plant['nickname']) ?> is <?= e($plant['health_status']) ?></li>
<?php endforeach; ?>
</ul>
```
Output sent to the browser:
```html
<p>You have 2 plants.</p>
<ul>
  <li>Monty is thriving</li>
  <li>Goldie is needs_attention</li>
</ul>
```
The second line shows why the project has `health_label()`: the database value `needs_attention` must be turned into the words "Needs attention" before it is shown.

## 6. Example: the rule "logic on top, HTML below"
The project's convention is to finish all the PHP work first, then write the HTML.

```php
<?php
require_once __DIR__ . '/../includes/helpers.php';
require_once __DIR__ . '/../includes/mock-data.php';

// 1. Work: prepare everything the page needs
$sick_plants = [];
foreach ($mock_plants as $plant) {
    if ($plant['health_status'] === 'sick') {
        $sick_plants[] = $plant;              // [] adds to the end of an array
    }
}
$page_title = 'Needs attention';
?>
<!-- 2. Display: only printing below this line -->
<h1><?= e($page_title) ?></h1>
<?php foreach ($sick_plants as $plant): ?>
  <p><?= e($plant['nickname']) ?></p>
<?php endforeach; ?>
```
Keeping the two apart is a small version of **separation of concerns**: the top decides *what* to show, the bottom decides *how* it looks.

## 7. Common mistakes
- **Forgetting the `$`.** `nickname` alone is not a variable.
- **`=` where `===` was meant.** `if ($x = 5)` assigns 5 and is always true.
- **`==` surprises.** `0 == 'a'` was true in older PHP, and `'1' == '01'` is true today. Use `===`.
- **A missing semicolon.** The error message points at the *next* line.
- **`+` to join strings.** PHP uses `.`; `+` is only for numbers.
- **Reading a key that does not exist.** PHP warns "Undefined array key". Use `??` when a key is optional.
- **Printing an array.** `<?= $plant ?>` prints the word `Array`. Print one of its values.
- **Variables inside single quotes.** `'Hello $name'` prints the dollar sign and the word. Only double quotes fill variables in.
- **Printing without `e()`.** Every printed value goes through `e()`: [[00.04 Output Escaping in PHP]].
- **Changing a value inside `foreach` and expecting the array to change.** The loop works on a copy of each item.
