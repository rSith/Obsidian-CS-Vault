# 00.99 · Lesson Summary: Project Foundations

> [!abstract] Back to [[00.00 Project Foundations]] · Progress: [[PlantFolio Week 01 - Foundation]]

## Must know
- **Request cycle:** browser → Apache → PHP runs the file top to bottom → HTML back to the browser. "View source" never shows PHP.
- **`public/` is the web root.** `includes/`, `partials/` and `config/` are locked with `Require all denied`; PHP can still read them from disk.
- **Every request starts from nothing.** Data lives in the database; login state lives in the session.
- **`<?php … ?>` runs code; `<?= … ?>` prints a value.** Templates use `foreach: … endforeach;` and `if: … endif;`.
- **A row is an associative array:** `$plant['nickname']`. `??` gives a fallback for a missing key. Prefer `===`.
- **Logic at the top of the file, HTML below.**
- **`require_once`** for files that define functions; **`include`** for files that print HTML. Always build paths from `__DIR__`.
- **`partial('plant-card', ['plant' => $plant])`** runs the partial inside a function, so its variables cannot leak.
- **`e()` on everything printed.** It converts `& < > " '`. Escape on output, store the original. The only exception is the project's own SVG from `icon()`.
- **Design tokens** are custom properties on `:root` in `variables.css`. Components use `var(--name)` and never a raw hex code. `var()` cannot be used in `@media`.
- **Components** = a base class plus modifiers (`.btn .btn-primary .btn-sm`), with states from `:focus-visible`, `[aria-invalid]`, `.is-active`. Native controls are restyled, not replaced.
- **The style guide** shows every component; a new component goes there first.
- **Mock data has the shape of future database rows:** real column names, raw values, joined columns marked, awkward cases included. Stage B swaps the data source only.
- **Git:** `main` ← `develop` ← `feature/*`. Commits are `type(scope): what changed (TASK-ID)`. Each module gets a UI pull request and a wired pull request.

## Key code
```php
<?php
require_once __DIR__ . '/../includes/helpers.php';
require_once __DIR__ . '/../includes/mock-data.php';
$page_title = 'My Garden';
?>
<?php foreach ($mock_plants as $plant): ?>
  <?php partial('plant-card', ['plant' => $plant]); ?>
<?php endforeach; ?>
```
```php
function e($value)
{
    return htmlspecialchars((string) $value, ENT_QUOTES, 'UTF-8');
}
```
```css
:root { --color-leaf: #4A7043; --space-16: 16px; }
.btn-primary { background: var(--color-leaf); padding: var(--space-16); }
```

## Important comparisons
| `include` | `require` |
|---|---|
| Warning, page continues | Fatal error, page stops |

| `==` | `===` |
|---|---|
| Equal after type conversion | Equal and same type |

| Client-side | Server-side |
|---|---|
| HTML, CSS, JavaScript in the browser | PHP on the server |

| `display: none` | `.visually-hidden` |
|---|---|
| Hidden from everyone | Hidden from sight, read by screen readers |

| Stored value | Calculated value |
|---|---|
| A column in a table | `COUNT()` or `AVG()` in the query |

| Branch | Tag |
|---|---|
| Moves with new commits | Fixed on one commit |
