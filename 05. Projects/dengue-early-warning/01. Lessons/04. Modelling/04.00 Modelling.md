## What this lesson is about
The goal is **a model that clearly beats simple baselines at predicting cases 4 weeks ahead, chosen by a fair comparison.** The lesson is less about any single algorithm and more about comparing them honestly:

1. **Split by time**, so the model is always tested on weeks after the ones it learned from.
2. **Build baselines first.** A model is good only compared with something simple.
3. **Try model families in order of complexity:** linear, count-based, tree ensembles, and optionally a neural network.
4. **Record every experiment**, then **explain** the winner.

## Suggested order of work
1. Fix the split and write the fold function (note 1).
2. Score both baselines (note 2). Every later result is compared with these numbers.
3. Linear regression, then Ridge, inside a pipeline (notes 3 and 4).
4. Poisson regression (note 5).
5. [[Random Forest]], then Gradient Boosting (note 6).
6. Log every run as you go (note 8).
7. Explain the best model (note 7) and check that its top features make sense.

## Optional: LSTM in Keras
An [[04. Concepts/AI & Deep Learning/LSTM|LSTM]] reads a **sequence** of past weeks instead of a row of lag columns. The input must be a three-dimensional array of shape `(samples, timesteps, features)`: for example `(n, 12, 5)` for the last 12 weeks of 5 variables. Scale the inputs, split by time as before, and compare it on the same validation weeks as the other models. With only a few thousand rows it often loses to gradient boosting, and saying so honestly is a good result for a report.
