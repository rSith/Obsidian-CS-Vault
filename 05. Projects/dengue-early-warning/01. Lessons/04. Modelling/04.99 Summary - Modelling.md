# 04.99 · Lesson Summary: Modelling

> [!abstract] Back to [[04.00 Modelling]] · Progress: [[Phase 04 - Modelling]]

## Must know
- **Split by time.** Train on earlier weeks, validate on later weeks, open the test set **once**.
- **Walk-forward cross-validation:** several validation blocks, each trained on everything before it, with a **gap of $h$ weeks**.
- **Baselines first:** persistence (newest known count) and seasonal (usual level for that week). A model must beat **both**.
- **Skill** $= 1 - \text{MAE}_{\text{model}} / \text{MAE}_{\text{baseline}}$.
- **Regularisation** adds a penalty on large weights. **Ridge (L2)** shrinks all weights; **Lasso (L1)** sets some to zero. **Scale first.**
- **Pipeline** = preprocessing + model in one object. It keeps the scaler inside each fold and is saved as one file.
- **Poisson regression** predicts counts through $\log(\mu) = w \cdot x + b$: never negative, effects multiply. Real outbreak data is **overdispersed**.
- **Gradient boosting** adds shallow trees one by one, each fitting the errors so far. [[Random Forest]] averages independent deep trees.
- **Trees cannot predict beyond the largest value they were trained on.**
- **SHAP:** prediction = base value + one contribution per feature. Global and local explanations.
- **Track every run:** commit, data, features, settings, validation score. Change one thing at a time.
- **The key comparison:** the same model **with and without weather features**.

## Key code
```python
folds = list(time_folds(df, n_splits=3, val_weeks=52, gap_weeks=4))

model = Pipeline([("preprocess", preprocess),
                  ("model", HistGradientBoostingRegressor(loss="poisson", learning_rate=0.05,
                                                          max_iter=400, early_stopping=False))])
search = GridSearchCV(model, {"model__max_depth": [3, 5]}, cv=folds,
                      scoring="neg_mean_absolute_error").fit(X, y)
joblib.dump(search.best_estimator_, "models/model_v1.joblib")
```

## Key formulas
$$J_{\text{ridge}} = \frac{1}{2m}\sum (\hat{y}_i - y_i)^2 + \frac{\lambda}{2m}\sum w_j^2 \qquad \log(\mu) = w \cdot x + b \qquad F_m = F_{m-1} + \nu\, h_m \qquad f(x) = \phi_0 + \sum \phi_j$$

## Important comparisons
| Ridge (L2) | Lasso (L1) |
|---|---|
| Squared weights | Absolute weights |
| Shrinks, never zero | Some exactly zero |
| Good with correlated features | Selects features |

| Random Forest (bagging) | Gradient boosting |
|---|---|
| Independent deep trees, averaged | Sequential shallow trees, added |
| Reduces variance | Reduces bias |
| Hard to overfit | Needs tuning |

| Linear regression | Poisson regression |
|---|---|
| Any real number | Positive only |
| Effects add | Effects multiply |

| k-fold CV | Time-series CV |
|---|---|
| Any order | Always tests on later data |

| Parameter | Hyperparameter |
|---|---|
| Learned from data (weights) | Set before training (`alpha`, depth) |
