# 04.02 · Forecasting Baselines: Persistence and Seasonal

> [!info] [[04.00 Modelling|Lesson 4]] · Roadmap Phase 4 · Priority 🔴 Core
> **Parent concept:** [[Model Evaluation]]
> **Used for:** the two numbers every model in the project must beat.

## 1. Definition
> [!note] Baseline
> A **baseline** is a very simple method of prediction that needs no learning. It gives the score you would get with almost no effort, so it shows how much a real model adds.

## 2. Why it is used
"MAE = 40 cases" means nothing alone. If a rule that copies the latest count scores 42, the model has achieved almost nothing. If that rule scores 90, the model is excellent. Without a baseline you cannot tell these apart, and neither can a reader.

## 3. How they work
| Baseline | Rule | Formula | It is good when |
|---|---|---|---|
| **Persistence** | The future equals the newest value you know | $\hat{y}_{t+h} = y_{\text{latest}}$ | Cases change slowly |
| **Seasonal** | The future equals the usual level for that time of year | $\hat{y}_{t+h} = \bar{y}_{\text{week-of-year}(t+h)}$ | Every year looks alike |

They fail in opposite ways:
- **Persistence** is always late. It sees a rise only after it has happened.
- **Seasonal** knows the calendar but cannot tell a normal year from an epidemic year.

A model worth keeping must beat **both**.

## 4. Syntax
```python
# Persistence: the newest published count, already built as a feature
df["pred_persistence"] = df["cases_last"]

# Seasonal: average for the target's week of year, from TRAINING years only
df["target_woy"] = df["target_week"].dt.isocalendar().week.astype(int)
train = df[df["week_start"] < "2022-01-01"]

seasonal = (train.groupby(["district", "target_woy"])["target"]
                 .mean().rename("pred_seasonal").reset_index())
df = df.merge(seasonal, on=["district", "target_woy"], how="left")
```

## 5. Example: scoring them
```python
from sklearn.metrics import mean_absolute_error

val = df[(df["week_start"] >= "2022-01-01") & (df["week_start"] < "2024-01-01")].dropna(
    subset=["target", "pred_persistence", "pred_seasonal"])

for name in ["pred_persistence", "pred_seasonal"]:
    print(name, round(mean_absolute_error(val["target"], val[name]), 1))
```

Then report every model against them:

| Model | Validation MAE | Better than persistence | Better than seasonal |
|---|---|---|---|
| Persistence | 52.0 | | |
| Seasonal mean | 61.0 | | |
| Ridge | 44.0 | 15 % | 28 % |
| Gradient boosting | 39.0 | 25 % | 36 % |

The numbers are invented to show the layout.

## 6. Skill score
The improvement over a baseline has a name and a formula:

$$\text{skill} = 1 - \frac{\text{MAE}_{\text{model}}}{\text{MAE}_{\text{baseline}}}$$

| Skill | Meaning |
|---|---|
| $1$ | Perfect |
| $0.25$ | 25 % less error than the baseline |
| $0$ | No better than the baseline |
| below $0$ | Worse than the baseline |

With the table above: $1 - 39/52 = 0.25$.

## 7. Common mistakes
- **No baseline.** The most common weakness in student forecasting projects, and in some published papers.
- **A baseline that cheats.** Persistence must use the newest count that was *published*, not last week's count if that arrives seven weeks late: [[01.06 Reporting Delay and Data Availability]].
- **A seasonal average that includes validation or test years.** That uses the future.
- **A seasonal average that includes the 2017 epidemic** without thought. Try it with and without flagged years.
- **Comparing with only the weaker baseline.** Report both.
- **Scoring the baseline on different weeks than the model.** Use exactly the same rows.
- **Hiding a small margin.** "The model beats persistence by 4 %" is an honest and useful result.

## 8. Exam and viva focus
- **Define** baseline model and say why one is needed.
- **Persistence (naive) forecast:** next value = last known value.
- **Seasonal naive forecast:** next value = value or average from the same season in earlier years.
- **Skill score** formula and meaning of $0$ and negative values.
- **Why might a complex model fail to beat persistence?** Strong autocorrelation makes the latest value a very good guess at short horizons.
- **Which baseline gets harder to beat as the horizon grows?** Seasonal, because persistence becomes stale.
