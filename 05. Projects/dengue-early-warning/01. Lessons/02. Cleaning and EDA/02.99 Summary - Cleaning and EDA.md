## Must know
- **Goal:** one table, one row per `(district, week_start)`, plus evidence of the lag between weather and cases.
- **merge** joins tables on keys; `how="left"` keeps every left row; `validate=` catches repeated keys; count rows before and after.
- **groupby** = split, apply, combine. `agg` gives one row per group; `transform` gives one row per original row.
- **shift(k)** gives each row the value from `k` rows earlier. **Sort by date and group by district first.**
- **Completeness:** build the full district × week grid. A missing week is usually a missing row, not a `NaN`.
- **Flag unusual periods** (2017, 2020–21). Do not delete them.
- **Missing values:** never fill the target; fill features only from the past; record what you filled.
- **Time series = trend + seasonality + remainder** (additive) or their product (multiplicative). Counts are usually multiplicative, so use `log1p`.
- **Autocorrelation** = a series compared with its own past. Dengue is strongly autocorrelated because cases cause more cases.
- **Cross-correlation** = weather $k$ weeks ago compared with cases now. The peak gives the lag, per district.
- **Feature lag = analysis lag − horizon.**
- **Two seasonal series correlate anyway.** Check the anomalies too.

## Important comparisons
| `agg` | `transform` |
|---|---|
| One row per group | One row per original row |
| Summaries | New columns |

| Forward fill | Interpolation |
|---|---|
| Uses only the past | Uses the next value too |
| Safe for model features | Analysis only |

| Autocorrelation | Cross-correlation |
|---|---|
| One series with itself | Two different series |
| Why recent cases predict cases | Why lagged weather predicts cases |

| Seasonality | Cycle |
|---|---|
| Fixed period (one year) | No fixed length |
