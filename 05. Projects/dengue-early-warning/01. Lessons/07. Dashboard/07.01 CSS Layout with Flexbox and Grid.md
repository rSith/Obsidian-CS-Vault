# 07.01 · CSS Layout with Flexbox and Grid

> [!info] [[07.00 Dashboard|Lesson 7]] · Roadmap Phase 7 · Priority 🟡 Supporting
> **Builds on:** [[00.07 CSS Fundamentals]] · [[06.04 Making Pages Responsive]] · [[06.05 Media Queries and Breakpoints]]. Those cover CSS basics and responsive design; this note covers only the two layout systems.
> **Used for:** the page skeleton: header on top, map on the left, detail panel on the right, one column on a phone.

## 1. Definitions
> [!note] Flexbox
> **Flexbox** (Flexible Box Layout) arranges items along **one line**: a row or a column. It decides how they share space and how they line up.

> [!note] CSS Grid
> **CSS Grid** arranges items in **rows and columns at the same time**.

## 2. Why they are used
Older layouts used floats and tables, which were never designed for page structure. Flexbox and Grid were made for it. A layout that once took dozens of lines and several tricks now takes three or four lines, and adapts to the screen size.

| Use | For |
|---|---|
| **Grid** | The overall page: areas in two dimensions |
| **Flexbox** | Items inside one area: a header bar, a row of buttons, a legend |

They are used together, not instead of each other.

## 3. How Flexbox works
Set `display: flex` on a **container**. Its direct children become **flex items**.

```text
main axis ─────────────────────────────▶   (flex-direction: row)
┌────────┐ ┌────────┐ ┌────────┐      │
│ item 1 │ │ item 2 │ │ item 3 │      │ cross axis
└────────┘ └────────┘ └────────┘      ▼
```

| Property (on the container) | Controls | Common values |
|---|---|---|
| `flex-direction` | Which way the main axis runs | `row`, `column` |
| `justify-content` | Position along the **main** axis | `flex-start`, `center`, `space-between` |
| `align-items` | Position along the **cross** axis | `stretch`, `center`, `flex-start` |
| `gap` | Space between items | `1rem` |
| `flex-wrap` | Whether items move to a new line when space runs out | `nowrap`, `wrap` |

| Property (on an item) | Meaning |
|---|---|
| `flex: 1` | Take an equal share of the leftover space |
| `flex: 0 0 200px` | Stay exactly 200px wide |

## 4. How Grid works
Set `display: grid` on a container and describe its columns.

| Property | Controls | Example |
|---|---|---|
| `grid-template-columns` | Number and width of columns | `2fr 1fr` |
| `grid-template-rows` | Height of rows | `auto 1fr auto` |
| `gap` | Space between cells | `1rem` |
| `grid-template-areas` | Named regions | `"header header" "map panel"` |

- **`fr`** means "a fraction of the free space". `2fr 1fr` gives the first column two thirds and the second one third.
- `repeat(3, 1fr)` is three equal columns.
- `repeat(auto-fit, minmax(220px, 1fr))` makes as many columns as fit, each at least 220px wide. It is responsive with no media query.

## 5. Example: the dashboard layout, mobile first
```html
<header class="top">
  <h1>Dengue Early-Warning</h1>
  <p>Data last updated: 10 Oct 2026</p>
</header>
<main class="layout">
  <section id="map" aria-label="Map of districts by alert level"></section>
  <aside id="panel">…chart and table…</aside>
</main>
```
```css
.top {
  display: flex;
  justify-content: space-between;   /* title on the left, date on the right */
  align-items: center;
  padding: 0.5rem 1rem;
}

/* Base styles = phone: one column */
.layout {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
  padding: 1rem;
}
#map { height: 60vh; }

/* Wider screens: map beside the panel */
@media (min-width: 768px) {
  .layout { grid-template-columns: 2fr 1fr; }
  #map { height: 80vh; }
}
```
The base styles are for the narrowest screen, and the media query adds the second column when there is room. That is **mobile first**: [[06.03 Mobile Web, One Web and Mobile First]].

## 6. Choosing between them
| Situation | Use |
|---|---|
| A row of items: logo, title, date | Flexbox |
| Centring one thing inside a box | Flexbox (`justify-content` and `align-items` both `center`) |
| The whole page: header, sidebar, content | Grid |
| A gallery of cards in rows and columns | Grid |
| You think "line the items up" | Flexbox |
| You think "put the items in these places" | Grid |

## 7. Common mistakes
- **`display: flex` on the item instead of its parent.** The property goes on the **container**.
- **Mixing up `justify-content` and `align-items`.** Justify is the main axis; align is the cross axis. With `flex-direction: column` they swap directions on screen.
- **Fixed pixel widths** (`width: 800px`) that overflow a phone screen. Use `fr`, `%` or `minmax`.
- **A map container with no height.** A `div` is zero pixels tall until told otherwise, so the map is invisible: [[07.04 Leaflet and GeoJSON]].
- **No viewport meta tag.** The phone then pretends to be 980px wide and the media query never fires: [[06.04 Making Pages Responsive]].
- **Margins on every item for spacing.** Use `gap`.
- **Nesting `div` inside `div`** when one grid would do.

## 8. Exam and viva focus
- **Flexbox vs Grid:** one dimension vs two dimensions.

- **What does `fr` mean?** A fraction of the available space.
