# 07.05 · Chart.js

> [!info] [[07.00 Dashboard|Lesson 7]] · Roadmap Phase 7 · Priority 🔴 Core
> **Builds on:** [[05.05 Charts That Communicate Results]] (what a good forecast chart contains) · [[07.02 JavaScript fetch and Promises]]
> **Used for:** the chart in the detail panel: actual cases, forecast, uncertainty band and threshold line.

## 1. Definition
> [!note] Chart.js
> **Chart.js** is a JavaScript library that draws charts on an HTML `<canvas>` element. You describe the chart as a JavaScript object and the library draws it.

## 2. Why it is used
- The dashboard needs the same figure as the report ([[05.05 Charts That Communicate Results]]), but **live**: redrawn in the browser whenever a district is clicked.
- Chart.js needs very little code for a line chart, resizes with the page, and shows values on hover.
- Plotly is a heavier alternative with more features. For one line chart Chart.js is enough.

## 3. How it works
Everything is in one **configuration object** with three parts:

```text
new Chart(canvas, {
  type:    what kind of chart            "line"
  data:    what to draw                  labels (x-axis) + datasets (one per line)
  options: how it looks and behaves      axes, titles, legend, tooltips
})
```

| Term | Meaning |
|---|---|
| **labels** | The x-axis values: the weeks |
| **dataset** | One series: its values, its label and its style |
| **scales** | The axes |
| **plugins** | Extras such as the legend and tooltip |

## 4. Syntax
```html
<div class="chart-box">
  <canvas id="chart" aria-label="Actual and forecast dengue cases" role="img"></canvas>
</div>
<script src="https://cdn.jsdelivr.net/npm/chart.js" defer></script>
```
```css
.chart-box { position: relative; height: 320px; }   /* the chart fills this box */
```
```js
const chart = new Chart(document.querySelector("#chart"), {
  type: "line",
  data: {
    labels: ["2026-10-10", "2026-10-17", "2026-10-24"],
    datasets: [{ label: "Forecast", data: [210, 240, 262], borderColor: "#1565c0" }],
  },
  options: { responsive: true, maintainAspectRatio: false },
});
```

## 5. Example: the forecast chart with a band and a threshold
```js
let chart;                                             // keep one chart and replace it

function drawChart(data) {
  const f = data.forecasts;
  if (chart) chart.destroy();                          // remove the previous district's chart

  chart = new Chart(document.querySelector("#chart"), {
    type: "line",
    data: {
      labels: f.map(d => d.week_start),
      datasets: [
        { label: "Upper bound", data: f.map(d => d.upper),
          borderWidth: 0, pointRadius: 0 },
        { label: "80 % interval", data: f.map(d => d.lower),
          borderWidth: 0, pointRadius: 0,
          fill: "-1", backgroundColor: "rgba(21, 101, 192, 0.15)" },   // fill up to the dataset before
        { label: "Forecast", data: f.map(d => d.predicted_cases),
          borderColor: "#1565c0", pointRadius: 2 },
        { label: "Actual cases", data: f.map(d => d.actual_cases),
          borderColor: "#212121", borderWidth: 2, pointRadius: 2 },
        { label: "Warning level", data: f.map(d => d.warning_level),
          borderColor: "#c62828", borderDash: [6, 4], pointRadius: 0 },
      ],
    },
    options: {
      responsive: true,
      maintainAspectRatio: false,
      scales: {
        x: { title: { display: true, text: "Week starting" } },
        y: { beginAtZero: true,
             title: { display: true, text: "Reported cases per week" } },
      },
      plugins: {
        legend: { position: "bottom",
                  labels: { filter: item => item.text !== "Upper bound" } },  // hide the helper line
      },
    },
  });
}
```
How the **band** is made: draw the upper bound as an invisible line, then draw the lower bound with `fill: "-1"`, which fills the space between it and the dataset listed just before it.

`actual_cases` is `null` for future weeks. Chart.js leaves a gap there, which is exactly right: the forecast continues where the actual line stops.

## 6. Updating without rebuilding
To change the numbers of a chart that already exists:
```js
chart.data.labels = newLabels;
chart.data.datasets[2].data = newForecast;
chart.update();
```

## 7. Canvas and SVG
| | **Canvas** (Chart.js) | **SVG** (D3, some other libraries) |
|---|---|---|
| Drawn as | Pixels | Shapes that are elements in the DOM |
| Many points | Fast | Slower |
| Each shape can be styled with CSS or read by a screen reader | No | Yes |

A canvas is one opaque picture to a screen reader. Give it an `aria-label`, and keep the **table** of values on the page as the text version.

## 8. Common mistakes
- **"Canvas is already in use".** A second chart was created on a canvas that still has one. Call `chart.destroy()` first, or update the existing chart.
- **A chart that grows without limit or is zero pixels high.** With `maintainAspectRatio: false` the canvas needs a parent with a set height.
- **`labels` and `data` of different lengths.** The lines no longer match the weeks.
- **Numbers sent as strings** from the API. Chart.js may plot them oddly. Send numbers.
- **No axis titles or units.**
- **A y-axis that does not start at zero** for counts, which exaggerates small changes.
- **Dates in a random order.** Sort by `week_start` in the SQL query.
- **Every line a different bright colour.** Keep actual black, forecast blue, threshold red and dashed, in the report and the dashboard alike.

## 9. Exam and viva focus
- **What is the `<canvas>` element?** A drawing surface controlled by JavaScript.
- **Canvas vs SVG:** pixels vs elements; one advantage of each.
- **Parts of a chart configuration:** type, data (labels and datasets), options.
- **Which chart type for which data?** Line for change over time; bar for comparing categories; pie only for a few parts of a whole.
- **Why use a library instead of drawing by hand?** Axes, scaling, resizing and tooltips are handled for you.
- **How is a chart made accessible?** A text alternative: an `aria-label` and a table of the data.
