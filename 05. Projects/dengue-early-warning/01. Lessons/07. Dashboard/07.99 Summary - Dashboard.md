# 07.99 · Lesson Summary: Dashboard

> [!abstract] Back to [[07.00 Dashboard]] · Progress: [[Phase 07 - Dashboard]]

## Must know
- **Goal:** understood by a non-technical reader in 30 seconds. Three questions in order: where is the risk, how bad and how sure, can I trust it.
- **Grid** lays out the page in two dimensions; **Flexbox** lines items up in one. `fr` = a fraction of the free space. Base styles for the phone, a media query for wider screens.
- **fetch** returns a **promise** (pending → fulfilled or rejected). Two steps: `fetch(url)`, then `response.json()`.
- **`fetch` does not fail on 404 or 500.** Check `response.ok`.
- **DOM** = the page as a tree of objects. Select with `querySelector`, change with `textContent` and `classList`, react with `addEventListener`.
- **Event delegation:** one listener on a parent handles all its children.
- **`textContent`, not `innerHTML`,** for any data. Otherwise cross-site scripting.
- **GeoJSON** = features with properties and geometry. Coordinates are **`[longitude, latitude]`**; Leaflet's functions take `[latitude, longitude]`.
- **Leaflet:** tile layer for the background, GeoJSON layer for the districts, `style` for colour, `onEachFeature` for tooltips and clicks. **The map `div` needs a height.**
- **Chart.js:** `type`, `data` (labels and datasets), `options`. Band = two datasets with `fill: "-1"`. Destroy the old chart before drawing a new one.
- **Jinja2:** `{{ value }}` prints, `{% … %}` controls, `{% extends %}` reuses a layout, `url_for` builds static URLs. Values are escaped automatically.
- **Never colour alone.** Text labels, a legend, a table as the text version of the map, contrast of at least 4.5 : 1.
- **Test with one non-technical person** using think-aloud tasks.

## Key code
```css
.layout { display: grid; grid-template-columns: 1fr; gap: 1rem; }
@media (min-width: 768px) { .layout { grid-template-columns: 2fr 1fr; } }
#map { height: 60vh; }
```
```js
async function getJson(url) {
  const response = await fetch(url);
  if (!response.ok) throw new Error(`Request failed (${response.status})`);
  return response.json();
}

L.geoJSON(geo, { style: f => ({ fillColor: COLOURS[byName[f.properties.name]?.alert_level] }) }).addTo(map);

```

## Important comparisons
| Flexbox | Grid |
|---|---|
| One dimension | Two dimensions |
| Items in a row or column | Page areas |

| `.then` / `.catch` | `async` / `await` |
|---|---|
| Chained callbacks | Reads top to bottom |

| `textContent` | `innerHTML` |
|---|---|
| Plain text; safe | Parsed as HTML; risky with data |

| Canvas (Chart.js) | SVG |
|---|---|
| Pixels; fast | Elements; styleable and readable |

| Server-side rendering | Client-side rendering |
|---|---|
| Jinja2 builds the HTML | JavaScript builds it in the browser |
| Page skeleton | Map, chart, table |

| GeoJSON | Leaflet |
|---|---|
| `[longitude, latitude]` | `[latitude, longitude]` |
