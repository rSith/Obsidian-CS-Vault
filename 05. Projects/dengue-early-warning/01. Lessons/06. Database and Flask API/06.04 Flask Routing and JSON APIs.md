# 06.04 · Flask Routing and JSON APIs

> [!info] [[06.00 Database and Flask API|Lesson 6]] · Roadmap Phase 6 · Priority 🔴 Core
> **Builds on:** [[02.04 HTTP Protocol]] · [[02.06 Client-Server and Three-Tier Architecture]]
> **Used for:** the four endpoints the dashboard calls.

## 1. Definitions
> [!note] Flask
> **Flask** is a small Python **web framework**: a library that receives HTTP requests and lets you decide, in Python, what to send back.

| Term | Meaning |
|---|---|
| **Route** | A URL pattern that the application answers, such as `/api/districts` |
| **View function** | The Python function that runs for a route and returns the response |
| **Endpoint** | One URL plus one method that a client can call |
| **Query parameter** | A value after `?` in the URL: `?district=Colombo` |

## 2. Why it is used
The dashboard runs in a browser and cannot open a database or run a model. It can only make HTTP requests. Flask is the piece in between: it receives the request, runs a query, and replies with JSON. Flask is called a **micro-framework** because it starts with almost nothing, which makes it easy to learn.

## 3. How it works
```text
Browser ──GET /api/predictions?district=Colombo──▶ Flask
                                                    │ 1. match the URL to a route
                                                    │ 2. run its view function
                                                    │ 3. the function queries the database
Browser ◀──── 200 OK + JSON ───────────────────────┘ 4. the return value becomes the response
```
The `@app.get(...)` line above a function is a **decorator**. It registers the function as the handler for that URL.

## 4. Syntax
```python
# app/__init__.py
import os
from flask import Flask, jsonify, request
from sqlalchemy import create_engine, text


def create_app() -> Flask:
    app = Flask(__name__)
    engine = create_engine(os.environ["DATABASE_URL"])

    @app.get("/api/health")
    def health():
        return {"status": "ok"}                      # a dict becomes JSON, status 200

    @app.get("/api/districts")
    def districts():
        with engine.connect() as conn:
            rows = conn.execute(
                text("SELECT id, name, population FROM districts ORDER BY name")
            ).mappings().all()
        return jsonify([dict(r) for r in rows])

    return app
```
```powershell
flask --app app run --debug        # http://127.0.0.1:5000/api/health
```
`create_app` is the **application factory** pattern: a function that builds and returns the app. It makes testing and configuration easier.

## 5. Example: an endpoint with a parameter and errors
```python
    @app.get("/api/predictions")
    def predictions():
        name = request.args.get("district")              # ?district=Colombo
        if not name:
            return {"error": "Query parameter 'district' is required."}, 400

        with engine.connect() as conn:
            district = conn.execute(
                text("SELECT id FROM districts WHERE name = :name"), {"name": name}
            ).mappings().first()
            if district is None:
                return {"error": f"Unknown district: {name}"}, 404

            rows = conn.execute(
                text("SELECT week_start, horizon_weeks, predicted_cases, lower_bound, "
                     "upper_bound, alert_level FROM predictions "
                     "WHERE district_id = :id ORDER BY week_start"),
                {"id": district["id"]},
            ).mappings().all()

        return jsonify({
            "district": name,
            "forecasts": [
                {"week_start": r["week_start"].isoformat(),      # date → "2026-11-07"
                 "horizon_weeks": r["horizon_weeks"],
                 "predicted_cases": float(r["predicted_cases"]), # Decimal → number
                 "lower": float(r["lower_bound"]),
                 "upper": float(r["upper_bound"]),
                 "alert_level": r["alert_level"]}
                for r in rows
            ],
        })
```
- `return body, 400` sets the **status code**. Without it the status is 200.
- Dates and decimals are converted by hand so the JSON is predictable.

Test it without a browser:
```powershell
curl "http://127.0.0.1:5000/api/predictions?district=Colombo"
curl -i "http://127.0.0.1:5000/api/predictions?district=Nowhere"     # -i shows the status line
```

## 6. Handling unexpected errors
```python
    @app.errorhandler(404)
    def not_found(error):
        return {"error": "Not found"}, 404

    @app.errorhandler(500)
    def server_error(error):
        return {"error": "Internal server error"}, 500
```
A client of a JSON API should always get JSON back, including when something breaks.

## 7. Common mistakes
- **Returning an error message with status 200.** The dashboard then treats the error as data.
- **`debug=True` on a public server.** The debugger lets visitors run code on your machine.
- **Using `flask run` in production.** It is a development server. Use a WSGI server such as gunicorn: [[08.03 Docker and Docker Compose]].
- **Trusting input.** Check that required parameters exist and have sensible values.
- **Putting user input into SQL text.** Always use bound parameters: [[06.03 SQLAlchemy]].
- **Running the model inside a request.** Forecasts are computed once a week by the pipeline and stored. The API only reads them.
- **Returning database rows as they are.** Dates and decimals do not turn into clean JSON by themselves.
- **Showing the raw Python error to the visitor.** It reveals how the system is built.
- **Creating the engine inside every view function.**

## 8. Exam and viva focus
- **What is a web framework?** Give Flask as an example of a micro-framework.
- **Route, view function, endpoint.**
- **Request–response cycle:** client sends a request, the server routes it, runs code, returns a response with a status code.
- **`GET` vs `POST`.**
- **Query parameter vs path parameter:** `/api/predictions?district=Colombo` vs `/api/districts/Colombo`.
- **WSGI:** the standard interface between a Python web application and a web server.
- **Why should an API return correct status codes?** So clients can react without reading the message text.
