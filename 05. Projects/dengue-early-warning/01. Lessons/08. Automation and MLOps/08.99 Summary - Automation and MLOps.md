# 08.99 · Lesson Summary: Automation and MLOps

> [!abstract] Back to [[08.00 Automation and MLOps]] · Progress: [[Phase 08 - Automation and MLOps]]

## Must know
- **MLOps** = keeping a model running, measured and up to date after it is built.
- **Pipeline script:** each step a function; log every step; **fail loudly** with a non-zero exit code; **safe to re-run** (idempotent).
- **Logging beats `print`:** time, level, file. Levels: DEBUG < INFO < WARNING < ERROR < CRITICAL.
- **cron expression:** minute, hour, day of month, month, day of week. `30 2 * * 1` = Mondays at 02:30.
- **GitHub Actions:** a YAML workflow in `.github/workflows/`. Schedules are in **UTC**, may start late, and the machine starts **empty** each run. Secrets come from repository settings.
- **CI/CD:** test automatically on every change; release automatically.
- **Image** = template; **container** = running instance. A container shares the host's kernel, so it is far lighter than a virtual machine.
- **Dockerfile order matters:** copy requirements and install first, copy code last.
- **Compose:** the database's address is its **service name** (`db`), not `localhost`. Use a **volume** or the data is lost.
- **Deployment:** production server (gunicorn), listen on `0.0.0.0` and the host's port, debug off, secrets in environment variables, health check.
- **IaaS / PaaS / SaaS:** you manage less at each step.
- **Data drift:** inputs change, $P(X)$. **Concept drift:** the relationship changes, $P(y \mid X)$.
- **Monitor performance** (rolling MAE; the truth arrives late) **and inputs** (PSI, KS test; an earlier signal).
- **Retraining flag:** 8-week rolling MAE more than 30 % above the test MAE. A flag means *investigate*.
- **A model version = code + data + settings + environment.** Store the version with every forecast. Compare **champion and challenger** before replacing. Keep old models for **rollback**.

## Important comparisons
| Virtual machine | Container |
|---|---|
| Whole operating system | Program and libraries only |
| Gigabytes; minutes to start | Megabytes; seconds to start |

| Image | Container |
|---|---|
| Template, read-only | Running instance |

| cron | GitHub Actions |
|---|---|
| Needs an always-on server | Needs only a repository |
| Files persist | Starts empty each run |

| Data drift | Concept drift |
|---|---|
| Inputs change | The input–output relationship changes |
| An unusually wet season | A new serotype; a new reporting rule |

| IaaS | PaaS | SaaS |
|---|---|---|
| Rent machines | Rent a platform for your app | Use finished software |
