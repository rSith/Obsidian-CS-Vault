## What this lesson is about
So far **you** run everything by hand. An early-warning system must run **without you**, every week, and must tell you when it stops being accurate. This lesson turns a set of scripts into a system:

```text
            every week, automatically
┌──────────────────────────────────────────────────────────────┐
│ collect weather → collect cases → build features → predict   │
│        → write alerts → log metrics                          │   one pipeline script
└──────────────────────────────────────────────────────────────┘
        │ started by a scheduler (cron or GitHub Actions)
        │ packaged in Docker, running on a host
        ▼
   monitoring: is the error growing? have the inputs changed? → retrain?
```

**MLOps** (machine learning operations) is the name for this work: keeping a model running, measured and up to date after it has been built.

> [!warning] This phase is the easiest to overrun
> It holds six separate skills. The core of the project is the forecasting and its honest evaluation. If time runs short, the order of importance is: pipeline script → monitoring → scheduling → Docker → online deployment. A dashboard that runs on your laptop is a complete project.
