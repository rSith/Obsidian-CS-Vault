# 03.99 · Lesson Summary: Feature Engineering

> [!abstract] Back to [[03.00 Feature Engineering]] · Progress: [[Phase 03 - Feature Engineering]]

## Must know
- **Origin $t$** = the week the forecast is made. **Horizon $h$** = weeks ahead. **Target** = cases at $t + h$.
- **One row** = one district at one origin week: features known at $t$, answer from $t + h$.
- **All lags are counted back from the origin.** Lag from origin = lag from case week − $h$.
- **Target:** `groupby("district")["cases"].shift(-H)`. The only place a negative shift belongs.
- **Lag feature** = a value from $k$ weeks earlier. **Rolling feature** = a total or average over recent weeks.
- **Shift by the availability delay, then roll.** Weather: about a week. Cases: the reporting delay.
- **Data leakage** = using information not available at prediction time. It gives no error, only results that are too good.
- **Six doors for leakage:** future data in a feature, unpublished data, the target inside a feature, preprocessing fitted before the split, a random split, tuning on the test set.
- **Change-the-future test:** alter later weeks; earlier features must not change.
- **Week of year → sine and cosine**, so week 52 sits next to week 1. Both are needed.
- **District → one-hot columns.** Numbers 1, 2, 3 would invent an order.
- **One feature function in `src/features.py`,** used by training, tests and the live pipeline.
- **pytest:** files `test_*.py`, functions `test_*`, checks with `assert`. Arrange, Act, Assert.

## Key code
```python
g = df.sort_values(["district", "week_start"]).groupby("district")

df["target"]     = g["cases"].shift(-H)
df["rain_lag4"]  = g["rain_mm"].shift(4)
df["rain_sum4"]  = g["rain_mm"].transform(lambda s: s.shift(1).rolling(4).sum())
df["cases_last"] = g["cases"].shift(CASE_DELAY)

doy = df["week_start"].dt.dayofyear
df["year_sin"] = np.sin(2 * np.pi * doy / 365.25)
df["year_cos"] = np.cos(2 * np.pi * doy / 365.25)
```

## Key formulas
$$\text{week\_sin} = \sin\left(\frac{2\pi w}{52}\right) \qquad \text{week\_cos} = \cos\left(\frac{2\pi w}{52}\right) \qquad \text{real horizon} = d + h$$

## Important comparisons
| Direct forecasting | Recursive forecasting |
|---|---|
| One model per horizon | One model, fed its own predictions |
| No error build-up | Errors add up step by step |

| Lag feature | Rolling feature |
|---|---|
| One week's value | A summary of several weeks |
| Precise but noisy | Smooth; shows sustained conditions |

| Label encoding | One-hot encoding |
|---|---|
| One column of integers | One 0/1 column per category |
| Implies an order | No order |

| Notebook cell | Function in `src/` |
|---|---|
| For exploring | For reuse and testing |
| Cannot be imported | Imported everywhere |
