## What this lesson is about
A model learns from a table where each row is one example: some **inputs** (features) and one **answer** (target). The weekly table from Phase 2 is not that table yet. This lesson builds it, under one strict rule:

> [!important] The rule of this phase
> Every feature in a row must use **only information that existed on the day that forecast would have been made**.

Break the rule and the model looks excellent in testing and fails in real use. That failure is called **data leakage**, and most of this lesson is about avoiding it.
