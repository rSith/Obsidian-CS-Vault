## What this lesson is about
Before any data or model, two things must be in place:
1. a **workspace** you can trust for six months: Git for history, a virtual environment for packages;
2. enough **knowledge of dengue** to choose sensible features later. A model can only learn patterns you give it, so you need to know *why* rain and temperature come before cases, and by how long.

## Topic structure

