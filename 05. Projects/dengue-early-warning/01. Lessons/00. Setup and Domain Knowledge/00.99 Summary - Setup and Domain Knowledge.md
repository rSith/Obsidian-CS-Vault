## Must know
- **Branch** = a pointer to a commit; a separate line of work. One branch per phase, merge into `main` when the checklist is done.
- **Commit message:** starts with a verb, short first line, one change per commit.
- **Virtual environment** = a folder with its own Python and packages. Activate it in every new terminal. Commit `requirements.txt`, never `.venv/`.
- **Dengue:** a virus with **four serotypes**, spread by female ***Aedes*** mosquitoes. Never directly person to person.
- **Extrinsic incubation** (in the mosquito, about 8–12 days) and **intrinsic incubation** (in the human, about 4–10 days).
- **Life cycle:** egg → larva → pupa → adult in about 8–10 days; eggs survive dry for months.
- **Weather:** rain makes breeding sites, warmth speeds everything up, humidity keeps adults alive.
- **Cases follow weather by weeks** because the delays add up. That delay is the early-warning window.
- **Sri Lanka:** south-west monsoon (May–September) and north-east monsoon (December–February) give two dengue peaks, about June–July and December–January. The Western Province carries about half the cases.
- **Unusual years:** 2017 (epidemic) and 2020–21 (COVID-19). Flag them.
- **Papers:** read in three passes; record data, features, model, lead time, evaluation and result.

## Important comparisons
| Extrinsic incubation | Intrinsic incubation |
|---|---|
| Inside the mosquito | Inside the human |
| About 8–12 days, shorter when warm | About 4–10 days |

| `requirements.txt` | `.venv/` |
|---|---|
| The recipe | The result |
| Committed | Ignored |

| Fast-forward merge | Merge commit |
|---|---|
| `main` had no new commits | Both branches had new commits |
| Pointer moves; no new commit | New commit with two parents |
