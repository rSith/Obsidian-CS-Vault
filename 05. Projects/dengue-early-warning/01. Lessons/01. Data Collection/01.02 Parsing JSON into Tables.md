# 01.02 · Parsing JSON into Tables

> [!info] [[01.00 Data Collection|Lesson 1]] · Roadmap Phase 1 · Priority 🔴 Core
> **Builds on:** [[02.07 Web Services, XML and JSON]] · [[Pandas]]
> **Used for:** turning each weather API reply into rows of `date, rain_mm, temp_mean, humidity`.

## 1. Definition
> [!note] JSON
> **JSON** (JavaScript Object Notation) is a text format for structured data. It is built from two shapes: **objects** `{ "key": value }` and **arrays** `[ value, value ]`.

> [!note] Parsing
> **Parsing** means reading text in a known format and turning it into data your program can use.

## 2. Why it is used
An API replies with JSON text. Analysis needs a table with one row per day. Parsing is the step between the two.

## 3. How it works
JSON maps directly onto Python types:

| JSON | Python |
|---|---|
| object `{ }` | `dict` |
| array `[ ]` | `list` |
| string `"abc"` | `str` |
| number `12`, `3.5` | `int`, `float` |
| `true` / `false` | `True` / `False` |
| `null` | `None` |

So a JSON reply becomes dictionaries and lists nested inside each other. The work is finding the path to the part you want.

## 4. Syntax
```python
import json
import pandas as pd

data = response.json()            # from a requests response
data = json.loads(text)           # from a string
data = json.load(open(path))      # from a file

data.keys()                       # see what is at the top level
data["daily"]["time"][0]          # walk down: dict → dict → list → item
data.get("daily", {})             # .get does not crash if the key is missing

pd.DataFrame(a_dict_of_lists)     # each key becomes a column
pd.json_normalize(a_list_of_dicts)  # flattens nested records into columns
```

## 5. Example A: a dictionary of lists
A weather reply shaped like this:

```json
{
  "latitude": 6.93, "longitude": 79.85,
  "daily": {
    "time": ["2024-01-01", "2024-01-02"],
    "precipitation_sum": [0.0, 12.4],
    "temperature_2m_mean": [27.1, 26.5]
  }
}
```
becomes a table in two lines:

```python
df = pd.DataFrame(data["daily"])
df = df.rename(columns={"time": "date", "precipitation_sum": "rain_mm",
                        "temperature_2m_mean": "temp_mean"})
df["date"] = pd.to_datetime(df["date"])
df["district"] = "Colombo"
```

| date | rain_mm | temp_mean | district |
|---|---|---|---|
| 2024-01-01 | 0.0 | 27.1 | Colombo |
| 2024-01-02 | 12.4 | 26.5 | Colombo |

## 6. Example B: a dictionary keyed by date
Some APIs reply like this:

```json
{ "properties": { "parameter": {
    "PRECTOTCORR": { "20240101": 0.0, "20240102": 12.4 },
    "T2M":         { "20240101": 27.1, "20240102": -999 }
} } }
```
```python
df = pd.DataFrame(data["properties"]["parameter"])   # the dates become the index
df.index = pd.to_datetime(df.index, format="%Y%m%d")
df = df.replace(-999, pd.NA)                          # -999 means "missing" here
```

## 7. Example C: a list of nested records
```python
records = [
    {"district": "Colombo", "coord": {"lat": 6.93, "lon": 79.85}},
    {"district": "Kandy",   "coord": {"lat": 7.29, "lon": 80.63}},
]
pd.json_normalize(records)
# columns: district, coord.lat, coord.lon
```

## 8. Common mistakes
- **Guessing the structure.** Print `data.keys()` and look at one item before you write the loop.
- **A missing key crashes the script** with `KeyError`. Use `.get()` when a key may be absent.
- **Leaving dates as text.** Convert with `pd.to_datetime` at once, or sorting and resampling will be wrong.
- **Treating a "missing" code as a real value.** A fill value such as `-999` would look like a freezing day. Read the API's documentation for its code.
- **Numbers stored as strings.** Check `df.dtypes`; convert with `pd.to_numeric`.
- **Forgetting to add the district.** After you combine all files you cannot tell the rows apart.

## 9. Exam and viva focus
- **JSON data types:** object, array, string, number, boolean, null.
- **JSON vs XML:** JSON is shorter, maps directly to program data types and is easier to parse; XML uses tags and supports attributes and schemas.
- **Serialisation vs parsing:** turning data into text to send, and turning text back into data.
- **Why is JSON language-independent?** It is plain text with a simple, published grammar.
