## Must know
- **API** = rules for one program to ask another for data. **REST API** = resources at URLs, read with `GET`, reply in JSON.
- **Request:** method, URL, query parameters, headers. **Response:** status code, body.
- **Status codes:** `200` OK, `400` bad request, `404` not found, `429` too many requests, `5xx` server problem.
- **JSON** maps to Python: object → `dict`, array → `list`, `null` → `None`.
- **Scraping:** request → parse → select → extract → save. `read_html` for tables, BeautifulSoup for links.
- **PDF:** stores character positions, not tables. Always **validate** extracted tables (row count, totals, numeric cells).
- **Epi week:** a fixed seven-day reporting period. Week systems differ, so store **`week_start`** and join on it.
- **Daily → weekly:** **sum** rainfall, **average** temperature and humidity, drop incomplete weeks.
- **Reporting delay:** case counts are published weeks late. **Real horizon = delay + lead time.**
- **Habits:** save raw files untouched, never download twice, wait between requests, write the data dictionary.

## Important comparisons
| API | Scraping |
|---|---|
| Built for programs | Built for people |
| Stable, documented | Breaks when the page layout changes |
| First choice | Only when there is no API |

| ISO week | Sri Lanka WER week (recent issues) |
|---|---|
| Monday – Sunday | Saturday – Friday |
| `resample("W")` | `resample("W-FRI")` |

| Nowcasting | Forecasting |
|---|---|
| Estimate the present | Predict the future |
| Needed because data is late | Needed for early warning |
