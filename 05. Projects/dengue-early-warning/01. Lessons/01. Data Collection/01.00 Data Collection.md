## What this lesson is about
The project needs three things for every district and week: **dengue cases**, **weather** and **population**. None arrives as one clean file. This lesson covers how to:
1. get weather from a web **API** that returns **JSON**;
2. get case counts from **web pages** and **PDF reports**;
3. line up **daily** weather with **weekly** case reports, where the week does not start on Monday;
4. deal with the fact that case counts are **published weeks late**.

The rule for the whole phase: every download is done by a **script that can be re-run**, and raw files are **saved and never edited**.
