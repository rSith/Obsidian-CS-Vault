# 01.03 · Web Scraping with BeautifulSoup and read_html

> [!info] [[01.00 Data Collection|Lesson 1]] · Roadmap Phase 1 · Priority 🟡 Supporting
> **Builds on:** [[00.02 HTML Document Structure]] · [[00.08 CSS Selectors, Pseudo-classes and the Cascade]]
> **Used for:** finding the links to every weekly report on a listing page, and reading case tables that exist only as web pages.

## 1. Definition
> [!note] Web scraping
> **Web scraping** is using a program to read a web page and pull out the data in it, when the site offers no API or download.

## 2. Why it is used
Health reports are often published as a page of links to PDF files. There may be several hundred. A scraper collects all the links in one run and can check for new reports every week.

## 3. How it works
1. Download the page's **HTML** with `requests`.
2. **Parse** the HTML into a tree of elements.
3. **Select** the elements you want, using tag names or CSS selectors.
4. **Extract** their text or attributes (for a link, the `href`).
5. **Save** what you found.

There are two tools, for two situations:

| Tool | Use it when |
|---|---|
| `pandas.read_html` | The data is already in an HTML `<table>`. One line gives you DataFrames. |
| **BeautifulSoup** | You need links, or data that is not in a table. |

## 4. Syntax
```python
import pandas as pd
```

## 5. Example: collect every PDF link on a page
```python
import time
from pathlib import Path
from urllib.parse import urljoin

import requests
from bs4 import BeautifulSoup

page_url = "https://example.org/weekly-reports"        # the listing page
html = requests.get(page_url, timeout=30).text
soup = BeautifulSoup(html, "html.parser")

links = [urljoin(page_url, a["href"])                  # make relative links complete
         for a in soup.select("a[href$='.pdf']")]      # links that end in .pdf

out = Path("data/raw/reports")
out.mkdir(parents=True, exist_ok=True)
for link in links:
    path = out / link.split("/")[-1]
    if path.exists():                                  # skip files you already have
        continue
    path.write_bytes(requests.get(link, timeout=60).content)
    time.sleep(1)                                      # one request per second
```
Work by hand first: open the page in the browser, right-click a link, choose **Inspect**, and see which tags surround it. Then write the selector.

## 6. Scraping responsibly
- Read the site's **terms of use** and its `robots.txt` file.
- **Wait** between requests. A public-health server is not built for heavy traffic.
- **Download each file once** and keep it.
- Having permission to read data is not the same as having permission to **republish** it. Keep raw case files out of a public repository.
- If the site has a contact address, **asking for the data** in table form is often faster than scraping.

## 7. Common mistakes
- **The data is not in the HTML.** Some pages load data with JavaScript after the page opens. `requests` sees only the empty page. Look in the browser's Network tab for the request that carries the data, and call that instead.
- **Relative links.** `/files/a.pdf` is not a full URL. Use `urljoin`.
- **Fragile selectors.** A long chain of tags breaks when the site changes its layout. Select by a stable class or by the link ending.
- **No raw copy.** If parsing fails later you must download everything again.
- **Assuming `read_html` found the right table.** It returns all of them. Print each one's shape.

## 8. Exam and viva focus
- **Define** web scraping and say when it is used instead of an API.
- **Steps:** request, parse, select, extract, store.
- **Static vs dynamic page:** static HTML contains the data; a dynamic page builds it with JavaScript in the browser.
- **Ethical and legal points:** terms of use, `robots.txt`, rate limits, copyright, personal data.
