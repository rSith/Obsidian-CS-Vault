# 01.04 · PDF Table Extraction with pdfplumber

> [!info] [[01.00 Data Collection|Lesson 1]] · Roadmap Phase 1 · Priority 🟡 Supporting
> **Used for:** reading the district case table out of each weekly report PDF.

## 1. Definition
> [!note] PDF table extraction
> **PDF table extraction** is rebuilding the rows and columns of a table from a PDF file, so the numbers can be used as data.

## 2. Why it is hard
A PDF does not store a table. It stores **characters and their positions on the page**: "put `Colombo` at x=40, y=310". The grid you see is only lines drawn nearby. A tool has to guess the rows and columns from the positions, so it can guess wrong.

| Kind of PDF | What is inside | Can it be extracted? |
|---|---|---|
| **Text-based** | Real characters. You can select text with the mouse. | Yes, with `pdfplumber` |
| **Scanned** | A photo of a page | Only with OCR (optical character recognition), which makes more errors |

## 3. How it works
1. Open the PDF and choose the page.
2. Ask the library for the table. It returns a **list of rows**, and each row is a list of text cells.
3. Turn the rows into a DataFrame.
4. Clean: remove header rows, fix names, convert text to numbers.
5. **Validate** before you trust it.

## 4. Syntax
```python
import pdfplumber

with pdfplumber.open("data/raw/reports/report.pdf") as pdf:
    page = pdf.pages[2]                 # pages count from 0
    text = page.extract_text()          # all text on the page
    table = page.extract_table()        # the largest table: list of rows
    tables = page.extract_tables()      # every table on the page
```

## 5. Example: one report → clean rows
```python
import pandas as pd
import pdfplumber

def read_case_table(pdf_path: str) -> pd.DataFrame:
    with pdfplumber.open(pdf_path) as pdf:
        for page in pdf.pages:                          # find the page by its content,
            if "Dengue" in (page.extract_text() or ""): # not by a fixed page number
                rows = page.extract_table()
                break
        else:
            raise ValueError(f"No dengue table found in {pdf_path}")

    df = pd.DataFrame(rows[2:])                         # skip the header rows
    df = df[[0, 1]]                                     # the area name and the weekly count
    df.columns = ["district", "cases"]
    df["district"] = df["district"].str.strip()
    df["cases"] = pd.to_numeric(df["cases"].str.replace(" ", ""), errors="coerce")
    return df
```
The column positions (`[0, 1]`) and header rows (`rows[2:]`) are examples. Print `rows` for one real report and adjust them.

> [!tip] Know what the columns mean
> Weekly disease tables often give two numbers per disease: the count for **the current week** and the **cumulative** count for the year. Read the table's footnote to see which is which, and write it in `docs/data.md`.

## 6. Validating the result
Never trust an extracted table until it passes checks like these:

| Check | Catches |
|---|---|
| Number of rows = number of reporting units (26) | A lost or split row |
| No missing values in `cases` | Text that did not convert to a number |
| Sum of rows = the table's own "total" row | A misread digit |
| This week's cumulative − last week's cumulative ≈ this week's count | Columns that shifted |
| Every area name is in your list of known names | Spelling changes and merged cells |

```python
assert len(df) == 26, f"expected 26 rows, got {len(df)}"
assert df["cases"].notna().all()
```
Write the checks into the script so a bad file stops the run instead of quietly adding wrong numbers.

## 7. Common mistakes
- **Checking one file and trusting the other 400.** Report layouts change over the years. Validate every file.
- **Using a fixed page number.** Find the page by a word that is always on it.
- **Losing digits to spaces.** `1 234` becomes two cells or fails to convert. Remove spaces first.
- **Merged or wrapped cells.** A long name on two lines can become two rows.
- **Silently dropping bad rows** with `errors="coerce"` and never counting the `NaN` values it produced.
- **Editing the PDF output by hand.** Fix the code so the fix is repeated on every run.
