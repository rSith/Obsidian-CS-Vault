# 05.99 · Lesson Summary: Evaluation and Alerts

> [!abstract] Back to [[05.00 Evaluation and Alerts]] · Progress: [[Phase 05 - Evaluation and Alerts]]

## Must know
- **MAE** = average size of the error. **RMSE** = the same, but large errors count more. **Bias** = which way the model leans.
- RMSE much larger than MAE means a few very bad misses, probably the outbreak weeks.
- **Report per district** and against the baselines. One overall number is dominated by Colombo.
- **Endemic channel** = the expected range of cases for each district and week of year, from earlier years.
- **Thresholds:** Watch above $\mu + \sigma$; Warning above $\mu + 2\sigma$.
- **Make the channel robust:** pool neighbouring weeks, exclude epidemic and disrupted years, use only earlier years; or use the median and percentiles.
- **Confusion matrix:** TP caught, FP false alarm, FN missed, TN correctly quiet.
- **Precision** = of the warnings, how many were right. **Recall** = of the outbreaks, how many were caught.
- **Accuracy misleads** because outbreak weeks are rare.
- **Lower threshold:** higher recall, lower precision. A missed outbreak usually costs more, so favour recall.
- **Lead time** is measured to the **start** of the outbreak. Count **episodes**, not weeks.
- **Compare with a naive alert:** "warn when the newest known count is already above the line."
- **Prediction interval:** a range with a stated probability. **Quantile regression** learns it through the pinball loss.
- **Check coverage:** an 80 % interval should contain the truth about 80 % of the time.
- **Final test:** once, on unseen years, reported in full.

## Key formulas
$$\text{MAE} = \frac{1}{n}\sum \lvert y_i - \hat{y}_i \rvert \qquad \text{RMSE} = \sqrt{\frac{1}{n}\sum (y_i - \hat{y}_i)^2}$$

$$\text{Precision} = \frac{TP}{TP + FP} \qquad \text{Recall} = \frac{TP}{TP + FN} \qquad F_1 = \frac{2PR}{P + R}$$

$$\text{Warning: } \hat{y} > \mu_w + 2\sigma_w \qquad L_q = \begin{cases} q\,(y - \hat{y}) & y \ge \hat{y} \\ (1-q)(\hat{y} - y) & y < \hat{y} \end{cases}$$

## Important comparisons
| MAE | RMSE |
|---|---|
| Typical error | Punishes big errors |
| Less affected by outliers | Sensitive to outliers |

| Precision | Recall |
|---|---|
| Looks at the **warnings** | Looks at the **outbreaks** |
| Low → many false alarms | Low → many missed outbreaks |

| Mean + SD | Median + percentiles |
|---|---|
| Simple, standard | Not thrown off by one extreme year |

| Confidence interval | Prediction interval |
|---|---|
| For an estimated average | For one future value |
| Narrower | Wider |

| Endemic | Epidemic |
|---|---|
| Expected level | Above the expected level |
