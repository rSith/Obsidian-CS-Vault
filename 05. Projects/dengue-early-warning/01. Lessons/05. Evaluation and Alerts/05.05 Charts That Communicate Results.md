# 05.05 · Charts That Communicate Results

> [!info] [[05.00 Evaluation and Alerts|Lesson 5]] · Roadmap Phase 5 · Priority 🟡 Supporting
> **Parent concepts:** [[Matplotlib]] · [[Seaborn]] · [[Exploratory Data Analysis]]. This note is about designing a chart for a reader, not about the libraries.
> **Used for:** the actual-versus-predicted figures, which become the strongest evidence in the report.

## 1. Definition
> [!note] Explanatory chart
> An **explanatory chart** is made to show a reader **one finding** quickly. An *exploratory* chart is made for yourself, to find out what is in the data.

## 2. Why it is used
Health officials, lecturers and recruiters read charts, not tables of MAE. One figure showing "the system raised a Warning three weeks before the outbreak began" is more convincing than any metric.

## 3. How it works: the anatomy of the key figure
```text
 cases
   │                         ░░░ Warning period ░░░
   │                         ░░░░░░░░░░░░░░░░░░░░░░    ── actual cases
   │  - - - - - - - - - - - -░- - - - - - - - - - -░   ── forecast (made 4 weeks earlier)
   │      Warning level      ░   ╱‾‾‾╲             ░   ▒▒ 80 % interval
   │                         ░ ╱▒▒▒▒▒▒╲            ░   - - Warning level
   │  ______________________╱▒▒▒▒▒▒▒▒▒▒╲___________░
   └──────────────────────────────────────────────────▶ week
```

| Element | Shows | matplotlib |
|---|---|---|
| Solid dark line | What actually happened | `ax.plot` |
| Coloured line | What was forecast | `ax.plot` |
| Shaded band | The prediction interval | `ax.fill_between` |
| Dashed line | The Warning threshold | `ax.plot(..., linestyle="--")` |
| Shaded vertical block | Weeks when a Warning was active | `ax.axvspan` |

## 4. Syntax
```python
import matplotlib.pyplot as plt

d = results[results["district"] == "Colombo"]

fig, ax = plt.subplots(figsize=(10, 4))
ax.plot(d["target_week"], d["target"], color="black", linewidth=1.8, label="Actual cases")
ax.plot(d["target_week"], d["pred"], color="tab:blue", label="Forecast, made 4 weeks earlier")
ax.fill_between(d["target_week"], d["lower"], d["upper"], color="tab:blue", alpha=0.2,
                label="80 % prediction interval")
ax.plot(d["target_week"], d["warning"], color="tab:red", linestyle="--", label="Warning level")

for start, end in warning_periods:                  # list of (first_week, last_week)
    ax.axvspan(start, end, color="tab:red", alpha=0.10)

ax.set_title("Colombo: Warning raised 3 weeks before the outbreak began")
ax.set_xlabel("Week")
ax.set_ylabel("Reported dengue cases per week")
ax.legend(frameon=False)
fig.tight_layout()
fig.savefig("reports/figures/colombo_forecast.png", dpi=200)
```

## 5. Eight rules
1. **One message per figure.** If you cannot state it in one sentence, split the figure.
2. **Put the message in the title.** "Warning raised 3 weeks before the outbreak began", not "Cases vs predictions".
3. **Label both axes, with units.** "Reported dengue cases per week".
4. **Say when the forecast was made.** Otherwise a reader assumes it was drawn after the fact.
5. **Use the same colour for the same thing in every figure.** Actual always black, forecast always blue.
6. **Do not rely on colour alone.** Use solid and dashed lines and direct labels, so the chart works in greyscale and for colour-blind readers.
7. **Start the y-axis at zero** for counts, so differences are not exaggerated.
8. **Remove what carries no information:** heavy grids, boxes, 3D effects.

## 6. Example: weak title, strong title
| Weak | Strong |
|---|---|
| "Figure 4: Results for Kandy" | "Kandy: the mid-2025 outbreak was missed; the forecast stayed below the Warning level" |

The strong version states a finding, and it reports a **failure** just as plainly as a success. Showing a miss, with a short explanation, makes every other figure more credible.

For many districts, use **small multiples**: one small panel per district with the same axes style, so a reader can scan them.
```python
fig, axes = plt.subplots(5, 5, figsize=(18, 14), sharex=True)
```

## 7. Common mistakes
- **A title that only names the variables.**
- **No units, or no axis labels.**
- **Too many lines** in one chart.
- **Red and green as the only difference.** The most common form of colour blindness cannot separate them.
- **Showing only the districts where the model worked.**
- **A default legend covering the data.**
- **A screenshot of a notebook cell** in the report. Save the figure as a file at 200 dpi or more.
- **Different y-axis scales in panels that are meant to be compared**, without saying so.

## 8. Exam and viva focus
- **Exploratory vs explanatory visualisation.**
- **Which chart for which data:** line for change over time, bar for comparing categories, scatter for the relationship between two numbers, histogram for a distribution.
- **Name four features of a good chart:** clear title, labelled axes with units, legend, suitable scale.
- **How can a chart mislead?** A cut-off axis, uneven scales, selective data.
- **Accessibility:** do not encode information by colour alone.
