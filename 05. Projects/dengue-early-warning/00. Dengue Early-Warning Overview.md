# 00 · Dengue Early-Warning: Project Overview

> [!abstract] Map of Content
> This is the **home page for the study notes** of the Dengue Outbreak Early-Warning System. Every lesson, summary and progress note is reachable from here.
> The project's front page, with the goal, plan and log, is [[Dengue Early-Warning - Project Home]].

## Project details
| Item | Detail |
|---|---|
| Goal | Forecast weekly dengue cases for each Sri Lankan district 4 to 8 weeks ahead, and raise a Normal / Watch / Warning alert |
| Roadmap | 10 phases over about 24 weeks, part-time. Planned start 12 October 2026, planned finish 28 March 2027. |
| Code | `Code Vault/Projects/Machine Learning-Projects/dengue-early-warning` |
| How the notes are split | **Lessons** explain what you need to know. **Phase notes** record what you actually did. |

## Suggested study order
1. **Before any code:** lesson 00, then [[01.06 Reporting Delay and Data Availability]], [[03.01 Forecast Origin, Horizon and Target]] and [[03.03 Data Leakage]]. These three ideas shape every later decision.
2. **Just in time:** read each lesson's overview when its phase starts, and each topic note when a step needs it.
3. **After each phase:** read the summary (`NN.99`) and answer its "Exam and viva focus" points aloud.
4. **Before a viva or interview:** the ten summaries, then [[09.03 Presenting and Storytelling]].
