# Phase 09 — Documentation and Portfolio
> [!info] [[Dengue Early-Warning - Project Home]] · Roadmap weeks 23–24, target finish 2027-03-28
> **Study notes:** [[09.00 Documentation and Portfolio]] · **Revision:** [[09.99 Summary - Documentation and Portfolio]]

> [!abstract] Phase goal
> Anyone (a lecturer, a recruiter or a health official) can understand what you built, why it works and its limits within five minutes.

## Steps
- [ ] Polish the README: problem, dashboard screenshot, architecture diagram, how to run it, results, limitations → [[09.02 Architecture Diagrams]]
- [ ] Write the technical report, 8–15 pages, structured like a paper → [[09.01 Technical and Scientific Writing]]
- [ ] State the limitations honestly: reporting delay, under-reporting, weather at one point per district, unusual periods
- [ ] Add an ethics section → [[09.04 Responsible AI in Health]]
- [ ] Record a 3–5 minute demo video, including one historical outbreak the system caught early → [[09.03 Presenting and Storytelling]]
- [ ] Share it: a LinkedIn post with the key result and a figure, and a talk → [[Learning in Public]]
- [ ] Ask a public-health lecturer or the regional epidemiology office for feedback

## Done when
- [ ] The README is complete, with a screenshot and an architecture diagram
- [ ] The technical report is finished and reviewed by one other person
- [ ] The demo video is recorded
- [ ] The project is shared publicly, and feedback is requested from a domain expert
