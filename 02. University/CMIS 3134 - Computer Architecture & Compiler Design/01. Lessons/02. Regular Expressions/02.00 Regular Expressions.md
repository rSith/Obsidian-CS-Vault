## What this lesson is about

A **regular expression (RE)** is a compact way to write a **pattern** that describes a set of strings. In a compiler, patterns are how the [[06.00 Lexical Analysis|lexical analyzer]] knows that `count` is an identifier and `-42` is a number.

You need to move fluently in **both directions**:
- **description → RE** (write an RE for a NIC number, a password, "strings that start with 1 and end with 0");
- **RE → description** (give example strings and describe the language of `(aa)*(bb)*b`).

## Course notation

> [!important] Notation used in this course
> - **Union** is written `+` (sometimes `|`). Example: `(a+b)` means "a or b".
> - **ε** (or λ) is the empty string; **φ** is the empty set.
> - `x*` = zero or more, `x+` (written x⁺) = one or more, `x?` = at most one.
