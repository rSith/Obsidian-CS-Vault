# 02.02 · Operations on Languages: Union, Concatenation, Kleene Closure

> [!info] [[02.00 Regular Expressions|Lesson 2]] · Theory Notes 2 (+ Theory Notes 3 for Kleene plus) · Priority 🟡 Medium
> **Asked as:** "Explain the following operations on languages with examples: (i) Union (ii) Concatenation (iii) Kleene Closure Star (L*) (iv) Kleene Closure Plus (L⁺)" (2023/24 Q3b)

A **language** is a set of strings. These operations build new languages from old ones. Everything a regular expression can express is built from them.

## 1. Union

> [!abstract] Theory Notes 2
> "Union of two languages L and M is written as $L \cup M = \{ s \mid s \text{ is in } L \text{ or } s \text{ is in } M \}$"

**Meaning:** "choice": a string in either language.
**Example:** $L = \{a, b\}$, $M = \{b, c\}$ → $L \cup M = \{a, b, c\}$. (Duplicates appear once, because these are sets.)
**RE notation:** `(r)|(s)` or `r + s`.

## 2. Concatenation

> [!abstract] Theory Notes 2
> "Concatenation of two languages L and M is written as $LM = \{ st \mid s \text{ is in } L \text{ and } t \text{ is in } M \}$"

**Meaning:** "sequence": a string from L **followed by** a string from M.
**Example:** $L = \{a, b\}$, $M = \{c, d\}$ → $LM = \{ac, ad, bc, bd\}$. Note $|LM| \le |L| \times |M|$.
**Order matters:** $ML = \{ca, cb, da, db\} \ne LM$.
**RE notation:** `(r)(s)` or `r . s`.

## 3. Kleene Closure (Star)

> [!abstract] Theory Notes 2
> "The Kleene Closure of a language L is written as $L^*$ = **zero or more** occurrence of language L."

$$
L^* = L^0 \cup L^1 \cup L^2 \cup L^3 \cup \dots \qquad \text{where } L^0 = \{\varepsilon\}
$$

**Example:** $L = \{a\}$ → $L^* = \{\varepsilon, a, aa, aaa, \dots\}$.
$L = \{ab\}$ → $L^* = \{\varepsilon, ab, abab, ababab, \dots\}$.
**ε is always included.**

## 4. Kleene Plus (positive closure)

From Theory Notes 3 (applied to alphabets) and the RE notation `x+ = x.x*`:

$$
L^+ = L^1 \cup L^2 \cup L^3 \cup \dots = L \cdot L^* = L^* - \{\varepsilon\} \;\;(\text{when } \varepsilon \notin L)
$$

**Example:** $L = \{a\}$ → $L^+ = \{a, aa, aaa, \dots\}$. **ε is not included** (unless ε was already in L).

> [!note] Precise point
> $L^+ = L^* - \{\varepsilon\}$ is exactly true only when $\varepsilon \notin L$. If L itself contains ε, then $L^+$ also contains ε. The lecture states the formula for alphabets ($\Sigma^+ = \Sigma^* - \{\lambda\}$), where it is always true because symbols are non-empty.

## 5. Summary table

| Operation | Notation | Formal definition | Example with L={a,b}, M={c} |
|---|---|---|---|
| Union | $L \cup M$, `r+s` | $\{s \mid s \in L \text{ or } s \in M\}$ | $\{a, b, c\}$ |
| Concatenation | $LM$, `rs` | $\{st \mid s \in L, t \in M\}$ | $\{ac, bc\}$ |
| Kleene star | $L^*$ | $L^0 \cup L^1 \cup L^2 \cup \dots$ | $\{\varepsilon, a, b, aa, ab, ba, bb, \dots\}$ |
| Kleene plus | $L^+$ | $L^1 \cup L^2 \cup \dots$ | $\{a, b, aa, ab, \dots\}$ (no ε) |

## 6. Practical explanation
- `identifier = letter (letter | digit)*` uses **concatenation** (letter followed by …), **union** (letter or digit) and **star** (any number of them).
- `number = digit+` uses **plus**: at least one digit, because an empty string is not a number.

- Give **notation + set definition + example** for each (each is mark-bearing).
- The key contrast: **star includes ε, plus does not.**
