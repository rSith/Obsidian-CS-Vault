# 02.99 · Lesson Summary: Regular Expressions

> [!abstract] Back to [[02.00 Regular Expressions]] · Practice: [[PP 02 - Regular Expressions]]

## Must know
- **RE:** a notation for specifying **patterns**; each pattern names a **set of strings**; defined **recursively**; efficient implementation (via finite automata).
- **RE → regular grammar → regular language** (notation → rules → set of strings).
- **Operations:** union $L \cup M$, concatenation $LM$, Kleene star $L^*$ (zero or more, **includes ε**), Kleene plus $L^+$ (one or more, **no ε**).
- **Precedence:** `*` highest → concatenation → `|`/`+` lowest; all left-associative.
- **Tokens:** `x*` {ε,x,xx,…} · `x⁺` {x,xx,…} = x.x* · `x?` {ε,x} · `[ ]` inclusive · `( )` exclusive.
- **Building blocks:** `letter=[a-z]|[A-Z]`, `digit=[0-9]`, `sign=[+|-]`.

## Important definitions
- **Regular grammar:** grammar defined by regular expressions.
- **Regular language:** language defined by a regular grammar.
- **Recursive definition:** ε → {ε}; φ → { }; x → {x}; X+Y → union; X.Y → concatenation; R* → star.

## Key patterns

| Token | RE |
|---|---|
| Decimal | `(sign)?(digit)+` |
| Identifier | `(letter)(letter\|digit)*` |
| NIC | `(digit)⁹(V\|X)` (9 digits written out) |
| Email @gmail.com | `(letter)(letter\|digit\|_\|.)*@gmail.com` |
| Binary number | `(0+1)⁺` |
| SL mobile | `07(digit)⁸` |
| Reg. no YYYY/ABC/NNN | `(digit)⁴/([A-Z])³/(digit)³` |
| Password (letter first, ≥6, letters+digits) | `(letter)(letter+digit)⁵(letter+digit)*` |
| Starts with 1, ends with 0 | `1(0+1)*0` |
| Starts and ends with a, b's between | `ab*a` |

## Key readings

| RE | Language |
|---|---|
| `(0*10*)` | exactly one 1 |
| `(a+b)*abb` | ends with abb |
| `(aa)*(bb)*b` | even a's then odd b's |
| `(aa+ab+ba+bb)*` = `((a+b)(a+b))*` | even length |
| `(a+b)((a+b)(a+b))*` | odd length |
| `(a+ab)*` | no string starts with b, no "bb" |
| `b*(aaa)*b*` | a-block length multiple of 3 |

## Important comparisons

| x* | x⁺ |
|---|---|
| zero or more | one or more |
| contains ε | no ε |

| [0-5] | (5-9) | [1-7) |
|---|---|---|
| {0,…,5} | {6,7,8} | {1,…,6} (half-open; state your reading) |
