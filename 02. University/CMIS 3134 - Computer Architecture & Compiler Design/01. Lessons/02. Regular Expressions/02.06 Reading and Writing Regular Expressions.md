# 02.06 · Reading and Writing Regular Expressions (Regular Sets)

> [!info] [[02.00 Regular Expressions|Lesson 2]] · Theory Notes 2 (RE examples table) + `Compiler note.pdf` (length examples) · Priority 🔴 High (every paper)
> **Asked as:** "Provide example strings (and the final output in your words) that can be generated by…" (2019/20 Q2c, 2020/21 Q2d, 2021/22 Q3d(ii), 2022/23 Q3d(ii)) · "Construct the RE for…" (2021/22 Q3d(i), 2022/23 Q3d(i)) · "Is 1101 acceptable by A, B, or both?" (2020/21 Q6a) · "Describe the language of (aa+ab+ba+bb)* … simpler expression?" (2023/24 Q3d)

## 1. Reading an RE → describing its language

**Method:**
1. Apply precedence: `*` binds tightest, then concatenation, then `+` ([[02.03 Notation, Precedence and Recursive Definition]]).
2. Generate the **shortest** strings first (check whether **ε** is included).
3. Generate a few longer ones.
4. Write one sentence: *"The set of all strings over Σ = {…} such that …"*.

> [!important] Strings alone lose half the marks
> Questions say "example strings **and the final output in your words**". Always give both.

### The lecture's examples table (Theory Notes 2)

| RE | Regular set | In words |
|---|---|---|
| `(0 + 10*)` | {0, 1, 10, 100, 1000, …} | either a single 0, or a 1 followed by any number of 0s |
| `(0*10*)` | {1, 01, 10, 010, 0010, …} | all binary strings with **exactly one 1** |
| `(0 + ε)(1 + ε)` | {ε, 0, 1, 01} | optional 0 then optional 1 (a finite set of 4 strings) |
| `(a+b)*` | {ε, a, b, aa, ab, bb, ba, aaa, …} | every string over {a,b}, including ε |
| `(a+b)*abb` | {abb, aabb, babb, aaabb, ababb, …} | strings over {a,b} **ending with abb** |
| `(11)*` | {ε, 11, 1111, 111111, …} | an **even number of 1s**, including ε |
| `(aa)*(bb)*b` | {b, aab, aabbb, aabbbbb, aaaab, aaaabbb, …} | an **even number of a's followed by an odd number of b's** |
| `(aa + ab + ba + bb)*` | {ε, aa, ab, ba, bb, aaab, aaba, …} | all strings over {a,b} of **even length** (ε included) |

> [!note] One correction to the lecture table
> The lecture lists the set of `(aa + ab + ba + bb)*` as `{aa, ab, ba, bb, aaab, aaba, …}` but its own description says "**including null**". ε (zero repetitions) is in the language, so include it.

### More examples from past papers (all checked)

| RE | Example strings | In words |
|---|---|---|
| `(0+1)*011` | 011, 0011, 1011, 10011 | binary strings **ending in 011** |
| `(ε + x)(y + ε)` | ε, x, y, xy | optional x then optional y (exactly 4 strings) |
| `(a+b)((a+b)(a+b))*` | a, b, aaa, aba, bbbab | strings over {a,b} of **odd length** |
| `(aa)*` | ε, aa, aaaa | strings of a's of **even length** |
| `(a + ab)*` | ε, a, ab, aab, abab, aaba | strings over {a,b} that do not start with b and have **no two consecutive b's** (every b comes right after an a) |
| `b*(aaa)*b*` | ε, b, aaa, baaab, bbaaaaaab | some b's, then a number of a's that is a **multiple of 3**, then some b's |

## 2. Writing an RE from a description

**Method:** decide what is **fixed** (start, end, required substring) and what is **free** (anything in between), then concatenate.

| Description | RE | Shortest string |
|---|---|---|
| Starts with 1 and ends with 0, over {0,1} | `1(0+1)*0` | 10 |
| Starts and ends with "a", with any combination of "b"s in between, over {a,b} | `ab*a` | aa |
| (alternative reading: any combination of a's and b's in between) | `a(a+b)*a` | aa |
| Ends with abb | `(a+b)*abb` | abb |
| Contains 01 | `(0+1)*01(0+1)*` | 01 |
| Length exactly 2 over {a,b} (handwritten notes) | `aa + ab + ba + bb` = `(a+b)(a+b)` | (none shorter) |
| Length at most 2 over {a,b} (handwritten notes) | `(ε + a + b)(ε + a + b)` | ε |

> [!tip] "Any combination of b's in between"
> The literal wording means only b's in the middle, so `ab*a` is the answer. Because the phrase could be misread, write `ab*a` and add one line: "if any mix of a and b were allowed, it would be `a(a+b)*a`".
> Watch out: does the string "a" (length 1) count as "starting and ending with a"? The usual answer is no for this pattern. Mention it if you want, for example `a + ab*a`.

## 3. Membership: is a string in an RE? (2020/21 Q6a)

**A = `110*(0+1)`** and **B = `1(0+1)*101`**. Is `1101` acceptable?

- **A:** `1` · `1` · `0*` · `(0+1)` → match `1101` as `1`,`1`,`0` (0* takes one 0),`1` ((0+1) takes 1). ✅ Accepted.
- **B:** `1` · `(0+1)*` · `101` → `1101` = `1` + ε + `101`. ✅ Accepted.
- **Answer: both.** (A separating example: `1100` is in A but not in B.)

## 4. Simplifying: `(aa + ab + ba + bb)*` (2023/24 Q3d)

(i) Each alternative has **length 2**, and the star repeats them, so every string is made of 2-symbol blocks. **Common property: even length** (ε included). The four alternatives are *all* strings of length 2, so **every** even-length string over {a,b} is generated.

(ii) Yes, it can be simplified, using the distributive identity $(P+Q)R = PR + QR$:

$$
(a+b)(a+b) = a(a+b) + b(a+b) = aa + ab + ba + bb
$$

so

$$
(aa + ab + ba + bb)^* = ((a+b)(a+b))^*
$$

"zero or more pairs of symbols". This is the same idea as your handwritten notes' "length exactly 2 = (a+b)(a+b)" example. See [[08.01 Regular Expression Identities]].

## 5. Exam-relevant points
- Always mention whether **ε** is in the language.
- Describe the language in a full sentence beginning *"the set of all strings over … such that …"*.
- For constructions, justify each piece (fixed start, free middle, fixed end) and give the shortest string.
