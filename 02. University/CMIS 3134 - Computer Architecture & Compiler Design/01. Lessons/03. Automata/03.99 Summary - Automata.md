# 03.99 · Lesson Summary: Automata

> [!abstract] Back to [[03.00 Automata]] · Practice: [[PP 03.1 - Automata Theory and Terminology]] · [[PP 03.2 - Acceptability and Designing Automata]]

## Must know
- **Automaton:** from Greek *αὐτόματα* = **"self-acting"**; an abstract self-propelled computing device following a predetermined sequence of operations automatically. **FA/FSM** = automaton with finitely many states.
- **5-tuple:** $(Q, \Sigma, \delta, q_0, F)$ with $q_0 \in Q$, $F \subseteq Q$.
- **DFA:** $\delta: Q \times \Sigma \rightarrow Q$ (exactly one next state). **NDFA:** $\delta: Q \times \Sigma \rightarrow 2^Q$ (any combination of states; $2^Q$ = power set).
- **Acceptance:** $\delta^*(q_0, S) \in F$. NDFA: accepted if **at least one** path ends in a final state.
- $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \dots$ (includes ε); $\Sigma^+ = \Sigma^1 \cup \Sigma^2 \cup \dots = \Sigma^* - \{\varepsilon\}$; $|\Sigma^n| = |\Sigma|^n$.
- **DFA validation rules:** ≥1 state · exactly 1 initial state · ≥1 final state · a transition for **every** input from **every** state · no multiple transitions for one input.
- **Java FSM question:** valid Java → **yes**; never loops forever → **no** (halting problem / undecidable).

## Important definitions
- **Alphabet:** finite set of symbols. **String:** finite sequence of symbols from Σ. **Length** |S| = number of symbols. **Empty string** ε/λ: |ε| = 0. **Language:** subset of Σ* (finite or infinite).
- **Acceptor:** computes a Boolean function (accept/reject). **Classifier:** more than two final states, single output on termination. **Transducer:** output from current input and/or state (Mealy, Moore).

## Important comparisons

| DFA | NDFA |
|---|---|
| one next state | multiple next states |
| no ε-moves | ε-moves allowed |
| backtracking allowed | backtracking not always possible |
| more space | less space |
| accepted if it reaches a final state | accepted if **at least one** path reaches a final state |
| δ: Q × Σ → Q | δ: Q × Σ → 2^Q |
| harder to design, simpler to run | easier to design, harder to run |

| Σ* | Σ⁺ |
|---|---|
| includes ε | excludes ε |

## Important examples
- NDFA "second-last symbol is a": q0 –a→ {q0,q1}, q0 –b→ {q0}, q1 –a,b→ q2 (final).
- DFA "not contains w": build "contains w", then swap final and non-final.
- DFA "even 0s and odd 1s": 4 states (EE, EO, OE, OO), final EO.
- ATM PIN DFA: states (parity of 1s, last symbol) + start + dead; final = (even, last 0).
- Exactly two a's: q0 → q1 → q2 (final) → q3 (dead) on a, b loops. At least two: q2 loops on a, dead state removed.
