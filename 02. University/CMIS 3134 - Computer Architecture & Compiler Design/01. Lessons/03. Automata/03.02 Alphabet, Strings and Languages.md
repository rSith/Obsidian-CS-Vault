# 03.02 · Alphabet, String, Length, Empty String and Language

> [!info] [[03.00 Automata|Lesson 3]] · Theory Notes 3 + Theory Notes 6 + `compier note.pdf` p. 7 · Priority 🔴 High
> **Asked as:** "Briefly explain the following terminologies with suitable example(s): Alphabet, String, Length of a String, Language" (2020/21 Q4b, 2021/22 Q5b) · "Define the following with examples: Alphabet, String, Language, Empty String" (2023/24 Q4b)

## 1. Definitions and examples

| Term | Definition (Theory Notes 3) | Example |
|---|---|---|
| **Alphabet (Σ)** | Any **finite set of symbols** | Σ = {a, b, c, d} where 'a','b','c','d' are symbols. Also Σ = {0, 1} (binary), {0–9, A–F} (hexadecimal) (Theory Notes 6) |
| **String** | A **finite sequence of symbols taken from Σ** | 'cabcad' is a valid string on Σ = {a, b, c, d} |
| **Length of a string \|S\|** | The **number of symbols** present in a string | If S = 'cabcad', \|S\| = 6. \|Lexical\| = 7 (Theory Notes 6) |
| **Empty string (ε or λ)** | The string with **\|S\| = 0**: no symbols at all | ε; \|ε\| = 0 |
| **Language** | A **subset of Σ\*** for some alphabet Σ. It **can be finite or infinite.** | All strings of length 2 over {a, b}: L = {ab, aa, ba, bb} (finite). All strings over {a,b} ending in b (infinite). |

> [!example] Non-example (handwritten notes, p. 7)
> "az" is **not** a string over Σ = {a, b, c, d}, because **z is not in the alphabet**. Giving a non-example shows you understand the rule "symbols taken from Σ".

## 2. The empty string, carefully

- Written **ε** (epsilon) or **λ** (lambda).
- **|ε| = 0.**
- Joining it to any string changes nothing: $\varepsilon w = w \varepsilon = w$.
- $\varepsilon \in \Sigma^*$ but $\varepsilon \notin \Sigma^+$ ([[03.03 Powers of Sigma, Kleene Star and Kleene Plus]]).
- In REs, $L(\varepsilon) = \{\varepsilon\}$ ([[02.03 Notation, Precedence and Recursive Definition]]).

> [!important] ε vs {ε} vs φ
> | Object | What it is | Size |
> |---|---|---|
> | ε | a **string** with no symbols | length 0 |
> | {ε} | a **set** containing the empty string | 1 member |
> | φ = { } | the **empty set** (empty language) | 0 members |

## 3. How the terms connect

```text
Alphabet Σ  ──(sequences of symbols)──►  Strings  ──(collect all of them)──►  Σ*
                                                                            │
                                         Language L  ◄──(choose a subset)──┘
```

Carry **one alphabet through all four definitions** in the exam (for example Σ = {a, b}). It reads as one coherent answer.

## 4. Practical explanation
In a compiler: the alphabet is the character set (letters, digits, symbols); a string is any sequence of characters; the **language of identifiers** is a subset of all strings (those starting with a letter and continuing with letters or digits).

## 5. Exam-relevant points
- Each term: **definition + example** (examples are separately marked).
- Stress **finite** in "finite set of symbols" and "finite sequence".
- Language = **subset of Σ\***, can be **finite or infinite**.
