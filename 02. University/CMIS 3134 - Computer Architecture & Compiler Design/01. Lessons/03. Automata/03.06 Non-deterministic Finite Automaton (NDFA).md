# 03.06 · Non-deterministic Finite Automaton (NDFA / NFA)

> [!info] [[03.00 Automata|Lesson 3]] · Theory Notes 3 + `Compiler note.pdf` (NDFA practice) · Priority 🔴 High
> **Asked as:** "Provide a Formal Definition for an NDFA" (2019/20 Q4a) · "Design an NDFA…" (2019/20 Q4b, 2020/21 Q4c, 2021/22 Q5c) · "Formally prove that every DFA is also an NDFA" (2023/24 Q5a)

## 1. Definition

> [!abstract] Theory Notes 3
> "In NDFA, for a particular input symbol, the machine can **move to any combination of the states** in the machine. In other words, the **exact state to which the machine moves cannot be determined**. Hence, it is called Non-deterministic Automaton."

**Formal definition:** an NDFA is a 5-tuple $(Q, \Sigma, \delta, q_0, F)$ where Q, Σ, $q_0$ and F are as in a DFA and
$$
\delta : Q \times \Sigma \rightarrow 2^Q
$$
("Here the power set of Q ($2^Q$) has been taken because in case of NDFA, from a state, transition can occur to any combination of Q states.")

The graphical representation is the **same as a DFA** (vertices, labelled arcs, empty incoming arc, double circles).

## 2. The lecture's example

Q = {a, b, c}, Σ = {0, 1}, q0 = a, F = {c}

| Present State | Next State for Input 0 | Next State for Input 1 |
|---|---|---|
| → a | a, b | b |
| b | c | a, c |
| \* c | b, c | c |

Entries are **sets**. From a on 0 the machine can go to a **or** b.

## 3. Acceptance in an NDFA

> A string is accepted by an NDFA if **at least one** of all possible transition paths ends in a final state. (Theory Notes 3, DFA vs NDFA table)

The other paths can fail. Only one successful path is needed. Equivalently, track the **set** of states you could be in: accept if that set at the end contains a final state ([[03.09 Acceptability of Strings]]).

## 4. Designing an NDFA: the "guess" idea

An NDFA can **guess** where an important part of the string starts, which makes designs very small. It also does not need a dead state: missing transitions mean "this path dies".

### Example 1: second-last symbol is 'a' over {a, b} (2020/21 Q4c)

| State | a | b |
|---|---|---|
| → q0 | {q0, q1} | {q0} |
| q1 | {q2} | {q2} |
| \* q2 | ∅ | ∅ |

q0 loops on everything; on an **a** it can also **guess** "this is the second-last symbol" and go to q1. Then exactly one more symbol leads to q2. Accepted: ab, aa, bab. Rejected: ba, bb, a.

### Example 2: third-last symbol is 'b' (2021/22 Q5c)

| State | a | b |
|---|---|---|
| → q0 | {q0} | {q0, q1} |
| q1 | {q2} | {q2} |
| q2 | {q3} | {q3} |
| \* q3 | ∅ | ∅ |

General rule: "the n-th last symbol is x" needs **n + 1 states**.

### Example 3: at least 4 a's and beginning with b, over {a, b} (2019/20 Q4b)

| State | a | b | Meaning |
|---|---|---|---|
| → q0 | ∅ | {q1} | must start with b |
| q1 | {q2} | {q1} | 0 a's so far |
| q2 | {q3} | {q2} | 1 a |
| q3 | {q4} | {q3} | 2 a's |
| q4 | {q5} | {q4} | 3 a's |
| \* q5 | {q5} | {q5} | 4 or more a's, anything may follow |

Accepted: baaaa, babaabab. Rejected: aaaab (does not start with b), baaa (only 3 a's).

## 5. Every DFA is an NDFA: formal proof (2023/24 Q5a)

Handwritten notes: "**Every DFA is an NDFA, but every NDFA is not a DFA.**"

**Proof.**
1. Let $D = (Q, \Sigma, \delta_D, q_0, F)$ be any DFA, with $\delta_D : Q \times \Sigma \rightarrow Q$.
2. Build $N = (Q, \Sigma, \delta_N, q_0, F)$ with the same Q, Σ, q0, F and
$$
\delta_N(q, a) = \{\, \delta_D(q, a) \,\}
$$
(the singleton set containing the DFA's next state).
3. $\{\delta_D(q,a)\} \subseteq Q$, so it is an element of $2^Q$. Hence $\delta_N : Q \times \Sigma \rightarrow 2^Q$, and N satisfies the NDFA definition.
4. By induction on the length of w, $\delta_N^*(q_0, w) = \{\delta_D^*(q_0, w)\}$. True for $w = \varepsilon$ (both give $q_0$). If true for w, then for wa the singleton maps to the singleton $\{\delta_D(\delta_D^*(q_0,w), a)\}$.
5. So N accepts w ⟺ $\delta_N^*(q_0,w) \cap F \neq \varnothing$ ⟺ $\delta_D^*(q_0,w) \in F$ ⟺ D accepts w. Therefore $L(N) = L(D)$, and the DFA *is* an NDFA (one that never uses its freedom to branch). ∎

The converse does not hold directly (an NDFA's δ returns sets), but **every NDFA has an equivalent DFA** via [[04.01 NDFA to DFA - Subset Construction|subset construction]].

## 6. Exam-relevant points
- Formal definition: **5-tuple + δ: Q × Σ → 2^Q + power set explanation + acceptance by at least one path**.
- NDFA designs: give the **table with set entries** and the diagram; verify with accepted/rejected strings.
- "Formally prove": use **5-tuples and singleton sets**, not intuition.
