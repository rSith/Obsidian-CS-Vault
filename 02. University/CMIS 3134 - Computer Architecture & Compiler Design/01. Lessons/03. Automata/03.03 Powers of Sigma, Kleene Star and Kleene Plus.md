# 03.03 · Powers of Σ, Kleene Star (Σ*) and Kleene Plus (Σ⁺)

> [!info] [[03.00 Automata|Lesson 3]] · Theory Notes 3 + `compier note.pdf` p. 7 · Priority 🔴 High
> **Asked as:** "What is the power of alphabet (Σ) and cardinality of alphabet (Σ)?" (2020/21 Q6b) · "By using the power and cardinality of Σ, prove that Σ* is the set of all possible strings of all lengths over {p, q}" (2020/21 Q6c) · "What is the Kleene Star (Σ*), and how does it differ from the Kleene Closure (Σ⁺)?" (2022/23 Q4b) · "Show that Σ* is the set of all possible strings of all lengths" (2022/23 Q5a) · "Prove that Σ⁺ = Σ* − {ε}" (2023/24 Q4c)

## 1. Powers of the alphabet, Σⁿ

**Σⁿ** = the set of all strings of **exactly length n** over Σ (handwritten notes call these "powers of sigma").

For Σ = {a, b}:

$$
\begin{aligned}
\Sigma^0 &= \{\varepsilon\} &&\text{(1 string)}\\
\Sigma^1 &= \{a, b\} &&\text{(2 strings)}\\
\Sigma^2 &= \{aa, ab, ba, bb\} &&\text{(4 strings)}\\
\Sigma^3 &= \{aaa, aab, aba, abb, baa, bab, bba, bbb\} &&\text{(8 strings)}
\end{aligned}
$$

## 2. Cardinality

The **cardinality** of a set is the **number of elements** in it, written $|\cdot|$.
- $|\Sigma|$ = number of symbols in the alphabet. For {a, b}, $|\Sigma| = 2$.
- $|\Sigma^n| = |\Sigma|^n$: each of the n positions can hold any of the $|\Sigma|$ symbols.
- For {a, b}: $|\Sigma^2| = 2^2 = 4$, $|\Sigma^3| = 2^3 = 8$.

> [!warning] Beyond the slides
> The phrase "cardinality of alphabet" and the formula $|\Sigma^n| = |\Sigma|^n$ are not written in the notes. The notes list Σ⁰, Σ¹, Σ² … The formula is the standard counting rule, needed for 2020/21 Q6b–c.

## 3. Kleene Star Σ*

> [!abstract] Theory Notes 3
> "The Kleene star, **Σ\***, is a **unary operator** on a set of symbols or strings, Σ, that gives the **infinite set of all possible strings of all possible lengths over Σ including λ**."
> **Representation:** $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots$ where $\Sigma^p$ is the set of all possible strings of length p.
> **Example:** If Σ = {a, b}, Σ* = {λ, a, b, aa, ab, ba, bb, …}

## 4. Kleene Closure / Plus Σ⁺

> [!abstract] Theory Notes 3
> "The set **Σ⁺** is the infinite set of all possible strings of all possible lengths over Σ **excluding λ**."
> **Representation:** $\Sigma^+ = \Sigma^1 \cup \Sigma^2 \cup \Sigma^3 \cup \dots$ and $\Sigma^+ = \Sigma^* - \{\lambda\}$
> **Example:** If Σ = {a, b}, Σ⁺ = {a, b, aa, ab, ba, bb, …}

## 5. Σ* vs Σ⁺

| | Kleene Star Σ* | Kleene Plus Σ⁺ |
|---|---|---|
| Definition | all strings of all lengths | all strings of length ≥ 1 |
| Union of | $\Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots$ | $\Sigma^1 \cup \Sigma^2 \cup \dots$ |
| Contains ε? | **Yes** | **No** |
| Relation | $\Sigma^* = \Sigma^+ \cup \{\varepsilon\}$ | $\Sigma^+ = \Sigma^* - \{\varepsilon\}$ |

**The only difference is the empty string.**

## 6. Proof: $\Sigma^+ = \Sigma^* - \{\varepsilon\}$ (2023/24 Q4c)

**Step 1 (definitions).** $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots$ and $\Sigma^+ = \Sigma^1 \cup \Sigma^2 \cup \dots$

**Step 2.** $\Sigma^0$ is the set of strings of length 0. The only such string is ε, so $\Sigma^0 = \{\varepsilon\}$.

**Step 3 (substitute).**
$$
\Sigma^* = \{\varepsilon\} \cup (\Sigma^1 \cup \Sigma^2 \cup \dots) = \{\varepsilon\} \cup \Sigma^+
$$

**Step 4 (disjoint).** Every string in $\Sigma^+$ has length ≥ 1, but $|\varepsilon| = 0$, so $\varepsilon \notin \Sigma^+$. The sets $\{\varepsilon\}$ and $\Sigma^+$ are **disjoint**.

**Step 5.** Removing ε from both sides of Step 3:
$$
\Sigma^* - \{\varepsilon\} = \Sigma^+ \qquad \blacksquare
$$

*Illustration (Σ = {a,b}):* Σ* = {ε, a, b, aa, ab, …}; remove ε to get {a, b, aa, ab, …} = Σ⁺.

## 7. Proof: Σ* is the set of all strings of all lengths (2020/21 Q6c over {p, q}; 2022/23 Q5a)

Let Σ = {p, q}, so $|\Sigma| = 2$.

**Step 1.** Σⁿ is the set of all strings of exactly length n, with $|\Sigma^n| = 2^n$:

$$
\Sigma^0 = \{\varepsilon\}\;(1),\quad \Sigma^1 = \{p, q\}\;(2),\quad \Sigma^2 = \{pp, pq, qp, qq\}\;(4),\quad \Sigma^3 = \{ppp, ppq, pqp, pqq, qpp, qpq, qqp, qqq\}\;(8)
$$

**Step 2.** By definition $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots$

**Step 3 (⊆).** Every element of Σ* lies in some Σⁿ, so it is a string over Σ of some finite length n.

**Step 4 (⊇).** Take any string w over {p, q}. It has some finite length n, so $w \in \Sigma^n \subseteq \Sigma^*$. **No string is missed.**

**Step 5.** Therefore Σ* is exactly the set of all possible strings of all possible lengths over Σ (including ε). Since n has no upper limit, Σ* is **infinite** even though Σ is finite. ∎

## 8. Exam-relevant points
- Write the **union formulas** for Σ* and Σ⁺; state the **ε difference**.
- In proofs, write **Σ⁰ = {ε}** and argue **disjointness** before subtracting.
- For the "all strings" proof, argue **both directions** (⊆ and ⊇).
