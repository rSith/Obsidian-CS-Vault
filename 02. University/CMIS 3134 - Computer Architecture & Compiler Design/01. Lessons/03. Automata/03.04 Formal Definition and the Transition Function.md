# 03.04 · The Formal Definition (5-tuple) and the Transition Function δ

> [!info] [[03.00 Automata|Lesson 3]] · Theory Notes 3 · Priority 🔴 High
> **Asked as:** "In the 5-tuple (Q, Σ, q0, F, δ) of a finite machine, what role does the transition function (δ) play?" (2022/23 Q4c) · "Explain why in DFA the transition function is δ: Q × Σ → Q while in NDFA it is δ: Q × Σ → 2^Q" (2023/24 Q5c) · formal definitions of DFA/NDFA (4 papers)

## 1. The 5-tuple

> [!abstract] Theory Notes 3
> An automaton can be represented by a **5-tuple (Q, Σ, δ, q0, F)**, where:
> - **Q** is a finite set of states.
> - **Σ** is a finite set of symbols, called the **alphabet** of the automaton.
> - **δ** is the **transition function**.
> - **q0** is the **initial state** from where any input is processed ($q_0 \in Q$).
> - **F** is a set of **final state/states** of Q ($F \subseteq Q$).

$$
M = (Q, \Sigma, \delta, q_0, F)
$$

## 2. The role of δ

δ is the machine's **rule book**. Given the **current state** and the **next input symbol**, it says **which state to move to**. It is what makes the automaton "self-acting" ([[03.01 What is an Automaton]]): every move is decided by δ.

- In a **state diagram**, δ is drawn as the **labelled arrows**.
- In a **transition table**, δ is the **table body** (row = current state, column = input symbol, cell = next state).

## 3. δ for a DFA vs an NDFA

| | DFA | NDFA |
|---|---|---|
| Signature | $\delta : Q \times \Sigma \rightarrow Q$ | $\delta : Q \times \Sigma \rightarrow 2^Q$ |
| Returns | **exactly one** state | a **set** of states (could be empty, one, or many) |
| Meaning | next move is always **determined** | machine can move to **any combination** of states |

**Why $2^Q$?** (2023/24 Q5c) $2^Q$ is the **power set** of Q: the set of **all subsets** of Q. Theory Notes 3: "*Here the power set of Q (2^Q) has been taken because in case of NDFA, from a state, transition can occur to any combination of Q states.*" Since δ returns a **set** of states, its codomain must be the set of all possible sets of states, $2^Q$, which has $2^{|Q|}$ members (including ∅ for "no move" and Q itself).

**Why just Q for a DFA?** "Deterministic" means for every (state, symbol) pair the next state is **unique**, so δ returns **one element of Q**. Consequence: in a DFA, **every state must have exactly one transition for every input symbol**.

**Example** with Q = {a, b, c}:
- DFA: δ(a, 0) = b (one state).
- NDFA: δ(a, 0) = {a, b} (a subset of Q, i.e. an element of $2^Q$), δ(c, 1) = ∅ allowed.
- $2^Q$ = {∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}}: 8 = 2³ subsets.

## 4. Extended transition function δ* and acceptance

δ handles **one** symbol. **δ\*** applies δ repeatedly over a **whole string**:

$$
\delta^*(q, \varepsilon) = q, \qquad \delta^*(q, wa) = \delta(\delta^*(q, w), a)
$$

Theory Notes 3 uses δ* for acceptance: a string S is accepted iff $\delta^*(q_0, S) \in F$. See [[03.09 Acceptability of Strings]].

> [!note] Beyond the slides
> The recursive formula for δ* is the standard definition. The notes use δ* in the acceptance condition but do not define it formally.

## 5. Exam-relevant points
- Define **all five components** before discussing δ.
- δ's role: **current state + input symbol → next state**; drawn as arcs, written as the table.
- DFA vs NDFA signature: **one state vs set of states**; $2^Q$ = power set; NDFA allows ∅ (no move) and ε-moves.
- Mention δ* and $\delta^*(q_0, S) \in F$.
