# 04.04 · Unreachable States, Dead States and Common Mistakes

> [!info] [[04.00 NDFA to DFA Conversion and DFA Minimization|Lesson 4]] · Priority 🟡 Medium
> Needed for the A–G DFA (2019/20 Q5d and 2020/21 Q5d), which contains an unreachable state **F**, and for every subset construction that produces ∅.

> [!warning] Beyond the slides
> The typed lecture notes do not discuss unreachable states. Removing them before minimizing is a standard first step. It is needed to get the correct minimal DFA for the A–G machine in two past papers.

## 1. Unreachable states

A state is **unreachable** if **no string** leads to it from the start state. It can never affect which strings are accepted, so it is **removed before minimizing**.

**How to find them:** start from q0, follow every transition, and list every state you reach (a simple search). Anything not on the list is unreachable.

**Past-paper example (2019/20 Q5d, 2020/21 Q5d):**

| State | 0 | 1 |
|---|---|---|
| → A | B | C |
| \* B | D | E |
| \* C | E | D |
| D | G | G |
| E | G | G |
| F | D | E |
| \* G | G | G |

From A: A → B, C → D, E → G. **F is never reached** (no arrow points into F). Remove F, then minimize {A, B, C, D, E, G}.

> [!tip] What happens if you forget?
> Keeping F gives a 5-state "minimal" DFA {A}, {B,C}, {D,E}, {F}, {G}. The true minimal DFA has **4 states**: {A}, {B,C}, {D,E}, {G}. Say *"F is unreachable from A, so it is removed first"*. That sentence alone earns credit.

## 2. Dead (trap) states

A **dead state** is a non-final state that, once entered, can never lead to acceptance. It has self-loops on every symbol.
- In **DFA design**, you add it to satisfy "every state has a transition for every symbol" (for example the "started with 0" state in the ATM PIN DFA).
- In **subset construction**, the empty set **∅** is the dead state.
- In **minimization**, keep it as a state (it is distinguishable from live non-final states). All dead states merge into one.

## 3. Common mistakes across Lesson 4

| Mistake | Fix |
|---|---|
| Not processing a newly created composite state | Keep a to-do list of states; tick each when its row is done |
| Marking only the "obvious" DFA final state | **Every** set containing an NDFA final state is final |
| Ignoring ∅ | Include ∅ as a dead state in the DFA and in minimization |
| Using the wrong minimization method | Use the method named in the question |
| Stopping Myhill-Nerode after one pass | Repeat until no new marks |
| Not chaining unmarked pairs | {c,d},{c,e},{d,e} together give one state {c,d,e} |
| Forgetting unreachable states | Remove them first |
| No reduced table or diagram | Always finish with both, plus start and final states |
