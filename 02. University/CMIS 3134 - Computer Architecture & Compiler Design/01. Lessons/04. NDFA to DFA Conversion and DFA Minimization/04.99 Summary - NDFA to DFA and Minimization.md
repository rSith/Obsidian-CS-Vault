# 04.99 · Lesson Summary: NDFA → DFA and DFA Minimization

> [!abstract] Back to [[04.00 NDFA to DFA Conversion and DFA Minimization]] · Practice: [[PP 04.1 - NDFA to DFA Conversion]] · [[PP 04.2 - DFA Minimization]]

## Must know
- **Problem:** NDFA X → DFA Y with **L(Y) = L(X)**.
- **Subset construction (6 steps):** NDFA table → blank DFA table → start [q0] → compute the set for each input → repeat for every new set → any set containing an NDFA final state is final. Cell = **union** of the members' transitions. ∅ = **dead state**.
- **Myhill-Nerode (4 steps):** table of all pairs → mark (final, non-final) → repeatedly mark (Qi,Qj) if {δ(Qi,A), δ(Qj,A)} is marked → combine unmarked pairs.
- **Equivalence (Algorithm 3):** P0 = {final}, {non-final} → split groups by k-distinguishability → repeat until **Pk = Pk−1** → groups = new states.
- **Distinguishable:** some string S leads one state to accept and the other to reject. **DFA minimal ⟺ all states distinguishable.**
- Remove **unreachable** states first.

## Lecture example results
- NDFA (a…e, final e) → DFA states [a], [a,b,c,d,e], [d,e], [b,d,e], [e], [c,e], [b], [c] (+ ∅). Finals: the 5 sets containing e.
- 6-state DFA (a…f, finals c,d,e) → minimal **{a,b}, {c,d,e}, {f}** by **both** methods. P0={(c,d,e),(a,b,f)} → P1={(c,d,e),(a,b),(f)} = P2.

## Important comparisons

| Myhill-Nerode | Equivalence theorem |
|---|---|
| pairs, triangular table | partitions P0, P1, … |
| stop when no new marks | stop when Pk = Pk−1 |
| unmarked pairs merge | final groups merge |
