# 04.03 · DFA Minimization using the Equivalence Theorem (Partitioning Method)

> [!info] [[04.00 NDFA to DFA Conversion and DFA Minimization|Lesson 4]] · Theory Notes 4 (Algorithm 3) + `Compiler note.pdf` (0th/1st/nth equivalence) · Priority 🔴 High (all 5 papers, 40 marks)
> **Asked as:** "Minimize the following DFA using (the) Equivalence Theorem" (2019/20 Q5d, 2020/21 Q5d, 2021/22 Q7d, 2022/23 Q7d, 2023/24 Q6d)

## 1. The theorem (quote it)

> [!abstract] Theory Notes 4
> "If X and Y are two states in a DFA, we can **combine these two states into {X, Y} if they are not distinguishable**. Two states are **distinguishable**, if there is **at least one string S**, such that one of δ(X, S) and δ(Y, S) is **accepting** and another is **not accepting**. Hence, **a DFA is minimal if and only if all the states are distinguishable**."

**k-equivalence** (handwritten notes): two states are **k-equivalent** if no string of length ≤ k distinguishes them.
- **0-equivalent:** using only |x| = 0 (the empty string), i.e. both final or both non-final.
- **1-equivalent:** no string of length ≤ 1 separates them, and so on.

## 2. The algorithm (Theory Notes 4, Algorithm 3)

> [!abstract] Algorithm 3
> 1. All the states Q are divided into **two partitions: final states and non-final states**, denoted by **P0**. All the states in a partition are 0th equivalent. Take a counter k and initialize it with 0.
> 2. **Increment k by 1.** For each partition in Pk, **divide the states into two partitions if they are k-distinguishable**. Two states X and Y within a partition are k-distinguishable if there is an input S such that δ(X, S) and δ(Y, S) are (k−1)-distinguishable.
> 3. **If Pk ≠ Pk−1, repeat Step 2**, otherwise go to Step 4.
> 4. **Combine the kth equivalent sets** and make them the new states of the reduced DFA.

**Doing step 2 in practice:** for every state in a group, write down **which group each of its transitions lands in** (its "signature"). States with identical signatures stay together; the rest split off.

## 3. The lecture's worked example

| q | δ(q,0) | δ(q,1) |
|---|---|---|
| → a | b | c |
| b | a | d |
| \* c | e | f |
| \* d | e | f |
| \* e | e | f |
| f | f | f |

**P0** = { (c, d, e) final, (a, b, f) non-final }

**P1:** check signatures (which P0 group each transition goes to; G1 = (c,d,e), G2 = (a,b,f)):

| State | on 0 → group | on 1 → group |
|---|---|---|
| a | b ∈ G2 | c ∈ G1 |
| b | a ∈ G2 | d ∈ G1 |
| f | f ∈ G2 | f ∈ G2 |
| c | e ∈ G1 | f ∈ G2 |
| d | e ∈ G1 | f ∈ G2 |
| e | e ∈ G1 | f ∈ G2 |

a and b agree; f differs, so it splits off. c, d, e agree.
**P1** = { (c, d, e), (a, b), (f) }

**P2:** recompute with P1's groups: a → (b, c) lands in ((a,b), (c,d,e)); b → (a, d) lands in ((a,b), (c,d,e)); same. c, d, e all → ((c,d,e), (f)); same.
**P2** = { (c, d, e), (a, b), (f) } = P1, so **stop**.

**Reduced DFA (3 states):**

| Q | δ(q,0) | δ(q,1) |
|---|---|---|
| → (a, b) | (a, b) | (c, d, e) |
| \* (c, d, e) | (c, d, e) | (f) |
| (f) | (f) | (f) |

## 4. Myhill-Nerode vs Equivalence theorem

| | Myhill-Nerode | Equivalence theorem |
|---|---|---|
| Works on | **Pairs** of states | **Groups (partitions)** of states |
| Start | Mark all (final, non-final) pairs | P0 = {final}, {non-final} |
| Step | Mark a pair if some input leads to a marked pair | Split a group if its states' transitions land in different groups |
| Stop when | A full pass marks nothing new | Pk = Pk−1 |
| Result | Unmarked pairs (chained) = merged states | Final partition = new states |
| Good for | Small machines; shows exactly why two states differ | Larger machines; fewer individual checks |

Both always give the **same** (unique) minimal DFA. **If the question names a method, use that method.** The other one will not earn the method marks.
