# 08.01 · Regular Expression Identities (Algebraic Laws)

> [!info] [[08.00 Arden's Theorem and RE-FA Conversion|Lesson 8]] · `Compiler note.pdf` pp. 31–33 · Priority 🟡 Medium
> **Asked as:** "Prove that (0110 + 01)(10)\* is equal to 01(10)\*" (2019/20 Q2d, 40 marks) · "Can this language be described by a simpler expression?" (2023/24 Q3d(ii))
> Theory Notes 2 also mentions: "There are a number of **algebraic laws** that are obeyed by regular expressions, which can be used to manipulate regular expressions into **equivalent forms**."

## 1. The 12 identities (handwritten notes)

| # | Identity | Meaning in words |
|---|---|---|
| 1 | $\varphi + R = R$ | Adding the empty set changes nothing |
| 2 | $\varphi R = R \varphi = \varphi$ | Concatenating with the empty set gives the empty set |
| 3 | $\varepsilon R = R \varepsilon = R$ | ε is the identity for concatenation |
| 4 | $\varepsilon^* = \varepsilon$, $\varphi^* = \varepsilon$ | Repeating nothing gives only the empty string |
| 5 | $R + R = R$ | Union of a set with itself is the same set |
| 6 | $R^* R^* = R^*$ | Zero-or-more twice is still zero-or-more |
| 7 | $R R^* = R^* R = R^+$ | One copy followed by zero-or-more = one-or-more |
| 8 | $(R^*)^* = R^*$ | Star of a star is just star |
| 9 | $\varepsilon + R^* R = \varepsilon + R R^* = R^*$ | "nothing, or one-or-more" = zero-or-more (**key to Arden's proof**) |
| 10 | $(PQ)^* P = P (QP)^*$ | A factor can be shifted across a star |
| 11 | $(P + Q)^* = (P^* Q^*)^* = (P^* + Q^*)^*$ | Any mixture of P's and Q's |
| 12 | $(P + Q) R = PR + QR$ | Concatenation distributes over union (also $R(P+Q) = RP + RQ$) |

**Notes' warnings:** in identity 12, order matters: $PR + QR \neq RP + RQ$ in general. In identity 10, $(PQ)^*P \neq P(PQ)^*$.

**Why identity 9 holds:** $R^* = \varepsilon + R + RR + RRR + \dots$ and $R^*R = R + RR + RRR + \dots = R^+$. Adding ε to $R^+$ gives $R^*$.

## 2. Worked proof from the notes

$$
(1 + 00^*1) + (1 + 00^*1)(0 + 10^*1)^*(0 + 10^*1) = 0^*1(0 + 10^*1)^*
$$

1. Take out the common factor $(1 + 00^*1)$: $(1 + 00^*1)\,[\varepsilon + (0 + 10^*1)^*(0 + 10^*1)]$ (identities 3 and 12).
2. With $R = (0 + 10^*1)$: $\varepsilon + R^*R = R^*$ (identity 9), giving $(1 + 00^*1)(0 + 10^*1)^*$.
3. $1 + 00^*1 = (\varepsilon + 00^*)1 = 0^*1$ (identity 12, then identity 9 with R = 0).
4. Result: $0^*1(0 + 10^*1)^*$ = RHS. ∎

## 3. Worked simplifications from the notes

- **Length exactly 2 over {a,b}:** $aa + ab + ba + bb = a(a+b) + b(a+b) = (a+b)(a+b)$.
- **Length exactly 3:** $(a+b)(a+b)(a+b)$.
- **Length at most 2:** $\varepsilon + a + b + aa + ab + ba + bb = (\varepsilon + a + b)(\varepsilon + a + b)$.

## 4. Past paper: prove $(0110 + 01)(10)^* = 01(10)^*$ (2019/20 Q2d)

$$
\begin{aligned}
(0110 + 01)(10)^* &= (01 \cdot 10 + 01 \cdot \varepsilon)(10)^* && \text{identity 3: } 01 = 01\varepsilon \\
&= 01(10 + \varepsilon)(10)^* && \text{identity 12 (factor out 01)} \\
&= 01\,[\,10(10)^* + \varepsilon(10)^*\,] && \text{identity 12} \\
&= 01\,[\,(10)^+ + (10)^*\,] && \text{identities 7 and 3} \\
&= 01\,[\,\varepsilon + (10)^+ + (10)^+\,] && \text{since } (10)^* = \varepsilon + (10)^+ \text{ (identity 9)} \\
&= 01\,[\,\varepsilon + (10)^+\,] && \text{identity 5: } R + R = R \\
&= 01(10)^* && \text{identity 9} \qquad \blacksquare
\end{aligned}
$$

**Verification by strings:** both sides give 01, 0110, 011010, 01101010, … (checked by computer for every string up to length 11).

## 5. Past paper: simplify $(aa + ab + ba + bb)^*$ (2023/24 Q3d(ii))

$aa + ab + ba + bb = (a+b)(a+b)$ (as in §3), so $(aa + ab + ba + bb)^* = ((a+b)(a+b))^*$, the set of all even-length strings over {a,b}.
