# 08.99 · Lesson Summary: Arden's Theorem, RE Identities and RE ⇄ FA

> [!abstract] Back to [[08.00 Arden's Theorem and RE-FA Conversion]] · Practice: [[PP 08 - Arden's Theorem and RE-FA Conversion]]

## Must know
- **Arden's Theorem:** if P and Q are REs over Σ and **P does not contain ε**, then $R = Q + RP$ has the **unique** solution $R = QP^*$.
- **Proof, Part 1:** $Q + QP^*P = Q(\varepsilon + P^*P) = QP^*$.
- **Proof, Part 2:** substitute repeatedly to get $R = Q(\varepsilon + P + \dots + P^n) + RP^{n+1}$. Since P has no ε, strings in $RP^{n+1}$ have length > n; choose n > |w|, so every w ∈ R lies in QP\*. Hence unique.
- **Why "no ε in P":** otherwise R = a + R has many solutions.
- **FA → RE:** one equation per state from **incoming** arrows, **+ε** on the start state, solve with Arden, answer = final state(s).
- **RE → FA rules:** (a+b): A –a,b→ B · (a.b): A –a→ B –b→ C · a\*: one final state with a self-loop · a⁺: A –a→ B, B self-loop.
- **Pipeline question:** (a) Arden → (b) NDFA → (c) subset construction (+ ∅) → (d) minimize (named method).

## Key identities

| | |
|---|---|
| φ + R = R | φR = Rφ = φ |
| εR = Rε = R | ε\* = ε, φ\* = ε |
| R + R = R | R\*R\* = R\* |
| RR\* = R\*R = R⁺ | (R\*)\* = R\* |
| **ε + R\*R = R\*** | (PQ)\*P = P(QP)\* |
| (P+Q)\* = (P\*Q\*)\* = (P\*+Q\*)\* | (P+Q)R = PR + QR |

## Past-paper results (all checked)
- $(0110 + 01)(10)^* = 01(10)^*$: factor 01(10 + ε), then (ε + 10)(10)\* = (10)\*.
- $(aa+ab+ba+bb)^* = ((a+b)(a+b))^*$ (even length).
- FA (A,B,C) → RE: $(b + a(a+ba)^*bb)^*\,a(a+ba)^*b$ ≡ **(a+b)\*ab**.
- `0* + 0*11*` → 2 states (q0 final with 0-loop; q0 –1→ q1 final with 1-loop) = 0\*1\*.
- `(01+10)*` → q0 (start, final), q0 –0→ q1 –1→ q0, q0 –1→ q2 –0→ q0.
- `10 + (0+11)0*1` → NDFA A,B,C,D,E → DFA [A],[D],[B,E],[C],∅ → **already minimal**.
- `ab* + (a+bb)a*b*` → NDFA q0–q4 → 7-state DFA → **5 states** ([q1,q2]≡[q2], [q1,q4]≡[q4]).
