# 08.02 · Arden's Theorem

> [!info] [[08.00 Arden's Theorem and RE-FA Conversion|Lesson 8]] · `Compiler note.pdf` p. 34 · Priority 🔴 High (**all 5 papers**, 20 marks)
> **Asked as (almost word for word every year):** "State Arden's Theorem and prove that R = QP\* is a solution, and it is the one and only unique solution of it. (Suppose that P, Q, and R are regular expressions)" (2019/20 Q5a, 2020/21 Q5a, 2021/22 Q6a, 2022/23 Q6a, 2023/24 Q7a: "…is a solution of R = Q + RP, and it is the only unique solution of it")

## 1. Statement (memorise)

> [!abstract] Arden's Theorem (handwritten notes)
> If **P and Q are two regular expressions over Σ**, and if **P does not contain ε**, then the following equation in R given by
> $$ R = Q + RP $$
> has a **unique solution** given by
> $$ R = QP^* $$

**In words:** an equation where R appears on its own right side, followed by P, is solved by "Q followed by any number of P's".

**Why it is useful:** it is the tool for converting a finite automaton into a regular expression ([[08.03 Finite Automaton to Regular Expression]]).

## 2. Proof, Part 1: R = QP\* is a solution

Substitute $R = QP^*$ into the right-hand side:

$$
\begin{aligned}
Q + RP &= Q + (QP^*)P \\
&= Q(\varepsilon + P^*P) && \text{(take out Q; } Q = Q\varepsilon\text{)} \\
&= Q(\varepsilon + P^+) && (P^*P = P^+) \\
&= QP^* && (\varepsilon + P^+ = P^*) \\
&= R
\end{aligned}
$$

The right-hand side equals R, so $R = QP^*$ satisfies the equation. **It is a solution.**

## 3. Proof, Part 2: it is the only (unique) solution

Start from $R = Q + RP$ and **substitute R into itself repeatedly**:

$$
\begin{aligned}
R &= Q + RP \\
&= Q + (Q + RP)P = Q + QP + RP^2 \\
&= Q + QP + (Q + RP)P^2 = Q + QP + QP^2 + RP^3 \\
&\;\;\vdots \\
&= Q + QP + QP^2 + \dots + QP^n + RP^{n+1} \\
&= Q(\varepsilon + P + P^2 + \dots + P^n) + RP^{n+1} \qquad (\star)
\end{aligned}
$$

**Use the condition "P does not contain ε".** Every string in P has length ≥ 1, so every string in $P^{n+1}$ has length ≥ n + 1, and every string in $RP^{n+1}$ has length **≥ n + 1**.

Take **any** string w in R, and let |w| = k. Choose n ≥ k. Then w is too short to belong to $RP^{n+1}$, so by $(\star)$:

$$
w \in Q(\varepsilon + P + P^2 + \dots + P^n) \subseteq QP^*
$$

So **every string of R is in QP\***, i.e. $R \subseteq QP^*$. Part 1 showed that QP\* satisfies the equation, and the same expansion $(\star)$ shows that any solution contains $Q(\varepsilon + P + \dots + P^n)$ for every n, so $QP^* \subseteq R$. Therefore

$$
R = QP^* \quad \text{is the one and only solution.} \qquad \blacksquare
$$

> [!note] How your handwritten notes finish Part 2
> The notes reach $R = Q + QP + QP^2 + \dots + QP^n + RP^{n+1}$, then substitute $R = QP^*$ to get $Q(\varepsilon + P + P^2 + \dots + P^n + P^*P^{n+1}) = QP^*$. That shows consistency. The **length argument** above (using "P does not contain ε") is what actually proves uniqueness, and it is the standard textbook proof. Write it: it is where the last marks are.

## 4. Why "P does not contain ε" matters

If P contains ε, then $RP \supseteq R$, so the equation $R = Q + RP$ is satisfied by many different R. **Example:** P = ε, Q = a. The equation is R = a + R, which is true for R = a, R = a + b, R = (a+b)\*, … so the solution is **not unique**. Always state this.

## 5. Exam checklist (20 marks, about 6 minutes)
- [ ] Full **statement**, including **"P does not contain ε"**.
- [ ] **Part 1:** substitute, factor, use $\varepsilon + P^*P = P^*$ (name the identity).
- [ ] **Part 2:** at least **three substitution steps**, then the general form with $RP^{n+1}$.
- [ ] Length argument using the ε-free condition, then conclude $R = QP^*$ is unique.
- [ ] (Bonus) Counter-example showing why P must not contain ε.
