# 08.03 · Finite Automaton → Regular Expression (using Arden's Theorem)

> [!info] [[08.00 Arden's Theorem and RE-FA Conversion|Lesson 8]] · `Compiler note.pdf` pp. 34–35 · Priority 🟡 Medium
> **Asked as:** "Convert the following Finite Machine into Regular Expression." (2019/20 Q5c, 2020/21 Q5c; the same 3-state machine A, B, C both years)

## 1. Method (handwritten notes)

1. **Write one equation per state.** A state equals the **sum of (source state)·(input symbol)** over every arrow **coming into** it.
   Notation: $q_2 = q_1 a + q_2 b$ means "reach q2 from q1 on a, or from q2 on b". (The notes sometimes write $aq_1$ for $q_1 a$. Read it the same way.)
2. **Add ε to the start state's equation.** You are in the start state having read nothing.
3. **Solve by substitution.** Whenever an equation has the shape $R = Q + RP$, apply [[08.02 Arden's Theorem|Arden's theorem]]: $R = QP^*$.
4. The RE for the **final state** is the answer. With several final states, take the **union** (+) of their REs.

> [!important] Incoming, not outgoing
> Build each equation from the arrows **entering** the state. Using outgoing arrows is the most common mistake, and it ruins the whole answer.

## 2. Example from the handwritten notes

Machine: q1 (start, final) loops on 0; q1 –1→ q2; q2 (final) loops on 1; q2 –0→ q3; q3 loops on 0, 1 (dead).

Equations:
$$
q_1 = \varepsilon + q_1 0 \qquad q_2 = q_1 1 + q_2 1 \qquad q_3 = q_2 0 + q_3 0 + q_3 1
$$

- $q_1 = \varepsilon + q_1 0$ has the form R = Q + RP with Q = ε, P = 0, so $q_1 = \varepsilon 0^* = 0^*$.
- $q_2 = q_1 1 + q_2 1 = 0^*1 + q_2 1$ has the form R = Q + RP with Q = 0\*1, P = 1, so $q_2 = 0^*1 1^*$.
- Finals are q1 and q2: $RE = q_1 + q_2 = 0^* + 0^*11^* = 0^*(\varepsilon + 11^*) = 0^*1^*$ (identity 9).

**Answer: 0\*1\*.** (q3 is a dead state and is not needed.)

## 3. Past-paper machine (2019/20 Q5c and 2020/21 Q5c)

Machine: **A** (start): b → A, a → B. **B**: a → B, b → C. **C** (final): b → A, a → B.

| State | Arrows coming in | Equation |
|---|---|---|
| A | from A on b, from C on b, + ε (start) | $A = \varepsilon + Ab + Cb$ |
| B | from A on a, B on a, C on a | $B = Aa + Ba + Ca$ |
| C | from B on b | $C = Bb$ |

**Solve:**
1. Substitute C = Bb into B: $B = Aa + Ba + Bba = Aa + B(a + ba)$. Arden (Q = Aa, P = a + ba, and P contains no ε): $B = Aa(a + ba)^*$.
2. Then $C = Bb = Aa(a+ba)^*b$.
3. Substitute into A: $A = \varepsilon + Ab + Aa(a+ba)^*bb = \varepsilon + A\,(b + a(a+ba)^*bb)$. Arden (Q = ε): $A = (b + a(a+ba)^*bb)^*$.
4. Final state C:
$$
\boxed{C = (b + a(a+ba)^*bb)^*\; a(a+ba)^*\, b}
$$

**Simplification / check:** the machine accepts exactly the strings over {a,b} that **end with "ab"**: A = "no useful suffix", B = "last symbol a", C = "last two symbols ab". So the answer is equivalent to **(a + b)\*ab** (checked by computer for all strings up to length 11). Writing the Arden result and then noting the simpler equivalent form shows full understanding.

> [!note] The same machine appears again
> 2022/23 Q4d asks for acceptability on this same A/B/C machine. Knowing that it means "ends with ab" lets you check those traces instantly.

## 4. Exam checklist
- [ ] State Arden's theorem at the top (it earns marks on its own).
- [ ] One equation per state from **incoming** arrows; **ε** in the start state's equation.
- [ ] At each Arden step, name Q and P.
- [ ] Final answer = RE of the final state(s), union if several.
- [ ] Simplify if possible and verify with a couple of strings.
