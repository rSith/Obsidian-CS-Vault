# 05.99 · Lesson Summary: Moore and Mealy Machines

> [!abstract] Back to [[05.00 Moore and Mealy Machines]] · Practice: [[PP 05 - Moore and Mealy Machines]]

## Must know
- Both are **finite automata with output** (transducers), with **6-tuple (Q, Σ, O, δ, X, q0)**, $\delta: Q \times \Sigma \rightarrow Q$.
- **Mealy:** $X: Q \times \Sigma \rightarrow O$, output depends on **state + input**, written on **arrows** (`0/1`). Output length = **n**.
- **Moore:** $X: Q \rightarrow O$, output depends on **state only**, written **in states** (`q1/0`). Output length = **n + 1**.
- **Table recognition:** `q3/0` cells = Mealy; a separate Output column = Moore.

## Algorithms
**Moore → Mealy (Algorithm 4):** (1) blank Mealy table, (2) copy all transitions, (3) for state Qi with output m, write m wherever Qi appears as a **next state**. Same number of states.

**Mealy → Moore (Algorithm 5):** (1) count the distinct outputs on transitions **entering** each Qi, (2) same output → keep Qi; n outputs → split into Qi0, Qi1 … (copies share outgoing transitions), (3) if the initial state's output is 1, add a new initial state with output 0.

## Important comparisons

| Mealy | Moore |
|---|---|
| state + input | state only |
| fewer states | more states |
| reacts in same clock cycle | one clock cycle later; more decode logic, more delay |
| output = function of transitions | output = function of current state at clock edges |
| n outputs | n + 1 outputs |

## Key designs
- 1's complement: 1 state, `0/1`, `1/0`.
- "M after 01, N after 10, O otherwise" (Mealy): q0, qA (last 0), qB (last 1); qA –1/M→ qB, qB –0/N→ qA.
- Vending (5, 10; dispense at ≥ 20): S0, S5, S10, S15; S10 –10/D→ S0, S15 –5/D,10/D→ S0. Moore form adds S0D (output D).
- Moore "101 → a, 110 → b": 6 states S0, S1, S10, S11, SA(a), SB(b).
