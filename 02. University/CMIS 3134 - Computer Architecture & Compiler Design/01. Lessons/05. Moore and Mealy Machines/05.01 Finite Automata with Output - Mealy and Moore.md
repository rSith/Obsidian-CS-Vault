# 05.01 · Finite Automata with Output: Mealy and Moore Machines

> [!info] [[05.00 Moore and Mealy Machines|Lesson 5]] · Theory Notes 5 + `Compiler note.pdf` · Priority 🔴 High

> [!abstract] Theory Notes 5
> "Finite automata may have **outputs corresponding to each transition**. There are two types of finite state machines that generate output: **Mealy Machine** and **Moore machine**."

## 1. Mealy Machine

> [!abstract] Theory Notes 5
> "A Mealy Machine is an FSM whose **output depends on the present state as well as the present input**. It can be described by a **6 tuple (Q, Σ, O, δ, X, q0)** where:
> - Q is a finite set of states.
> - Σ is a finite set of symbols called the **input alphabet**.
> - O is a finite set of symbols called the **output alphabet**.
> - δ is the input transition function where $\delta: Q \times \Sigma \rightarrow Q$
> - X is the output transition function where $X: Q \times \Sigma \rightarrow O$
> - q0 is the initial state from where any input is processed ($q_0 \in Q$)."

**State table (lecture example).** Each input column holds **next state AND output**:

| Present state | input 0: State | input 0: Output | input 1: State | input 1: Output |
|---|---|---|---|---|
| → a | b | x1 | c | x1 |
| b | b | x2 | d | x3 |
| c | d | x3 | c | x1 |
| d | d | x3 | d | x2 |

In the papers this is written compactly as `next/output`, e.g. `b/x1`. **On the diagram, the output goes on the arrow:** `0/x1`.

## 2. Moore Machine

> [!abstract] Theory Notes 5
> "Moore machine is an FSM whose **outputs depend on only the present state**. A Moore machine can be described by a **6 tuple (Q, Σ, O, δ, X, q0)** where … δ is the input transition function where $\delta: Q \times \Sigma \rightarrow Q$, and **X is the output transition function where $X: Q \rightarrow O$**."

**State table (lecture example).** The input columns hold only the next state, plus **one Output column**:

| Present state | Next (input 0) | Next (input 1) | Output |
|---|---|---|---|
| → a | b | c | x2 |
| b | b | d | x1 |
| c | c | d | x2 |
| d | d | d | x3 |

**On the diagram, the output goes inside the state:** e.g. `a/x2`.

> [!tip] Recognise the table type first
> **`q3/0` in the cells means Mealy. A separate "Output" column means Moore.** Always check this before starting a conversion question.

## 3. Output length (handwritten notes)

| Machine | Output length for an input of length n |
|---|---|
| **Mealy** | **n** (one output per transition) |
| **Moore** | **n + 1** (one output for the start state *before* reading anything, then one per transition) |

**Worked trace (illustrative):** a Moore machine that outputs the last bit read (start state outputs 0):

| State | 0 | 1 | Output |
|---|---|---|---|
| → S0 | S0 | S1 | 0 |
| S1 | S0 | S1 | 1 |

Input `1101`: states S0 → S1 → S1 → S0 → S1, so the outputs are **0 1 1 0 1**: 5 symbols for 4 inputs.
The equivalent Mealy machine gives **1 1 0 1**: 4 symbols, the same as Moore's output without its first symbol.

## 4. Formal definitions side by side

$$
\text{Mealy: } (Q, \Sigma, O, \delta, X, q_0),\; X: Q \times \Sigma \rightarrow O
\qquad
\text{Moore: } (Q, \Sigma, O, \delta, X, q_0),\; X: Q \rightarrow O
$$

The handwritten notes use the letters $(Q, I, \Delta, \delta, \lambda, q_0)$: I for input alphabet, Δ for output alphabet, λ for the output function. Same meaning.

## 5. Practical explanation
- A **vending machine** that dispenses as soon as the coin that completes the price is inserted is naturally **Mealy** (output depends on the coin just inserted).
- A **traffic light** whose colour depends only on its current phase is naturally **Moore**.
