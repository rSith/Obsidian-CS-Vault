# 05.03 · Moore → Mealy Conversion (Algorithm 4)

> [!info] [[05.00 Moore and Mealy Machines|Lesson 5]] · Theory Notes 5 · Priority 🔴 High (all 5 papers)
> **Asked as:** "Convert the following Moore machine into the Mealy machine." (2019/20 Q6b, 2020/21 Q8b, 2021/22 Q7b, 2022/23 Q7b, 2023/24 Q6c)

## 1. The algorithm

> [!abstract] Theory Notes 5: Algorithm 4
> **Input:** Moore machine · **Output:** Mealy machine
> 1. Take a **blank Mealy Machine transition table** format.
> 2. **Copy all the Moore Machine transition states** into this table format.
> 3. Check the present states and their corresponding outputs in the Moore Machine state table; **if for a state Qi output is m, copy it into the output columns of the Mealy Machine state table wherever Qi appears in the next state**.

**In one sentence:** the output that belongs to a state **moves onto every arrow pointing into that state**. The transitions (δ) do not change, and **the number of states does not change**. This is the easy direction.

## 2. The lecture's worked example

Moore machine:

| Present State | Next (a=0) | Next (a=1) | Output |
|---|---|---|---|
| → a | d | b | 1 |
| b | a | d | 0 |
| c | c | c | 0 |
| d | b | a | 1 |

Steps 1 & 2 (copy transitions), then Step 3 (write the output of the **next** state):

| Present State | a=0: State | a=0: Output | a=1: State | a=1: Output |
|---|---|---|---|---|
| → a | d | **1** | b | **0** |
| b | a | **1** | d | **1** |
| c | c | **0** | c | **0** |
| d | b | **0** | a | **1** |

Example cell: δ(a, 0) = d, and d's Moore output is 1, so the Mealy entry is **d/1**.

> [!note] Same machine as the papers
> The 2020/21 Q8b and 2022/23 Q7b Moore machine is **this exact machine** with a, b, c, d renamed q0, q1, q2, q3 (and inputs a=0, a=1 written as 0, 1). Likewise, the q0–q3 **Mealy** table in 2019/20 Q6c, 2020/21 Q8c and 2022/23 Q7c is the lecture's Mealy example from [[05.04 Mealy to Moore Conversion]], renamed the same way. Full answers: [[PP 05 - Moore and Mealy Machines]].

## 3. Checking your answer
Run one input on both machines. The **Mealy output = the Moore output with its first symbol removed**.
