# 07.06 · Language of a Grammar, Proofs, and "Does G Generate w?"

> [!info] [[07.00 Syntax Analysis|Lesson 7]] · Theory Notes 7 + `Compiler note.pdf` pp. 37–39 · Priority 🔴 High
> **Asked as:** "Find out the language can be generated" (2021/22 Q8a) · "What is the language generated by this grammar? Derive the string…" (2022/23 Q8a, 2023/24 Q8a) · "Prove that the grammar generates all strings of the form aⁿb / all strings with an equal number of a's and b's" (2022/23 Q8d, 2023/24 Q8d) · "Verify whether the grammar … generates the following string(s) or not" (2019/20 Q7c, 2020/21 Q7d, 2021/22 Q8d)

> [!warning] Beyond the slides
> The lecture notes show how to derive strings, and the handwritten notes find languages from simple grammars (e.g. $a^n b^n$). The **proof methods** below (induction, the "invariant" trick) are standard techniques, not written in the notes. They are what these 40-mark questions need.

## 1. Finding the language of a grammar

1. **Generate** the shortest strings (apply the non-recursive rules), then one or two levels of the recursive rules.
2. **Spot the pattern** (counts, order, symmetry).
3. **State it** in set-builder notation and in words.
4. **Justify** (induction on the number of rule applications).

**Example (2021/22 Q8a):** `S → aSbb | abb`
- Strings: abb → a(abb)bb = aabbbb → aaabbbbbb …
- Each S → aSbb adds **one a and two b's**.
- $L(G) = \{ a^n b^{2n} \mid n \ge 1 \}$: n a's followed by twice as many b's. **n ≥ 1**, because there is no ε-rule, so the empty string is not included.
- Induction: base abb = a¹b²; if S ⇒* aⁿb²ⁿ then S ⇒ aSbb ⇒* a·aⁿb²ⁿ·bb = aⁿ⁺¹b²⁽ⁿ⁺¹⁾.

## 2. The invariant trick (for counting properties)

Define $d(w) = \#_a(w) - \#_b(w)$ (or $\#_b - \#_a$). Check what **each production** does to d. If every production keeps a property true, then every generated string has that property. This proves the **⊆** direction.

To prove **⊇** (every string with the property is generated), give a **construction** or use **induction on length**.

## 3. Worked proof: `S → aSb | bSa | SS | ε` generates exactly the strings with equal numbers of a's and b's (2022/23 Q8d(ii), 2023/24 Q8d(ii))

**(⊆) Every generated string is balanced.** Let $d(w) = \#_a(w) - \#_b(w)$.
- S → ε: d = 0.
- S → aSb: adds one a and one b, so d is unchanged.
- S → bSa: same.
- S → SS: d = d(first) + d(second) = 0 + 0 = 0.
Every production preserves d = 0, so every string in L(G) has equal numbers of a's and b's.

**(⊇) Every balanced string is generated.** By strong induction on |w|.
- Base: |w| = 0, so w = ε, generated by S → ε.
- Step: let w be balanced, |w| > 0. Read w from left to right, tracking d of the prefix read so far.
  - **Case 1:** d returns to 0 at some point **before the end**. Then w = uv with u and v both balanced, non-empty and shorter. Use S → SS and the induction hypothesis on u and v.
  - **Case 2:** d first returns to 0 **only at the end**. Then the first and last symbols must be different (if w starts with a, d goes positive and the final step back to 0 must be a b). So w = a x b or w = b x a, with x balanced and shorter. Use S → aSb or S → bSa and the induction hypothesis on x.

So L(G) = {w ∈ {a,b}* : #a(w) = #b(w)}. ∎

## 4. Worked proof: `S → AB | aB, A → a | Aa, B → b` generates all strings aⁿb, n ≥ 1 (2022/23 Q8d(i), 2023/24 Q8d(i))

- **B** generates exactly {b}.
- **A** generates $a^+$: base A → a gives a¹; step A → Aa turns aᵏ into aᵏ⁺¹. So A ⇒* aⁿ for every n ≥ 1, and nothing else.
- **(⊆)** S → AB gives aⁿ·b (n ≥ 1). S → aB gives ab = a¹b. Every string has the form aⁿb, n ≥ 1.
- **(⊇)** For any n ≥ 1: S ⇒ AB, apply A → Aa (n − 1) times then A → a to get aⁿ, then B → b. So aⁿb is generated. ∎
- Remark: S → aB only repeats the n = 1 case, so the grammar is **ambiguous** for `ab` (and `aab` in 2021/22 Q8b uses the similar S → aaB).

## 5. The language of `S → aSb | bSa | ab | ba` (2022/23 Q8a, 2023/24 Q8a)

- Strings: ab, ba; then aabb, abab, baba, bbaa; then aaabbb, aababb, abaabb, …
- Each rule adds **one symbol at each end**, and the two added symbols are **always different** (a…b or b…a). The base cases ab, ba do the same.
- **Language:** all non-empty even-length strings $w = w_1 w_2 \dots w_{2n}$ over {a,b} such that $w_i \neq w_{2n+1-i}$ for every i, i.e. the second half is the **reverse of the first half with a and b swapped**.
- Consequence: every such string has equal numbers of a's and b's (but not every balanced string is included: `abba` is balanced but not generated).

**Derive "aabbab"? It cannot be derived.** Positions 2 and 5 are both **a**, but the grammar always puts *different* symbols in matching positions. Attempt: S ⇒ aSb (first a, last b ✔). The inner S must produce `abba`, which starts and ends with the same symbol, so none of aSb, bSa, ab, ba applies. **Not in L(G).**
A derivable string of the same length: **aababb**: S ⇒ aSb ⇒ aaSbb ⇒ aababb.

> [!warning] What to write in the exam
> Show the attempt, show exactly where it blocks, give the reason (matching positions must differ), then demonstrate the technique on a nearby derivable string. That earns the method marks, and it is the honest answer. (Checked by computer: "aabbab" ∉ L(G).)

## 6. "Does the grammar generate w?": `S → aB | bA, A → aS | bAA | ε, B → b | bS | aBB` (2020/21 Q7d, 2021/22 Q8d; also used in 2022/23 & 2023/24 Q8c)

> [!important] The grammar as printed has A → ε (not A → a)
> The well-known textbook grammar for "equal a's and b's" is S → aB | bA, A → **a** | aS | bAA, B → b | bS | aBB. The papers print **A → ε** instead. This changes the language completely: with A → ε, S ⇒ bA ⇒ **b**, which is not balanced.

**Invariants for the grammar as printed** (proved by induction over the productions):
1. Let $d = \#_b - \#_a$. Then $d(S) \ge 0$, $d(A) \ge -1$, $d(B) \ge 1$.
   *Check:* S → aB: −1 + d(B) ≥ 0. S → bA: 1 + d(A) ≥ 0. A → ε: 0. A → aS: −1 + d(S) ≥ −1. A → bAA: 1 + 2d(A) ≥ −1. B → b: 1. B → bS: 1 + d(S) ≥ 1. B → aBB: −1 + 2d(B) ≥ 1. ✔
   So **every string generated from S has at least as many b's as a's.**
2. **Every non-empty string generated from S ends with b** (B always ends with b; A is ε or ends with b; so S → aB and S → bA both end with b).

| String | a's | b's | Last symbol | Generated? | Reason |
|---|---|---|---|---|---|
| aababab | 4 | 3 | b | **No** | #b < #a (breaks invariant 1) |
| bbabaababbba | 5 | 7 | a | **No** | ends with a (breaks invariant 2) |
| aaaaabbbb | 5 | 4 | b | **No** | #b < #a |
| abababbbbaaa | 6 | 6 | a | **No** | ends with a |

All four results were checked by computer with a complete parser.

**Under the textbook grammar (A → a)**, S generates exactly the strings with **equal** numbers of a's and b's (excluding ε). Then aababab (4 a, 3 b), aaaaabbbb (5 a, 4 b) and bbabaababbba (5 a, 7 b) are rejected (unequal counts), and **abababbbbaaa (6 a, 6 b) is generated** (checked). Derivation of abababbbbaaa:
S ⇒ aB ⇒ abS ⇒ abaB ⇒ ababS ⇒ ababaB ⇒ abababS ⇒ abababbA ⇒ abababbbAA ⇒ abababbbbAAA ⇒ abababbbbaAA ⇒ abababbbbaaA ⇒ abababbbbaaa.

> [!tip] Exam strategy for this question
> Write the grammar **as printed**, state the invariants, and decide each string with them. Then add one line: "If A → ε is a misprint for A → a, then only abababbbbaaa is generated (derivation shown)." That covers both readings.

## 7. 2019/20 Q7c: `S → 0B | 1A, A → 0S | 1AA | ε, B → 1 | 1S | 0BB`

> [!warning] Correction to the earlier analysis
> Your earlier topic map recorded this rule as "B → 0DD". The paper actually prints **B → 0BB** (checked at high zoom). With 0BB it is the same grammar as in §6 with a → 0 and b → 1.

Invariants: #1 ≥ #0 for strings from S, and every non-empty string ends with 1.
- **0010101**: four 0s, three 1s, so #1 < #0. **Not generated.**
- **110100101110**: ends with **0**. **Not generated.**
