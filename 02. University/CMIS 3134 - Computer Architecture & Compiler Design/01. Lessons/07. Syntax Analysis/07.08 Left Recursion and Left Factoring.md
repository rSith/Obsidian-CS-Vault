# 07.08 · Left Recursion and Left Factoring

> [!info] [[07.00 Syntax Analysis|Lesson 7]] · Theory Notes 7 · Priority 🟢 Low (never examined in the 5 papers, but needed if top-down parsing (LL(1)) returns, see [[07.11 Parsing Strategies - Top-Down, Bottom-Up, LL(1), LR(0)]])

## 1. Left recursion

> [!abstract] Theory Notes 7
> "A grammar becomes **left-recursive** if it has any non-terminal 'A' whose derivation contains 'A' itself as the **left-most symbol**. Left-recursive grammar is considered to be a problematic situation for **top-down parsers**. Top-down parsers start parsing from the Start symbol… when the parser encounters the same non-terminal in its derivation, it becomes hard for it to judge when to stop parsing the left non-terminal and it goes into an **infinite loop**."

| Type | Form (lecture) |
|---|---|
| **Immediate** left recursion | A ⇒ Aα \| β |
| **Indirect** left recursion | S ⇒ Aα \| β, A ⇒ Sd (S → A… → S… loops back) |

**Why it loops:** a top-down parser trying to expand A with A → Aα replaces A by Aα, then must expand that A again, and so on, without ever reading an input symbol.

## 2. Removing immediate left recursion

> [!abstract] Theory Notes 7
> The production `A ⇒ Aα | β` is converted into
> ```text
> A  ⇒ βA'
> A' ⇒ αA' | ε
> ```
> "This does not impact the strings derived from the grammar, but it removes immediate left recursion."

**Why it works:** A ⇒ Aα | β generates β α α α … (β followed by any number of α). The new rules generate exactly that, but recursing on the **right**.

**Example (standard, not in notes):** `E → E + T | T` becomes `E → T E'`, `E' → + T E' | ε`.

## 3. Removing all (direct and indirect) left recursion (lecture algorithm)

```text
START
Arrange non-terminals in some order like A1, A2, A3, …, An
for each i from 1 to n
  for each j from 1 to i-1
    replace each production of form Ai ⟹ Aj γ
    with Ai ⟹ δ1 γ | δ2 γ | … | δn γ
    where Aj ⟹ δ1 | δ2 | … | δn are current Aj productions
  eliminate immediate left-recursion
END
```

**Lecture example:** S ⇒ Aα | β, A ⇒ Sd
1. Substitute S into A: A ⇒ Aαd | βd.
2. Remove immediate left recursion: **A ⇒ βdA'**, **A' ⇒ αdA' | ε**.

## 4. Left factoring

> [!abstract] Theory Notes 7
> "If more than one grammar production rules has a **common prefix string**, then the top-down parser **cannot make a choice** as to which of the production it should take… e.g. `A ⟹ αβ | αγ | …`. To remove this confusion, we use a technique called left factoring… we make **one production for each common prefix** and the rest of the derivation is added by new productions."
> ```text
> A  ⇒ αA'
> A' ⇒ β | γ | …
> ```

**Example (standard):** `S → if E then S else S | if E then S` becomes `S → if E then S S'`, `S' → else S | ε`.

## 5. Left recursion vs Left factoring

| | Left recursion | Left factoring |
|---|---|---|
| Problem | A non-terminal derives itself as the left-most symbol, so a top-down parser loops forever | Two productions share a prefix, so the parser cannot choose |
| Fix | A → βA', A' → αA' \| ε | A → αA', A' → β \| γ |
| Needed for | Top-down (LL) parsing | Top-down (predictive) parsing |
