# 07.09 · FIRST and FOLLOW Sets

> [!info] [[07.00 Syntax Analysis|Lesson 7]] · Theory Notes 7 · Priority 🟡 Medium (never asked on their own, but they are the first step of the 2019/20 Q7d LL(1) parser question, 40 marks)

## 1. Why we need them

> [!abstract] Theory Notes 7
> "An important part of **parser table construction** is to create first and follow sets. These sets can provide the actual position of any terminal in the derivation. This is done to create the parsing table where the decision of replacing **T[A, t] = α** with some production rule."

In a predictive (LL(1)) parser, when the top of the stack is non-terminal A and the next input is t, the table entry T[A, t] says which production to use. FIRST and FOLLOW fill that table.

## 2. FIRST set

> [!abstract] Theory Notes 7
> "This set is created to know what **terminal symbol is derived in the first position** by a non-terminal. For example, α → tβ: α derives t in the very first position. So, t ∈ FIRST(α)."
> **Algorithm:**
> - if α is a **terminal**, then FIRST(α) = { α }.
> - if α is a non-terminal and **α → ℇ** is a production, then FIRST(α) = { ℇ } (i.e. ε ∈ FIRST(α)).
> - if α is a non-terminal and α → γ1 γ2 γ3 … γn and any FIRST(γ) contains t, then t is in FIRST(α).

> [!note] Precise version of rule 3
> Add FIRST(γ1) − {ε}. If γ1 can derive ε, also add FIRST(γ2) − {ε}, and so on. ε ∈ FIRST(α) only if **all** of γ1 … γn can derive ε. The lecture's wording "any FIRST(γ)" is a simplification.

## 3. FOLLOW set

> [!abstract] Theory Notes 7
> "We calculate what terminal symbol **immediately follows a non-terminal** α in production rules."
> **Algorithm:**
> - if α is the **start symbol**, then **$ ∈ FOLLOW(α)** ($ = end of input).
> - if α is a non-terminal and has a production α → AB, then **FIRST(B) is in FOLLOW(A) except ℇ**.
> - if α is a non-terminal and has a production α → AB, where **B ⇒ ℇ**, then **FOLLOW(α) is in FOLLOW(A)**.
> FOLLOW(α) = { t | S ⇒* … α t … }

## 4. Worked example (the 2019/20 Q7d grammar)

```text
S → A
A → aDC
C → dC | ε
D → b
E → g
```

**FIRST:**
- FIRST(D) = {b}; FIRST(E) = {g}
- FIRST(C) = {d, ε}
- FIRST(A) = {a} (A → aDC starts with terminal a)
- FIRST(S) = FIRST(A) = {a}

**FOLLOW:**
- FOLLOW(S) = {$} (start symbol)
- FOLLOW(A) ⊇ FOLLOW(S) (from S → A, A at the end) = {$}
- In A → aDC: FOLLOW(D) ⊇ FIRST(C) − {ε} = {d}; and since C ⇒ ε, FOLLOW(D) ⊇ FOLLOW(A) = {$}. So FOLLOW(D) = {d, $}.
- FOLLOW(C) ⊇ FOLLOW(A) = {$} (C at the end of A → aDC; C → dC adds nothing new). So FOLLOW(C) = {$}.
- E is **unreachable** from S, so FOLLOW(E) = ∅.

| Non-terminal | FIRST | FOLLOW |
|---|---|---|
| S | {a} | {$} |
| A | {a} | {$} |
| C | {d, ε} | {$} |
| D | {b} | {d, $} |
| E | {g} | ∅ (unreachable) |
