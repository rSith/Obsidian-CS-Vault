# 07.02 · Context-Free Grammar (CFG)

> [!info] [[07.00 Syntax Analysis|Lesson 7]] · Theory Notes 7 + `Compiler note.pdf` pp. 37–38 · Priority 🔴 High (basis of every grammar question)

## 1. The four components

> [!abstract] Theory Notes 7
> A context-free grammar has four components:
> - A set of **non-terminals (V)**. Non-terminals are **syntactic variables** that denote sets of strings. The non-terminals define sets of strings that help define the language generated by the grammar.
> - A set of tokens, known as **terminal symbols (Σ)**. Terminals are the **basic symbols** from which strings are formed.
> - A set of **productions (P)**. The productions specify the manner in which the terminals and non-terminals can be combined to form strings. Each production consists of a **non-terminal called the left side** of the production, an **arrow**, and a **sequence of tokens and/or non-terminals, called the right side**.
> - One of the non-terminals is designated as the **start symbol (S)**, from where the production begins.
> "The strings are derived from the start symbol by **repeatedly replacing a non-terminal** (initially the start symbol) **by the right side of a production** for that non-terminal."

$$
G = (V, \Sigma, P, S)
$$

Your handwritten notes write the same thing as **G = {V, T, S, P}**: V = set of variables, T = set of terminals, S = starting symbol (a variable), P = production rules.

**Conventions:** non-terminals are **capital letters** (S, A, B, E); terminals are **lower-case letters, digits and symbols** (a, b, 0, 1, id, +).

## 2. Reading a grammar written as a tuple

`G = ({S, A, B}, {a, b}, S, {S → AB, A → aA | a, B → bB | b})` means
- V = {S, A, B}, Σ = {a, b}, start symbol S,
- productions: S → AB; A → aA; A → a; B → bB; B → b. (The `|` means "or": several productions for the same non-terminal.)

## 3. Language of a grammar

The **language** L(G) is the set of all **terminal strings** that can be derived from S.

**Handwritten notes example:** G = {{S, A, B}, {a, b}, S, {S → AB, A → a, B → b}}:
```text
S ⇒ AB ⇒ aB (A → a) ⇒ ab (B → b)
```
"All the collection known as language", so here L(G) = {ab}.

**Another handwritten-notes example:** grammars generating $L = \{a^n b^n : n \ge 0\}$, for instance S → aSb | ε.

## 4. Regular grammars: left linear and right linear (handwritten notes)

A **regular grammar** is a restricted CFG where each right side has at most one variable, at one end:

| Type | Form | Example |
|---|---|---|
| **Right linear** | variable **last** on the right side: A → xB or A → x | S → abS \| b |
| **Left linear** | variable **first** on the right side: A → Bx or A → x | S → Sab \| b |

S → abS | b generates b, abb, ababb, … = `(ab)*b`, which is a regular language.

## 5. Example: what language does `S → AB, A → aA | a, B → bB | b` generate? (2020/21 Q7a)

- A → aA | a generates **a⁺** (one or more a's): a, aa, aaa, …
- B → bB | b generates **b⁺**.
- S → AB, so $L(G) = \{a^n b^m \mid n \ge 1, m \ge 1\}$ = `a⁺b⁺`: ab, aab, abb, aaabb, …

Full derivations: [[07.03 Derivations - Left-most and Right-most]].
