## What this lesson is about

The lexical analyzer (scanner) is **phase 1** of the compiler ([[01.07 Phases of a Compiler]]). It reads the source code **character by character** and groups the characters into **tokens**: the "words" of the language (keywords, identifiers, operators…). It throws away whitespace and comments, and reports any invalid token.
