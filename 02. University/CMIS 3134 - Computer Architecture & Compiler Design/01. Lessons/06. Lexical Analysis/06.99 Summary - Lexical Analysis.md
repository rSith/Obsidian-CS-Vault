# 06.99 · Lesson Summary: Lexical Analysis

> [!abstract] Back to [[06.00 Lexical Analysis]] · Practice: [[PP 06 - Lexical Analysis]]

## Must know
- **Lexical analysis = first phase.** It takes modified source from the preprocessor, breaks it into **tokens**, **removes whitespace and comments**, reports **invalid tokens**, works with the syntax analyzer and passes tokens **on demand**.
- Output format: `<token-name, attribute-value>`.
- **Lexeme** = actual characters; **pattern** = rule (RE) for a token; **token** = classified pair.
- **Token categories:** keywords, identifiers, constants/numbers, strings/literals, operators, punctuators, special characters.
- **Longest match rule:** the lexeme is the longest match among the available tokens (`int intvalue;` → `intvalue` is one identifier).
- **Rule priority:** reserved words win over user input (`int` is always the keyword).

## Important definitions
- **Alphabet:** finite set of symbols ({0,1}; {0–9, A–F}; {a–z, A–Z}).
- **String:** finite sequence of alphabet symbols; |Lexical| = 7; empty string ε.
- **Special symbols:** arithmetic `+ - % * /`; punctuation `, ; . ->`; assignment `=`; special assignment `+= -= *= /=`; comparison `== != < <= > >=`; preprocessor `#`; location `&`; logical `& && | || !`; shift `>> >>> << <<<`.

## Important comparisons

| Keyword | Identifier |
|---|---|
| reserved (`int`, `void`, `return`, `if`) | programmer-chosen (`main`, `age`, `printf`) |

| Constant | String literal |
|---|---|
| `25`, `100` | `"Max is %d"` (one token, with quotes) |

| Operator | Punctuator |
|---|---|
| `= + < ==` | `( ) { } ; ,` |

## Important examples
- `int value = 100;` → int (keyword), value (identifier), = (operator), 100 (constant), ; (symbol).
- Program 1 (`int main(){int a = 20, b = 30; if(a<b)…}`) → **50 tokens**.
- Program 2 (`void main(){int age; age=25; age=age+5; printf(…);…}`) → **39 tokens**.
