## How the papers have changed

| Trend | Evidence |
|---|---|
| Fixed core every year | Arden's theorem, NDFA→DFA, both minimizations, Moore↔Mealy, DFA design, LMD/RMD, ambiguity, LPS and phases |
| The question order is not fixed | Minimization has been Q5–Q8; Moore/Mealy Q6–Q8; Arden Q5–Q7 |
| Moore/Mealy moved from **comparison** to **design** | Compare in 2019/20, 2020/21 → design in 2021/22, 2022/23, 2023/24 |
| L1 became more **applied** | 2022/23 and 2023/24 ask scenario questions (embedded systems, wrong output, `int x = "10" + 5`) instead of plain definitions |
| Parsing (LL/LR) dropped | Only in 2019/20 |
| Tokenizing dropped in 2023/24 | Present 2019/20–2022/23 |
| Whole questions reused | 2019/20 Q3, Q5 → 2020/21; 2021/22 Q3, Q6 → 2022/23; 2022/23 Q8 → 2023/24 |
