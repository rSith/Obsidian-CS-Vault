## 2019/20 · Q3(a), 2020/21 · Q3(a), 2021/22 · Q4(a) (20 marks)
> **Question:** What is meant by the **finite automaton**?

**Lesson:** [[03.01 What is an Automaton]] · [[03.04 Formal Definition and the Transition Function]]

### Expected answer
- "Automata" comes from the Greek *αὐτόματα*, meaning **"self-acting"**. An automaton is an **abstract self-propelled computing device which follows a predetermined sequence of operations automatically**.
- An automaton with a **finite number of states** is a **Finite Automaton (FA)** or **Finite State Machine (FSM)**.
- Formally, a 5-tuple $(Q, \Sigma, \delta, q_0, F)$: Q finite set of states; Σ alphabet; δ transition function; $q_0 \in Q$ initial state; $F \subseteq Q$ final states.
- It reads an input string symbol by symbol, changing state according to δ, and **accepts** the string if it ends in a final state.
- Types: **DFA** and **NDFA** (and, with output, Mealy and Moore machines).
- Small example diagram: two states E/O for "even number of 1s".

### Key points to include
- Definition · "finite number of states" · 5-tuple · types · small example.

### How to approach this question
Definition, then the 5-tuple, then one tiny example.

## 2019/20 · Q3(b), 2020/21 · Q3(b), 2021/22 · Q4(b) (20 marks)
> **Question:** State whether we can design a finite state machine for the following scenarios and justify your answer. i. To accept all valid Java codes. ii. To accept all valid Java codes that never go into an infinite loop.

**Lesson:** [[03.01 What is an Automaton]]

### Expected answer
**(i) Yes.** Checking whether a program is valid Java is a **syntactic** question: whether the program text follows a fixed, finite set of language rules. A machine can read the code and decide this (this is what a compiler front end does). Your handwritten notes: an automaton "can be used to find if a Java programme is a valid one".
*(Precision: nested structures need a push-down automaton/CFG parser, but a recognising machine can be designed.)*

**(ii) No.** Whether a program **never enters an infinite loop** depends on its **run-time behaviour**, not just its text. This is the **halting problem**, which is **undecidable**: no machine can decide it for all programs. A finite automaton, with finite memory, cannot track unbounded loop states. Handwritten notes: an automaton "cannot be used to identify an infinite loop".

### Key points to include
- Clear yes/no for each · syntax (decidable) vs run-time behaviour (undecidable, halting problem).

### How to approach this question
Verdict first, then a 2–3 sentence justification for each part.

## 2019/20 · Q3(c), 2020/21 · Q3(c) and 2022/23 · Q5(c) (20 marks)
> **Question:** Compare and contrast **DFA** and **NDFA**. (2022/23: "Compare and contrast a Deterministic Finite Automaton (DFA) and a Non-deterministic Finite Automaton (NFA).")

**Lesson:** [[03.07 DFA vs NDFA]]

### Expected answer
**Similarities:** both are finite automata described by a 5-tuple (Q, Σ, δ, q0, F); both have one start state and a set of final states; same diagram conventions; both recognise exactly the regular languages (every NDFA can be converted to an equivalent DFA).

| DFA | NDFA |
|---|---|
| Transition from a state goes to a **single** next state for each input | Transition can go to **multiple** next states for each input |
| δ: Q × Σ → Q | δ: Q × Σ → 2^Q |
| **No ε (empty string) transitions** | **ε-transitions permitted** |
| Backtracking **allowed** | Backtracking **not always possible** |
| Requires **more space** (more states) | Requires **less space** |
| Accepted if it **transits to a final state** | Accepted if **at least one** of all possible paths ends in a final state |
| Harder to design, simple to execute | Easier to design, harder to execute |

"Every DFA is an NDFA, but every NDFA is not a DFA."

### Key points to include
- Similarities + at least 6 differences (lecture's 5 rows + δ signature).

### How to approach this question
Table + one-sentence similarities + the quotable line.

## 2019/20 · Q4(a) (20 marks)
> **Question:** Provide a **Formal Definition** for an **NDFA**.

**Lesson:** [[03.06 Non-deterministic Finite Automaton (NDFA)]]

### Expected answer
An NDFA is a 5-tuple $(Q, \Sigma, \delta, q_0, F)$ where
- Q: finite set of states; Σ: finite set of input symbols (alphabet);
- **δ: Q × Σ → 2^Q**, the transition function; $2^Q$ is the **power set** of Q, because from a state the machine can move to **any combination** of states (including ∅);
- $q_0 \in Q$: initial state; $F \subseteq Q$: final states.
A string is accepted if **at least one** possible path ends in a final state. ε-moves are allowed.

Example: Q = {a,b,c}, Σ = {0,1}, q0 = a, F = {c}; δ(a,0) = {a,b}, δ(a,1) = {b}, δ(b,0) = {c}, δ(b,1) = {a,c}, δ(c,0) = {b,c}, δ(c,1) = {c}.

### Key points to include
- 5 components · δ into the power set, with explanation · acceptance condition · example table.

### How to approach this question
List the tuple, explain 2^Q, give the lecture's example.

## 2020/21 · Q4(a) and 2021/22 · Q5(a) (20 marks)
> **Question:** Provide a **Formal Definition** for a **DFA**.

**Lesson:** [[03.05 Deterministic Finite Automaton (DFA)]]

### Expected answer
A DFA is a 5-tuple $(Q, \Sigma, \delta, q_0, F)$ where Q is a finite set of states, Σ a finite set of symbols (alphabet), **δ: Q × Σ → Q** the transition function (exactly one next state for each state and input), $q_0 \in Q$ the initial state and $F \subseteq Q$ the set of final states.
- Deterministic: "for each input symbol, one can determine the state to which the machine will move".
- Validation rules: ≥ 1 state; exactly one initial state; ≥ 1 final state; a transition for **every** input from **every** state; no multiple transitions for the same input.
- Acceptance: $\delta^*(q_0, S) \in F$.
- Example: Q = {a,b,c}, Σ = {0,1}, q0 = a, F = {c}; δ: a→(a,b), b→(c,a), c→(b,c) for inputs (0,1), with its state diagram.

### Key points to include
- Tuple · δ: Q × Σ → Q · determinism · validation rules · example.

### How to approach this question
As for the NDFA definition, plus the validation rules.

## 2020/21 · Q4(b), 2021/22 · Q5(b) and 2023/24 · Q4(b) (20 marks)
> **Question:** Briefly explain the following terminologies with suitable example(s). i. Alphabet ii. String iii. Length of a String iv. Language. (2023/24: "Define the following with examples: i. Alphabet ii. String iii. Language iv. Empty String")

**Lesson:** [[03.02 Alphabet, Strings and Languages]]

### Expected answer
- **Alphabet (Σ):** any finite set of symbols. e.g. Σ = {a, b, c, d}; binary Σ = {0, 1}.
- **String:** a finite sequence of symbols taken from Σ. e.g. 'cabcad' over {a,b,c,d}. ('az' is not a string over this Σ, since z ∉ Σ.)
- **Length of a string |S|:** number of symbols in S. e.g. |cabcad| = 6; |ε| = 0.
- **Language:** a subset of Σ\* for some alphabet Σ; can be finite or infinite. e.g. all strings of length 2 over {a,b}: L = {aa, ab, ba, bb}; or {a, aa, aaa, …}.
- **Empty string (2023/24):** the string with no symbols, |S| = 0, written ε or λ. ε ∈ Σ\* but ε ∉ Σ⁺; εw = wε = w. It is different from the empty set φ ({ε} has one element, φ has none).

### Key points to include
- Definition + example for each.

### How to approach this question
Use one alphabet throughout; 4 short paragraphs.

## 2020/21 · Q6(b) (20 marks)
> **Question:** What is the **power of alphabet (Σ)** and **cardinality of alphabet (Σ)**? Briefly explain with suitable example(s).

**Lesson:** [[03.03 Powers of Sigma, Kleene Star and Kleene Plus]]

### Expected answer
- **Power of the alphabet Σⁿ:** the set of all strings of **exactly length n** over Σ. For Σ = {a, b}: Σ⁰ = {ε}, Σ¹ = {a, b}, Σ² = {aa, ab, ba, bb}, Σ³ = {aaa, aab, aba, abb, baa, bab, bba, bbb}.
- **Cardinality:** the number of elements in a set. |Σ| = number of symbols (here 2). The number of strings of length n is $|\Sigma^n| = |\Sigma|^n$: |Σ²| = 4, |Σ³| = 8.
- Link: $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots$ and $\Sigma^+ = \Sigma^1 \cup \Sigma^2 \cup \dots$

> [!warning] Partly beyond the notes
> The notes list Σ⁰, Σ¹, Σ²… but do not use the word "cardinality". The definition and the formula $|\Sigma^n| = |\Sigma|^n$ are standard.

### Key points to include
- Both definitions · listed example layers · the count formula.

### How to approach this question
Definition + table of Σ⁰…Σ³ with their sizes.

## 2020/21 · Q6(c) (20 marks) and 2022/23 · Q5(a) (20 marks)
> **Question (2020/21):** By using the power of alphabet (Σ) and cardinality of alphabet (Σ), prove that Σ\* is the set of all possible strings of all lengths over {p, q}.
> **Question (2022/23):** Show that Σ\* is the set of all possible strings of all lengths (i.e. language) where the Σ is the alphabet.

**Lesson:** [[03.03 Powers of Sigma, Kleene Star and Kleene Plus]]

### Expected answer
Let Σ = {p, q}, |Σ| = 2.
1. Σⁿ = all strings of length exactly n, $|\Sigma^n| = 2^n$: Σ⁰ = {ε} (1), Σ¹ = {p, q} (2), Σ² = {pp, pq, qp, qq} (4), Σ³ = {ppp, ppq, pqp, pqq, qpp, qpq, qqp, qqq} (8), …
2. By definition $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots$
3. **(⊆)** Each element of Σ\* belongs to some Σⁿ, so it is a string over Σ of finite length n.
4. **(⊇)** Any string w over Σ has some finite length n, so w ∈ Σⁿ ⊆ Σ\*.
5. Hence Σ\* is exactly the set of all strings of all lengths over Σ (including ε); it is infinite because n is unbounded. ∎

### Key points to include
- Layers with cardinalities · union definition · both directions · conclusion.

### How to approach this question
Write it as a numbered proof.

## 2021/22 · Q4(c) (20 marks)
> **Question:** Categories the finite automation machines with their examples.

**Lesson:** [[03.08 Classification of Finite Automata]]

### Expected answer
```text
Finite Automata
├── without output: DFA, NDFA/NFA
└── with output:    Mealy machine, Moore machine
```
- **DFA:** one next state per (state, input). e.g. DFA accepting strings with an even number of 1s.
- **NDFA:** may move to several states; ε-moves allowed. e.g. NDFA for strings whose second-last symbol is a.
- **Mealy:** output depends on present state and input. e.g. 1's complement machine (0/1, 1/0).
- **Moore:** output depends on present state only. e.g. machine counting occurrences of "abb".
Also (Theory Notes 3): **acceptor** (Boolean output: accept/reject), **classifier** (more than two final states, single output on termination), **transducer** (output from current input and/or state: Mealy, Moore).

### Key points to include
- The tree · one-line definition + example for each leaf · acceptor/classifier/transducer.

### How to approach this question
Draw the tree first.

## 2022/23 · Q4(a) and 2023/24 · Q4(a) (20 marks)
> **Question (2022/23):** What does "**Automata**" mean, and why is it significant in computing?
> **Question (2023/24):** What is meant by the term **Automaton**? Explain why it is referred to as a "self-acting" machine.

**Lesson:** [[03.01 What is an Automaton]]

### Expected answer
**Meaning:** from the Greek *αὐτόματα* = "self-acting"; an abstract self-propelled computing device that follows a predetermined sequence of operations automatically. With finitely many states it is a finite automaton (5-tuple Q, Σ, δ, q0, F).

**Why "self-acting" (2023/24):** once started it needs no external control; each move is fixed in advance by δ (current state + input → next state); it proceeds automatically symbol by symbol until the input ends.

**Significance (2022/23):**
- The **lexical analyzer** of a compiler is a finite automaton (REs → FA for token recognition).
- Pattern matching and text search.
- Design of sequential circuits and controllers (Mealy/Moore machines).
- Theoretical foundation of computation: shows what can be recognised with finite memory (regular languages; push-down automata for context-free languages).

### Key points to include
- Greek origin · definition · self-acting explanation **or** significance list (depending on the year).

### How to approach this question
Definition + 3–4 bullets for the second half.

## 2022/23 · Q4(b) (20 marks)
> **Question:** What is the **Kleene Star (Σ\*)**, and how does it differ from the **Kleene Closure (Σ⁺)**? Provide an example.

**Lesson:** [[03.03 Powers of Sigma, Kleene Star and Kleene Plus]]

### Expected answer
- **Σ\*** (Kleene star): unary operator giving the infinite set of all possible strings of all lengths over Σ **including λ (ε)**: $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots$
- **Σ⁺** (Kleene closure / plus): all strings of all lengths **excluding λ**: $\Sigma^+ = \Sigma^1 \cup \Sigma^2 \cup \dots = \Sigma^* - \{\lambda\}$
- **Difference:** only the empty string.
- **Example (Σ = {a, b}):** Σ\* = {ε, a, b, aa, ab, ba, bb, …}; Σ⁺ = {a, b, aa, ab, ba, bb, …}.

## 2022/23 · Q4(c) (20 marks) and 2023/24 · Q5(c) (20 marks)
> **Question (2022/23):** In the 5-tuple (Q, Σ, q₀, F, δ) of a finite machine, what role does the **transition function (δ)** play?
> **Question (2023/24):** Explain why in DFA the transition function (δ) is defined as δ: Q × Σ → Q while in NDFA it is defined as δ: Q × Σ → 2^Q, where Q is the set of states, and Σ is the input symbols (alphabet).

**Lesson:** [[03.04 Formal Definition and the Transition Function]]

### Expected answer
**Role of δ:** it is the machine's set of rules: for the **current state** and **current input symbol** it gives the **next state**. It drives the machine automatically ("self-acting"), is drawn as the labelled arcs of the state diagram and written as the transition table. Applied repeatedly (δ\*), it determines acceptance: $\delta^*(q_0, S) \in F$.

**Why Q in a DFA:** deterministic means for each (state, symbol) the next state is **unique**, so δ returns **one element of Q**. Hence every state has exactly one transition per symbol.

**Why 2^Q in an NDFA:** the machine may move to **any combination of states** (none, one or several). The result is a **set** of states, an element of the **power set** $2^Q$ (all $2^{|Q|}$ subsets of Q, including ∅). So the codomain must be $2^Q$. (NDFAs may also have ε-moves.)
Example: DFA δ(a,0) = b; NDFA δ(a,0) = {a, b} and δ(c,1) = ∅.
Consequence: subset construction builds DFA states that are subsets of the NDFA's states.

### Key points to include
- Role (state + symbol → next state; arcs; table; δ\*) · DFA = one state; NDFA = set of states = power set.

## 2022/23 · Q5(b) and 2023/24 · Q5(b) (20 marks)
> **Question:** Why might **NFAs** be computationally easier to design for certain problems, even though **DFAs** are simpler in execution? (2023/24: "Discuss why NDFAs might be…")

**Lesson:** [[03.07 DFA vs NDFA]]

### Expected answer
**Easier to design (NFA/NDFA):**
- Can be in **several states at once**, so it can "guess" where a pattern begins instead of tracking every case.
- Often needs **far fewer states**: "second-last symbol is a" needs 3 NDFA states vs 4 DFA states; for "n-th last symbol" a DFA may need up to $2^n$ states.
- **Missing transitions are allowed** (no dead state needed).
- **ε-transitions** let sub-machines be joined easily (as in RE → finite machine).

**Simpler in execution (DFA):**
- Exactly **one current state** and **one path**; each input symbol is a single table lookup, with no backtracking.
- An NFA must keep track of a **set of possible states** at each step.

**Conclusion:** design with an NFA, convert to a DFA (subset construction) to run. They are equally powerful.

### Key points to include
- Design advantages (guessing, fewer states, no dead state, ε) · execution advantage of DFAs · conclusion.

## 2023/24 · Q4(c) (20 marks)
> **Question:** Prove that Σ⁺ = Σ\* − {ε}.

**Lesson:** [[03.03 Powers of Sigma, Kleene Star and Kleene Plus]]

### Expected answer
1. Definitions: $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \cup \dots$ and $\Sigma^+ = \Sigma^1 \cup \Sigma^2 \cup \dots$
2. $\Sigma^0$ is the set of strings of length 0, and the only such string is ε, so $\Sigma^0 = \{\varepsilon\}$.
3. Hence $\Sigma^* = \{\varepsilon\} \cup \Sigma^+$.
4. Every string in Σ⁺ has length ≥ 1, while |ε| = 0, so $\varepsilon \notin \Sigma^+$: the two sets are **disjoint**.
5. Removing ε from both sides: $\Sigma^* - \{\varepsilon\} = \Sigma^+$. ∎
Illustration (Σ = {a, b}): Σ\* = {ε, a, b, aa, …} → remove ε → {a, b, aa, …} = Σ⁺.

### How to approach this question
Write it as a proof (definitions → substitution → disjointness → conclusion).

## 2023/24 · Q5(a) (20 marks)
> **Question:** Formally prove that every **Deterministic Finite Automaton (DFA)** is also a **Non-deterministic Finite Automaton (NDFA)**.

**Lesson:** [[03.06 Non-deterministic Finite Automaton (NDFA)]]

### Expected answer
1. Let $D = (Q, \Sigma, \delta_D, q_0, F)$ be a DFA with $\delta_D: Q \times \Sigma \rightarrow Q$.
2. Define $N = (Q, \Sigma, \delta_N, q_0, F)$ with $\delta_N(q, a) = \{\delta_D(q, a)\}$ for every q ∈ Q, a ∈ Σ.
3. $\{\delta_D(q,a)\} \subseteq Q$, so $\delta_N(q,a) \in 2^Q$. Thus $\delta_N: Q \times \Sigma \rightarrow 2^Q$ and N satisfies the NDFA definition (no ε-moves needed).
4. By induction on |w|: $\delta_N^*(q_0, w) = \{\delta_D^*(q_0, w)\}$ (true for ε; if true for w, then for wa both sides give the singleton of $\delta_D(\delta_D^*(q_0,w), a)$).
5. Therefore N accepts w ⟺ $\delta_N^*(q_0,w) \cap F \ne \varnothing$ ⟺ $\delta_D^*(q_0,w) \in F$ ⟺ D accepts w. So L(N) = L(D), and every DFA is an NDFA (one whose transition sets are all singletons). ∎
"Every DFA is an NDFA, but every NDFA is not a DFA."

### How to approach this question
"Formally" means 5-tuples and transition functions. Do not answer only in words.
