## 2019/20 · Q4(d) (40 marks)
> **Question:** Find the equivalent DFA for the NDFA given by X = [{q0, q1, q2, q3, q4}, (0, 1), δ, q0, {q4}] where δ is given by:
>
> | | 0 | 1 |
> |---|---|---|
> | → q0 | {q0, q1, q2, q3, q4} | {q3, q4} |
> | q1 | {q2} | {q4} |
> | q2 | ∅ | {q1} |
> | q3 | {q4} | ∅ |
> | ⓠ4 | ∅ | ∅ |

### Expected answer
This is the lecture example with a, b, c, d, e renamed q0…q4.

| DFA state | 0 | 1 | Final? |
|---|---|---|---|
| → [q0] | [q0,q1,q2,q3,q4] | [q3,q4] | |
| [q0,q1,q2,q3,q4] | [q0,q1,q2,q3,q4] | [q1,q3,q4] | ✔ |
| [q3,q4] | [q4] | ∅ | ✔ |
| [q1,q3,q4] | [q2,q4] | [q4] | ✔ |
| [q4] | ∅ | ∅ | ✔ |
| [q2,q4] | ∅ | [q1] | ✔ |
| [q1] | [q2] | [q4] | |
| [q2] | ∅ | [q1] | |
| ∅ (dead) | ∅ | ∅ | |

Sample unions: δ([q0..q4], 1) = {q3,q4} ∪ {q4} ∪ {q1} ∪ ∅ ∪ ∅ = [q1,q3,q4]; δ([q1,q3,q4], 0) = {q2} ∪ {q4} ∪ ∅ = [q2,q4].
Final states: every set containing q4 (6 of the 9 DFA states, counting ∅ as a state).

### Key points to include
- Problem statement + 6 steps · unions shown · all 8 sets + ∅ · final states marked · DFA diagram.

### How to approach this question
Rename states (A = [q0], B = [q0..q4], C = [q3,q4], D = [q1,q3,q4], E = [q4], F = [q2,q4], G = [q1], H = [q2], Ø) to draw a clean diagram.

## 2020/21 · Q6(d) (40 marks)
> **Question:** Find the equivalent DFA for the following NDFA given by X = [{q0, q1, q2, q3, q4}, (a, b), δ, q0, {q1}] where δ is given by:
>
> | | a | b |
> |---|---|---|
> | → q0 | {q1, q2, q3} | {q2, q3} |
> | ⓠ1 | {q1, q2} | {q2, q3} |
> | q2 | ∅ | {q2, q3, q4} |
> | q3 | {q4} | {q2, q3, q4} |
> | q4 | ∅ | ∅ |

### Expected answer
| DFA state | a | b | Final? |
|---|---|---|---|
| → [q0] | [q1,q2,q3] | [q2,q3] | |
| [q1,q2,q3] | [q1,q2,q4] | [q2,q3,q4] | ✔ |
| [q2,q3] | [q4] | [q2,q3,q4] | |
| [q1,q2,q4] | [q1,q2] | [q2,q3,q4] | ✔ |
| [q2,q3,q4] | [q4] | [q2,q3,q4] | |
| [q4] | ∅ | ∅ | |
| [q1,q2] | [q1,q2] | [q2,q3,q4] | ✔ |
| ∅ (dead) | ∅ | ∅ | |

Sample unions: δ([q1,q2,q3], a) = {q1,q2} ∪ ∅ ∪ {q4} = [q1,q2,q4]; δ([q1,q2,q3], b) = {q2,q3} ∪ {q2,q3,q4} ∪ {q2,q3,q4} = [q2,q3,q4].
Final states: sets containing **q1**: [q1,q2,q3], [q1,q2,q4], [q1,q2].

> [!note] Final state is q1
> The final state is **q1** (circled in the paper), not the last state q4. Students often mark the sets containing q4 by mistake.

## 2021/22 · Q6(c) and 2022/23 · Q6(c) (20 marks)
> **Question:** Find the equivalent DFA for the above NDFA Machine given in part (b). [Part (b): NDFA for `10 + (0 + 11)0* 1` over Σ = {0,1}]

**Lesson:** [[08.05 The Full Pipeline - RE to Minimized DFA]]

### Expected answer
NDFA from (b) (see [[PP 08 - Arden's Theorem and RE-FA Conversion]]): A –1→ {B,E}, A –0→ {D}, B –0→ {C}, D –0→ {D}, D –1→ {C}, E –1→ {D}; final C.

| DFA state | 0 | 1 | Final? |
|---|---|---|---|
| → [A] | [D] | [B,E] | |
| [D] | [D] | [C] | |
| [B,E] | [C] | [D] | |
| [C] | ∅ | ∅ | ✔ |
| ∅ | ∅ | ∅ | |

δ([B,E], 0) = {C} ∪ ∅ = [C]; δ([B,E], 1) = ∅ ∪ {D} = [D].

### How to approach this question
Your DFA depends on your NDFA from (b). Different but correct NDFAs give different-looking DFAs. A correct method on your own NDFA earns the marks.

## 2023/24 · Q7(c) (20 marks)
> **Question:** Find the equivalent DFA for the NDFA Machine given in part (b). [Part (b): NDFA for `ab* + (a + bb)a*b*` over Σ = {a, b}]

### Expected answer
NDFA from (b): q0 –a→ {q1,q2}, q0 –b→ {q3}, q1 –b→ {q1}, q2 –a→ {q2}, q2 –b→ {q4}, q3 –b→ {q2}, q4 –b→ {q4}; finals q1, q2, q4.

| DFA state | a | b | Final? |
|---|---|---|---|
| → [q0] | [q1,q2] | [q3] | |
| [q1,q2] | [q2] | [q1,q4] | ✔ |
| [q3] | ∅ | [q2] | |
| [q2] | [q2] | [q4] | ✔ |
| [q1,q4] | ∅ | [q1,q4] | ✔ |
| [q4] | ∅ | [q4] | ✔ |
| ∅ | ∅ | ∅ | |

δ([q1,q2], b) = {q1} ∪ {q4} = [q1,q4]; δ([q1,q2], a) = ∅ ∪ {q2} = [q2].
