## A–G DFA: 2019/20 · Q5(d) and 2020/21 · Q5(d) (Equivalence Theorem, 40 marks)
> **Question:** Minimize the following DFA using the **Equivalence Theorem**. [diagram]

**Transition table read from the diagram** (start A; finals B, C, G):

| State | 0 | 1 |
|---|---|---|
| → A | B | C |
| \* B | D | E |
| \* C | E | D |
| D | G | G |
| E | G | G |
| F | D | E |
| \* G | G | G |

### Expected answer
**Step 0: remove unreachable states.** From A we reach B, C, D, E, G. **No arrow enters F**, so F is unreachable and is removed.

**P0** = { (A, D, E) non-final, (B, C, G) final }

**P1:** signatures w.r.t. P0 (N = {A,D,E}, F = {B,C,G}):
- A: 0→B (F), 1→C (F); D: 0→G (F), 1→G (F); E: 0→G (F), 1→G (F). Same, so (A, D, E) stays.
- B: 0→D (N), 1→E (N); C: 0→E (N), 1→D (N); G: 0→G (F), 1→G (F). G differs.
- **P1** = { (A, D, E), (B, C), (G) }

**P2:** w.r.t. P1:
- A: 0→B ∈ (B,C), 1→C ∈ (B,C); D: both → G; E: both → G. A differs from D, E.
- B: both → (D/E) ∈ (A,D,E); C: both ∈ (A,D,E). Same.
- **P2** = { (A), (D, E), (B, C), (G) }

**P3:** A: (B,C),(B,C); D, E: (G),(G); B, C: (D,E),(D,E). No split. **P3 = P2, so stop.**

**Minimized DFA (6 reachable states → 4):**

| State | 0 | 1 |
|---|---|---|
| → A | (B,C) | (B,C) |
| \* (B,C) | (D,E) | (D,E) |
| (D,E) | G | G |
| \* G | G | G |

Check: the machine accepts all strings of length **1** or length **≥ 3**.

> [!warning] Note on F
> If F is kept, the partition gives 5 groups ({A},{B,C},{D,E},{F},{G}). Mention that F is unreachable and removed. The scribbles on the 2019/20 scan cross out F's arrows, which supports this.

## A–E DFA: 2019/20 · Q6(d) and 2020/21 · Q8(d) (Myhill-Nerode, 40 marks)
> **Question:** Minimize the following DFA using **Myphill Nerode Theorem**. [diagram]

**Table** (start A; final E):

| State | 0 | 1 |
|---|---|---|
| → A | B | D |
| B | C | E |
| C | B | E |
| D | C | E |
| \* E | E | E |

### Expected answer
**Step 1–2:** pair table; mark (final, non-final): (A,E), (B,E), (C,E), (D,E).

**Step 3, pass 1:**
- (A,B): input 1 → (D, E), marked, so **mark**.
- (A,C): input 1 → (D, E), so **mark**.
- (A,D): input 1 → (D, E), so **mark**.
- (B,C): 0 → (C,B) unmarked; 1 → (E,E) same. Leave.
- (B,D): 0 → (C,C); 1 → (E,E). Leave.
- (C,D): 0 → (B,C) unmarked; 1 → (E,E). Leave.

**Pass 2:** no new marks. Stop.

| | A | B | C | D |
|---|---|---|---|---|
| **B** | ✔ | | | |
| **C** | ✔ | | | |
| **D** | ✔ | | | |
| **E** | ✔ | ✔ | ✔ | ✔ |

**Step 4:** unmarked (B,C), (B,D), (C,D) → combine into **{B, C, D}**.

| State | 0 | 1 |
|---|---|---|
| → A | (B,C,D) | (B,C,D) |
| (B,C,D) | (B,C,D) | E |
| \* E | E | E |

5 states → 3 states. (Accepts strings containing a 1 somewhere after the first symbol.)

## 2023/24 · Q6(d) (Equivalence Theorem, 40 marks)
> **Question:** Minimize the following DFA using the **Equivalence Theorem**.
>
> | Present State | 0 | 1 |
> |---|---|---|
> | A (Initial) | B | C |
> | B | A | D |
> | C | E | F |
> | D | E | F |
> | E (Final) | E | E |
> | F (Final) | F | F |

### Expected answer
- **P0** = { (E, F) final, (A, B, C, D) non-final }
- **P1:** A: 0→B (N), 1→C (N); B: 0→A (N), 1→D (N). Both (N,N). C: 0→E (F), 1→F (F); D: 0→E (F), 1→F (F). Both (F,F). E: (F,F); F: (F,F).
  **P1** = { (A, B), (C, D), (E, F) }
- **P2:** A: 0→B ∈ (A,B), 1→C ∈ (C,D); B: 0→A ∈ (A,B), 1→D ∈ (C,D). Same. C, D: both → (E,F). E, F: stay in (E,F). **P2 = P1, so stop.**

| State | 0 | 1 |
|---|---|---|
| → (A,B) | (A,B) | (C,D) |
| (C,D) | (E,F) | (E,F) |
| \* (E,F) | (E,F) | (E,F) |

6 → 3 states. (The handwritten note on the scanned paper, "{E,F}, {A,B}, {C,D}", agrees.)

## 2021/22 · Q6(d) and 2022/23 · Q6(d) (Myhill-Nerode, 40 marks)
> **Question:** Minimize the DFA in part (c) using the **Myphill-Nerode Theorem**.

### Expected answer
DFA from (c): P = [A], Q = [D], R = [B,E], T = [C] (final), Z = ∅.
P: 0→Q, 1→R · Q: 0→Q, 1→T · R: 0→T, 1→Q · T: 0,1→Z · Z: 0,1→Z.

- Step 2: mark (P,T), (Q,T), (R,T), (Z,T).
- Pass 1: (P,Q): 1 → (R,T), so mark · (P,R): 0 → (Q,T), so mark · (Q,R): 0 → (Q,T), so mark · (Q,Z): 1 → (T,Z), so mark · (R,Z): 0 → (T,Z), so mark.
- Pass 2: (P,Z): 0 → (Q,Z), so mark.
- No unmarked pairs remain.

**Conclusion:** every pair of states is distinguishable, so the DFA from (c) is **already minimal** (4 states + dead state). Full working: [[08.05 The Full Pipeline - RE to Minimized DFA]].

- Pass 1: (S0,S2): a → (S1,Z), so mark · (S0,Z): a → (S1,Z), so mark · (S2,Z): b → (S3,Z), so mark · (S1,S4), (S1,S5), (S3,S4), (S3,S5): a → (S3,Z), so mark. (S1,S3): a → (S3,S3), b → (S4,S5) unmarked, so leave · (S4,S5): a → (Z,Z), b → (S4,S5), so leave.

| State | a | b |
