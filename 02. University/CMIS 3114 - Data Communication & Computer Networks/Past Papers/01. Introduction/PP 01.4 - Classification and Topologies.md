## A. Classification by geographical coverage / scale

> **2019/20 Q2(a), 2021/22 Q2(a):** Classify computer networks according to the geographical coverage.
> **2023/24 Q2(a):** Classify computer networks according to the geographical scale.

**Related topic:** [[01.09 Network Classification by Scale]]

### Expected answer
| Type | Coverage | Description and example |
|---|---|---|
| **BAN** (Body Area Network) | On the body (~1 m) | Wearable devices: smartphone controlling a hearing aid; heart-rate/blood-glucose sensors |
| **PAN** (Personal Area Network) | ~1–10 m, one person | Computer with wireless mouse, keyboard, printer; Bluetooth (IEEE 802.15) |
| **LAN** (Local Area Network) | Room → building → campus (up to a few km) | Privately owned; 10/100/1000+ Mbps; low delay, high reliability; **Ethernet (IEEE 802.3, bus-based broadcast)**, **Token Ring (IEEE 802.5)**, WiFi; e.g. a university lab |
| **MAN** (Metropolitan Area Network) | A city (~10 km) | Larger version of a LAN; public or private; e.g. **cable-TV-based network** of 500–5,000 homes |
| **WAN** (Wide Area Network) | Country, continent, world | Transmission lines + **routers**; hosts connected by a **communication subnet** owned by a telco/ISP; **store-and-forward / packet-switched**; e.g. **the Internet** |

Draw the distance scale (1 m → 10 km → 10,000 km) and/or a nested-circle diagram (PAN inside LAN inside MAN inside WAN).

### Key points
Five types with distance, ownership, speed and example; mention store-and-forward for WAN.

## B. Classification by transmission technology

> **2020/21 Q2(a), 2022/23 Q2(a):** Classify computer networks according to the transmission technology.

**Related topic:** [[01.07 Network Hardware and Transmission Technology]]

### Expected answer
Two types:
1. **Broadcast links:** a **single communication channel shared by all machines**. A packet sent by one machine is received by all; an **address field** in the packet identifies the intended recipient. Each machine checks the address: if it is for that machine it processes the packet, otherwise ignores it. Addressing modes: **unicast** (one specific machine), **broadcast** (all machines), **multicast** (a subset). Examples: WiFi, classic Ethernet bus.
2. **Point-to-point links:** **individual connections between pairs of machines**. A packet may pass through **one or more intermediate machines (routers)**, and several routes of different lengths may exist, so **routing** is important. Unicast transmission. Examples: WAN links between routers, leased lines.

(Generally small, localised networks use broadcasting; large networks use point-to-point.)

## C. Topologies

> **2018/19 Q2(b):** It is required to setup a separate network for each of the following requirements. Identify the suitable topologies and explain your answer. i. Connecting major cities for a backbone network. ii. Computer laboratory with 100 computers.
> **2019/20 Q2(b):** Compare and contrast the following two network topologies, i. Star topology ii. Partial Mesh topology
> **2020/21 Q2(b):** Describe three network topologies using diagrams. Also mention a suitable usage for each topology.
> **2021/22 Q2(b):** Compare and contrast the following two network topologies, also mention a suitable usage for each topology. i. Star topology ii. Partial Mesh topology.
> **2022/23 Q2(b):** Draw diagrams of the following two network topologies. Mention a suitable device and media used in the topology. Also write a suitable usage for each topology. i. Ring topology ii. Partial Mesh topology.
> **2023/24 Q2(b):** Draw diagrams of the following two network topologies. List suitable devices and media used in the topology. Also write a suitable usage for each topology. i. Ring topology ii. Star topology.

**Related topic:** [[01.08 Network Topologies]]

### Expected answers

**Star:** every node connects by a point-to-point link to a **central node** that retransmits the data to some or all nodes.
```text
        [PC]   [PC]
           \   /
   [PC] ── (SWITCH) ── [PC]
           /   \
        [PC]  [Printer]
```
Device: **switch** (or hub / WiFi AP). Media: **UTP twisted pair (Cat 5e/6)**. Usage: **computer lab, office LAN**. ✅ easy to install/expand, a cable fault affects one node, easy to manage. ❌ central switch is a single point of failure, more cable.

**Partial mesh:** some nodes connect to **more than one** other node, giving **redundant paths** without the cost of connecting every pair.
```text
  [Colombo]───[Kandy]───[Jaffna]
      │   \      │      /
  [Galle]  [Kurunegala]
```
Devices: **routers**. Media: **optical fibre** (or microwave) WAN links. Usage: **national/ISP backbone between cities**, the Internet. ✅ alternative routes if a link fails, cheaper than full mesh. ❌ costly, needs routing, complex.

**Ring:** each node connects to **two others**, the last back to the first; data travels **one direction** node to node.
```text
   [A] → [B]
    ↑      ↓
   [D] ← [C]
```
Devices: **Token Ring MAU / ring switches; repeaters**. Media: twisted pair (Token Ring, IEEE 802.5) or **fibre rings with active repeaters** (metro/backbone). Usage: **Token Ring LANs, metropolitan fibre rings**. ✅ no collisions (token passing), fair access. ❌ one break can stop the ring (unless dual ring), adding nodes disrupts it.

**Bus** (third topology option for 2020/21): nodes on one shared cable (coax, terminators); early Ethernet. ✅ cheap ❌ one cable fault stops all, collisions.

**Star vs partial mesh comparison (2019/20, 2021/22):**
| | Star | Partial mesh |
|---|---|---|
| Structure | All nodes to one central device | Some nodes have several links |
| Redundancy | None (central point of failure) | Multiple paths |
| Cost/cabling | Low–moderate | High |
| Management | Easy | Complex (routing needed) |
| Typical device/media | Switch + UTP | Routers + fibre |
| Usage | LAN in a lab or office | WAN backbone between cities |
Similarities: both use **point-to-point links**; both are widely used physical layouts; both can be combined (stars connected by a partial-mesh backbone).

**2018/19 answers:** (i) **partial mesh** for the city backbone (redundant routes if one long-distance link fails; full mesh too costly); (ii) **star** (or extended star/tree with several 24/48-port switches) for 100 lab PCs (easy management, fault isolation, cheap switches).

### Exam approach
For every topology: **definition → labelled diagram → device → media → usage → 1 advantage + 1 disadvantage**.
