## A. FDM / TDM / OFDM / WDM comparisons

> **2019/20 Q5(a), 2022/23 Q6(a):** Compare and contrast FDM, TDM and OFDM.
> **2020/21 Q4(c), 2023/24 Q4(b):** Compare and contrast TDM, WDM and OFDM.
> **2021/22 Q6(a):** Compare and contrast FDM and TDM.

### Expected answer: definitions (lecture)
- **FDM:** divides the **spectrum into frequency bands**, each user having **exclusive possession of a band**; **guard bands** separate channels (voice: ~3100 Hz used within 4000 Hz allocated). E.g. AM radio (~500–1500 kHz).
- **TDM:** each user periodically gets the **entire bandwidth for a short time slot**; bits from each input stream taken in fixed slots; streams must be **synchronised**; **guard time** between slots. E.g. **T1 = 24 × 64 kbps → 1.544 Mbps**, GSM 8-slot TDM.
- **OFDM:** divides the spectrum **without guard bands**; subcarriers **overlap**, but each subcarrier's response is **zero at the centre of its neighbours** (orthogonal), so each can be sampled without interference. Used in **WLAN, power-line, 4G**.
- **WDM:** FDM for **optical fibre**: several signals on **different wavelengths (colours)** are combined onto one fibre (prism/grating) and separated at the far end. Used in backbone/undersea fibre.

### Comparison tables
| | FDM | TDM | OFDM |
|---|---|---|---|
| Shares | Frequency | Time | Orthogonal subcarriers |
| Separation | Guard bands | Guard time | None needed |
| Spectrum efficiency | Lowest | Good | Highest |
| Synchronisation | Not needed | Needed | Needed (subcarrier timing) |
| Signal | Analog mostly | Digital | Digital (QAM on subcarriers) |
| Example | Radio/TV | T1, GSM | WiFi, 4G LTE, ADSL |

| | TDM | WDM | OFDM |
|---|---|---|---|
| Dimension | Time slots | Wavelengths of light | Frequencies (orthogonal) |
| Medium | Any (copper, fibre, radio) | **Fibre only** | Mostly wireless |
| Key device/idea | Synchronised multiplexer | Prism/diffraction grating | Overlapping orthogonal subcarriers |
| Example | T1 (1.544 Mbps) | DWDM backbones (Tbps) | WiFi, 4G |

**FDM vs TDM (2021/22):** frequency vs time division; guard bands vs guard times; analog vs digital; no sync vs sync needed; each user transmits continuously in a narrow band vs at full bandwidth in bursts. **Similarities:** both share one link among many users with **fixed (static) allocation**, both waste capacity when a user is idle, both need demultiplexing.

### Exam approach
Definition + small diagram of each (frequency axis for FDM/OFDM/WDM, time axis for TDM) → comparison table → one example each.

## B. CDMA calculation

> **2020/21 Q4(d):** Code Division Multiplexing (CDM) shows high tolerance to interference. Consider there are four CDM signal towers with the following chip sequences.
> A: 0 0 0 1 1 0 1 1 · B: 0 0 1 0 1 1 1 0 · C: 0 1 0 1 1 1 0 0 · D: 0 1 0 0 0 0 1 0
> Consider the towers transmitting the following bits at a given transmission. **Transmission-1: A = 1, B = 1, C = 0, D = 1.**
> i. State the bipolar chip sequence of all the stations. ii. Calculate the bipolar transmission sequences. iii. If a 5th CDM station wants to listen to tower C in Transmission-1, how does 5th CDM station achieve it?

**Related topic:** [[02.07 Code Division Multiple Access (CDMA)]]

### Solution
**(i)** Bipolar: 0 → −1, 1 → +1.
- A = (−1 −1 −1 +1 +1 −1 +1 +1)
- B = (−1 −1 +1 −1 +1 +1 +1 −1)
- C = (−1 +1 −1 +1 +1 +1 −1 −1)
- D = (−1 +1 −1 −1 −1 −1 +1 −1)

**(ii)** A bit 1 is sent as the chip sequence, a bit 0 as its **negation**. A, B, D send 1; C sends 0 → transmit A, B, **−C**, D, and the channel adds them:
| Chip | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| A | −1 | −1 | −1 | +1 | +1 | −1 | +1 | +1 |
| B | −1 | −1 | +1 | −1 | +1 | +1 | +1 | −1 |
| −C | +1 | −1 | +1 | −1 | −1 | −1 | +1 | +1 |
| D | −1 | +1 | −1 | −1 | −1 | −1 | +1 | −1 |
| **S** | −2 | −2 | 0 | −2 | 0 | −2 | +4 | 0 |

**S = (−2, −2, 0, −2, 0, −2, +4, 0)**

**(iii)** The 5th station computes the **normalised inner product** of the received sequence with C's chip sequence:
$$S\cdot C = \frac{(-2)(-1)+(-2)(1)+(0)(-1)+(-2)(1)+(0)(1)+(-2)(1)+(4)(-1)+(0)(-1)}{8} = \frac{-8}{8} = -1$$
**−1 ⇒ tower C transmitted 0.** This works because the chip sequences are **pairwise orthogonal** ($A\cdot C = B\cdot C = D\cdot C = 0$, $C\cdot C = 1$), so all other towers' contributions cancel out. (Check: S·A = S·B = S·D = +1 → bit 1.)

### Common mistakes
Forgetting to negate C, forgetting to divide by 8, adding 0/1 values instead of ±1.
