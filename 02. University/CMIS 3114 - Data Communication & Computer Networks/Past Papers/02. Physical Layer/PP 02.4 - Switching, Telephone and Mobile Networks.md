## A. Telephone network vs the Internet

> **2019/20 Q2(c), 2021/22 Q2(c), 2023/24 Q2(c):** Compare the Telephone network and the Internet, discussing the similarities and their differences.

**Related topic:** [[02.04 Public Switched Telephone Network]] · [[01.18 Example Networks]]

### Expected answer
The **telephone network (PSTN)** was built for **voice**: **local loops** (analog twisted pair) connect phones to **end offices**; **trunks** (digital fibre) connect **switching offices** in a hierarchy; calls use **circuit switching**. The **Internet** is a **network of networks** built for **data**: hosts connect through ISPs (POP), regional networks and backbones joined at NAPs; all nodes run **TCP/IP** and use **packet switching**.

| Feature | Telephone network | Internet |
|---|---|---|
| Designed for | Voice | Data / any application |
| Switching | **Circuit switching** (dedicated path) | **Packet switching** (store-and-forward) |
| Setup | Call setup required | No setup (IP connectionless) |
| Bandwidth | Fixed per call; wasted when idle | Shared dynamically |
| Route / order | Same path, in order | Independent routes, may reorder |
| Failure of a switch | Call dropped | Packets rerouted |
| Congestion | At setup (busy tone) | On every packet (delay/loss) |
| Intelligence | In central switches; simple phones | In end hosts; simpler routers |
| Addressing | Telephone numbers (hierarchical) | IP addresses (prefixes) |
| Charging | Per minute / distance | Flat rate / per volume |

**Similarities:** both are huge **WANs** connecting millions of users; both share the same **physical infrastructure** (copper local loops, fibre trunks, microwave, satellite) and **multiplexing** (TDM/WDM); both are **hierarchical** with switching nodes and **addressing**; today they **converge**: DSL Internet runs over phone lines, the phone core is digital, and voice is carried as **VoIP**.

### Exam approach
Short description of each → table of 6–8 differences → 3–4 similarities.

## B. Circuit vs packet switching

> **2019/20 Q5(b):** Explain the similarities and differences between Circuit Switching and Packet Switching.
> **2021/22 Q6(b):** Differentiate between the circuit switching and packet switching techniques. Provide example usages.

**Related topic:** [[02.09 Switching - Circuit, Message and Packet]]

### Expected answer
**Circuit switching:** switching equipment **seeks out a physical path all the way** from caller to receiver before communication; the path is reserved for the whole call (Strowger gear, modern exchanges).
**Packet switching:** packets are sent **as soon as they are available**, **no dedicated path is set up**; routers use **store-and-forward** to send each packet independently; packets may **arrive out of order**; packet size has a **tight upper limit** so no user monopolises a line.

| Item | Circuit switched | Packet switched |
|---|---|---|
| Call setup | Required | Not needed |
| Dedicated physical path | Yes | No |
| Each packet follows the same route | Yes | No |
| Packets arrive in order | Yes | No |
| Switch crash fatal | Yes | No |
| Bandwidth available | Fixed | Dynamic |
| Time of possible congestion | At setup | On every packet |
| Potentially wasted bandwidth | Yes | No |
| Store-and-forward | No | Yes |
| Charging | Per minute | Per packet |

**Similarities:** both move data through **intermediate switching nodes** from source to destination; both need **addressing**; both run over the same physical media and multiplexed trunks.
**Example usages:** circuit: **traditional telephone calls, GSM voice calls, leased lines**; packet: **the Internet (e-mail, web), VoIP, mobile data (GPRS/4G)**.

## C. GSM architecture

> **2019/20 Q5(c):** Following diagram represents the architecture of a simple GSM network which contain the BSC, MSC, HLR, VLR and PSTN. Identify each of these components and describe how they support a land line telephone to call a mobile phone.
> **2021/22 Q6(c):** Following diagram represents a sample GSM architecture. Identify the components represented as BSC, MSC, HLR, VLR and PSTN. Describe their functionality in the network.
> **2020/21 Q8(b)(ii):** Write short notes on any three of the following topics: GSM mobile architecture.

*(Both diagrams show mobiles → cell towers → two BSCs → MSC (with VLR and HLR) → PSTN.)*

**Related topic:** [[02.11 GSM Architecture]]

### Expected answer
- **Base station (cell tower):** radio link to mobiles in its cell.
- **BSC (Base Station Controller):** controls the **radio resources** of its cells (channel allocation) and **handles handoff** between them.
- **MSC (Mobile Switching Center):** **routes calls**, switches between BSCs and **connects the mobile network to the PSTN**.
- **VLR (Visitor Location Register):** database at the MSC of **mobiles currently in the cells it manages**, so the MSC knows where nearby mobiles are.
- **HLR (Home Location Register):** database with the **last known location of each subscriber**; used to **route incoming calls**.
- **PSTN:** the fixed public telephone network.
- (SIM card: identifies the subscriber and holds keys for authentication and encryption; GSM uses 124 channels × 8-slot TDM.)

**Landline → mobile call (2019/20):**
1. The landline call enters the **PSTN**, which routes it to the mobile operator's **MSC**.
2. The MSC asks the **HLR** for the mobile's **last known location** (which MSC/VLR area).
3. The call is routed to that MSC, which checks its **VLR** for the mobile's current location area.
4. The MSC instructs the **BSC(s)** to **page** the mobile through their base stations.
5. The mobile responds; the **BSC allocates a radio channel/time slot** and the MSC connects the call PSTN ↔ MSC ↔ BSC ↔ base station ↔ mobile.
6. If the user moves, the **BSC performs handoff**; HLR/VLR are updated as the mobile changes area.

## D. Handoff

> **2019/20 Q5(d), 2021/22 Q6(d):** Describe the procedure of "handoff" operation in Mobile Networks.

**Related topic:** [[02.10 Mobile Telephone System and Handoff]]

### Expected answer
**Handoff** transfers an ongoing call from one cell's base station to another as the user moves, without dropping the call.
1. The current base station notices the phone's **signal fading** as it approaches the cell edge.
2. It **asks all surrounding base stations how much power they are receiving** from the phone.
3. The controller (**MSC** in AMPS / **BSC** in GSM) selects the base station with the **strongest signal**.
4. A **new channel** is allocated in the new cell (adjacent cells use different frequencies).
5. The phone is instructed to **switch to the new channel/base station**; the call continues and the old channel is released.
6. The whole process takes about **300 ms**.
(Hard handoff = break before make; soft handoff in CDMA/3G = connected to both briefly.)
