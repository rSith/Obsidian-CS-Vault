## A. 2018/19 Q5(d)
> **Question:** A large number of consecutive IP addresses are available starting at 198.16.0.0. Suppose that four organizations, A, B, C, and D, request 4000, 2000, 4000, and 8000 addresses, respectively, and in that order. For each of these, give the first IP address assigned, the last IP address assigned, and the mask in the w.x.y.z/s notation.

### Solution
Round up: 4000 → **4096 (2¹², /20)**; 2000 → **2048 (2¹¹, /21)**; 8000 → **8192 (2¹³, /19)**. Allocate **in the order requested**, each block aligned to a multiple of its size (in the third octet: /20 → multiples of 16, /21 → 8, /19 → 32).

| Org | Need | Block | First address | Last address | Mask (w.x.y.z/s) |
|---|---|---|---|---|---|
| A | 4000 | 4096 | 198.16.0.0 | 198.16.15.255 | 198.16.0.0/20 |
| B | 2000 | 2048 | 198.16.16.0 | 198.16.23.255 | 198.16.16.0/21 |
| C | 4000 | 4096 | 198.16.32.0 | 198.16.47.255 | 198.16.32.0/20 |
| D | 8000 | 8192 | 198.16.64.0 | 198.16.95.255 | 198.16.64.0/19 |

**Why C starts at .32 and D at .64:** a /20 must start at a multiple of 16 in the third octet (16 is taken by B, 24 is not a multiple of 16) → 32; a /19 must start at a multiple of 32 (32 is taken by C) → 64. The gaps 198.16.24.0–31.255 and 198.16.48.0–63.255 stay free for future use.

## B. 2019/20 Q8(c) and 2022/23 Q8(c): department subnets of 192.168.14.0/24

> **2019/20 Q8(c):** Consider the address block used for the network as 192.168.14.0/24. The Physics department is assigned the following IP specification. Determine the IP specifications for the other three departments.
> *(Requirements table: Physics 28 computers, Chemistry 40, Mathematics 35, ICT 50; each with one printer and one department server. Given: Physics: Network ID 192.168.14.0, Broadcast ID 192.168.14.63, Subnet mask 255.255.255.192, Range 192.168.14.1 – 192.168.14.62.)*
> **2022/23 Q8(c):** Consider the address block used for the network as 192.168.14.0/24. The HR department is assigned the following IP specification. Determine the IP specifications for the other three departments.
> *(Requirements: HR 28 computers, Accounts 40, Administration 35, IT Service 50; each with one printer and one server. Given: HR: 192.168.14.0, 192.168.14.63, 255.255.255.192, 192.168.14.1 – 192.168.14.62.)*

### Solution
**Hosts needed** (computers + printer + server, + router interface): e.g. 40 + 1 + 1 + 1 = 43; 35 + 3 = 38; 50 + 3 = 53 (+ DNS, proxy, firewall in ICT/IT ≈ 56). All are **≤ 62 usable** hosts of a **/26 (64 addresses)**, and 4 × 64 = 256 fills the /24 exactly. The given first department already uses **/26 = 255.255.255.192**, so use /26 for all.

| Department (2019/20 / 2022/23) | Network ID | Broadcast ID | Subnet mask | Usable IP range |
|---|---|---|---|---|
| Physics / HR *(given)* | 192.168.14.0 | 192.168.14.63 | 255.255.255.192 | 192.168.14.1 – 192.168.14.62 |
| **Chemistry / Accounts** | **192.168.14.64** | **192.168.14.127** | **255.255.255.192** | **192.168.14.65 – 192.168.14.126** |
| **Mathematics / Admin** | **192.168.14.128** | **192.168.14.191** | **255.255.255.192** | **192.168.14.129 – 192.168.14.190** |
| **ICT / IT Service** | **192.168.14.192** | **192.168.14.255** | **255.255.255.192** | **192.168.14.193 – 192.168.14.254** |

**Explanation to write:** /26 → 32 − 26 = 6 host bits → 2⁶ = 64 addresses per subnet, 62 usable; mask last octet 11000000 = 192; subnets start at multiples of 64.

## C. 2020/21 Q8(a)
> **Question:** Some Universities in London wants to network their computers. Their requirements are as follows. *(Cambridge 2048, Oxford 4096, Edinburgh 1024 computers; table columns First IP, Last IP, Subnet Mask.)* Assuming that IP addresses are available from 194.24.0.0/20 block. Determine their IP address range and the subnet mask for each University.

> [!warning] Inconsistency in the question
> A **/20 block holds only 2¹² = 4096 addresses**, but the three universities need 2048 + 4096 + 1024 = **7168**. The question is adapted from a Tanenbaum example where addresses are available **starting at 194.24.0.0**. Treat it that way, state the assumption, and treat the numbers as **address counts** (each already a power of 2).

### Solution (largest block first: the lecture method)
| University | Addresses | Prefix | First IP | Last IP | Subnet mask |
|---|---|---|---|---|---|
| Oxford | 4096 = 2¹² | /20 | 194.24.0.0 | 194.24.15.255 | **255.255.240.0** |
| Cambridge | 2048 = 2¹¹ | /21 | 194.24.16.0 | 194.24.23.255 | **255.255.248.0** |
| Edinburgh | 1024 = 2¹⁰ | /22 | 194.24.24.0 | 194.24.27.255 | **255.255.252.0** |

*Alternative (allocating in the table's order, as in the textbook):* Cambridge 194.24.0.0 – 194.24.7.255 (/21); Edinburgh 194.24.8.0 – 194.24.11.255 (/22, fits the gap); Oxford 194.24.16.0 – 194.24.31.255 (/20, must start at a multiple of 16). Both are valid if every block is aligned. (Usable host ranges exclude the first and last address of each block.)

## D. 2021/22 Q8(d) and 2023/24 Q8(b): 192.168.1.0 into 30, 30, 60, 100

> **2021/22 Q8(d):** Consider that a Class C network (192.168.1.0) is required to be separated in to 4 segments which require 30, 30, 60 and 100 computers respectively. Determine the subnet mask and the address range for each segment.
> **2023/24 Q8(b):** Consider that a Class C network (192.168.1.0) is required to be separated in to 4 segments which require 30, 30, 60 and 100 computers respectively. Determine the subnet mask, Network address, Usable address range and the Broadcast address for the remaining three segments. *(Given row: 100 hosts → 255.255.255.128 (/25), 192.168.1.0, 192.168.1.1 – 192.168.1.126, 192.168.1.127.)*

### Solution
| Need | +2 | Block | Prefix | Mask |
|---|---|---|---|---|
| 100 | 102 | 128 | /25 | 255.255.255.128 |
| 60 | 62 | 64 | /26 | 255.255.255.192 |
| 30 | 32 | 32 | /27 | 255.255.255.224 |
| 30 | 32 | 32 | /27 | 255.255.255.224 |
Total 128 + 64 + 32 + 32 = 256 = the whole class C block. Allocate largest first:

| Hosts needed | Subnet mask | Network address | Usable IP range | Broadcast address |
|---|---|---|---|---|
| 100 *(given)* | 255.255.255.128 (/25) | 192.168.1.0 | 192.168.1.1 – 192.168.1.126 | 192.168.1.127 |
| **60** | **255.255.255.192 (/26)** | **192.168.1.128** | **192.168.1.129 – 192.168.1.190** | **192.168.1.191** |
| **30** | **255.255.255.224 (/27)** | **192.168.1.192** | **192.168.1.193 – 192.168.1.222** | **192.168.1.223** |
| **30** | **255.255.255.224 (/27)** | **192.168.1.224** | **192.168.1.225 – 192.168.1.254** | **192.168.1.255** |

Note: a /27 gives exactly **30 usable** addresses, enough for 30 computers but with no spare for the router interface. If a gateway address is also required, say so (the question's numbers are designed to fill the /24 exactly).

## E. 2023/24 Q8(a): classful network counts
> **Question:** Calculate the maximum number of class A, B and C network Ids (IP Addresses).

### Solution
| Class | Leading bits | Network bits that vary | Network IDs | Hosts per network |
|---|---|---|---|---|
| A | 0 | 8 − 1 = 7 | $2^7 = $ **128** (126 usable; 0 and 127 reserved) | $2^{24} - 2 = 16{,}777{,}214$ |
| B | 10 | 16 − 2 = 14 | $2^{14} = $ **16,384** | $2^{16} - 2 = 65{,}534$ |
| C | 110 | 24 − 3 = 21 | $2^{21} = $ **2,097,152** | $2^{8} - 2 = 254$ |
(The lecture: Class A up to 128 networks with 16 million hosts each; B 16,384 networks with up to 65,536 hosts; C 2 million networks with up to 256 hosts.)
