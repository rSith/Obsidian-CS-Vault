## E. Flooding

> **2021/22 Q8(b):** "Flooding" is a technique used for communication in computer networks. Describe methods of limiting the negative effects of this technique.
> **2023/24 Q7(b):** Define message flooding in computer networks. Explain two techniques that can be used to control flooding congestion.

### Expected answer
**Flooding:** a routing technique in which **every incoming packet is sent out on every outgoing line except the one it arrived on**. It needs no routing tables and always finds the shortest path, but it **generates vast numbers of duplicate packets** (infinitely many in a network with loops), causing congestion, so the process must be **damped**:
1. **Hop counter:** the sender puts a hop count in each packet's header (e.g. the path length or network diameter); **each router decrements it**, and the packet is **discarded when it reaches zero**.
2. **Sequence numbers / tracking flooded packets:** the **source router puts a sequence number** in every packet; **each router keeps a list per source router** of sequence numbers already seen; a packet whose (source, sequence number) is already on the list is **not flooded again** (discarded).
(Also: **selective flooding**, sending only on lines roughly in the right direction.)

## F. Distance vector routing

> **2020/21 Q8(b)(iv):** Write short notes on any three of the following topics: Distance Vector Routing.
> **2023/24 Q8(d):** Distance Vector Routing is a popular routing protocol. Calculate the new estimated delays and the output line for the router J in the following network. *(Vectors from J's four neighbours A, I, H, K; JA delay 8, JI 10, JH 12, JK 6.)*

### Short note
An **adaptive** routing algorithm. Each router keeps a **table (vector)** giving the **best known distance** to every destination and the **outgoing line** to use. Periodically each router **sends its vector to its neighbours**; each router measures the delay to each neighbour and computes, for every destination, **min over neighbours (delay to neighbour + neighbour's distance)**, choosing that neighbour as the line. Simple and distributed, but **converges slowly** after failures (count-to-infinity problem). Used in the original ARPANET and RIP.
