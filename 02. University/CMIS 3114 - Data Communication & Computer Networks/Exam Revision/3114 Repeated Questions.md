## B. Repeated concepts (asked in different words)
- **Uses of networks applied to a situation**: pandemic, economic crisis, online business, emergency healthcare.
- **Q1(d) essays** on security, misinformation, AI, social networks: same structure each time.
- **"Draw a diagram + device + media + usage"** for topologies and network design.
- **Compare two MAC protocols** (always one ALOHA variant vs one CSMA variant).
- **Layered communication**: message through 5 layers, host–router–router–host diagram, layer-k changes.
- **Physical media**: construction, wired vs wireless, long-distance options.

## C. Common answer skeletons
- **Compare X and Y:** 1-line definition of each → table (5–6 rows) → 2 similarities → example of each.
- **Short note (benefits and issues):** definition → how it works (diagram) → 3 benefits → 3 issues → example.
- **Step-by-step process:** numbered steps + a sequence diagram.
- **Calculation:** Given → formula → substitution → answer with units → interpretation.
