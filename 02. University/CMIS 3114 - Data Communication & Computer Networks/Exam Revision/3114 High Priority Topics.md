## Suggested order of study
1. **Guaranteed marks:** subnetting → framing (all three methods) → topologies → protocols/layering → uses/definition.
2. **Ch1 bank:** distributed systems, mobile computing, IoT, classification, client–server steps, TCP vs UDP, OSI vs TCP/IP, Telephone vs Internet, one essay plan.
3. **Calculations:** Nyquist/Shannon, Hamming code, sink trees, binary countdown, DV for J, parity burst, CRC, CDMA.
4. **Ch2/Ch4 theory:** media diagrams, multiplexing, ALOHA/CSMA, CSMA/CD, hidden/exposed + MACA.
5. **Ch5 procedures:** store-and-forward, flooding, routing tables/VC/label switching, design scenario.
6. **🟡/🟢 topics** as time allows.
