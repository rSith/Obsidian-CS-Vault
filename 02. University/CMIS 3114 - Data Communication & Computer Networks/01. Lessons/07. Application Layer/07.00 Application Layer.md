## What the application layer does
From the Ch1 slides: the application layer *"contains a variety of protocols that are commonly needed by users"*; in TCP/IP it is *"the residence of network applications and their application control logic"*: **HTTP** (Web), **FTP** (file transfer), **Telnet** (remote terminal), **SMTP** (mail), **DNS** (Domain Name System).

## Quick revision
| Protocol | Purpose | Transport / port |
|---|---|---|
| HTTP / HTTPS | Web pages | TCP 80 / 443 |
| DNS | Name → IP lookup | UDP 53 (TCP for large replies) |
| SMTP | Send / relay mail | TCP 25 (587 submission) |
| POP3 / IMAP | Retrieve mail | TCP 110 / 143 |
| FTP | File transfer | TCP 20/21 |
| Telnet / SSH | Remote login | TCP 23 / 22 |
| DHCP | Automatic IP configuration | UDP 67/68 |
