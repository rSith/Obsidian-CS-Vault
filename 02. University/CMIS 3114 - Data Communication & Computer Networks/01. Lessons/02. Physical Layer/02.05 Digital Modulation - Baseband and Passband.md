## 1. What is digital modulation?
**Lecture:** *"Wires and wireless channels carry **analog signals** such as continuously varying voltage, light intensity, or sound intensity. To send digital information, we must devise analog signals to represent bits. The process of **converting between bits and signals** that represent them is called **digital modulation**."*

Two families: **1. baseband transmission** and **2. passband transmission**.

## 2. Baseband transmission
**Lecture:** *"Schemes that directly convert bits into a signal in which the signal occupies frequencies from **zero up to a maximum** that depends on the signaling rate. It is common for **wires**."*

### NRZ (Non-Return-to-Zero)
- *"Use a **positive voltage to represent a 1** and a **negative voltage to represent a 0**."* For fibre: **light = 1, no light = 0**.
- The receiver converts the signal to bits by **sampling at regular intervals**.
- Called "non-return-to-zero" because the voltage stays at its level for the whole bit and does not return to 0 V in the middle.

### NRZI (Non-Return-to-Zero Inverted)
- *"Coding a **1 as a transition** and a **0 as no transition**, or vice versa."* (Course convention: **1 = change level, 0 = keep level**.)
- **USB** uses NRZI.
- Advantage: long runs of 1s still produce transitions, helping the receiver keep **clock synchronisation** (long runs of 0s still do not; USB fixes that with bit stuffing).

### Worked drawings (past-paper bit streams)
Assumptions to state in the answer: NRZ uses +V for 1 and −V for 0; NRZI starts at −V and **changes level at the start of every 1 bit**.

**2019/20 Q4(c): 10111011000**
```text
bits        1   0   1   1   1   0   1   1   0   0   0
NRZ  +V   ┌───┐   ┌───────────┐   ┌───────┐
     -V ──┘   └───┘           └───┘       └───────────
NRZI +V   ┌───────┐   ┌───┐       ┌───┐
     -V ──┘       └───┘   └───────┘   └───────────────
```

**2021/22 Q4(d): 11000110111**
```text
bits        1   1   0   0   0   1   1   0   1   1   1
NRZ  +V   ┌───────┐           ┌───────┐   ┌───────────
     -V ──┘       └───────────┘       └───┘
NRZI +V   ┌───┐               ┌───┐       ┌───┐   ┌───
     -V ──┘   └───────────────┘   └───────┘   └───┘
```

**How to draw NRZI quickly:** go bit by bit; on a **1, flip** the level; on a **0, stay**. Check: the number of transitions equals the number of 1s.

## 3. Passband transmission
**Lecture:** *"Schemes that regulate the **amplitude, phase, or frequency of a carrier signal** to convey bits. The signal occupies a **band of frequencies around the frequency of the carrier**. It is common for **wireless and optical channels** for which the signals must reside in a given frequency band."*

| Technique | What is changed | Lecture description |
|---|---|---|
| **ASK** (Amplitude Shift Keying) | **Amplitude** | *"Two different amplitudes are used to represent 0 and 1."* (e.g. carrier on = 1, carrier off/low = 0) |
| **FSK** (Frequency Shift Keying) | **Frequency** | *"Two or more different tones are used"* (e.g. high frequency = 1, low = 0) |
| **BPSK** (Binary Phase Shift Keying) | **Phase** | Carrier *"shifted 0 or 180 degrees at each symbol period."* "Binary" refers to the **two symbols**, not that each symbol has 2 bits |
| **QPSK** (Quadrature PSK) | Phase (4 shifts) | **45°, 135°, 225°, 315°** → **2 bits per symbol** |
| **QAM-16** (Quadrature Amplitude Modulation) | **Amplitude + phase** | **16 combinations** → **4 bits per symbol** |
| **QAM-64** | Amplitude + phase | **64 combinations** → **6 bits per symbol** (higher-order QAMs exist too) |

```text
 Binary signal:    0     1     0     0     1     0
 ASK:            ____ ∿∿∿∿∿ ____ ____ ∿∿∿∿∿ ____     (amplitude off/on)
 FSK:            ∿ ∿ ∿ ∿∿∿∿∿∿ ∿ ∿ ∿ ∿ ∿ ∿ ∿∿∿∿∿∿ ∿ ∿ ∿ (low / high frequency)
 PSK:            ∿∿∿∿ ∽∽∽∽ ∿∿∿∿ ∿∿∿∿ ∽∽∽∽ ∿∿∿∿     (phase flips 180° for a 1)
```

**Constellation diagrams:** points on a plane where **distance from origin = amplitude** and **angle = phase**. BPSK has 2 points, QPSK 4, QAM-16 16 in a grid. Denser constellations carry more bits per symbol but points are closer, so they are **more sensitive to noise**. The lecture shows modem constellations for **9,600 bps and 14,400 bps** modems.

### Bits per symbol
$$
\text{bits per symbol} = \log_2 V \qquad (V = \text{number of distinct symbols/levels})
$$

| Scheme | V | Bits/symbol |
|---|---|---|
| ASK, FSK, BPSK (binary) | 2 | 1 |
| QPSK | 4 | 2 |
| QAM-16 | 16 | 4 |
| QAM-64 | 64 | 6 |

### "How efficient is QAM-16 compared to binary ASK/FSK?" (2022/23 Q4c)
Binary ASK/FSK send **1 bit per symbol** ($\log_2 2 = 1$); QAM-16 sends **4 bits per symbol** ($\log_2 16 = 4$). At the same symbol (baud) rate and bandwidth, QAM-16 carries **4 times the data rate**. Using Nyquist ([[02.08 Maximum Data Rate - Nyquist and Shannon]]) on a 3 kHz channel: binary → $2 \times 3000 \times 1 = 6$ kbps; QAM-16 → $2 \times 3000 \times 4 = 24$ kbps. The cost: QAM-16 points are closer together, so it needs a **better signal-to-noise ratio**.

## 4. Baseband vs passband (exam table)

| | Baseband | Passband |
|---|---|---|
| Signal frequencies | From **0 Hz** up to a maximum | A **band around a carrier frequency** |
| How bits are sent | Directly as voltage levels / light on-off | By **modulating a carrier's** amplitude, frequency or phase |
| Typical channel | **Wires** (twisted pair, coax), fibre on/off | **Wireless** and **optical** channels, telephone modems, DSL |
| Techniques | **NRZ, NRZI** (also Manchester, 4B/5B: textbook) | **ASK, FSK, PSK (BPSK, QPSK), QAM-16/64** |
| Example | Ethernet over UTP, USB (NRZI) | WiFi, 4G, cable/telephone modems |
| Multiple users on one medium | Usually no (one signal) | Yes: different carriers (FDM/OFDM) |
