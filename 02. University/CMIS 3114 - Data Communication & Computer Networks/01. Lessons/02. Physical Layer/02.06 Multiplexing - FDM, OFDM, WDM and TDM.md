# 02.06 · Multiplexing: FDM, OFDM, WDM and TDM

> [!info] [[02.00 Physical Layer|Lesson 2]] · Lecture ref Ch2 slides 63–72 · Priority 🔴 High (5/6 papers)
> **Asked as:** "Compare and contrast FDM, TDM and OFDM" (2019/20 Q5a, 2022/23 Q6a) · "Compare and contrast TDM, WDM and OFDM" (2020/21 Q4c, 2023/24 Q4b) · "Compare and contrast FDM and TDM" (2021/22 Q6a)

## 1. What is multiplexing and why is it needed?
**Simple English:** sending **many users' signals over one shared link** at the same time.

A long-distance fibre or trunk is expensive and has far more capacity than one user needs. Multiplexing lets many conversations **share** it, cutting cost per user. The receiving end **demultiplexes** (separates) the signals. Multiplexing is one of the layer design issues ([[01.12 Design Issues for the Layers]]).

The lecture's **airport analogy** (from the CDMA slide):
- **TDM** = pairs of people **take turns** to speak.
- **FDM** = pairs of people speak at **different pitches**.
- **CDMA** = pairs of people speak in **different languages** → [[02.07 Code Division Multiple Access (CDMA)]].

## 2. FDM: Frequency Division Multiplexing
**Lecture:** *"Divides the spectrum into **frequency bands**, with each user having **exclusive possession of some band** in which to send their signal."*

- Example: **AM radio**: allocated spectrum about **1 MHz (roughly 500–1500 kHz)**; *"different frequencies are allocated to different logical channels (stations), each operating in a portion of the spectrum, with the interchannel separation great enough to prevent interference."*
- **Telephone example:** three voice channels multiplexed using FDM. Filters limit each voice channel to **about 3100 Hz**, but **4000 Hz is allocated per channel**. *"The excess is called a **guard band**. It keeps the channels well separated."*
- **Channel overlap:** real filters do not have sharp edges, so *"a strong spike at the edge of one channel will be felt in the adjacent one as non-thermal noise."*
- Steps (lecture figure): (a) original bandwidths (all 300–3100 Hz) → (b) each **raised to a different frequency** (e.g. 60, 64, 68 kHz) → (c) the **multiplexed channel**.

```text
 Frequency →
 | Ch1 |guard| Ch2 |guard| Ch3 |      all channels transmit ALL the time,
 60kHz       64kHz       68kHz 72kHz  each in its own frequency band
```

## 3. OFDM: Orthogonal Frequency Division Multiplexing
**Lecture:**
- *"It is possible to divide the spectrum efficiently **without using guard bands** for sending digital data (e.g., with QAM)."*
- *"Signals from each **subcarrier extend into adjacent ones**,"* but *"the frequency response of each subcarrier is designed so that it is **zero at the center of the adjacent subcarriers**. The subcarriers can therefore be **sampled at their center frequencies without interference** from their neighbors."* That is the meaning of **orthogonal**.
- Used in **WLAN (802.11a/g/n)**, **power-line communication**, **4G**.

```text
   ∩   ∩   ∩   ∩      overlapping subcarriers; at each peak,
  / \ / \ / \ / \     all other subcarriers are exactly zero
 ─────────────────►   frequency (no guard bands)
```

## 4. WDM: Wavelength Division Multiplexing
FDM for **optical fibre**: each signal uses a **different wavelength (colour) of light**. A **prism / diffraction grating** combines the wavelengths onto one shared fibre and splits them at the far end. The slide shows the standard figure: fibres 1–4, each with its own wavelength band, combined into one shared fibre and filtered at the other end. *(Slide is a picture only; explanation from the textbook.)* **Dense WDM** puts dozens of wavelengths on one fibre, giving terabits per second.

## 5. TDM: Time Division Multiplexing
**Lecture:**
- *"Each user periodically getting the **entire bandwidth** for a little **burst of time**."*
- *"Bits from each input stream are taken in a **fixed time slot** and output to the aggregate stream."*
- *"The streams must be **synchronized in time**."* Small intervals of **guard time** (like a frequency guard band) handle small timing variations.

```text
 Time →
 | A | B | C | D | A | B | C | D | A | ...   one frame = one slot per user,
 └──── frame 1 ───┘└──── frame 2 ───┘       each user uses the WHOLE bandwidth in its slot
```

### T1 carrier (lecture)
**24 voice channels × 64 kbps** multiplexed by TDM:
$$
24 \times 64\ \text{kbps} = 1.536\ \text{Mbps} \;+\; \text{framing} = \mathbf{1.544\ Mbps}
$$
(Each 125 µs frame has 24 × 8 = 192 data bits + **1 framing bit** = 193 bits; 193 × 8000 frames/s = 1.544 Mbps.) T1 streams are multiplexed into **higher carriers** (T2, T3, T4).

## 6. Comparison tables

### FDM vs TDM (2021/22 Q6a)
| Feature | FDM | TDM |
|---|---|---|
| What is divided | **Frequency** (bandwidth) | **Time** |
| Each user gets | A **narrow band all the time** | The **whole bandwidth for a short slot** |
| Separation | **Guard bands** | **Guard times** |
| Signal type | Mainly **analog** | Mainly **digital** |
| Synchronisation | Not required | **Required** (slots must line up) |
| Main problem | Crosstalk between adjacent bands; filters | Idle slots wasted if a user has nothing to send |
| Examples | AM/FM radio, TV, old telephone trunks | **T1/E1 carriers**, GSM (8-slot TDM), digital trunks |

**Similarities:** both share **one physical link among many users**, both give each user a **fixed, dedicated share** (static allocation), and both need a demultiplexer at the receiver.

### FDM vs TDM vs OFDM (2019/20, 2022/23)
| Feature | FDM | TDM | OFDM |
|---|---|---|---|
| Division | Frequency bands | Time slots | Many **orthogonal subcarriers** |
| Guard | Guard bands | Guard time | **No guard bands** (orthogonality) |
| Spectrum efficiency | Lower (guard bands waste spectrum) | Good | **Highest** (overlapping subcarriers) |
| Interference handling | Filters | Synchronisation | Each narrow subcarrier resists multipath fading |
| Users | One user per band | One user per slot | Subcarriers can carry one high-rate stream **or** many users (OFDMA) |
| Examples | Radio, TV | T1, GSM | **WiFi 802.11a/g/n, 4G LTE, WiMAX, ADSL (DMT), power-line** |

### TDM vs WDM vs OFDM (2020/21, 2023/24)
| Feature | TDM | WDM | OFDM |
|---|---|---|---|
| Domain | Time | **Wavelength of light** (optical FDM) | Frequency (orthogonal subcarriers) |
| Medium | Copper, fibre, radio | **Optical fibre only** | Mostly **wireless**, also DSL/power-line |
| Signal | Digital | Optical | Digital (QAM on each subcarrier) |
| Key idea | Each user sends in its own **time slot** | Each signal on its own **colour**, combined by a prism/grating | Subcarriers **overlap but do not interfere** |
| Capacity | Limited by line rate | **Huge** (Tbps with DWDM) | High spectral efficiency |
| Examples | T1 (1.544 Mbps), GSM | Undersea and backbone fibre | WiFi, 4G LTE, WiMAX |
