# 04.99 · Lesson Summary: MAC Sublayer

> [!abstract] Back to [[04.00 MAC Sublayer]] · Practice: [[PP 04.1 - ALOHA, CSMA and Collision-Free Protocols|PP 04.1]] · [[PP 04.2 - Wireless LAN Protocols and Standards|PP 04.2]]

## Must know
- **DLL = LLC + MAC.** LLC faces the network layer; MAC faces the physical layer and holds the **MAC address** (IEEE 802.3).
- **Main MAC problem:** allocate **one broadcast channel** among competing users.
- **Static allocation** (TDM/FDM/WDM): no interference, good for constant flow, bad for bursty traffic. **Dynamic** assumptions: independent traffic, single channel, observable collisions, continuous/slotted time, carrier sense or not.
- **Pure ALOHA:** send any time; random wait after collision; ~18%. **Slotted ALOHA:** send at slot start; ~37%.
- **CSMA:** listen first. **1-persistent** (send at once when idle) · **non-persistent** (busy → wait random time) · **p-persistent** (idle → send with prob. p, else defer a slot).
- **CSMA/CD:** listen while sending, stop on collision, random retry; channel is in **transmission, contention or idle** state.
- **Collision-free:** **bit-map** (N reservation slots, 1 bit/station overhead) · **token passing** (ring/bus) · **binary countdown** (OR of addresses, highest address wins).
- **Hidden terminal:** can't hear competitor → collision at receiver. **Exposed terminal:** hears a sender → needlessly waits.
- **MACA:** RTS (30 bytes, carries data length) → CTS → data. Hear RTS → quiet until CTS passes; hear CTS → quiet for the whole data frame.
- **802.11:** infrastructure vs ad hoc; b (DSSS 2.4 GHz 11 Mbps), a (OFDM 5 GHz 54), g (2.4 GHz 54), n (MIMO 600); data/control/management frames; services; WEP (broken) → WPA2 (AES).
- **802.16 WiMAX:** OFDM, 2–10 GHz, non-line-of-sight; competes with 3G/4G.

## Important comparisons
| Pure ALOHA | Slotted ALOHA | 1-persistent | Non-persistent | p-persistent |
|---|---|---|---|---|
| No sensing, any time | No sensing, slot start | Sense; send immediately when idle | Sense; if busy wait random | Sense; send with prob. p |

| Hidden terminal | Exposed terminal |
|---|---|
| Missed competitor → collision | Heard harmless sender → wasted time |

| Collision detection | Collision-free |
|---|---|
| Simple; good at light load; wasted collisions | No collisions; predictable; overhead |

## Important processes
1. **CSMA/CD:** sense → send → listen while sending → collision? abort, contention slots, random backoff → winner transmits → idle.
2. **Binary countdown (0001, 0101, 1000, 1001):** bit0 OR=1 (0001, 0101 quit) → bit1 0 → bit2 0 → bit3 OR=1 (1000 quits) → **1001 wins**.
3. **MACA:** RTS → CTS → DATA (→ ACK).
