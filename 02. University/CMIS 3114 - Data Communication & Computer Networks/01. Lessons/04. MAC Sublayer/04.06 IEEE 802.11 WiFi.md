# 04.06 · IEEE 802.11 (WiFi)

> [!info] [[04.00 MAC Sublayer|Lesson 4]] · Lecture ref Ch4 slides 25–31 · Priority 🟡 Medium (WLAN advantages/disadvantages, WiFi vs Li-Fi, WiFi vs WiMAX vs 4G, WLAN security in essays)

## 1. Two modes (lecture)
| Mode | Description | Use |
|---|---|---|
| **Infrastructure mode** | Each client is **associated with an AP (Access Point)**, which is in turn **connected to the other network** (wired LAN/Internet) | Homes, offices, campuses |
| **Ad hoc mode** | A collection of computers **associate directly** so they can send frames **to each other**, with no AP | Quick file sharing, MANETs |

## 2. 802.11 protocol stack (lecture figure)
The **physical layer** variants sit below the **MAC sublayer**, with the **logical link layer (LLC)** above (MAC + LLC = data link layer).

| Standard | Year | Physical technique | Band | Max rate |
|---|---|---|---|---|
| 802.11 (legacy) | 1997–1999 | Frequency hopping and infrared | 2.4 GHz | 1–2 Mbps |
| **802.11b** | 1999 | **Direct sequence spread spectrum** (1–2 Mbps, extended to **11 Mbps**) | **2.4 GHz** | 11 Mbps |
| **802.11a** | 1999 | **OFDM** | **5 GHz** | **54 Mbps** |
| **802.11g** | 2003 | OFDM, **2.4 GHz for compatibility** with b | 2.4 GHz | 54 Mbps |
| **802.11n** | Oct 2009 | **MIMO** (Multiple Input Multiple Output): up to **4 antennas** + wider channels | 2.4/5 GHz | up to **600 Mbps** (goal was ≥ 100 Mbps) |

MIMO: the signals of several streams **interfere at the receiver** but can be **separated** using MIMO techniques, multiplying throughput.

## 3. Frame structure
802.11 defines **three classes of frames** in the air: **data, control and management**. (The data frame has a Frame Control field, Duration, three addresses, Sequence number, Data, and a Check sequence/CRC: textbook detail.) **Control** frames include **RTS, CTS and ACK** ([[04.05 Hidden and Exposed Terminals and MACA]]).

## 4. 802.11 services (lecture)
| Service | What it does |
|---|---|
| **Association** | A mobile station **connects to an AP**; they exchange supported data rates, security arrangements, power-saving and QoS capabilities. The AP may **accept or reject** |
| **Reassociation** | Station **changes its preferred AP** (moving from one AP to another, like handoff) |
| **Disassociation** | Station or AP breaks the relationship (before shutting down or leaving) |
| **Authentication** | Station must authenticate before sending frames via the AP ("open" networks allow anyone) |
| **Distribution** | Once frames reach the AP, decides **how to route them**: local destination → send over the air; otherwise forward over the **wired** network |
| **Integration** | Translation needed to send/receive frames **outside the 802.11 LAN** |
| **Data delivery** | Lets stations transmit and receive data |
| **Privacy** | **Encryption and decryption** so data stays confidential; **WPA2 uses AES** |
| **QoS traffic scheduling** | Gives **voice and video** preference over best-effort and background traffic |
| **Transmit power control** | Adjusts power (regulatory limits, battery) |
| **Dynamic frequency selection** | Avoids frequencies used by radar etc. |

### Security: WEP → WPA → WPA2
- **WEP (Wired Equivalent Privacy):** authentication with a **pre-shared key before association**. *"Design flaws make WEP easy to compromise. Software to crack WEP passwords is now freely available!"*
- **WPA2 (WiFi Protected Access 2):** the AP can talk to an **authentication server** with a username/password database, **or** use a **pre-shared key** (network password). A **challenge–response** exchange of several frames lets the station prove its credentials; this happens **after association**. Encryption based on **AES**.
