# 01.99 · Lesson Summary: Introduction

> [!abstract] Back to [[01.00 Introduction]] · Practice: [[PP 01.1 - Networks, Uses and Distributed Systems|PP 01.1]] · [[PP 01.4 - Classification and Topologies|PP 01.4]] · [[PP 01.5 - Protocols, Layering and Services|PP 01.5]] · [[PP 01.6 - Reference Models, TCP and UDP|PP 01.6]]

## Must know
- **Computer network:** *"a collection of autonomous computers interconnected by a single technology"*; *"interconnection of 2 or more independent computers"* that can **exchange information**.
- **Why network:** resource sharing · robustness (fault tolerance through redundancy) · load balancing · location independence. **Problem:** security.
- **Internet** = network of networks. **Web** = distributed system running **on top of** the Internet (not a network).
- **Distributed system:** independent computers that **appear as a single coherent system**; **middleware**; e.g. the Web.
- **Uses:** business (resource sharing, communication, B2B, B2C), home (remote info, person-to-person, entertainment, e-commerce), mobile users, social issues.
- **Client–server** (request/reply, two processes) vs **P2P** (no fixed roles, BitTorrent).
- **Classifications:** type of connection · transmission technology (broadcast vs point-to-point; unicast/broadcast/multicast) · topology (bus, star, ring, full mesh, partial mesh, tree) · scale (BAN, PAN, LAN, MAN, WAN).
- **Protocol:** rules for the **format and meaning** of messages. **Layering:** divide and conquer; each layer offers **services** to the layer above and hides its implementation.
- **Message through layers:** headers added going down (L3 splits M into M1, M2; L2 adds header + trailer), stripped going up.
- **Design issues:** addressing, error control, QoS, flow control, multiplexing, routing, message size.
- **Services:** connection-oriented (telephone) vs connectionless (post office); datagram, acknowledged datagram, request–reply.
- **Primitives:** LISTEN, CONNECT, ACCEPT, RECEIVE, SEND, DISCONNECT (9 phases, 6 packets).
- **OSI (7)** vs **TCP/IP (4)** vs **Hybrid (5)**.

## Important definitions

| Term | Definition |
|---|---|
| Protocol | A set of rules that specify the format and meaning of messages exchanged between computers |
| Protocol suite / hierarchy | A set of related protocols designed for compatibility |
| Peers | Entities in the corresponding layers on different machines |
| Interface | Defines the services one layer offers the layer above |
| Service | A set of primitives a layer provides to the layer above |
| Network architecture | A set of layers and protocols |
| Protocol stack | List of protocols used by a system, one per layer |
| Topology | The way network elements are interconnected (physical layout) |
| Store-and-forward subnet | Packets received whole at each router, stored, then forwarded |

## Important comparisons

| Connection-oriented | Connectionless |
|---|---|
| Setup → transfer → release; in order | Full address on each message; may reorder |
| TCP, virtual circuits | UDP, IP |

| TCP | UDP |
|---|---|
| Reliable, connection-oriented byte stream, flow control | Unreliable, connectionless, fast |
| Web, e-mail, FTP | DNS queries, VoIP, video |

| OSI | TCP/IP |
|---|---|
| 7 layers, model first, services/interfaces/protocols distinct | 4 layers, protocols first, not distinct |
| Network: both modes; transport: connection-oriented only | Network: connectionless only; transport: both |

| LAN | MAN | WAN |
|---|---|---|
| Building/campus, private, fast | City, cable TV | Country/world, routers, store-and-forward |

## Important processes
1. **Client–server connection-oriented interaction:** LISTEN → CONNECT (1) → OS unblocks listener, ACK (2) → client released → RECEIVE → SEND request (3) → server works, SEND reply (4) → DISCONNECT (5) → DISCONNECT (6).
2. **Message through 5 layers:** M → H4+M → split into H3+H4+M1 and H3+M2 → H2…T2 frames → bits → reverse at the receiver.
3. **Store-and-forward in a WAN:** cut into numbered packets → each router receives whole packet, stores, forwards (local routing decision) → reassemble.

## Important formula
Links in a full mesh of $n$ nodes: $\dfrac{n(n-1)}{2}$
