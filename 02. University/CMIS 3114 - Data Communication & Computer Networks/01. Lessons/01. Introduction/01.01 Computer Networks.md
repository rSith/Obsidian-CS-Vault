# 01.01 · Computer Networks: Definition, Purpose and Problems

> [!info] [[01.00 Introduction|Lesson 1]] · Lecture ref Ch1 §1.1 (slides 10–18) · Priority 🔴 High (6/6 papers)
> **Asked as:** "Define what is a computer network and discuss its advantages and disadvantages" (2020/21 Q1a) · "Define the term Computer Network. Describe the 4 reasons as to why Computer Networks are required" (2021/22 Q1a) · "Describe four (4) reasons why Computer Networks are required" (2022/23 Q1a) · "Define … and how it has become a part of daily life" (2019/20 Q1a)

## 1. What is it?

**Simple English:** a computer network is two or more computers joined together so they can send information to each other.

**Lecture definitions (learn both word for word):**
- *"A collection of **autonomous** computers interconnected by a **single technology**."* (Tanenbaum)
- *"A computer network is defined as the interconnection of **2 or more independent computers**."*
- Two computers are **interconnected** if they are **able to exchange information**.

**Key terms:**
- **Autonomous / independent:** each computer can work on its own; no computer is the master of another.
- **Interconnected:** connected by copper wire, fibre, microwave, infrared, satellite and so on, so that data can move between them.

## 2. Why is it needed? (the history in the lecture)

| Before networks | After networks |
|---|---|
| One large **mainframe** did all the processing for a business or university | Many **smaller, cheaper PCs/workstations** on desks |
| Users went to the computer | Users access **local and remote resources** from their desk |

*"The old model of a single computer serving all of the organization's computational needs has been replaced by one in which a large number of separate but interconnected computers do the job. These systems are called computer networks."*

A network is a **collection of interconnected end systems**: computing devices (mainframes, workstations, PCs, palmtops) and peripherals (printers, scanners, terminals).

## 3. Why network? The four reasons (exam favourite)

| Reason | Meaning | Example |
|---|---|---|
| **1. Resource sharing** | Share **hardware** (printers, disks, terminals), **software** (text processors, compilers) and **data** | 20 office PCs share one laser printer and one customer database |
| **2. Robustness** | **Fault tolerance through redundancy**: if one machine fails, another copy takes over | Bank data replicated on two servers; one fails, service continues |
| **3. Load balancing** | **Processing and data can be distributed** over the network | A busy website spreads requests across several servers |
| **4. Location independence** | Users can access their files **from anywhere** in the network | A student opens the same files from any lab PC |

## 4. Problems (disadvantages)

The lecture lists **security**:
- *"It's much easier to protect centralized resources than when they are distributed."*
- *"The network itself [is] a target."* (attackers can attack the links and devices, not only the computers)

> [!note] Additional explanation (beyond the slides)
> For a "discuss advantages and disadvantages" question you can add other standard disadvantages: **cost** of cabling and devices, **need for administration** (skilled staff), **viruses/malware spread quickly** across connected machines, **dependence on the network** (if the server or link fails, many users stop work), and **privacy risks** (see [[01.06 Social Issues of Computer Networks]]).

## 5. What a network does

A network provides communication that is **reliable, fair and efficient** from one application to another. It **automatically detects and corrects**:
- data **corruption**
- data **loss**
- **duplication**
- **out-of-order delivery**

and it **automatically finds the optimal path** from source to destination. Each of these jobs belongs to a layer you will study later: error detection in [[03.04 Error Detection - Parity, Interleaving and Checksum]], ordering and duplicates in [[03.03 Error Control and Flow Control]], best path in [[05.03 Routing Algorithms and the Sink Tree]].

## 6. Network vs Internet vs Web (a common trap)

The lecture makes a surprising point: *"neither the Internet nor the World Wide Web is a computer network."*

| Term | What it really is |
|---|---|
| **Computer network** | Autonomous computers interconnected by **one technology**; users see the actual machines |
| **Internet** | **A network of networks**: many different networks interconnected by routers |
| **World Wide Web** | **Not a network**: a **distributed system / distributed application** that runs **on top of the Internet**, where everything looks like a document (web page) |

See [[01.02 Distributed Systems]] for why the Web counts as a distributed system.

## 7. Practical networking example

Your university lab: 40 PCs connect by twisted-pair cable to a **switch** (a LAN). The switch connects to the faculty **router**, which connects to the ISP and the **Internet** (a network of networks). When you open Google Docs in a browser, you use the **Web** (a distributed application) running over the Internet.
