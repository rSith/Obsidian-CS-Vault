# 05.99 · Lesson Summary: Network Layer

> [!abstract] Back to [[05.00 Network Layer]] · Practice: [[PP 05.1 - Store-and-Forward, Datagram and VC Networks|PP 05.1]] · [[PP 05.2 - Routing - Sink Tree, Flooding and Distance Vector|PP 05.2]] · [[PP 05.3 - IP Addressing and Subnetting|PP 05.3]] · [[PP 05.4 - Network Design Scenarios|PP 05.4]]

## Must know
- **Job:** packets from source **all the way** to destination over many hops.
- **Store-and-forward:** host → nearest router; packet **stored until fully arrived and checksum verified**; forwarded router to router; delivered.
- **Services to transport (3 goals):** independent of router technology · transport shielded from number/type/topology of routers · **uniform numbering plan** across LANs and WANs.
- **Connectionless** = datagrams, datagram network, **IP**. **Connection-oriented** = virtual circuits, tables set up in advance, **label switching**, **MPLS** (20-bit label inside ISPs).
- **Routing:** forwarding (look up table per packet) vs routing algorithm (fill tables). Properties: correctness, simplicity, robustness, stability, fairness, efficiency. **Non-adaptive (static)** vs **adaptive (dynamic)**.
- **Optimality principle → sink tree** (optimal routes to one destination form a tree; metric = hops).
- **Shortest path (Dijkstra)** on a weighted graph.
- **Flooding:** every packet out on every line except the arrival line; damp with **hop counter** or **sequence numbers per source**.
- **Distance vector:** table of (distance, outgoing line); new = min over neighbours of (delay to neighbour + neighbour's distance).
- **IPv4 header:** 20-byte fixed + options; Version, IHL, ToS, Total length (≤ 65,535), Identification, DF, MF, Fragment offset, TTL, Protocol, Header checksum, Source, Destination, Options.
- **IP address:** 32 bits, dotted decimal, network + host, prefix **/n**, **subnet mask** ANDed to get the network.
- **Classes:** A (0, 128 nets × 16M) · B (10, 16,384 × 65,536) · C (110, 2M × 256) · D multicast · E reserved. Special: this host, broadcast, loopback 127.
- **Subnetting:** largest block first, powers of 2, aligned starts.

## Important formulas
$$
2^{32-n}\ \text{addresses in a /n}\qquad \text{prefix} = 32-\log_2(\text{block})\qquad \text{usable} = \text{block}-2
$$
$$
D_J(\text{dest}) = \min_X\big(\text{delay}(J\to X) + D_X(\text{dest})\big)
$$
$$
\text{Class A: }2^7\qquad\text{Class B: }2^{14}\qquad\text{Class C: }2^{21}\ \text{network IDs}
$$

## Important comparisons
| Datagram | Virtual circuit |
|---|---|
| No setup; full address per packet; no state in routers; independent routing; router failure loses only in-transit packets; QoS/congestion control difficult | Setup required; short VC number; table entry per VC; all packets follow the route; failure kills VCs through it; QoS/congestion control easy |

| Static routing | Adaptive routing |
|---|---|
| Computed offline, loaded at boot | Reacts to topology/traffic changes |

| Distance vector | Link state |
|---|---|
| Tell neighbours your distances | Flood link costs; each runs Dijkstra |
| Slow convergence, count-to-infinity | Fast convergence |

## Important processes
- **Sink tree:** BFS from the destination, one parent per router.
- **Label switching:** H3 reuses label 1 → router A maps (H3, 1) → (C, 2); each router swaps labels.
- **Subnet:** sort → round up → prefix → align → network/broadcast/usable.
