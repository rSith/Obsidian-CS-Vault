# 05.08 · IP Addresses, Prefixes, Subnet Masks and Classful Addressing

> [!info] [[05.00 Network Layer|Lesson 5]] · Lecture ref Ch5-L2 slides 8–13 · Priority 🟡 Medium (basis of the 6/6 subnetting question)
> **Asked as:** "Calculate the maximum number of class A, B and C network Ids (IP Addresses)" (2023/24 Q8a)

## 1. IPv4 addresses (lecture)
- *"A defining feature of IPv4 is its **32-bit addresses**."* Every host and router on the Internet has an IP address, used in the Source/Destination fields.
- Each address = a **variable-length network portion** (top bits) + a **host portion** (bottom bits).
- A network = a **contiguous block** of IP address space, called a **prefix**.
- Written in **dotted decimal**: each of the 4 bytes as a decimal 0–255, e.g. **128.208.2.151**.

```text
 128      .208      .2        .151
 10000000  11010000  00000010  10010111
 └──────── network (prefix) ────────┘└ host ┘   (for a /24)
```

## 2. Prefix notation (/n)
- *"Prefixes are written by giving the **lowest IP address in the block** and the size of the block, which is a **power of 2**."* After the address write a **slash and the length in bits of the network portion**.
- E.g. a prefix of $2^8$ addresses leaves **24 bits** for the network → **128.208.0.0/24**.
- *"The prefix length cannot be inferred from the IP address alone"*, so routing protocols carry prefixes to routers.

$$
\text{addresses in a /n block} = 2^{\,32-n}
$$

## 3. Subnet mask
- *"The length of the prefix corresponds to a **binary mask of 1s in the network portion**. When written out this way, it is called a **subnet mask**."*
- *"It can be **ANDed** with the IP address to extract only the network portion."*

**Example:** IP 192.168.14.70 with mask /26 = 255.255.255.192:
```text
 IP     192.168.14.70   = 11000000.10101000.00001110.01000110
 Mask   255.255.255.192 = 11111111.11111111.11111111.11000000
 AND →  192.168.14.64   = 11000000.10101000.00001110.01000000   (network address)
```

### Mask reference table (learn this)
| Prefix | Last octet bits | Mask | Block size (addresses) | Usable hosts |
|---|---|---|---|---|
| /24 | 00000000 | 255.255.255.0 | 256 | 254 |
| /25 | 10000000 | 255.255.255.128 | 128 | 126 |
| /26 | 11000000 | 255.255.255.192 | 64 | 62 |
| /27 | 11100000 | 255.255.255.224 | 32 | 30 |
| /28 | 11110000 | 255.255.255.240 | 16 | 14 |
| /29 | 11111000 | 255.255.255.248 | 8 | 6 |
| /30 | 11111100 | 255.255.255.252 | 4 | 2 |
| /20 | (3rd octet 11110000) | 255.255.240.0 | 4096 | 4094 |
| /21 | (3rd octet 11111000) | 255.255.248.0 | 2048 | 2046 |
| /22 | (3rd octet 11111100) | 255.255.252.0 | 1024 | 1022 |
| /19 | (3rd octet 11100000) | 255.255.224.0 | 8192 | 8190 |

Usable hosts = block size − 2 (the **network address** and the **broadcast address** cannot be given to hosts).

## 4. Advantage of prefixes (lecture)
*"Routers can forward packets based on **only the network portion** of the address, as long as each of the networks has a unique address block. The host portion does not matter to the routers because all hosts on the same network will be sent in the same direction. It is only when the packets reach the network for which they are destined that they are forwarded to the correct host."* → **smaller routing tables**.

## 5. Classful addressing (lecture)

| Class | Leading bits | Format | Range | Networks | Hosts per network |
|---|---|---|---|---|---|
| **A** | 0 | 8-bit network (7 usable bits) · 24-bit host | 1.0.0.0 – 127.255.255.255 | **128** | **16 million** ($2^{24}$) |
| **B** | 10 | 16-bit network (14 usable bits) · 16-bit host | 128.0.0.0 – 191.255.255.255 | **16,384** | **65,536** ($2^{16}$) |
| **C** | 110 | 24-bit network (21 usable bits) · 8-bit host | 192.0.0.0 – 223.255.255.255 | **2 million** ($2^{21}$) | **256** ($2^{8}$) |
| D | 1110 | Multicast address | 224.0.0.0 – 239.255.255.255 | — | — |
| E | 1111 | Reserved for future use | 240.0.0.0 – 255.255.255.255 | — | — |

### Worked: maximum number of network IDs (2023/24 Q8a)
The class bits are fixed, so only the remaining network bits vary:
- **Class A:** 8 network bits − 1 fixed bit = 7 bits → $2^7 = \mathbf{128}$ network IDs (126 usable, since 0.x.x.x and 127.x.x.x (loopback) are reserved). Hosts: $2^{24} - 2 = 16{,}777{,}214$.
- **Class B:** 16 − 2 = 14 bits → $2^{14} = \mathbf{16{,}384}$ network IDs. Hosts: $2^{16} - 2 = 65{,}534$.
- **Class C:** 24 − 3 = 21 bits → $2^{21} = \mathbf{2{,}097{,}152}$ network IDs. Hosts: $2^8 - 2 = 254$.

## 6. Special IP addresses (lecture table)
| Address | Meaning |
|---|---|
| All 0s | **This host** (used during boot-up) |
| 0s network part + host | **A host on this network** |
| All 1s (255.255.255.255) | **Broadcast on the local network** |
| Network + all-1s host part | **Broadcast to a distant network** |
| 127.anything | **Loopback** (packets never leave the machine) |
