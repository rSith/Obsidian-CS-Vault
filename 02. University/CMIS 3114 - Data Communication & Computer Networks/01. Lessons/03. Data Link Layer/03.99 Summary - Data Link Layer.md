# 03.99 · Lesson Summary: Data Link Layer

> [!abstract] Back to [[03.00 Data Link Layer]] · Practice: [[PP 03.1 - DLL Functions and Framing|PP 03.1]] · [[PP 03.2 - Error Detection and Correction|PP 03.2]] · [[PP 03.3 - Sliding Window and Go-Back-N|PP 03.3]]

## Must know
- **Functions:** service interface to the network layer · dealing with transmission errors · regulating data flow; tools: framing, error control, flow control. DLL is **best effort**.
- **Services:** unacknowledged connectionless (**Ethernet**) · acknowledged connectionless (**WiFi**) · acknowledged connection-oriented (**satellite**, 3 phases, exactly once, in order).
- **Framing:** byte count (can't resynchronise) · FLAG + ESC byte stuffing · 01111110 + bit stuffing (0 after five 1s; USB) · coding violations (preamble + length).
- **Error control:** ACKs, timers, sequence numbers → exactly once. **Flow control:** feedback-based vs rate-based.
- **Errors:** single-bit (thermal noise) vs burst. **Detection** (parity, checksum, CRC; retransmit) vs **correction** (Hamming, FEC).
- **Parity** detects odd numbers of errors; **interleaving** (parity per column) detects a burst ≤ n.
- **Internet checksum:** one's complement sum, complement; receiver sum = FFFF → 0000 = OK.
- **CRC:** append r zeros, modulo-2 divide by G, append remainder; receiver remainder 0 = OK.
- **Hamming distance:** XOR and count. Detect d → distance d+1; correct d → 2d+1.
- **Hamming code:** check bits at 1, 2, 4, 8, 16; $m+r+1 \le 2^r$; syndrome = position of the bad bit.
- **Sliding window:** 3-bit seq numbers 0–7; window size 1 = stop-and-wait. **Go-Back-N** (receiver window 1, discard and resend all) vs **selective repeat** (large receiver window, buffer, resend only the bad frame).

## Important formulas
$$
\text{code rate} = \frac{m}{n}\qquad n=m+r\qquad m+r+1\le 2^{r}
$$
$$
\text{detect } d \Rightarrow D \ge d+1\qquad \text{correct } d \Rightarrow D \ge 2d+1
$$
$$
\text{max burst detected by interleaved parity} = n\ (\text{number of parity bits})
$$

## Must-remember answers
| Question | Answer |
|---|---|
| Byte count ABCD/EFG/HIJKLM | `5 A B C D 4 E F G 7 H I J K L M` |
| Byte stuffing `A B ESC C ESC FLAG FLAG D` | `A B ESC ESC C ESC ESC ESC FLAG ESC FLAG D` |
| Bit stuffing `0111101111101111110` | `011110111110011111010` |
| CRC 10011001, G = 1011 | Remainder 100 → `10011001100` |
| Hamming, 16-bit `1101001100110101` | r = 5 → `011110110011001110101` |
| Codewords 00000/01011/10101/11110 | Min distance 3 → corrects 1 error |
| Hamming (11,7) for "A" 1000001 | `00100001001` |

## Important comparisons
| Error detection | Error correction |
|---|---|
| Little redundancy, retransmit | Much redundancy, fix at receiver (FEC) |
| Parity, checksum, CRC | Hamming code |

| Go-Back-N | Selective Repeat |
|---|---|
| Receiver window 1, discards out-of-order | Receiver window large, buffers |
| Resends bad frame and all after it | Resends only the bad frame |
