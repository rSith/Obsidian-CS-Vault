# 06.03 · TCP Flow Control and Congestion Control

> [!warning] Not in the available CMIS 3114 slides
> Additional explanation from the reference textbook (Tanenbaum 6e §6.3, §6.5). Not examined in the six past papers. Related lecture ideas: feedback-based flow control ([[03.03 Error Control and Flow Control]]), sliding windows ([[03.09 Sliding Window and Go-Back-N]]), "congestion" as a network-layer job ([[01.15 OSI Reference Model]]).

## 1. Flow control: protect the receiver
**Purpose:** stop a fast sender overflowing a slow receiver's buffer.
**Mechanism (sliding window):**
1. The receiver advertises a **window size (rwnd)** in every ACK: how many more bytes it can buffer.
2. The sender may have at most **rwnd** unacknowledged bytes outstanding.
3. As the application reads data, the window opens again; if rwnd = 0 the sender **stops** (and probes occasionally).

## 2. Congestion control: protect the network
**Purpose:** stop senders overloading routers and links (queues overflow → packet loss → retransmissions → worse congestion).
**Mechanism:** the sender keeps a **congestion window (cwnd)**; it may send at most **min(cwnd, rwnd)** bytes unacknowledged. Packet **loss** (timeout or duplicate ACKs) is taken as a sign of congestion.

### Algorithm (Reno-style, step by step)
1. **Slow start:** cwnd starts at 1 segment and **doubles every round-trip** (+1 segment per ACK) → exponential growth.
2. When cwnd reaches the **threshold (ssthresh)**, switch to **congestion avoidance**: cwnd grows by **1 segment per RTT** (linear, **additive increase**).
3. On **3 duplicate ACKs** (one segment lost): **fast retransmit** it, set ssthresh = cwnd/2 and cwnd = ssthresh (**multiplicative decrease**, fast recovery).
4. On a **timeout** (serious congestion): ssthresh = cwnd/2, cwnd = 1, back to slow start.

```text
 cwnd
  │            /\        ← loss: halve
  │           /  \  /\
  │          /    \/  \/  …   "sawtooth" (AIMD)
  │      __/  ← linear (congestion avoidance)
  │    /
  │  /  ← exponential (slow start)
  └──────────────────────────► time (RTTs)
```

## 3. Comparison
| | Flow control | Congestion control |
|---|---|---|
| Protects | The **receiver** | The **network** |
| Signal | Receiver's advertised window (rwnd) | Packet loss / delay (cwnd) |
| Scope | One sender–receiver pair | All flows sharing the routers |
| Layer | DLL and transport | Network and transport |
