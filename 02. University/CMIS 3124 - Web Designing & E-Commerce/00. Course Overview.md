## Suggested study order
1. **🔴 Current-paper heavy hitters:** 06 RWD (Q2 is a whole question) → 13 Security → 10 E-Commerce → 09 Accessibility → 02 Architecture.
2. **🔴 Short-answer topics:** 05 HCI (UI/UX, cognitive load, usability) → 04 CARP → 08 Bootstrap code → 12 Ethics and dark patterns → 01 Web evolution.
3. **🟡 Topics on the same questions:** 15 Future Trends + 14 AI (share Q3) → 11 SEO and influencers → 03 Web Engineering.
4. **🟢 Background:** 00 HTML/CSS (needed to write code answers) → 07 React.
5. **Practise:** answer the full 2023/24 paper from [[Papers by Year]] under timed conditions, then the old-paper scenario questions in [[PP 10 - E-Commerce]].
