# 06.99 · Lesson Summary: Responsive Web Design

> [!abstract] Back to [[06.00 Responsive Web Design]] · Practice: [[PP 06 - Responsive Web Design]]

## Must know
- **Layout history:** free-flowing (Mosaic) → tables and frames (Netscape frames March 1996, HTML 3.0) → XHTML (Jan 2000) + CSS (IE5 Mac March 2000); CRT → LCD, resized windows.
- **Fixed vs flexible debate** (John Allsopp, *A Dao of Web Design*): the designer controls (fixed) vs the user chooses (fluid %, elastic em). Flexible won, but the tools were weak, and the blog's multi-column layout meant nested divs, so many designers went back to fixed.
- **Mobile web:** handheld stylesheet → scaled desktop → **separate mobile site** (own domain). **One Web** = same information and services on every device (not the same representation). **Mobile first** = design narrow first, then tweak for wider.
- **RWD (Ethan Marcotte, May 2010, A List Apart):** **flexible grid + flexible images + media queries**, plus the **viewport meta tag**.
- **Viewport:** `<meta name="viewport" content="width=device-width, initial-scale=1.0" />`. Without it, phones use a 980px viewport.
- **Media types (CSS2):** all, print, screen, speech. **Features (CSS3):** width (min/max), aspect-ratio, orientation, resolution. **Operators:** and, comma (or), not.
- **Ordering:** graceful degradation = large first + `max-width` descending; mobile first / progressive enhancement = small first + `min-width` ascending.
- **Breakpoints:** where a media query changes styles; per component; narrow first; em-based.
- **Designing responsively:** content hierarchy (content parity), layout (1 column → more; 45–75 characters per line), typography, navigation, images (smallest by default), special content (forms with flexbox, responsive tables, scale video, link to map apps).
- **Testing:** real devices (best), emulators, browser testing services.
- **Performance:** eliminate unnecessary downloads, minify, leverage caching, reduce HTTP requests (combine files, fewer images), optimise images, enable compression.
- **HTTP caching + ETags:** server-generated tokens let the browser check whether its cached copy is still current.

## Key code
```css
@media screen and (orientation: portrait) and (max-width: 800px) {
  body { background-color: LightGreen; }
}
@media screen and (min-width: 768px) {
  body { font-size: 80px; color: DarkBlue; }
}
img { max-width: 100%; height: auto; }
.layout { display: grid; grid-template-columns: 2fr 1fr; }
```

## Important comparisons
| Fixed | Fluid | Elastic |
|---|---|---|
| px | % | em |
| Designer control; predictable | Adapts to the window | Scales with font size |
| Horizontal scroll / wasted space | Very long lines on wide screens | |

| Graceful degradation | Progressive enhancement (mobile first) |
|---|---|
| Large first, `max-width` ↓ | Small first, `min-width` ↑ |
