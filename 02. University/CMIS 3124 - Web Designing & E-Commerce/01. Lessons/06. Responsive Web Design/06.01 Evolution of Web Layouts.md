# 06.01 · Evolution of Web Layouts

> [!info] [[06.00 Responsive Web Design|Lesson 6]] · Lecture ref L6.1, L6.3 · Priority 🟢 Low (background for why RWD exists)

## Timeline (lecture)

| Period | Layout approach | Details |
|---|---|---|
| **Mid 1990s** | **Free-flowing content** | Content flowed to the **margins of the browser window** (e.g. the **Mosaic** browser). Screens were low-resolution, so text lines rarely got too long. |
| **Late 1990s** | **HTML4 tables and frames** | As interfaces got more complex, **tables or frames** were used to divide and arrange page components. **Netscape Navigator introduced frames in March 1996**: different page elements marked up as **different HTML files**. Frames were included in the **HTML 3.0** specification by the W3C. |
| **2000s** | **XHTML and CSS** | **XHTML** became a W3C recommendation in **January 2000**. **CSS 1.0** was recommended in **December 1996**, but the first browser to fully support it (**IE5 for Mac**) only came in **March 2000**, by which time **CSS2** had been recommended. Monitors changed from **CRT to LCD** (bigger, new aspect ratios, higher resolutions), and browsers were now viewed in **resized windows** instead of full-screen. |

### Why tables for layout were a problem

> [!note] Beyond the slides
> Tables were meant for **tabular data**, not page layout. Table layouts were rigid, hard to maintain and confusing for screen readers. CSS separated **presentation** from **structure**, which is the basis of modern design.

```html
<!-- 1990s style: layout with a table -->
<table width="800">
  <tr><td width="200">Menu</td><td width="600">Content</td></tr>
</table>
```

## Complexity and divs (lecture)
- The **philosophical debate was won by flexible design and user choice** ([[06.02 Fixed vs Flexible Layouts]]).
- But **the available tools (XHTML and CSS)** could not easily build **simple, flexible designs in all the column combinations required**.
- With the **rise of the blog** and its distinctive **multi-column layout**, many designers took a **pragmatic view and went back to fixed-width designs**.
- The lecture shows a **3-column liquid layout** that needed a complicated **nested div structure**.

```html
<!-- A "liquid" 3-column layout needed wrappers inside wrappers -->
<div class="colmask">
  <div class="colmid">
    <div class="colleft">
      <div class="col1">Main content</div>
      <div class="col2">Left column</div>
      <div class="col3">Right column</div>
    </div>
  </div>
</div>
```

Modern tools (**CSS Grid and Flexbox**) solved this ([[06.04 Making Pages Responsive]]).
