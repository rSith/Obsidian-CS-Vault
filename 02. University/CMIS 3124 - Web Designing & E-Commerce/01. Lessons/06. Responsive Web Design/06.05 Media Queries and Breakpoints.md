# 06.05 · CSS Media Queries and Breakpoints

> [!info] [[06.00 Responsive Web Design|Lesson 6]] · Lecture ref L6.9 · Priority 🔴 High
> **Asked as:** writing media queries from a sentence (2023/24 Q2(e)(i) and (ii), 3 + 3 marks). **Exact syntax matters.**

## 1. What is a media query?
A **media query** asks the browser a question about the device or viewport, for example *"Is the browser at least a certain width?"* or *"Is the orientation landscape or portrait?"*, and **applies the CSS inside only when the answer is yes**.

### Syntax

```css
@media  screen  and  (min-width: 768px)  {
/* ↑      ↑      ↑         ↑                */
/* rule  media  logical  media feature      */
/*       type   operator  : value           */
  h1 { font-size: 3rem; }   /* ← rules applied only when the query is TRUE */
}
```

## 2. Media types (introduced in CSS2)

| Type | Used for |
|---|---|
| `all` | All media type devices |
| `print` | Printers |
| `screen` | Computer screens (and phones/tablets) |
| `speech` | Devices that **"read out"** a page (screen readers) |

## 3. Media features (introduced in CSS3)
Media features **test for a particular feature of a viewport or device**. The major ones (lecture):

| Feature | Example |
|---|---|
| `width` (with `min-width`, `max-width`) | `(min-width: 768px)` → width **≥ 768px**; `(max-width: 600px)` → width **≤ 600px** |
| `aspect-ratio` (`min-`/`max-aspect-ratio`) | `(max-aspect-ratio: 16/9)` → narrower than 16:9 |
| `orientation` | `(orientation: portrait)` or `(orientation: landscape)` |
| `resolution` | `(min-resolution: 2dppx)` → high-density "retina" screens |

> [!tip] min vs max
> **`min-width: X`** → "at least X" → applies **from X upwards**.
> **`max-width: X`** → "at most X" → applies **from X downwards**.

## 4. Logical operators (lecture)

| Operator | Meaning | Example |
|---|---|---|
| **and** | All conditions must be true | `@media (min-width: 600px) and (max-width: 800px)` |
| **, (comma) = or** | Any one condition true | `@media (max-width: 600px), (min-width: 800px)` |
| **not** | Negates the whole query | `@media not screen and (color)` |

## 5. Lecture examples (learn the pattern)

```css
/* Width between 400px and 600px on screen */
@media screen and (max-width: 600px) and (min-width: 400px) { … }

/* Portrait orientation and width less than 640px */
@media screen and (max-width: 640px) and (orientation: portrait) { … }

/* Narrower than 16:9 and width between 480px and 960px */
@media screen and (max-width: 960px) and (min-width: 480px) and (max-aspect-ratio: 16/9) { … }
```

## 6. ⭐ 2023/24 exam questions, worked

**(i) "Set the background color to LightGreen when the screen is in portrait orientation and the width is less than 800px."**

```css
@media screen and (orientation: portrait) and (max-width: 800px) {
  body {
    background-color: LightGreen;
  }
}
```
- Two conditions → join with **`and`**.
- "Less than 800px" → `max-width: 800px`, following the lecture's own convention ("less than 640px" was written `max-width: 640px`).
- Strictly, `max-width: 800px` *includes* 800px. For "strictly less than", write `(max-width: 799px)` or the modern range syntax `(width < 800px)`. Adding this one-line note shows extra understanding.

**(ii) "Set font-size and color to 80px and DarkBlue for devices with a minimum width of 768px."**

```css
@media screen and (min-width: 768px) {
  body {
    font-size: 80px;
    color: DarkBlue;
  }
}
```
- "Minimum width of 768px" → **`min-width: 768px`** (768px and above).
- Put **both declarations in one rule**.

### Checklist for full marks
- [ ] `@media` keyword
- [ ] media type (`screen`); optional, but it matches the lecture style
- [ ] each feature in **parentheses** with a **colon**: `(min-width: 768px)`
- [ ] `and` between conditions
- [ ] a **selector** (e.g. `body`) and **curly braces** for both the query and the rule
- [ ] correct property names: `background-color`, `font-size`, `color`
- [ ] semicolons after declarations

## 7. Arranging (ordering) media queries

| **Graceful degradation** | **Mobile first / progressive enhancement** |
|---|---|
| Default styles for **large screens first** | Default styles for the **smallest screen first** |
| Then **`max-width`** rules in **descending** order | Then **`min-width`** rules in **ascending** order |

```css
/* Graceful degradation */
@media screen and (max-width: 1400px) {...}
@media screen and (max-width: 1000px) {...}
@media screen and (max-width: 600px)  {...}
@media screen and (max-width: 400px)  {...}

/* Mobile first / progressive enhancement */
@media screen and (min-width: 400px)  {...}
@media screen and (min-width: 600px)  {...}
@media screen and (min-width: 1000px) {...}
@media screen and (min-width: 1400px) {...}
```

**Why the order matters:** CSS applies the **last matching rule**. With `min-width` in ascending order, the widest matching rule comes last and wins.

## 8. Media queries on mobile devices
*To make media queries correctly recognise the width on mobile browsers, the **viewport must be set** with the viewport meta tag. Otherwise **the viewport defaults to 980px** and rules for smaller screens **may not be triggered**.* See [[06.04 Making Pages Responsive]].

## 9. Where to put media queries (lecture)
**In a stylesheet:** put the `@media` rule in the stylesheet; it **should come after the baseline styles**.

**With external stylesheets:** `link` or `@import` separate stylesheets based on a query:

```html
<link rel="stylesheet" href="base.css">
<link rel="stylesheet" media="screen and (min-width: 768px)" href="wide.css">
```
```css
@import url("wide.css") screen and (min-width: 768px);
```
> [!note]
> The external-stylesheet slide is an image. The code above is the standard form it shows.

## 10. Breakpoints
- A **breakpoint** is **"the point at which a media query is used to introduce a style change"** (e.g. 768px).
- **Best practice:**
  - create breakpoints for **individual parts of the page**, not the entire page at once;
  - design the **narrow-screen version first**, then change components as needed as the screen grows;
  - **em-based breakpoints** introduce layout changes **proportional to the font size** (e.g. `@media (min-width: 40em)`).
