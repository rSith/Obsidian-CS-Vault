## What this lesson is about
**Responsive web design (RWD)** makes **one website adapt to every screen size**, from a phone to a wide monitor, using the same HTML. The lesson:
1. traces how layouts **evolved** (free-flowing → tables/frames → XHTML + CSS), the **fixed vs flexible debate**, separate mobile sites, **One Web** and **mobile first**;
2. teaches **Ethan Marcotte's three ingredients** (flexible grids, flexible images, media queries) plus the **viewport** tag;
3. covers **designing responsively**, **site testing** and **web performance optimisation** (including HTTP caching and ETags).

