# 06.04 · Making Web Pages Responsive: Viewport, Flexible Grids and Flexible Images

> [!info] [[06.00 Responsive Web Design|Lesson 6]] · Lecture ref L6.5–L6.8 · Priority 🔴 High
> **Asked as:** "Describe how web pages could be made responsive." (2023/24 Q2(d), **6 marks**)

## 1. Origin (lecture)
- **May 2010:** **Ethan Marcotte** wrote the article **"Responsive Web Design"** for **A List Apart**.
- He built on ideas from **John Allsopp's "A Dao of Web Design"** (A List Apart, **April 2000**).
- **Marcotte identified three core components:**
  1. **Flexible grid**
  2. **Flexible images**
  3. **CSS media queries** → see [[06.05 Media Queries and Breakpoints]]

Plus a practical requirement: the **viewport meta tag**.

### How to check responsiveness (lecture)
- **Adjust the browser width** and watch the changes;
- Use a tool such as **responsinator.com**;
- Use **browser developer tools** (device mode).

---

## 2. Setting the viewport

### What is the viewport?
Mobile browsers **render pages on a canvas called the viewport** and then **shrink it to fit the screen** (the device width).
*Lecture example:* a page is rendered on a **980-pixel viewport** and shrunk to fit a **480-pixel-wide screen**, so everything looks tiny.

### The fix
Include this `<meta>` element in the **`<head>` of every page**:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

| Part | Meaning |
|---|---|
| `name="viewport"` | This meta tag controls the viewport |
| `width=device-width` | Make the viewport **as wide as the device's screen** (e.g. 390px on a phone), not 980px |
| `initial-scale=1.0` | Start at **100% zoom** (no shrinking) |

⚠️ **Without it, media queries for small screens may never trigger**, because the browser thinks the screen is 980px wide.

## 3. Flexible grids

| Layout | How column widths are set (lecture) |
|---|---|
| **Fixed** (typical) | A **fixed number of pixels** in each column |
| **Fluid** | Column width as a **percentage**; columns **resize proportionally** with the window |
| **CSS Grid** | Designed to **avoid ungainly percentage values** by introducing **fraction units (`fr`)**; makes it **easy to express ratios** |

**For flexibility, use (lecture):** `fr`, **`minmax()`** and **content-based grid track values**; **`flex`** in **Flexbox**; **percentage** measurements.

```css
/* Fluid: percentages */
.main  { width: 66.66%; float: left; }
.aside { width: 33.33%; float: left; }

/* CSS Grid: 2:1 ratio with fr units */
.layout { display: grid; grid-template-columns: 2fr 1fr; gap: 16px; }

/* CSS Grid: cards at least 200px wide that wrap automatically */
.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); }

/* Flexbox: share space equally */
.row { display: flex; }
.row > div { flex: 1; }
```

**Explanation:**
- `2fr 1fr` means "split the free space into 3 parts: the first column gets 2, the second gets 1".
- `minmax(200px, 1fr)` means "never narrower than 200px, otherwise take a fair share".
- `flex: 1` means each child grows equally to fill the row.

## 4. Flexible images
- In RWD, we need to **resize images to maintain the integrity of the layout**.
- **To create a "fluid" image (lecture):**
  1. Give the **container a fluid (percentage) width**;
  2. Set the image's **`max-width` to `100%`**.
- **Result:** *the image remains inside its container and is scaled with it as the container gets larger or smaller.*

```css
img {
  max-width: 100%;  /* never wider than its container */
  height: auto;     /* keep the aspect ratio */
}
```

`max-width` (not `width`) means the image **never grows larger than its natural size**, so it won't become blurry.

## 5. Putting it together: a complete minimal responsive page

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">   <!-- viewport -->
  <style>
    img { max-width: 100%; height: auto; }                                  /* flexible images */
    .grid { display: grid; grid-template-columns: 1fr; gap: 1rem; }         /* flexible grid (mobile) */
    @media screen and (min-width: 768px) {                                  /* media query */
      .grid { grid-template-columns: repeat(3, 1fr); }
    }
  </style>
</head>
<body>
  <div class="grid">
    <article><img src="a.jpg" alt="Product A"><h2>Product A</h2></article>
    <article><img src="b.jpg" alt="Product B"><h2>Product B</h2></article>
    <article><img src="c.jpg" alt="Product C"><h2>Product C</h2></article>
  </div>
</body>
</html>
```

On a phone: 1 column. From 768px: 3 columns. The images always fit their column.

## 6. Model answer outline (6 marks)
1. RWD (Ethan Marcotte, 2010) adapts one page to any screen using **3 core components**.
2. **Viewport meta tag**, with the code line and what it does.
3. **Flexible grid:** %, `fr`/`minmax()`, flexbox instead of fixed pixels.
4. **Flexible images:** `max-width: 100%`.
5. **Media queries and breakpoints:** e.g. `@media (min-width: 768px) {…}` changing 1 → 3 columns.
6. **Approach and testing:** mobile first, content parity, 45–75 characters per line; test with real devices, emulators, dev tools.
