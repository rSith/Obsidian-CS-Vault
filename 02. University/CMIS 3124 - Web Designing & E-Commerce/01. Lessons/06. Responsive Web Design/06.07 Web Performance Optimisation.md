# 06.07 · Optimisation of Web Performance

> [!info] [[06.00 Responsive Web Design|Lesson 6]] · Lecture ref L6.12 · Priority 🔴 High
> **Asked as:** "List four (04) techniques to optimize the web performance." (2023/24 Q2(b), 2 marks)

## 1. Why does it matter?
*"A website that functions well in one region of the world might not function the same way in another, due to **Internet speed differences**."* Slow pages lose visitors and customers, and speed also affects SEO.

## 2. Techniques (lecture list) with explanations

| # | Technique | What it means | Example |
|---|---|---|---|
| 1 | **Eliminate unnecessary downloads** | Don't send files the page doesn't need; remove **unnecessary code comments and white space (tabs, spaces)** | Remove an unused JavaScript library |
| 2 | **Leverage browser caching** | Let the browser **reuse stored copies** of files instead of downloading them again ([[06.08 HTTP Caching and ETags]]) | The logo is downloaded once and reused on every page |
| 3 | **Reduce HTTP requests** | Each file is a separate request. **Combine multiple script files into one** and **multiple stylesheets into one**; **reduce the number of image requests** | `all.css` instead of 6 CSS files |
| 4 | **Image optimisation** | Right size, format and compression ([[04.03 Graphics and Typography]]) | A 3 MB photo resized and compressed to 150 KB |
| 5 | **Enable compression techniques** | The server compresses text files before sending them (e.g. **gzip**) | HTML shrinks by about 70% in transit |
| 6 | **Minimise HTML, CSS and JavaScript** (minify) | Remove everything the browser doesn't need: comments, spaces, line breaks | `styles.min.css` |

### Minification example

```css
/* Before (readable source) */
.button {
    background-color: #ff6a00;   /* brand orange */
    padding: 10px 20px;
}

/* After minification (sent to the browser) */
.button{background-color:#ff6a00;padding:10px 20px}
```

> [!note] Beyond the slides
> **Image sprites** (many small icons combined into one image file) are a classic way to "reduce the number of image requests". **Brotli** is a newer alternative to gzip. Neither is named on the slide.

## 3. Exam answer (2 marks, any four × ½)
1. Eliminate unnecessary downloads / **minify** code by removing comments and white space.
2. **Leverage browser (HTTP) caching**.
3. **Reduce HTTP requests** by combining script and style files, and reduce image requests.
4. **Optimise images** and **enable compression** (gzip).
