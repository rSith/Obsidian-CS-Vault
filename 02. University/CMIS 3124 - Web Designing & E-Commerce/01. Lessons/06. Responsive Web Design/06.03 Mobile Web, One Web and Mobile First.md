# 06.03 · Mobile Web, One Web and Mobile First

> [!info] [[06.00 Responsive Web Design|Lesson 6]] · Lecture ref L6.4 · Priority 🔴 High
> **Asked as:** "What is mobile-first design?" (2023/24 Q2(a), 2 marks)

## 1. The mobile web (lecture history)
1. The **handheld media type** could serve a **different stylesheet to handheld devices**, but most mobile browsers **weren't very capable**.
2. As browsers improved, developers **simply scaled the default (desktop) stylesheet down**, because most sites had no handheld stylesheet.
3. Many designers then provided an **alternate mobile version** of their websites, and **the "mobile web" was born**.
   - A **separate mobile site** has **its own domain and address** and is **independent from the main site** (lecture example: `bbc.co.uk/` vs `bbc.co.uk/mobile`).

**Problem with separate mobile sites (beyond the slides):** two sites to maintain, content often missing on the mobile version, duplicate URLs.

## 2. One Web
**One Web** means **"providing consumers with the same information and services regardless of the device they are using."**
- ⚠️ It does **not** mean *exactly the same information in exactly the same representation* on every device. The **content is the same**, but the **layout can differ**.
- Reference: **W3C Mobile Web Best Practices 1.0**.

## 3. Mobile first

### What is it?
*"It is now **standard practice** to begin the responsive design process by **designing for mobile devices (narrow viewports) first**. After that, the layout of a page can be **tweaked so that the arrangement of content works well for wider viewports**."*

### Why design mobile first?
- Small screens force you to decide **what content really matters** (content hierarchy).
- Mobile users are often the **majority** and may have **slower connections**, so starting small keeps pages light.
- It is easier to **add** features for larger screens than to **squeeze** a desktop design down.

> [!note]
> The reasons above are explanations. The slide gives only the definition.

### How is it implemented in CSS?
**Base styles for the smallest screen**, then **`min-width` media queries in ascending order** add or change styles as the screen gets wider. This is called **progressive enhancement** ([[06.05 Media Queries and Breakpoints]]).

```css
/* Base (mobile) styles: one column */
.products { display: grid; grid-template-columns: 1fr; }

/* Tablet and up */
@media screen and (min-width: 600px) {
  .products { grid-template-columns: 1fr 1fr; }
}

/* Desktop and up */
@media screen and (min-width: 1000px) {
  .products { grid-template-columns: repeat(4, 1fr); }
}
```

## 4. Mobile first vs desktop first

| Mobile first (progressive enhancement) | Desktop first (graceful degradation) |
|---|---|
| Default styles = **smallest screen** | Default styles = **large screen** |
| **`min-width`** queries, **ascending** | **`max-width`** queries, **descending** |
| Adds features as space grows | Removes or simplifies as space shrinks |

## 5. Exam answer (2 marks)
*Mobile-first design is a responsive design approach that **starts by designing for the smallest (mobile) screens first** and then **adapts/enhances the layout for larger screens**. It uses base styles for mobile plus **`min-width` media queries in ascending order** (progressive enhancement), and prioritises essential content and performance.*
