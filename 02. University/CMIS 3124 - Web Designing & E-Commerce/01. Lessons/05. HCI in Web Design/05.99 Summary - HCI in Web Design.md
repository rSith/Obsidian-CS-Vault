# 05.99 · Lesson Summary: HCI in Web Design

> [!abstract] Back to [[05.00 HCI in Web Design]] · Practice: [[PP 05 - HCI in Web Design]]

## Must know
- **Design** = achieving goals (purpose: who, why) within constraints (materials, platforms).
- **Three interface questions:** Where am I? What can I do? Where have I been / where am I going?
- **Norman** introduced **affordance** (shape suggests use) and **user-centred design**.
- **UI vs UX** (below). **HCI goals:** safety, effectiveness, efficiency, usability, appeal. **7 HCI factors:** organisational, users, UI, task, constraints, system functionality, productivity.
- **HCI tasks:** know your user (personas, cultural probes/probe packs, ethnographic studies) → scenarios ("stories for design") → layout → user action and control (entering information, knowing what to do, affordance) → appropriate appearance → navigation.
- **Navigation:** 4 levels (widgets, screens, within the app, environment); **4 golden rules** (where you are, what you can do, where you're going, where you've been); global structure = hierarchy vs network diagram; **NSU → WoN → navigational nodes + links**; content architectures: linear, grid, hierarchical, network.
- **17 UI principles:** familiarity, consistency, minimal surprise, recoverability, user diversity, anticipation, communication, controlled autonomy, efficiency, focus, human interface objects, latency reduction, learnability, work-product integrity, readability, track state, visible navigation.
- **Cognitive load:** intrinsic (simplify), extraneous (reduce), germane (maximise); small working memory vs huge long-term memory; **4 CLT principles**.
- **7 usability testing methods:** in-person, unmoderated remote, moderated remote, guerrilla, phone interview, card sorting, session recording (Hotjar).

## Important comparisons

| UX | UI |
|---|---|
| Feel and experience; emotions, satisfaction | Visual aesthetics; visual appeal |
| Wireframes and prototypes (flow) | Mockups and graphics (final visuals) |
| Holistic journey | Individual elements |
| Research; user-centred; solves pain points | Implementation; interface-centred; pleasing designs |

| CLT principle | UX techniques |
|---|---|
| Information store | Familiar, consistent, simple; tooltips, videos, onboarding, personalisation |
| Borrowing and reorganising | Consistent layouts, chunking, gradual disclosure |
| Randomness as genesis | Onboarding, contextual help, progressive disclosure, no novelty for its own sake, familiar patterns |
| Narrow limits of change | Small steps, progressive disclosure, familiar labels, recognisable UI elements, clear onboarding |

| Hierarchy diagram | Network diagram |
|---|---|
| Logical groupings, high-level breakdown | Paths through the system, branches; task-oriented |
