# 05.01 · UI vs UX

> [!info] [[05.00 HCI in Web Design|Lesson 5]] · Lecture ref L5.4 · Priority 🔴 High
> **Asked as:** "How does user experience (UX) design differ from user interface (UI) design?" (2023/24 Q4(b), 2 marks)

## 1. What are they?
- **UI (User Interface) design** is about **how the product looks and how its individual elements behave**: the screens, buttons, colours, typography and layout the user interacts with.
- **UX (User Experience) design** is about **how the whole experience feels**: the user's entire journey, whether it is easy, meaningful and satisfying, and whether it solves their problem.

> [!example] Analogy
> In a restaurant, **UI** is the menu card design, the tables and the plates. **UX** is the whole visit: how easy it was to book, how long you waited, whether the food met your need, and how you felt leaving.

## 2. Features of each (lecture slide)
| UI design features | UX design features |
|---|---|
| **Visual elements** | **User research** |
| **Interactivity** | **Usability testing** ([[05.10 Usability Testing Methods]]) |
| **Consistency** | **Information architecture** |
| **Responsiveness** | **Wireframing and prototyping** |
| **Navigation** | **Interaction design** |
| **Accessibility** | **Accessibility** (shared) |

Key terms:
- **Wireframe:** a simple black-and-white sketch of a page's layout (boxes and lines, no styling).
- **Prototype:** a clickable model used to test the flow before building.
- **Mockup:** a detailed, static visual design showing final colours, fonts and images.
- **Information architecture:** how content is organised and labelled.

## 3. UI vs UX comparison (lecture slide)

| **UX** | **UI** |
|---|---|
| Focuses on creating a **feel and experience** that addresses **emotions and satisfaction** | Focuses on **visual aesthetics** and elements to achieve **visual appeal** |
| **Wireframes and prototypes** are created to define **user flow and functionality** | **Mockups and graphics** are used to **finalise visual designs** for user engagement |
| Ensures a **seamless and meaningful user journey**, emphasising the **holistic** experience | Focuses on **individual elements and interactions**, perfecting details for aesthetics and functionality |
| **Research:** user analysis, testing, developing strategies | **Implementation:** putting design choices into action |
| **User-centred** approach: understanding user needs, behaviours and emotions | **Interface-centred** approach: visually appealing, user-friendly interfaces |
| **Problem-solving:** address user issues and alleviate **pain points** | **Visual appeal:** creating pleasing designs |

## 4. Example: an online-shop checkout
- **UX work:** research shows users abandon checkout because it has 8 steps → redesign the flow to 3 steps, test it with users, add guest checkout.
- **UI work:** design the 3 checkout screens: button colour and size, input-field style, typography, a consistent look.

## 5. Exam-relevant points (2 marks)
- **One-line contrast:** *UX decides **what** the product should do and **how it flows and feels** (whole journey, research, user-centred). UI decides **how it looks** and how its elements are presented (visual, interface-centred).*
- Present it as a short **table** with 3–4 rows.
