# 05.07 · Navigation Design

> [!info] [[05.00 HCI in Web Design|Lesson 5]] · Lecture ref L5.9 · Priority 🟡 Medium. Not asked directly, but useful for "planning a website" and "features of a good e-commerce website".

## 1. What is navigation design?
Navigation is **"the process or activity of accurately ascertaining one's position and planning and following a route."** On a website, it means users can always tell **where they are** and **how to get where they want to go**.

## 2. The four levels of navigation (lecture)

| Level | General meaning | In a WebApp |
|---|---|---|
| **Widgets** | Appropriate choice of widgets and **wording** in menus and buttons, so users know how to use them | Elements and tags such as `<a href="...">` |
| **Screens or windows** | Users need to **find things on the screen** and understand the **logical grouping** of buttons | **Page design** |
| **Navigation within the application** | Understand **what will happen when a button is pressed** and **where you are** in the interaction | **Site structure** |
| **Environment** | Other apps, the web | **The web, the browser, external links** |

## 3. Local structure: "from one screen looking out"
- **Goal seeking:** *each state or screen needs to give the user enough knowledge of what to do to get closer to their goal.*
- **The four golden rules:**
  1. **Knowing where you are**
  2. **Knowing what you can do**
  3. **Knowing where you are going**, or what will happen
  4. **Knowing where you have been**, or what you have done
- **Lecture example:** a breadcrumb trail (*web site › top-level category › sub-category › this page*) gives **live links to higher levels**.
- ⚠️ *"No means of getting back to the wider website without hitting the web browser's back button is a **poor design**."*

```html
<!-- Breadcrumb: tells users where they are and links to higher levels -->
<nav aria-label="Breadcrumb">
  <a href="/">Home</a> › <a href="/electronics">Electronics</a> ›
  <a href="/electronics/laptops">Laptops</a> › <span>Dell XPS 13</span>
</nav>
```

## 4. Global structure: "between screens within the application"
| Diagram | What it shows | Lecture example |
|---|---|---|
| **Hierarchy (hierarchical diagram)** | Links screens, pages or states in **logical groupings**; a **high-level breakdown** | *The system → info and help / management / messages; management → add user / remove user* |
| **Network diagram** | **Different paths through the system**: what leads to what, what happens when, **including branches**; **more task-oriented** than a hierarchy | *main screen → remove user → confirm; main screen → add user* |

## 5. Navigation semantic units (NSU), WoN and navigational nodes
- When a user interacts with a WebApp, they encounter a series of **navigation semantic units (NSUs)**.
- **NSU:** *"a set of information and related navigation structures that **collaborate in the fulfilment of a subset of related user requirements**."*
- An NSU is made of **ways of navigating (WoN)**. **A WoN represents the best navigation pathway to achieve a navigational goal for a specific type of user.**
- **Each WoN is a set of navigational nodes (NN) connected by navigational links.**
- The **overall navigation structure** of a WebApp may be organised as **a hierarchy of NSUs**.

```text
NSU: "Buy a product"
 ├─ WoN 1 (new visitor):     Home ─► Category ─► Product ─► Cart
 └─ WoN 2 (returning buyer): Search ─► Product ─► Cart
         (each box = a navigational node NN; each arrow = a navigational link)
```
The lecture's "Creating an NSU" diagram shows a product NSU with links such as *select product, recommend component, show description, purchase product component, view bill of materials*.

## 6. Content architecture (lecture diagram)
| Structure | Shape | Use |
|---|---|---|
| **Linear** (also "linear with optional flow" and "linear with diversions") | Pages in a fixed sequence | Tutorials, checkout steps |
| **Grid** | Pages arranged in rows and columns (two dimensions) | Product catalogues by category × brand |
| **Hierarchical** | Tree: home → sections → sub-pages | Most websites |
| **Network** | Every page can link to many others | Wikis, highly interlinked content |
