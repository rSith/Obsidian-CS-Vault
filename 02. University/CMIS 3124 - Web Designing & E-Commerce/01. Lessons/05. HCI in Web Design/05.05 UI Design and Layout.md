# 05.05 · UI Design and Layout; User Action and Control

> [!info] [[05.00 HCI in Web Design|Lesson 5]] · Lecture ref L5.7 · Priority 🟢 Low

## 1. UI design and layout (lecture)
- The **UI describes how users interact with a computer system**.
- **"UI is the key to usability."**
- UI design **requires an understanding of HCI and user-centred design principles**.
- **Layout decisions** include: **grouping of items, order of items, decoration, text and number alignment, multiple-column alignment, white space**.

These echo the CARP principles: grouping = proximity, alignment = alignment ([[04.01 Aesthetic Layout and CARP Principles]]).

## 2. User action and control (three parts, lecture)

### (1) Entering information
- Through **forms, text boxes and select options**; **alignment is still important**.
- Use a **logical layout**:
  - use **task analysis** to decide **how to group and order** screen items;
  - follow the **natural order** for entering information: **top → bottom, left → right** (*depending on culture*);
  - **right-justified text for field labels may be best** (labels sit close to their boxes).

```html
<style>
  .row   { display: flex; gap: 8px; margin-bottom: 8px; }
  .row label { width: 120px; text-align: right; }  /* right-justified labels */
</style>
<form>
  <div class="row"><label for="n">Name:</label><input id="n"></div>
  <div class="row"><label for="e">Email:</label><input id="e" type="email"></div>
  <div class="row"><label for="p">Phone:</label><input id="p" type="tel"></div>
</form>
```
**Task analysis** means studying the steps a user takes to complete a task, so that the form follows the same order (e.g. name → address → payment).

### (2) Knowing what to do
- Users must see **what is active and what is passive**: **where to click, where to type**.
- A **consistent style** helps.
- Use **clear labels and icons** on menus.
- **Standards** help for common actions such as **save, delete or print** (e.g. the familiar floppy-disk and printer icons).

### (3) Affordance
Things suggest **by their shape and other attributes** what you can do with them: a **button-like object affords a mouse click**; **icons afford clicking or double-clicking** (learned from the "culture of computer use"). See [[05.03 Users, Affordance and Norman's Doors]].
