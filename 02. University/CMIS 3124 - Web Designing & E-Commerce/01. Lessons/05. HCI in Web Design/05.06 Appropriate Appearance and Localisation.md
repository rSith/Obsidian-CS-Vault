# 05.06 · Appropriate Appearance, Colour and Localisation

> [!info] [[05.00 HCI in Web Design|Lesson 5]] · Lecture ref L5.8 · Priority 🟢 Low. Localisation is a useful point for "contribute to your mother tongue using the WWW" (2019/20 Q5(c)).

## 1. Presenting information (lecture)
How you present information **depends on**:
- the **kind of information** (text, numbers, maps, tables);
- the **technology available** (character display, line drawing, graphics, virtual reality);
- the **purpose** for which it is used.

**Purpose matters:**
| Purpose / data | Suitable presentation |
|---|---|
| Lists | Choose a **sort order** (alphabetical or by date) to match the task |
| Complex numerical data | **Scatter graphs, histograms or 3D surfaces** |
| Hierarchical structures | **Outlines, organisation diagrams** |

**Add interactivity:** allow the user to **choose among several representations** (e.g. table view / chart view).

## 2. Aesthetics and utility
- **Aesthetically pleasing designs increase user satisfaction and improve productivity.**
- But **beauty and utility may conflict**:
  - mixed-up visual styles;
  - **excessively complex and strong backgrounds**.
- **The background of text must have low contrast to be readable.** In other words, the *background itself* should be plain and calm (no busy pattern behind text), so that the text stands out.

## 3. Colour and 3D (lecture)
- **Colour:**
  - older monitors had a limited palette;
  - colour is **over-used "because it is there"**;
  - **beware colour blindness!**
  - **use sparingly to reinforce other information** (not as the only signal).
- **3D effects:**
  - good for presenting **physical information and some graphs**;
  - **do not overuse**: **3D text is very difficult to read**, and **3D pie charts** distort proportions.

## 4. How to apply colour (lecture)
1. **Limit the number of colours.**
2. **Use colour change to show a change in system status** (e.g. a button turns green when saved).
3. **Use colour coding to support the task** users are trying to perform.
4. **Use colour coding in a thoughtful and consistent way.**
5. **Be careful about colour pairings.**

See also [[04.02 Colour Psychology and Colour Schemes]].

## 5. Localisation, internationalisation and globalisation
| Term | Meaning (lecture) | Example |
|---|---|---|
| **Localisation / internationalisation** | **Changing interfaces for particular cultures / languages** | Sinhala and Tamil versions of a government site; local date formats; right-to-left layout for Arabic |
| **Globalisation** | **Try to choose symbols that work everywhere** | A magnifying glass for search; avoid hand gestures that are rude in some cultures |

> [!note] Beyond the slides
> Strictly, **internationalisation** means *preparing* software so it can be adapted (e.g. using Unicode), and **localisation** means *doing* the adaptation for one locale. The slide treats them together.
