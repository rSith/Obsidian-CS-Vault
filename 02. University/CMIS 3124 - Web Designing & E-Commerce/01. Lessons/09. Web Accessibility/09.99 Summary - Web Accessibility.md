# 09.99 · Lesson Summary: Web Accessibility and Inclusive Design

> [!abstract] Back to [[09.00 Web Accessibility]] · Practice: [[PP 09 - Web Accessibility]]

## Must know
- **Why:** a large share of people have a disability; W3C (quality, don't exclude); Tim Berners-Lee ("universality"); the **UN CRPD** makes ICT/Web access a **basic human right**.
- **Components:** **web content** · **user agents** (browsers, media players, assistive technologies such as screen readers) · **authoring tools** (editors, CMSs, blogs).
- **W3C WAI guidelines:** **WCAG** (content) · **UAAG** (user agents) · **ATAG** (authoring tools). WCAG 2.2 (Dec 2024).
- **Techniques:** alt text, captions/transcripts, screen readers (JAWS), contrast, simple navigation, minimal content, tab through the site, accessible PDFs for flyers, proper web forms, test the site.
- **Flyer:** Optimise → Upload → Utilise; PDF → image + alt + link; image → descriptive text + printable PDF + alt/captions.
- **ARIA** = Accessible Rich Internet Applications: roles + properties + states. **Why:** improved accessibility, dynamic content, custom widgets. **"Only use ARIA when absolutely necessary."**
- **5 rules:** (1) use native HTML; (2) don't change native semantics; (3) keyboard-usable; (4) semantic and visible; (5) accessible name.
- **Roles** = what it is (landmarks: navigation/`<nav>`, contentinfo/`<footer>`; also search, tablist, tab). **Properties** = extra semantics (`aria-required`, `aria-labelledby`). **States** = current condition (`aria-expanded`, `aria-selected`).
- **When to use ARIA:** landmarks (+ `aria-label` for duplicates) · `aria-live` (off/polite/assertive) · labels (`aria-labelledby` = id of visible text; `aria-label` = text in the attribute; labelable elements only; they override names) · keyboard (`tabindex="0"` makes focusable; `"-1"` removes from the tab order / programmatic focus).
- **Tab widget:** Step 1 roles (tablist/tab/tabpanel) → Step 2 properties (aria-controls, aria-labelledby, tabindex) → Step 3 states (aria-selected, hidden/aria-hidden).

## Important comparisons
| aria-label | aria-labelledby |
|---|---|
| Label text in the attribute | Points to the id of existing text |

| tabindex="0" | tabindex="-1" |
|---|---|
| Adds to the natural tab order | Removes from the tab order; focus() only |

| polite | assertive |
|---|---|
| Announced when the user is idle | Announced immediately |
