## Part A: Graphics

### 1. Role of graphics
- Graphics **enhance web pages** and help create an **engaging, interesting experience**.
- They should **complement and be relevant to the website's look and feel**.
- **Popular graphics applications (lecture):** Adobe Photoshop, Adobe Fireworks, GIMP, Inkscape, Paint.net, Pixlr.

### 2. File compression
**Compression** reduces an image's file size so that pages load faster.

| | **Lossless compression** | **Lossy compression** |
|---|---|---|
| Lecture definition | The image is compressed and **all the information can be restored** | **Permanently eliminates certain information**; the image **cannot be fully restored** |
| File size | Larger | **Much smaller** |
| Quality | Perfect, identical to the original | Some quality loss (often unnoticeable) |
| Typical formats* | PNG, GIF | JPEG, WebP (lossy) |
| Best for* | Logos, icons, text, sharp edges | Photographs |

\* *Formats and "best for" are standard examples, not lecture content.*

Link: image optimisation is a web-performance technique ([[06.07 Web Performance Optimisation]]).

## Part B: Typography

### 1. Font vs typography (lecture)
| **Font** | **Typography** |
|---|---|
| The style of **typeface** used to display text, numbers, characters and other **"glyphs"** | The **arrangement and appearance** of text |
| Best controlled through **CSS** | Concerns not only the look of the glyphs but **how they are placed on the page**: **page margins, space between paragraphs or lines, text alignment**, etc. |

A **glyph** is a single drawn character shape (a letter, a number or a symbol).

*"Colour and font styles affect the **mood** of the text."*

### 2. Typography best practices (lecture)
- Use **"real text"**, not **text as graphics**, because text in images **becomes pixelated when enlarged**. (Screen readers and search engines also cannot read text inside images.)
- Use the **most readable fonts**.
- Use **fonts native to modern operating systems** (already installed on the PC).
- Fonts and typography **improve readability, establish branding and enhance the tone or style** of the site.

### 3. The five generic font families (lecture)

| Family | Characteristics | Lecture examples |
|---|---|---|
| **Serif** | **Flared extensions (strokes)** on the tips of letters such as f, l, i; a mix of **thick and thin strokes** | Times New Roman, Georgia, Book Antiqua |
| **Sans-serif** | **Plain endings**, blockier; **no** flared extensions ("sans" = without) | Arial, Franklin Gothic, Open Sans, Helvetica |
| **Cursive** | Resemble **hand-written pen or brush strokes**; ornamentation; letters may connect; **generally harder to read**, a poor choice for usability/accessibility | Monarda, Rampage Monoline, Krysttal Spears, Gustav, America |
| **Fantasy** | **Primarily decorative**; not for long passages; vary widely; no common feature except decorativeness | Cinzel, Lucid Fantasy, Aquary, Baskerville, Gothic, Redina |
| **Monospace** | **Every letter (and space) takes the same width** | Courier, Courier New, Consolas, Lucida Console, Roboto Mono; used for **computer code and HTML markup** |

```css
body { font-family: "Open Sans", Arial, sans-serif; }   /* fall back to a generic family */
code { font-family: Consolas, "Courier New", monospace; }
h1   { font-family: Georgia, "Times New Roman", serif; }
```
The **last name in the list is the generic family**, which the browser uses if the named fonts are not installed.

### 4. Cursive fonts: do's and don'ts (lecture)
| ✅ Do | ❌ Don't |
|---|---|
| Add character, emphasis, visual appeal | Use in **long-form text** |
| Use in **display text**: logos, headlines, billboards | Use for **important guidelines, instructions** or lots of information |
| Use for **easily legible, short words** | Use at **small sizes** |

### 5. Electronic-media fonts (designed for screens)
- **Verdana:** one of the most popular fonts for **on-screen viewing**; simple design; **glyphs not easily confused**: upper-case "I" and lower-case "l" have **unique shapes, unlike Arial**.
- **Tahoma:** an **alternative to Arial/Helvetica**; **larger than Arial but smaller than Verdana**; **tighter letter spacing**, giving a "scrunched together" look.

### 6. Proper use of fonts (lecture)
- **Number of fonts:** use a **limited number**. Documents with **no more than 2 or 3 font faces** look more organised and coherent; too many clutter and confuse.
- **Capitalisation:** typing sentences **IN ALL CAPITALS is rarely a good idea**.
- **Font variations: `<b>` vs `<strong>`**

| `<b>` | `<strong>` |
|---|---|
| **No semantic meaning**, purely **cosmetic/stylistic** | Means **"strong emphasis"** (importance) |
| Use when you just want **fatter text** | Use when the bold text **carries importance** |

```html
<p><strong>Warning:</strong> payment cannot be refunded.</p> <!-- meaning: important -->
<p>Our <b>new</b> collection is here.</p>                       <!-- just visual -->
```
Screen readers can stress `<strong>`, so it also matters for accessibility ([[00.03 HTML Elements - Text, Lists, Links, Images, Tables]]).
