# 04.01 · Aesthetic Layout and the CARP Principles

> [!info] [[04.00 Web Design Principles|Lesson 4]] · Lecture ref L4.2 · Priority 🔴 High
> **Asked as:** "Briefly explain the CARP design principles in Aesthetic Web Design." (2023/24 Q4(c), 4 marks)

## 1. Why layout matters (lecture)
The **layout** of a page:
- **helps form relationships and define the meaning** of page elements;
- **creates visual hierarchy and visual interest**;
- **increases readability and usability**;
- **should follow the CARP design principles**.

**Visual hierarchy** means arranging elements so that the eye sees the **most important thing first**, then the next, and so on (e.g. a big headline, then a sub-heading, then body text).

## 2. The CARP principles

### C · Contrast
**Lecture definition:** *"Two or more page elements display differently in **colour, size, shape, texture, orientation, position or movement** to group or separate elements on the page."*
- **Why:** contrast draws attention to what matters most and separates different kinds of content.
- **Example:** a bright orange **"Buy now"** button on a white/grey page; a large bold heading above small body text.

### A · Alignment
**Lecture definition:** *"The **placement, position, orientation and grouping** of elements."*
- **Why:** elements lined up along shared edges or a grid make the page look **organised** and easy to scan.
- **Example:** form labels and input boxes lined up in a neat column; product cards in an even grid.

### R · Repetition
**Lecture definition:** *"Repeated elements can include **colours, shapes, textures, fonts, typography, graphics, spatial relationships** and so on."*
- **Why:** repetition creates **consistency** and **brand identity**, so users learn the site quickly.
- **Example:** the same header, logo, button style and colour palette on every page.

### P · Proximity
**Lecture definition:** *"The use of **white space and logical structure** (such as **grouping related items**) to create **visual unity**."*
- **Why:** items placed close together are seen as related; white space separates unrelated groups.
- **Example:** a product's photo, name, price and "Add to cart" sit together in one card, with space between it and the next product.

## 3. Seeing CARP in code

```html
<style>
  .card { padding: 16px; margin-bottom: 32px; }              /* Proximity: space between groups */
  .card h3, .card p, .card button { margin-left: 0; }        /* Alignment: shared left edge */
  .btn  { background: #ff6a00; color: #fff; font-size: 1.1rem; } /* Contrast: CTA stands out */
  h3    { font-family: "Open Sans", sans-serif; color: #003366; } /* Repetition: same style everywhere */
</style>

<div class="card">
  <h3>Running Shoes</h3>
  <p>Rs. 12,500</p>
  <button class="btn">Add to cart</button>
</div>
```

One mark per principle: **name → lecture definition → web example**. Open with one line on *why* layout matters (relationships, hierarchy, readability).
