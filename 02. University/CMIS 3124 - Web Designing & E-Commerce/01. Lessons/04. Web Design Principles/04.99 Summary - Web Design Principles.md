# 04.99 · Lesson Summary: Web Design Principles

> [!abstract] Back to [[04.00 Web Design Principles]] · Practice: [[PP 04 - Web Design Principles]]

## Must know
- **Web design** = planning and creation of websites: information architecture, UI, site structure, navigation, layout, colours, fonts, imagery.
- **Layout** forms relationships, creates visual hierarchy, and increases readability and usability → follow **CARP**.
- **CARP:** **Contrast** (differ in colour/size/shape/texture/orientation/position/movement) · **Alignment** (placement, position, orientation, grouping) · **Repetition** (colours, shapes, fonts, graphics, spacing repeated) · **Proximity** (white space + grouping related items → visual unity).
- **Colour:** reinforces branding; good contrast; about 85% of buying decisions. Know the psychology table (red = CTA but aggressive; blue = calm, finance/IT, bad for food; green = nature, not luxury/tech; …).
- **Schemes:** monochromatic, analogous, complementary, triadic, split-complementary, tetradic/rectangle, square. **Hue/tint/tone/shade** = colour family / + white / + grey / + black.
- **Best practices:** audience, industry, **60-30-10**, greyscale first, no complementary text/background, bright CTAs, base/accent/text colours, negative space.
- **Compression:** lossless (fully restorable) vs lossy (permanently removes data).
- **Font vs typography;** 5 families (serif, sans-serif, cursive, fantasy, monospace); Verdana and Tahoma; 2–3 fonts; avoid ALL CAPS; `<strong>` (meaning) vs `<b>` (looks only).
- **Functional site:** links work, interactivity works, loads quickly. **Usability:** how easy the UI is to use. **LEMES** attributes.
- **Accessibility basics:** text links, high contrast, not colour alone, alt text, table summaries/headings, transcripts and captions.

## Important comparisons
| Lossless | Lossy |
|---|---|
| All information restored | Some information permanently removed |
| Bigger files | Smaller files |

| `<b>` | `<strong>` |
|---|---|
| No semantic meaning (cosmetic) | Strong emphasis (importance) |

| Serif | Sans-serif |
|---|---|
| Flared strokes, thick/thin | Plain endings, blockier |
| Times New Roman, Georgia | Arial, Helvetica, Open Sans |
