# 08.01 · Introduction to Bootstrap and Installing It

> [!info] [[08.00 Bootstrap|Lesson 8]] · Lecture ref L8.1–L8.2 · Priority 🟢 Low

## 1. What is Bootstrap? (lecture)
- The **most popular HTML, CSS and JavaScript framework** for **responsive, mobile-friendly** web design.
- **Free** to download and use.
- A **front-end framework** that includes **HTML and CSS design templates**.
- Allows **faster and easier** web development.
- **Latest version: Bootstrap 5 (released in 2021)**. It supports the latest stable releases of all major browsers and platforms, and **does not support Internet Explorer 11 and below**.

**Key term: framework.** A pre-written collection of code (here, CSS classes and JavaScript components) that gives you ready-made building blocks, so you don't start from zero.

## 2. Advantages (lecture)
| Advantage | Meaning |
|---|---|
| **Easy to use** | Basic HTML/CSS knowledge is enough; you just add classes |
| **Browser compatibility** | Looks consistent across modern browsers |
| **Mobile-first approach** | Base styles target small screens first ([[06.03 Mobile Web, One Web and Mobile First]]) |
| **Responsive features** | The grid and utilities adapt to screen size automatically |

## 3. Installing Bootstrap (lecture)
**Option 1: custom Bootstrap file.** Go to https://getbootstrap.com/ and follow the instructions (download or build).

**Option 2: use it directly from the Internet via a CDN** such as **jsDelivr** (a Content Delivery Network: see [[02.08 Web Application Architecture Components]]):

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">

  <!-- Latest compiled and minified CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
        rel="stylesheet">

  <!-- Latest compiled JavaScript -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</head>
<body>
  <div class="container">
    <h1>My First Bootstrap Page</h1>
    <p>This part is inside a .container class.</p>
  </div>
</body>
</html>
```

**Line by line:**
- `meta viewport` makes the page responsive on phones ([[06.04 Making Pages Responsive]]).
- `bootstrap.min.css` is all the Bootstrap styles (`.min` = minified, see [[06.07 Web Performance Optimisation]]).
- `bootstrap.bundle.min.js` is the JavaScript for interactive components (dropdowns, modals) and includes Popper.
- `class="container"` wraps the content in a Bootstrap container ([[08.02 Bootstrap Containers]]).
