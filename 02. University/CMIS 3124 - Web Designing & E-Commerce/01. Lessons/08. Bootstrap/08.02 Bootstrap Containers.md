# 08.02 · Bootstrap Containers

> [!info] [[08.00 Bootstrap|Lesson 8]] · Lecture ref L8.3 · Priority 🔴 High
> **Asked as:** "A **fixed-width container** with a border, padding of 3 units on all sides and background set to bg-light contextual class" (2023/24 Q4(e)(i)).

## 1. Why containers? (lecture)
- **Bootstrap requires a containing element to wrap site contents.**
- **Containers are used to pad the content inside.**
- **Two container classes:**
  1. **`.container`**: a **responsive fixed-width** container;
  2. **`.container-fluid`**: a **full-width** container spanning **the entire width of the viewport**.

## 2. `.container`: fixed width (lecture)
- **Sets a maximum width (`max-width`) for different screen sizes but remains fixed within each breakpoint.**
- **Centres the content horizontally.**
- **15px padding on the left and right sides** (as stated on the slide).

| Screen | XS (<576) | SM (≥576) | MD (≥768) | LG (≥992) | XL (≥1200) | XXL (≥1400) |
|---|---|---|---|---|---|---|
| `.container` max-width | 100% | 540px | 720px | 960px | 1140px | 1320px |

> [!note]
> The max-width values come from the slide's image (W3Schools table), as read in the study guide.

```html
<div class="container">
  <h1>My First Bootstrap Page</h1>
  <p>This part is inside a .container class.</p>
</div>
```

## 3. `.container-fluid`: full width
*"Maintains responsiveness, adjusting to the screen size seamlessly."* It is always **100%** wide.
```html
<div class="container-fluid">
  <h1>My First Bootstrap Page</h1>
  <p>This part is inside a .container-fluid class.</p>
</div>
```

## 4. Responsive containers
Use **`.container-sm`, `.container-md`, `.container-lg`, `.container-xl`, `.container-xxl`** to decide **when** the container becomes fixed-width. Each is **100% wide until** its named breakpoint, then fixed.

```html
<div class="container-sm">100% wide until small breakpoint</div>
<div class="container-md">100% wide until medium breakpoint</div>
<div class="container-lg">100% wide until large breakpoint</div>
<div class="container-xl">100% wide until extra large breakpoint</div>
<div class="container-xxl">100% wide until extra extra large breakpoint</div>
```

| Class | XS | SM | MD | LG | XL | XXL |
|---|---|---|---|---|---|---|
| `.container` | 100% | 540 | 720 | 960 | 1140 | 1320 |
| `.container-sm` | 100% | 540 | 720 | 960 | 1140 | 1320 |
| `.container-md` | 100% | 100% | 720 | 960 | 1140 | 1320 |
| `.container-lg` | 100% | 100% | 100% | 960 | 1140 | 1320 |
| `.container-xl` | 100% | 100% | 100% | 100% | 1140 | 1320 |
| `.container-xxl` | 100% | 100% | 100% | 100% | 100% | 1320 |
| `.container-fluid` | 100% | 100% | 100% | 100% | 100% | 100% |

## 5. `.container` vs `.container-fluid`
| `.container` | `.container-fluid` |
|---|---|
| **Fixed** max-width at each breakpoint | **Always 100%** of the viewport |
| Centred, with side space on big screens | Edge to edge |
| = a "fixed-width layout" that steps with breakpoints | = a "fluid layout" |

Link: [[06.02 Fixed vs Flexible Layouts]].

## 6. ⭐ Exam fragment (2023/24 Q4(e)(i))
"A fixed-width container with a border, padding of 3 units on all sides and background set to bg-light":

```html
<div class="container border p-3 bg-light">
  <h1>My Bootstrap page</h1>
  <p>Content inside a fixed-width, bordered container.</p>
</div>
```
| Requirement | Class |
|---|---|
| Fixed-width container | `container` (**not** `container-fluid`) |
| Border | `border` (all four sides) |
| Padding of 3 units on all sides | `p-3` (no side letter = all sides) |
| Background bg-light | `bg-light` |

**Lecture exercise:** fixed-width container with a border and padding of **5** units on all sides → `<div class="container border p-5">…</div>`
