## What this lesson is about
**Bootstrap** is a ready-made CSS/JS **framework**: instead of writing CSS, you **add class names** to HTML elements. The lesson covers installing it, **containers**, **spacing, background, border and text utilities**, the **12-column grid**, **tables**, **images** and **buttons**.

Exam questions ask you to *write the classes from a description*, so learn the **naming patterns**, not just the ideas.

## Topic structure
```text
Bootstrap
├── What it is · advantages · installing (custom build / CDN)
├── Containers: .container · .container-fluid · .container-sm/md/lg/xl/xxl
├── Customising: spacing {property}{sides}-{size} · bg-* · border* · text utilities
├── Grid: 12 columns · .row · .col-, -sm-, -md-, -lg-, -xl-, -xxl-
├── Tables: .table, -striped, -bordered, -hover, -dark, -borderless, contextual, -responsive
├── Images: .rounded, .rounded-circle, .img-thumbnail, .float-start/end, .mx-auto .d-block, .img-fluid
└── Buttons: .btn + styles, sizes, active/disabled, spinners, block (.d-grid)
```
