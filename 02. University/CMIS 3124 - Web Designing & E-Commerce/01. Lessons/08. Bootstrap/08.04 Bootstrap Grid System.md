# 08.04 · The Bootstrap Grid System

> [!info] [[08.00 Bootstrap|Lesson 8]] · Lecture ref L8.8 · Priority 🔴 High
> **Asked as:** "A Bootstrap grid layout with three equal-width columns starting at screen width equal to or greater than 768px (medium devices)" (2023/24 Q4(e)(ii)).

## 1. What is it? (lecture)
- **Built with flexbox** and **allows up to 12 columns** across the page.
- You can **group columns together** to create wider columns.
- **Responsive:** columns **rearrange automatically** depending on screen size.

## 2. Grid classes (lecture)

| Class prefix | Devices | Applies when screen width is |
|---|---|---|
| `.col-` | Extra small | **< 576px** (and up) |
| `.col-sm-` | Small | **≥ 576px** |
| `.col-md-` | Medium | **≥ 768px** |
| `.col-lg-` | Large | **≥ 992px** |
| `.col-xl-` | Extra large | **≥ 1200px** |
| `.col-xxl-` | Extra extra large | **≥ 1400px** |

## 3. Basic structure (lecture)
```html
<div class="row">
  <div class="col-*-*"></div>
  <div class="col-*-*"></div>
</div>
<div class="row">
  <div class="col-*-*"></div>
  <div class="col-*-*"></div>
  <div class="col-*-*"></div>
</div>
```
- **First `*`** = responsiveness: `sm`, `md`, `lg`, `xl` or `xxl`.
- **Second `*`** = a **number** of columns (1–12). **The numbers should add up to 12 in each row.**

### How to read a class
`col-md-4` = "**from medium (≥768px) upwards**, this column takes **4 of 12** parts (one third)". **Below 768px** it **stacks** at full width.

## 4. Lecture examples
**Four equal-width columns from tablets up** (stacked on phones < 576px):
```html
<div class="row">
  <div class="col-sm-3">.col-sm-3</div>
  <div class="col-sm-3">.col-sm-3</div>
  <div class="col-sm-3">.col-sm-3</div>
  <div class="col-sm-3">.col-sm-3</div>
</div>
```
3 + 3 + 3 + 3 = 12.

**Two unequal columns:**
```html
<div class="row">
  <div class="col-sm-4">.col-sm-4</div>
  <div class="col-sm-8">.col-sm-8</div>
</div>
```
4 + 8 = 12, a one-third / two-thirds split.

**Bootstrap handles the layout automatically: three equal columns:**
```html
<div class="row">
  <div class="col"></div>
  <div class="col"></div>
  <div class="col"></div>
</div>
```
Plain `.col` (no number) splits the row **equally at every screen size** (never stacks).

## 5. ⭐ Exam fragment (2023/24 Q4(e)(ii))
"Three equal-width columns starting at screen width ≥ 768px (medium devices)":

```html
<div class="container">
  <div class="row">
    <div class="col-md-4">Column 1</div>
    <div class="col-md-4">Column 2</div>
    <div class="col-md-4">Column 3</div>
  </div>
</div>
```
| Requirement | Why |
|---|---|
| `.row` wrapper | Columns must sit in a row |
| `col-md-…` | "md" = **medium = ≥768px** |
| `-4` × 3 | **Equal** widths that add to 12 (4 + 4 + 4) |
| Behaviour | Below 768px the three columns **stack vertically** |

⚠️ Don't answer with plain `col`, because it never stacks, so it doesn't "start at 768px".

## 6. Mixing breakpoints (beyond the slides)
```html
<div class="col-12 col-md-6 col-lg-3">…</div>
```
Full width on phones → half on tablets → a quarter on laptops. This is how Bootstrap implements **mobile-first** media queries for you ([[06.05 Media Queries and Breakpoints]]).
