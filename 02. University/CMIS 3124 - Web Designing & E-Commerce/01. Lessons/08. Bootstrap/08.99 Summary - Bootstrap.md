# 08.99 · Lesson Summary: Bootstrap

> [!abstract] Back to [[08.00 Bootstrap]] · Practice: [[PP 08 - Bootstrap]]

## Must know
- **Bootstrap:** the most popular free HTML/CSS/JS framework for responsive, mobile-first sites; **Bootstrap 5 (2021)**, no IE11. **Advantages:** easy to use, browser compatibility, mobile-first, responsive features.
- **Install:** a custom file from getbootstrap.com, or a **CDN (jsDelivr)**: `bootstrap.min.css` + `bootstrap.bundle.min.js`.
- **Containers:** `.container` = responsive **fixed-width** (max-width per breakpoint, centred, side padding); `.container-fluid` = **full width**; `.container-sm/md/lg/xl/xxl` = 100% until that breakpoint.
- **Spacing:** `{m|p}{t|b|s|e|x|y|blank}-{0..5}`, e.g. `p-3`, `mt-2`, `px-4`, `mx-auto`.
- **Background:** `bg-primary/secondary/success/danger/warning/info/light/dark/white/transparent` + `bg-gradient`.
- **Borders:** `border`, `border-top/end/bottom/start`; `border-0`, `border-top-0` …; colour `border-primary` …; width `border-1..5`.
- **Text:** `text-start/center/end`, `text-primary`…, `fs-1..6`, `fw-bold/normal/light`, `fst-italic`, `lh-1/sm/base/lg`, `text-decoration-underline/line-through`.
- **Grid:** flexbox, **12 columns**; `.row` > `.col-*-*` adding to 12; `col-` <576, `sm` ≥576, `md` ≥768, `lg` ≥992, `xl` ≥1200, `xxl` ≥1400; plain `.col` = equal and automatic.
- **Tables:** `.table` + `-striped`, `-bordered`, `-hover`, `-dark`, `-borderless`, contextual, `.table-responsive`.
- **Images:** `.rounded`, `.rounded-circle`, `.img-thumbnail`, `.float-start/end`, `.mx-auto .d-block`, `.img-fluid`.
- **Buttons:** `.btn .btn-primary…`; works on `<a>`, `<button>`, `<input>`; `.btn-lg/.btn-sm`; `.active`; the `disabled` attribute (or the `.disabled` class on `<a>`); spinners; `.d-grid` for full width.

## The two exam answers
```html
<div class="container border p-3 bg-light">…</div>

<div class="container">
  <div class="row">
    <div class="col-md-4">1</div>
    <div class="col-md-4">2</div>
    <div class="col-md-4">3</div>
  </div>
</div>
```

## Exam focus
- 🔴 Translate a description into classes: container + border + padding + background; equal columns from a breakpoint.
- 🟡 Possible: tables (striped/hover), `img-fluid`, button states, unequal columns.
