# 08.03 · Customising Containers: Spacing, Background, Border and Text Utilities

> [!info] [[08.00 Bootstrap|Lesson 8]] · Lecture ref L8.4–L8.7 · Priority 🔴 High (2023/24 Q4(e)(i) used `border`, `p-3`, `bg-light`)

## 1. Spacing: padding and margin
**Format: `{property}{sides}-{size}`**

| Part | Options |
|---|---|
| **property** | **`m`** = margin · **`p`** = padding |
| **sides** | **`t`** top · **`b`** bottom · **`s`** start (left in LTR) · **`e`** end (right in LTR) · **`x`** left + right (horizontal) · **`y`** top + bottom (vertical) · **blank** = all 4 sides |
| **size** | **`0, 1, 2, 3, 4, 5`** |

*LTR = left-to-right languages such as English. In right-to-left languages, "start" is the right side.*

| Class | Meaning |
|---|---|
| `p-3` | padding, all sides, size 3 |
| `mt-2` | margin-top, size 2 |
| `px-4` | padding left and right, size 4 |
| `mb-0` | no bottom margin |
| `my-5` | margin top and bottom, size 5 |
| `ms-1` | margin-start (left), size 1 |

> [!note] Beyond the slides
> Sizes map to multiples of the base spacer: 0 = 0, 1 = 0.25rem, 2 = 0.5rem, 3 = 1rem, 4 = 1.5rem, 5 = 3rem. Margins also accept `auto` (e.g. `mx-auto` centres a block horizontally; the lecture uses it for images).

## 2. Background colour (contextual classes)
*"Set the background of an element to any **contextual class**."*

**Contextual classes** are named by **meaning**, not colour: primary, secondary, success (green), danger (red), warning (yellow), info (light blue), light, dark.

```html
<div class="p-3 mb-2 bg-primary text-white">.bg-primary</div>
<div class="p-3 mb-2 bg-success text-white">.bg-success</div>
<div class="p-3 mb-2 bg-light text-dark">.bg-light</div>
<div class="p-3 mb-2 bg-dark text-white">.bg-dark</div>
<div class="p-3 mb-2 bg-transparent text-dark">.bg-transparent</div>
```
- Full set: `bg-primary`, `bg-secondary`, `bg-success`, `bg-danger`, `bg-warning`, `bg-info`, `bg-light`, `bg-dark`, `bg-white`, `bg-transparent`.
- Pair dark backgrounds with `text-white`, and light backgrounds with `text-dark` (contrast).
- **`.bg-gradient`** adds a **linear gradient** as a background image:
```html
<div class="p-3 mb-2 bg-primary bg-gradient text-white">Gradient</div>
```

## 3. Borders
**Add or remove** an element's borders.

| Additive | Subtractive |
|---|---|
| `border` (all sides) | `border-0` (remove all) |
| `border-top` | `border-top-0` |
| `border-end` | `border-end-0` |
| `border-bottom` | `border-bottom-0` |
| `border-start` | `border-start-0` |

**Border colour** (use with `border`): `border-primary`, `border-secondary`, `border-success`, `border-danger`, `border-warning`, `border-info`
**Border width:** `border-1` … `border-5`

```html
<span class="border border-danger border-3"></span>   <!-- red border, width 3 -->
```

## 4. Text utilities
| Utility | Classes |
|---|---|
| **Alignment** | `text-start`, `text-center`, `text-end` |
| **Colour** | `text-primary`, `text-secondary`, `text-success`, `text-danger`, … |
| **Font size** | `fs-1` (largest) … `fs-6` (smallest) |
| **Font weight and italics** | `fw-bold`, `fw-normal`, `fw-light`, `fst-italic` |
| **Line height** | `lh-1`, `lh-sm`, `lh-base`, `lh-lg` |
| **Text decoration** | `text-decoration-underline`, `text-decoration-line-through` |

```html
<p class="text-center text-danger fs-3 fw-bold">Sale ends today!</p>
```

## 5. Combining everything
```html
<div class="container border border-primary border-2 rounded p-4 my-3 bg-light">
  <h2 class="text-center fw-bold">Welcome</h2>
  <p class="text-secondary lh-lg mb-0">Bootstrap utilities stacked together.</p>
</div>
```
Each class does one small job, and you stack them in the `class` attribute separated by spaces.
