# 01.01 · World Wide Web (WWW)

> [!info] [[01.00 Evolution of the Web|Lesson 1]] · Lecture ref L1.2 · Priority 🟢 Low. It has not been asked on its own, but it is the starting point for every evolution answer.

## 1. What is it?

The lecture defines the **World Wide Web (WWW)** as:

- **A graphical entryway to the Internet**, and
- **A collection of inter-linked documents (web pages) on the Internet.**

A **web page** is a document that a browser can display. Pages are **linked** to one another by **hyperlinks**, and those links turn the separate pages into a "web".

## 2. Internet vs Web (a common confusion)

> [!note] Beyond the slides
> This distinction is not on the slide, but it helps you explain the definition clearly.

| Internet | World Wide Web |
|---|---|
| The global **network** of connected computers (cables, routers, wireless links) | One **service** that runs *on top of* the Internet |
| Carries many services: email, file transfer, video calls, the Web | Made of web pages linked together by hyperlinks |
| Infrastructure | Content plus the rules for reaching it |

**Analogy:** the Internet is the road network. The Web is the set of shops you visit using those roads. You find each shop by its address (the URL) and speak to it in a shared language (HTTP). The pages themselves are written in HTML.

## 3. What makes the Web work?

The lecture names **three** things:

| Component | Simple meaning | Detailed in |
|---|---|---|
| **Protocols** | Agreed rules for sending data between browser and server. The main one is **HTTP/HTTPS**: the browser *requests* a page and the server *responds*. | [[02.04 HTTP Protocol]] |
| **URL (Uniform/Universal Resource Locator)** | The unique **address** of each resource, e.g. `https://www.wyb.ac.lk/index.html` | [[02.03 URL Structure and Domains]] |
| **HTML (HyperText Markup Language)** | The language that describes the **structure** of a page. Its hyperlinks join pages together. | [[00.02 HTML Document Structure]] |

### How they work together, step by step
1. You type a **URL** (the address) into the browser.
2. The browser uses the **HTTP protocol** (the rules) to ask the server for that page.
3. The server sends back an **HTML** document (the content and structure).
4. The browser displays it. When you click a **hyperlink** inside it, the cycle starts again with a new URL.

## 4. Why it matters

The Web made the Internet usable by ordinary people. Before it, using the Internet needed text commands. With the Web, people just **click links** on graphical pages. Everything else in this module (e-commerce, social media, web apps) is built on the Web.
