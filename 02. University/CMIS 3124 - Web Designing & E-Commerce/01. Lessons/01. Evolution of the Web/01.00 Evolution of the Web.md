## What this lesson is about

This lesson tells the story of how the Web changed. It began as a set of **read-only pages**. Then it became a place where people **write and collaborate**. Next came a place where people can **own** digital assets. The latest stage is a web that **interacts with intelligent machines**.

Each stage has a name (Web 1.0, 2.0, 2.5, 3.0, 4.0), a rough time period, a core idea and some example technologies. The lesson also covers the **Web 2.0 tools** (blogs, wikis, mashups, RSS, social bookmarking) and **how a web browser** fetches and shows a page.

## The big picture in one table

| | Web 1.0 | Web 2.0 | Web 2.5 | Web 3.0 | Web 4.0 |
|---|---|---|---|---|---|
| Nickname | Static web | Participatory / social web | Transitional / hybrid | Decentralised web | Symbiotic web |
| Period | Early 1990s to early 2000s | 2000s onwards | Bridge to Web 3.0 | Emerging | Next stage |
| User role | **Read** | **Read + write** | Read + write + some ownership | **Read + write + own** | **Interact with intelligent systems** |
| Core technology | Static HTML pages | Dynamic web apps, APIs, cloud | Blockchain and NFTs on top of centralised platforms | Blockchain, P2P, smart contracts | AI + ML + IoT |
| Examples | Information portals, AltaVista | Gmail, YouTube, blogs, wikis | Social platforms with NFT wallets | DeFi, NFTs, metaverse assets | Smart cities, BCI, self-driving cars |

> [!tip] The pattern to remember
> At every stage the **user gains more power**: read → read + write → read + write + own → working together with intelligent machines. When you write an essay answer, show this trend.

## Module overview (from the first slides of this deck)

The opening slides of this deck describe the whole module:

- **Aims:** understand the technology for web-based application design and e-commerce applications, and explore the impact of e-commerce strategies on businesses and consumers.
- **Intended learning outcomes:** use multimedia for web design; identify web development tools; describe the legal and regulatory aspects of e-commerce; design e-enabled dynamic websites.
- **Credits:** 4. **Assessment:** continuous assessment 10%, mini-project/presentation 30%, end-semester theory exam 60%. Each week has 3 hours of lectures and 2 hours of practicals.
- **Theory content:** Evolution of the Web → Web Architecture & Development → Web Design Principles (UI/UX, responsive design, accessibility & inclusive design) → E-commerce → Social Media & Web Influence → Web Design Ethics & Policies → Web Security & Cyber Threats → Role of AI → Future Trends.
- **Practical content:** web design tools; HTML, CSS, Bootstrap, responsive web design; JavaScript and PHP; database connectivity; web security and deployment.
