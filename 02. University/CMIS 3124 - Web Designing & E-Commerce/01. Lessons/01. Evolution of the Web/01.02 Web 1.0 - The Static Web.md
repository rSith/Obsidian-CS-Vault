# 01.02 · Web 1.0: the "Static Web"

> [!info] [[01.00 Evolution of the Web|Lesson 1]] · Lecture ref L1.3 · Priority 🔴 High, as the first paragraph of the evolution essay (2023/24 Q1(d), 8 marks).

## 1. What is it?

**Web 1.0** is the **earliest stage of the Web**, from roughly the **early 1990s to the early 2000s**. The lecture calls it the **"static web"**: websites were *static information portals that offered content without interactivity.*

"Static" means the page stays the same for every visitor. It changes only when its owner edits the file.

## 2. Characteristics (from the lecture)

| Characteristic | What it means |
|---|---|
| **Static information portals** | Sites published information. Visitors could only *read* it, with no comments, accounts or sharing. |
| **Basic information sharing** | The focus was on sharing information, *not* on interactive communities. |
| **Few images or videos** | **Bandwidth constraints** (slow dial-up connections) made large media impractical. |
| **Directory-like search engines** | Simple search engines such as **AltaVista** worked like directories. |

> [!note] Beyond the slides
> Web 1.0 pages were usually hand-written HTML files stored on a server. To change one, someone had to edit the file and upload it again. The user was a **consumer only**. This is why Web 1.0 is often described as the **"read-only web"**.

## 3. How it worked (simple model)

```text
Website owner ──writes HTML file──► Web server ──sends same page──► Every visitor (read only)
```

There was no data flowing back from the visitor, apart from following links.

## 4. Why it matters

The lecture's key sentence: **"Web 1.0 laid the foundation for the modern Internet and provided the basic framework for future innovations, such as Web 2.0."** Hyperlinks, URLs, HTML pages and web servers all began here.

## 5. Web 1.0 vs Web 2.0

| Web 1.0 | [[01.03 Web 2.0 - The Participatory Web\|Web 2.0]] |
|---|---|
| Static web | Participatory, dynamic web |
| Users **read** content | Users **read and write** (user-generated content) |
| Content from the site owner only | Content mostly from users |
| Few images/videos (low bandwidth) | Rich media (YouTube) |
| Directory search (AltaVista) | Web apps, APIs, cloud, social sharing |

## 6. Exam-relevant points
- Dates: **early 1990s → early 2000s**.
- Keywords: **static, information portals, no interactivity, bandwidth constraints, AltaVista**.
