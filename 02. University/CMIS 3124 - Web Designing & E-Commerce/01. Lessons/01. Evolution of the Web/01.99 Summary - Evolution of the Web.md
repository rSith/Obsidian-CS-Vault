# 01.99 · Lesson Summary: Evolution of the Web

> [!abstract] Revise in 10 minutes · Back to [[01.00 Evolution of the Web]] · Practice: [[PP 01 - Evolution of the Web]]

## Must know
- The **WWW** is a *graphical entryway to the Internet* and a *collection of inter-linked documents*. It works through **protocols (HTTP), URLs and HTML**.
- There are five stages: **Web 1.0 (static, read) → 2.0 (participatory, read-write) → 2.5 (hybrid bridge) → 3.0 (decentralised, own) → 4.0 (symbiotic, AI + IoT)**.
- There are five **Web 2.0 tools**: **blog, wiki, mashup, RSS, social bookmarking**. Know the definition, key feature and example of each, and when to choose it.
- A browser does three things: **request (HTTP) → find server (DNS → IP) → render (HTML/CSS)**. Its five features are navigation, display, search, security and caching.

## Important definitions
- **Web 1.0:** the earliest stage (early 1990s to early 2000s); static information portals without interactivity; few images (bandwidth); directory search (AltaVista).
- **Web 2.0:** empowers users to participate, create and share content (blogs, wikis, social media); community-driven collaboration, usability, interoperability.
- **Web 2.5:** transitional phase between 2.0 and 3.0; adds blockchain, NFTs and privacy to Web 2.0 platforms; a stepping stone.
- **Web 3.0:** the decentralised web; user control, privacy, P2P without central authorities; data ownership and interoperability.
- **Web 4.0:** the symbiotic web; AI + ML + connected devices; predictive, context-aware, real-time decisions; blurs the physical and digital.
- **Blog:** "web log"; a two-way web-based communication tool; private or public.
- **Wiki:** a web-based collaborative authoring/CMS system; anyone can add and edit articles with a browser (Wikipedia).
- **Mashup:** a page or site combining information and services from multiple web sources.
- **RSS:** Really Simple Syndication; a web feed format (XML) with a summary and link; read by aggregators; "subscribe".
- **Social bookmarking:** a browser-based way to save, sort and share web links digitally.

## Important comparisons

| Web 1.0 | Web 2.0 | Web 3.0 | Web 4.0 |
|---|---|---|---|
| Read | Read + write | Read + write + own | Interact with intelligent systems |
| Static HTML | Web apps, APIs, cloud | Blockchain, P2P, smart contracts | AI + ML + IoT |
| AltaVista, portals | Gmail, YouTube, blogs | DeFi, NFTs, metaverse | Smart cities, BCI, self-driving |

| Blog | Wiki |
|---|---|
| One author or a small team | Anyone, collaboratively |
| Readers **comment** | Users **edit** the article |
| Opinions, dated posts | Neutral, topic articles |

## Choosing a tool (scenario questions)
| Goal | Tool |
|---|---|
| Get reader **comments** (story, poem) | **Blog** |
| Let experts or a group **edit** together | **Wiki** |
| Let researchers **save, tag, discover** a paper | **Social bookmarking** (+ RSS) |
| Keep readers **updated** automatically | **RSS** |
| **Combine** maps + listings into a new service | **Mashup** |

## Important examples
- **HousingMaps.com** = craigslist + Google Maps. **Fishing Solutions** = Google Maps + anglers' information.
- Business uses of mashups: new core apps, employee-built apps, mix data in new ways, better decisions, customer/sales insight; payroll, CRM, logistics, procurement, marketing, e-commerce.
- Web 3.0 uses: **DeFi**, supply-chain records, creator NFTs, metaverse assets.
- Web 4.0 uses: smart cities and homes, healthcare wearables, AR/VR education, decentralised finance, self-driving vehicles.
- Future Internet (7): hyper-personalisation, IoT and ubiquitous computing, intelligent/emotional web, decentralisation at scale, AR/VR metaverse, quantum internet, sustainability and ethical tech.
