# 01.07 · RSS Feeds

> [!info] [[01.00 Evolution of the Web|Lesson 1]] · Lecture ref L1.5(d) · Priority 🟡 Medium. RSS has not had its own question, but it is a good supporting point in the "publish/promote" scenarios (2017/18 Q8(c), Q8(d)(iii)).

## 1. What is it?

**RSS (Really Simple Syndication)** is **"a family of web feed formats used for syndication of content from web pages or blogs."**

- **Syndication** means making your content available for other sites or apps to pick up and show.
- An RSS feed **provides a summary of information items and links to the source**, and it is **presented as an XML file**.

## 2. Why is it used?

It **lets an Internet user be aware of updates to websites he or she is interested in**, without having to visit each site again and again. Web feeds are common on blogs and websites.

## 3. How does it work?

1. The website publishes an **XML feed file**. Each `<item>` has a title, a short summary and a link.
2. The user **subscribes** by adding the feed URL to a **feed reader / aggregator**.
3. The **aggregator checks the list of feeds on the user's behalf** and **displays any updated articles** it finds.
4. Browsers can have **built-in feed readers**, so new feeds are easy to add.

Example of a minimal RSS file:

```xml
<rss version="2.0">
  <channel>
    <title>My Web Design Blog</title>
    <link>https://example.com</link>
    <item>
      <title>What is Responsive Design?</title>
      <link>https://example.com/rwd</link>
      <description>A short summary of the post...</description>
    </item>
  </channel>
</rss>
```

The reader software looks for new `<item>` entries and lists them for the user.

> [!note] Beyond the slides
> The XML structure above is a standard RSS 2.0 illustration. It is not on the slides, which only say the feed is "presented as an XML file". XML itself is covered in [[02.07 Web Services, XML and JSON]].

## 4. How to recognise a feed
RSS feeds are typically linked with the word **"subscribe"**, an **orange rectangle** icon, or the letters **XML** or **RSS**.

## 5. Practical use
- News sites and blogs offer RSS so readers get updates automatically.
- A researcher can follow journal or blog feeds on a topic. This is useful in the "publish a scientific article so others continue the research" scenario.

## 6. Exam-relevant points
- Expand the acronym: **Really Simple Syndication**.
- Key words: **web feed format, XML file, summary + link, aggregator/feed reader, "subscribe"**.
