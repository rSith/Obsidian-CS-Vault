# 01.06 · Mashups

> [!info] [[01.00 Evolution of the Web|Lesson 1]] · Lecture ref L1.5(c) (also L2.11) · Priority 🔴 High
> **Asked in 3 papers:** short note on mashups (2019/20 Q6(b)(iii)); "what is a mashup and what are its uses?" (2018/19 Q5(a)(iii)); "uses of mashups + 3 successful business instances" (2017/18 Q8(b)).

## 1. What is it?

The lecture's definition: **"A web mashup is a web page or website that combines information and services from multiple sources on the Web."**

**A web mashup server** *"enables you to connect, collect, and mash up anything on the Web and data on some back-end systems."*

In simple words, a mashup **takes data from two or more existing sources and combines it to make something new and more useful.**

## 2. How does it work?

```text
Source A (e.g. craigslist listings) ─┐
                                      ├─► Mashup application ─► New combined view (listings on a map)
Source B (e.g. Google Maps API)    ──┘
```

1. The mashup **requests data** from each source, usually through an **API / web service**.
2. It **combines** the data (for example, it matches each listing's address to a map position).
3. It **displays** the result in one new interface.

**Technical link to Lesson 2:** in PHP, any website can be treated as a web service with the `file()` function, which stores the result of an HTTP GET in a variable. Combining sources this way is also called a mashup. See [[02.07 Web Services, XML and JSON]].

```php
<?php
// Read a remote page/feed into an array of lines (HTTP GET)
$lines = file("https://example.com/data.txt");
// ...combine $lines with data from another source and display it
?>
```

## 3. Lecture examples (learn these two)

| Mashup | Sources combined | Benefit |
|---|---|---|
| **HousingMaps.com** | Rental/sale listings from **craigslist.com** + **Google Maps** | Users drag the map to see what is for sale or rent in an area |
| **Fishing Solutions** (fishingsolutions.com.au) | **Google Maps** + information from **other anglers** | Helps users find fish |

## 4. Uses of mashups in business (lecture list)

1. Create **new core business applications** that extend the scope and functions of existing applications, **knit together multiple services** and provide **rich user interfaces**.
2. **Empower employees** to build value-added applications themselves, **quickly**, instead of waiting for enterprise IT teams.
3. Let enterprises **mix and match data and services in unexpected ways**.
4. Used **internally** to collect information from different sources and combine it intelligently, to help people make **better, smarter decisions**.
5. Help **executives** gain a deeper understanding of **customers and sales**.
6. Applied in **payroll, CRM, logistics, procurement, marketing and e-commerce**.
