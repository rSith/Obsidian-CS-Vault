# 01.05 · Wikis (and Wikipedia)

> [!info] [[01.00 Evolution of the Web|Lesson 1]] · Lecture ref L1.5(b) · Priority 🔴 High
> **Asked as:** short note on Wikipedia (2019/20 Q6(b)(ii)); compare a blog with Wikipedia (2018/19 Q5(a)(i)); which tool lets experts edit an article (2017/18 Q8(d)(i)) or lets friends write together (2019/20 Q6(a)(ii)).

## 1. What is it?

The lecture defines a **wiki** as a **"web-based collaborative authoring (or content management) system where users can create and edit content."**

- It *"allows **anyone** to **add a new article** as well as **revise and edit an existing article** using a **web browser**."*
- It is a *"simple, easy-to-use, yet powerful tool for supporting **collaborative work**."*
- **Example:** **Wikipedia** (http://en.wikipedia.org).

## 2. Why is it used?

A wiki lets **many people build one body of knowledge together**. Nobody needs special software, only a browser. Mistakes can be corrected by any other user.

## 3. How does it work?

1. A user opens a page in the browser and clicks **Edit**.
2. They change the text and save it. The new version is live immediately.
3. Other users can improve or correct it later.

> [!note] Beyond the slides
> Most wikis keep a **revision history**, so earlier versions can be restored if someone makes a mistake or vandalises a page. Because anyone can edit, a wiki's **quality depends on community review**, so important facts should be checked.

## 4. Wikipedia: short-note points
- The best-known example of a **wiki**: a web-based collaborative authoring / content management system.
- **Anyone** can create a new article or revise and edit existing ones **using just a web browser**.
- Simple, easy to use, powerful for collaborative work. A free online encyclopedia written by volunteers.
- The revision history lets errors be reverted. The information should still be verified.

## 5. Wiki vs Blog
See the comparison table in [[01.04 Blogs]] (section 5, "Blog vs Wiki"). The key difference: **wiki users edit the content itself; blog readers only comment.**

## 6. When should you choose a wiki? (scenario questions)
Choose a wiki when **several people must write or correct the same content**:
- "Scientific facts followed in Hinduism", to be edited by knowledgeable people → **wiki**.
- An article written collaboratively by you and five friends → **wiki** (everyone edits the same page, with history).
- Contributing to your mother tongue → write or improve Wikipedia articles in Sinhala/Tamil.

## 7. Exam-relevant points
- Use the phrase "**collaborative authoring / content management system**".
- "**Anyone** can add and edit **using a web browser**."
- Example: **Wikipedia**.
