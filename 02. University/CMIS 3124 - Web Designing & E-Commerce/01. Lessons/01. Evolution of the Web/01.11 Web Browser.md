# 01.11 · Web Browser

> [!info] [[01.00 Evolution of the Web|Lesson 1]] · Lecture ref L1.10 (also [[00.01 How Websites Work]]) · Priority 🟢 Low. Not asked directly, but "what happens when you enter a URL" underpins Lesson 2.

## 1. What is it?
A **web browser** is **"a software application that lets you access and view websites and other content on the internet."** Examples: Chrome, Edge, Firefox, Safari.

## 2. How does it work? (3 steps from the lecture)

| Step | What happens |
|---|---|
| **1. Requesting a web page** | You enter a **URL** or click a link. The browser **sends an HTTP request** to the website's server. |
| **2. Finding the server** | The server is located using the **Domain Name System (DNS)**, a worldwide database that **matches the domain name to the website's IP address**. |
| **3. Displaying the content** | The server **sends the website's files back**. The browser **interprets the code (HTML, CSS, JavaScript)** and **renders** it into a visual page you can see and interact with. |

> [!tip] Order in real life
> In practice the DNS lookup (step 2) happens *before* the request can reach the server. The slide lists "requesting" first because that is what the user starts.

```text
You type www.wyb.ac.lk
   │
   ▼
Browser ──"what is the IP of www.wyb.ac.lk?"──► DNS ──► 203.x.x.x
   │
   ▼
Browser ──HTTP GET /index.html──► Web server (203.x.x.x)
   │                                    │
   ◄────── HTML + CSS + JS files ───────┘
   │
   ▼
Browser renders the page on screen
```

Key terms:
- **IP address:** the numeric address of a computer on the Internet.
- **DNS:** the "phone book" that turns names into IP addresses. See [[02.08 Web Application Architecture Components]].
- **Rendering:** turning code into the visual page.

## 3. Browser features (lecture list)

| Feature | What it does |
|---|---|
| **Navigation** | Move between websites and pages (address bar, back/forward, tabs) |
| **Content display** | Renders text, images, videos and other media |
| **Search functionality** | Integrates with search engines so you can type keywords |
| **Security** | Virus checks and **encryption** (e.g. the HTTPS padlock) protect your data |
| **Caching** | **Stores visited sites in a local cache** so they load faster next time. See [[06.07 Web Performance Optimisation]] |

## 4. Exam-relevant points
- Three steps: **request (HTTP) → find server (DNS → IP) → display (interpret and render HTML/CSS)**.
- Five features: **navigation, content display, search, security, caching**.
