# 01.03 · Web 2.0: the Participatory Web

> [!info] [[01.00 Evolution of the Web|Lesson 1]] · Lecture ref L1.4 · Priority 🔴 High
> **Asked as:** a short note on Web 2.0 (2019/20 Q6(b)(iv)); part of the evolution essay (2023/24 Q1(d)); and as background to the online-teaching and online-exam scenarios (2017/18 Q8(a), 2019/20 Q4(c)).

## 1. What is it?

**Web 2.0** is the stage of the Web that **empowers users to actively participate, create and share content** through **dynamic platforms such as blogs, wikis and social media**.

In Web 1.0 the website *owner* supplied the content. In Web 2.0 the website becomes a **platform**, and the **users supply most of the content**. This is called **user-generated content (UGC)**. Web 2.0 is often called the **read-write web**.

The lecture says Web 2.0 **"emphasizes community-driven collaboration, usability, and interoperability, revolutionizing how people engage with the internet."**

- **Collaboration:** people build content together (e.g. Wikipedia).
- **Usability:** sites are easy for ordinary users.
- **Interoperability:** different services can work together and share data (e.g. "Log in with Google", or an embedded Google Map).

## 2. Features of Web 2.0 (lecture list)

| Feature | Example |
|---|---|
| Platforms like **Gmail and YouTube** function seamlessly on the web | You use full applications inside the browser, with no installation |
| **Integration between services** for enhanced functionality | Sign in with Google; maps inside a real-estate site ([[01.06 Mashups\|mashups]]) |
| **Built-in tools for sharing and interaction** across platforms | Share, like and comment buttons |
| **Optimised for various devices and screen sizes** | The same site works on phone, tablet and PC (see [[06.00 Responsive Web Design]]) |
| **Easy content subscription and updates** | [[01.07 RSS Feeds\|RSS feeds]], "follow", notifications |
| Encourages **community-driven development and sharing** | Open-source projects, forums |

## 3. Impact of Web 2.0 (lecture list)

- **E-commerce:** it fuelled the rise of e-commerce, with **personalised shopping experiences and peer reviews**. See [[10.00 E-Commerce]].
- **Business:** marketing, customer engagement and **remote collaboration**.
- **Education:** interactive learning through **online courses and forums**.
- **The Internet as a whole** became a **participatory ecosystem** of dynamic websites, **cloud-based applications and APIs**.

> **Lecture's closing line:** *"Web 2.0's interactive and community-driven nature has redefined how people interact with the web, shaping modern digital culture and innovation."*

## 5. Applying Web 2.0: online teaching and exams (scenario questions)

The past papers asked about online teaching and online exams during COVID-19. The lecture's link is **"educational institutions use Web 2.0 tools … online courses and forums."** A good answer combines:

- an LMS (e.g. Moodle) for online courses and **forums**;
- live classes by video conference and recorded lectures on YouTube;
- **blogs** for reflections, **wikis** for group work, shared documents;
- online quizzes with automatic marking, plus **RSS/notifications** for updates;
- immersive options such as AR/VR classrooms (see [[15.05 AR and VR for the Web]]).

> [!warning]
> The specific tools (Moodle, Zoom, Google Meet) are not named in the lecture slides. They come from the study-guide answer as sensible examples. The lecture only says "online courses and forums".

## 6. Exam-relevant points
- **Short-note checklist (4 marks):** definition (participatory / read-write web, UGC) → emphasis (collaboration, usability, interoperability) → features (web apps, service integration, sharing tools, multi-device, subscriptions) → tool examples (blogs, wikis, mashups, social bookmarking) → impact (e-commerce reviews, business, education, cloud and APIs).
- In the evolution essay, contrast Web 2.0 with Web 1.0: users moved from **read** to **read + write**.
