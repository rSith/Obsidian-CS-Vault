# 01.09 · Web 2.5 and Web 3.0

> [!info] [[01.00 Evolution of the Web|Lesson 1]] · Lecture ref L1.6–L1.7 · Priority 🔴 High, as part of the evolution essay (2023/24 Q1(d)). Web 3.0 is covered again, in more depth, in [[15.01 Web 3.0]].

---

## Part A: Web 2.5 (the bridge)

### What is it?
**Web 2.5** is a **transitional phase between Web 2.0 and Web 3.0**. It **combines elements of both** to *"bridge the gap between centralised and decentralised technologies."*

### What does it combine?
| Kept from Web 2.0 | Added from Web 3.0 |
|---|---|
| Interactive, **user-generated content** | Some **decentralisation**: **blockchain** |
| **Social networking** features | **Tokenised ecosystems (NFTs)** |
| Existing centralised platforms and infrastructure | **Enhanced data privacy** |

### Why does it exist?
- It is a **stepping stone**: organisations and users can **adopt Web 3.0 technologies without fully moving** to a decentralised Internet.
- It offers a **hybrid approach** that **balances innovation with existing infrastructures**.

> [!example] Illustration (not from the slides)
> Picture a normal, company-run social platform that also lets you keep NFTs in a crypto wallet. The platform is still centralised, but some assets are owned on a blockchain.

## Part B: Web 3.0 (the decentralised web)

### What is it?
**Web 3.0** is **"the decentralized web"**. It **emphasises user control, privacy and decentralisation**, and it **enables peer-to-peer (P2P) interactions, removing the need for centralised authorities** such as banks or big platforms.

**Aim:** *"a more secure, transparent and interconnected online ecosystem where **data ownership and interoperability** take centre stage."*

Key terms in plain English:
- **Decentralised:** no single company controls the data. Many computers share it.
- **Peer-to-peer:** users deal with each other directly, without a middleman.
- **Blockchain:** a shared, tamper-proof record of transactions. See [[15.04 Blockchain]].
- **Smart contract:** a program on a blockchain that carries out an agreement automatically when its conditions are met.
- **NFT (Non-Fungible Token):** a unique digital token that proves ownership of a digital item.

### What Web 3.0 does (lecture list)
1. **Safeguards data and transactions** using **advanced encryption**.
2. **Automates agreements without intermediaries** (smart contracts).
3. **Enables financial activities on blockchain networks**.
4. Lets **digital assets represent real-world assets or utilities** (tokenised assets).
5. **Personalises content** and streamlines processes.
6. Lets **users own and monetise their data or digital assets**.

### Where Web 3.0 is used (lecture list)
| Area | How Web 3.0 is used |
|---|---|
| **Decentralised finance (DeFi)** | Peer-to-peer lending, borrowing and trading **without banks**. **Smart contracts** make transactions secure and automatic. |
| **Supply chain management** | An **immutable record** of transactions and product histories gives transparency and trust in retail and manufacturing. |
| **Creators** | Earn money directly through **NFTs or tokenised content**, bypassing traditional platforms. Users **own and earn** from their contributions. |
| **Metaverse** | Digital assets **move freely between platforms**. |

### Web 2.0 vs Web 3.0

| Web 2.0 | Web 3.0 |
|---|---|
| Centralised platforms own the data | **Users own** their data and assets |
| Platforms act as middlemen | **Peer-to-peer**, no intermediaries |
| Trust the company | Trust the **code and the blockchain** |
| Read + write | Read + write + **own** |

## Exam-relevant points
- Web 2.5 = **hybrid / transitional**: blockchain, NFTs, privacy added to Web 2.0 platforms. It is a **stepping stone**.
- Web 3.0 = **decentralised; user control, privacy; P2P; encryption, smart contracts, DeFi, tokenised assets, user-owned data**.
- In the 8-mark essay, give each about 1.5 marks.
