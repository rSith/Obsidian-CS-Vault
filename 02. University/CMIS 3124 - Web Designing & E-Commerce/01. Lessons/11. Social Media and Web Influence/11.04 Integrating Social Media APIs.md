# 11.04 · Integrating Social Media APIs in a Web App

> [!info] [[11.00 Social Media and Web Influence|Lesson 11]] · Lecture ref L11.4 · Priority 🟢 Low (not examined; the most technical part of the lesson)

## 1. What are social media APIs? (lecture)
- **"Interfaces provided by social media platforms that allow developers to access and interact with their data and services programmatically."**
- They enable **fetching user profiles, posts, comments, likes** and other social interactions, so social features can be built **directly into a website**.

An **API (Application Programming Interface)** is a defined way for one program to request data or services from another, in this case your website talking to Facebook's or X's servers. It is a kind of **web service** ([[02.07 Web Services, XML and JSON]]).

## 2. Step-by-step integration (lecture)

```text
1 Set up tools → 2 Register app (API keys) → 3 Authenticate (access token)
   → 4 Call API endpoints (parameters, rate limits) → 5 Parse JSON → 6 Display with HTML/CSS/JS
```

| Step | Lecture details |
|---|---|
| **1. Choose tools** | A code editor (**Visual Studio Code**) and a browser; basic **HTML, CSS, JavaScript**; may need **Node.js and npm** |
| **2. Register the app** | Create a **developer account**, register the app, obtain **API keys or access tokens** |
| **3. Set up authentication** | **Redirect users to the platform to log in and authorise the app**; once authorised, you receive an **access token** for making API requests |
| **4. Understand API endpoints** | **Endpoints** are **specific URLs** for different types of data; each needs certain **parameters** and may have **rate limits** (a maximum number of requests per period) |
| **5. Parse API responses** | Responses are usually **JSON**; **extract specific fields** and format them |
| **6. Display content** | Format with **HTML and CSS**; insert dynamically with **JavaScript** |

### Illustration (pseudo-API, not a real endpoint)
```javascript
// Step 4–6: call an endpoint with an access token, parse JSON, display
const token = "ACCESS_TOKEN_FROM_STEP_3";
fetch("https://api.example-social.com/v1/me/posts?limit=3", {
  headers: { Authorization: `Bearer ${token}` }
})
  .then(res => res.json())                       // parse JSON
  .then(data => {
    const list = document.getElementById("feed");
    data.posts.forEach(post => {                 // extract fields
      const li = document.createElement("li");
      li.textContent = post.text + " (" + post.likes + " likes)";
      list.appendChild(li);                      // display
    });
  });
```
> [!note]
> The code is an illustration. The lecture describes the steps without code.

## 3. Social features you can add (lecture)
| Feature | Benefit |
|---|---|
| **Social login** | Users sign up and log in with their social accounts, so there are **no new credentials to create and remember** |
| **Social sharing buttons** | Users share content to their profiles → **more reach and visibility** |
| **Displaying social media feeds** | Fetch the latest posts → **keeps the website fresh and engaging** |
| **Comments and likes** | **More user interaction and engagement** |

## 4. Advanced integrations (lecture)
- Use **analytics tools and APIs** to **process and visualise social media data**.
- **Schedule and post updates** to social platforms **programmatically**.
- Social integration can **enhance SEO** by increasing content visibility and driving traffic.
