# 11.99 · Lesson Summary: Social Media and Web Influence

> [!abstract] Back to [[11.00 Social Media and Web Influence]] · Practice: [[PP 11 - Social Media and Web Influence]]

## Must know
- **Social media in e-commerce:** visual and interactive; thrives on **UGC**; real-time sharing; **micro-targeting**; analytics and ad tools. Facebook (ads, live shopping), YouTube (promo codes in descriptions), TikTok (viral, flash sales), Instagram (swipe-up, **Instagram Shopping**).
- **Social commerce:** in-app shopping; sell where people socialise; respond swiftly to trends.
- **8 benefits:** brand awareness · targeted ads and lead generation · **social proof and trust** · engagement and relationships · traffic to the store · influencer marketing · real-time analytics · community and loyalty.
- **Influencer marketing:** strategic collaboration with credible personalities. **Tiers:** mega (>1M), macro (100K–1M), micro (10K–100K), nano (<10K). **Strategies:** sponsored posts, affiliate codes/links, reviews and unboxing, live streams. **Why effective:** psychological trust + urgency and exclusivity. **Challenges:** fake followers, disclosure, saturation.
- **Social media APIs:** tools → register (API keys) → authenticate (access token) → endpoints (parameters, rate limits) → parse JSON → display with HTML/CSS/JS. Features: social login, sharing, feeds, comments and likes. Advanced: analytics, scheduled posting, SEO.
- **Search engines:** crawl → render → index → rank.
- **SEO** = improving a site so search engines rank it higher in organic results.
- **On-page:** titles + meta description · simple URLs, shallow directories, one URL per document, breadcrumbs · alt text, file names, media descriptions · anchor text, headings, content keywords.
- **Off-page:** links/PageRank (votes; $\text{votes per page} = \text{importance} \div \text{links}$) · social media · XML/HTML sitemap · robots.txt.
- **Content marketing:** creation → distribution → engagement; types (blog, video, social, podcast, infographic, email, white paper); challenges (engaging content, consistency, ROI).

## Important comparison
| On-page SEO | Off-page SEO |
|---|---|
| Titles, meta, URLs, alt, headings, keywords | Backlinks/PageRank, social, sitemap, robots.txt |
