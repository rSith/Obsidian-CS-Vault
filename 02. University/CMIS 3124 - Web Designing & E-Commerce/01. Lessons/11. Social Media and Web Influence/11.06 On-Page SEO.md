# 11.06 · On-Page SEO Techniques

> [!info] [[11.00 Social Media and Web Influence|Lesson 11]] · Lecture ref L11.6 · Priority 🔴 High (2023/24 Q6(a): "Give two on-page SEO techniques")

The lecture groups on-page SEO into four areas: **basic practices, site structure, usability, content**.

## 1. Basic practices
| Technique | Lecture explanation |
|---|---|
| **Create unique, accurate page titles** | The **title tag tells both users and search engines what the topic of a page is**. Its contents are **displayed in search results**. |
| **Use the "description" meta tag** | Gives Google and other search engines **a summary of what the page is about** (often shown as the result **snippet**) |

```html
<head>
  <title>Handmade Brass Oil Lamps | Ceylon Artefacts</title>
  <meta name="description"
        content="Traditional Sri Lankan brass oil lamps, hand-cast in Kandy. Free island-wide delivery.">
</head>
```

## 2. Site structure
| Technique | Lecture explanation |
|---|---|
| **Simple URLs** | **Simple-to-understand URLs convey content information**; the URL is **displayed in search results** below the title and snippet |
| **Simple directory structure** | Organises content well; visitors know where they are; **avoid deep nesting** like `.../dir1/dir2/dir3/dir4/dir5/dir6/page.html` |
| **One version of a URL per document** | Avoid pages on **subdomains and the root directory showing the same content** (duplicate content) |
| **Breadcrumbs** | **"A row of internal links at the top or bottom of the page that allows visitors to quickly navigate back to a previous section or the root page"** |

```text
❌ https://shop.lk/index.php?id=3489&cat=7&x=12
✅ https://shop.lk/lamps/brass-oil-lamp
```
```html
<nav aria-label="Breadcrumb">
  <a href="/">Home</a> › <a href="/lamps">Lamps</a> › Brass Oil Lamp
</nav>
```

## 3. Usability
| Technique | Lecture explanation |
|---|---|
| **Image alt text** | A place to give **more information about the image** and **target keywords** |
| **File names** | Search engines look at **the filename for clues to the content** |
| **Media description** | A **description of a video, animation, etc.** helps users and search engines understand it |

```html
<img src="brass-oil-lamp-kandy.jpg" alt="Five-wick brass oil lamp from Kandy">
<!-- not: <img src="IMG_0042.jpg" alt=""> -->
```
Alt text helps **both SEO and accessibility** ([[09.03 Applying Accessible Design]]).

## 4. Content
| Technique | Lecture explanation |
|---|---|
| **Anchor text** | **The actual text in a link**; **keyword-rich** anchor text does more for rankings |
| **Heading tags** | Indicate a **headline hierarchy**; search engines show a **slight preference for keywords in headings** |
| **Content keywords** | **One of the most important on-page practices**: the **more relevant a keyword or phrase is to the query**, the higher the page ranks |

```html
<h1>Brass Oil Lamps</h1>
<h2>Traditional Kandyan Designs</h2>
<p>Browse our <a href="/lamps/brass">handmade brass oil lamps</a>.</p>   <!-- ✅ descriptive -->
<p>For lamps, <a href="/lamps/brass">click here</a>.</p>              <!-- ❌ meaningless anchor -->
```

## 5. Model answer for 2023/24 Q6(a) (4 marks)
**SEO** is improving a website's content and structure so search engines can crawl, index and rank it higher in organic results, increasing visibility and relevant traffic *(about 2 marks)*.
**Two on-page techniques** *(about 1 mark each, explained)*:
1. **Unique, accurate page titles and a meta description** that summarise each page; both are shown in search results.
2. **Simple, descriptive URLs and directory structure with breadcrumbs**. *(Or: image alt text and descriptive file names; or keyword-rich headings, anchor text and content.)*
