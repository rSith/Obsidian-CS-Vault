# 11.05 · How Search Engines Work, and What SEO Is

## 1. The four stages of search (lecture)
Traditional web search engines such as Google have **four separate stages**:

| Stage | What happens (lecture) |
|---|---|
| **1. Crawling** | Search engines use **crawlers** (bots) to **discover pages** on the web by **following links and using sitemaps** |
| **2. Rendering** | They **generate how the page will look** using its **HTML, JavaScript and CSS** |
| **3. Indexing** | They **analyse the content and metadata** of discovered pages and **add them to a database** (the index); *there is no guarantee every page will be indexed* |
| **4. Ranking** | **Complex algorithms look at many signals** to decide whether a page is **relevant and high-quality enough** to show for a searcher's query |

```text
Web pages ──crawl (follow links, sitemaps)──► render (HTML+CSS+JS) ──► index (database)
                                                                          │
User query ─────────────────────────────────────────────► rank ◄──────────┘ → results page (SERP)
```

## 2. What is SEO?

> [!note]
> The lecture does not give a one-line SEO definition. It goes straight to the four stages and the techniques. This definition is the study guide's, built from them.

**Search Engine Optimisation (SEO)** is **the practice of improving a website's content and structure so that search engines can crawl, index and rank it higher in organic (unpaid) search results**, increasing its **visibility** and bringing more **relevant traffic**.

- **Organic results** are the normal, unpaid listings (as opposed to paid ads such as Google Ads/AdWords).
- **SERP** (search engine results page) is the page of results you see after searching.

SEO is divided into:
- **On-page SEO:** what you control **on your own pages** (titles, URLs, alt text, headings, content) → [[11.06 On-Page SEO]]
- **Off-page SEO:** signals from **elsewhere** (links from other sites, social media, sitemaps, robots.txt) → [[11.07 Off-Page SEO]]

## 3. Why SEO matters for e-commerce
Most people never scroll past the first page of results. A higher rank means more visitors, at **no cost per click**.
