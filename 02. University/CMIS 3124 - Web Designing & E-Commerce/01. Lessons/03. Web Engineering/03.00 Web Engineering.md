## What this lesson is about
**Web engineering** applies **engineering discipline** (planned processes, modelling, testing) to building web applications. The lesson:
1. shows that WebE is **multidisciplinary**;
2. compares **WebE with traditional software engineering**;
3. presents the **incremental WebE process framework** (5 activities);
4. lists **design goals**, the **quality requirement tree**, the **design pyramid**, **testing types** and **best practices**.

## Topic structure
