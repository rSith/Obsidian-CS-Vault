# 14.04 · Emerging AI Trends in Web Development

> [!info] [[14.00 AI in Web Development|Lesson 14]] · Lecture ref L14.5 · Priority 🟡 Medium (not asked directly, but AI-enhanced cybersecurity supports 2023/24 Q3(e))

## The eight trends (lecture)

### 1. AI-powered personalisation
AI analyses behaviour, preferences and interactions **immediately**, giving **hyper-personalised** experiences:
- **Dynamic content:** specific content for specific users based on their profiles (product recommendations, blog suggestions);
- **Adaptive interfaces:** layouts, colours and navigation change with user preferences;
- **Predictive analytics:** anticipate needs, **suggesting products before the user even searches**.

### 2. Voice search optimisation
Driven by **Siri, Alexa and Google Assistant**:
- **Natural Language Processing (NLP):** understands and responds to **conversational queries**;
- **Schema markup:** AI **automatically generates structured data** so search engines can crawl and index content for voice search;
- **Local SEO:** recognises **user intent** and gives **location-specific** answers.

> **Schema markup** is extra code (e.g. JSON-LD) that labels content for search engines ("this is a product, price Rs 2,500, rating 4.5"). It links to [[11.06 On-Page SEO]].

### 3. AI-driven accessibility
- **Alt-text generation:** descriptive alt text produced automatically for images;
- **Screen-reader optimisation:** more accurate, contextual descriptions;
- **Compliance monitoring:** checks accessibility against **WCAG**. Links to [[09.00 Web Accessibility]].

### 4. Generative AI for content creation
Tools such as **ChatGPT, DALL·E and Jasper**:
- **Generate text:** blog posts, product descriptions, code snippets;
- **Create visuals:** logos, banners and other assets (helping start-ups look professional);
- **Enhance creativity:** brainstorm ideas, build prototypes, experiment with designs.

### 5. AI-enhanced cybersecurity
- **Threat detection** in **real time** (e.g. **DDoS attacks, malware**);
- **Fraud prevention:** analyses behaviour patterns to spot **fake accounts or payment fraud**;
- **Data encryption:** stronger encryption with advanced techniques.
See [[13.11 AI and ML in Web Security]].

### 6. Progressive Web Apps (PWAs) with AI
- **Offline functionality:** AI **foresees what the user needs and caches it** for use without Internet access;
- **Performance:** optimises load times and resources, even on **low-bandwidth** networks;
- **Push notifications:** **personalised** notifications based on activity → engagement and retention.
See [[15.03 Progressive Web Apps]].

### 7. AI in e-commerce development
- **Visual search:** find products using **pictures** instead of words;
- **Chatbots and virtual assistants:** answer queries, suggest products, even **process orders**;
- **Inventory management:** **forecasts demand**, manages stock, cuts waste.

### 8. Low-code / no-code development with AI
Makes web development available to **non-programmers**:
- **Automate design:** layouts from user input;
- **Simplify development:** AI writes code, **integrates APIs**, manages back-end tasks;
- **Rapid prototyping** without extensive coding knowledge.
