# 14.03 · Role of AI: Improved Performance and Security

> [!info] [[14.00 AI in Web Development|Lesson 14]] · Lecture ref L14.3 · Priority 🟡 Medium (feeds 2023/24 Q3(e))

| Use | Lecture explanation |
|---|---|
| **Performance optimisation** | AI **analyses website performance** and **identifies areas for improvement**, such as **slow loading times or inefficient code** |
| **Website security** | AI **helps detect and prevent security threats**, such as **malware and hacking attempts** |

## Going deeper
- **Performance:** AI can recommend image compression, caching or code changes, linking to the manual techniques in [[06.07 Web Performance Optimisation]].
- **Security:** the full picture (detection, incident response, prevention, challenges) is in [[13.11 AI and ML in Web Security]]. The emerging trend **"AI-enhanced cybersecurity"** adds **real-time DDoS/malware detection, fraud prevention and stronger encryption** ([[14.04 Emerging AI Trends]]).
