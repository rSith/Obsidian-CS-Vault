# 14.01 · Role of AI: Automation and Efficiency

> [!info] [[14.00 AI in Web Development|Lesson 14]] · Lecture ref L14.1 · Priority 🟡 Medium (benefits for 2023/24 Q3(b))

| Use | Lecture explanation | Example |
|---|---|---|
| **Code generation and analysis** | AI tools (code assistants) **generate code snippets, suggest improvements and identify potential errors**, speeding up development. **OpenAI Codex** generates code from a programmer's prompt, **but the code still needs to be revised and checked manually**. **GitHub Copilot** can be used to **complete code**. | Typing a comment "validate email" and Copilot suggests the function |
| **Automated testing** | AI tools **automate testing**, including **bug detection and performance testing**, saving developers time and effort | AI generates test cases and finds a broken checkout path |
| **Content generation** | AI assists with **content creation**, from **website copy** to **images and videos**, making it easier to populate websites | Product descriptions written for 500 items |
| **Workflow optimisation** | AI **analyses workflows** and **identifies areas for improvement**, streamlining development | Spotting slow steps in the build or deploy pipeline |

## Key point: AI assists, humans verify
The lecture stresses that Codex output **"still needs to be revised and checked manually"**. This links to the limitations in [[14.05 Ethical Considerations and Limitations of AI]]: AI **can't handle complex tasks independently**, and **accountability** stays with developers.
