# 15.01 · Web 3.0 in Depth

> [!info] [[15.00 Future Trends|Lesson 15]] · Lecture ref L15.1 · Priority 🟡 Medium. First introduced in [[01.09 Web 2.5 and Web 3.0]]; useful for the 2023/24 Q1(d) essay.

## 1. What is Web 3.0? (lecture)
- **The third generation of the World Wide Web.**
- Emphasises **personal data ownership** and the use of **blockchain technology and cryptocurrencies**.
- **Goal:** build an **open, decentralised Internet** that offers consumers **increased value and security**.

## 2. Projections (lecture)
- Web 3.0 technologies will be **distributed, trustless and open**; content platforms built on **open-source** technology (accessibility, transparency).
- **Zero Trust principles in a trustless environment:** users, devices and services interact **without permission from a single authority**.
- Blockchain lets people **communicate directly**; users join **DAOs (Decentralised Autonomous Organisations)** that are **owned and managed by their community**.
- Blockchain will **trace every transaction on a distributed ledger**, decentralising data transfers.
- **Data integrity** will no longer need centralised entities, thanks to **open intelligent (smart) contracts**.
- The **metaverse** will boost the entertainment industry's earnings.
- Blockchain will **safeguard intellectual property and personally identifiable information (PII)** while letting users create **digital goods and NFTs** instantly.

"**Trustless**" doesn't mean untrustworthy. It means you **don't need to trust** a middleman, because the code and the blockchain enforce the rules.

## 3. Characteristics (lecture)
| Characteristic | Meaning |
|---|---|
| **Semantic web** | Search and analysis focused on **understanding the meaning of words**, not just numbers and keywords |
| **Machine learning and AI** | More intelligent and responsive, especially with **NLP** |
| **Trustless data** | Users communicate privately or openly **without worrying about third parties**, thanks to **decentralised protocols** |
| **Internet of Things** | **Semantic metadata** connects devices and apps, so Internet access becomes commonplace |
| **3D graphics** | Better UX in **virtual tours, e-commerce and gaming** |
| **Participation without authorisation** | Take part **without permission from a central authority** |

## 4. Applications (lecture)
| Application | Meaning |
|---|---|
| **NFT** (non-fungible token) | **Individually unique tokens** kept on a blockchain with a **cryptographic hash** |
| **DeFi** (decentralised finance) | Financial services **beyond conventional centralised banking** |
| **Cryptocurrency** | A new form of money distinct from **fiat cash** (e.g. **Bitcoin**) |
| **dApps** (decentralised applications) | Programs **logged in an immutable ledger**, **built on blockchain**, using **smart contracts** |
| **Cross-chain bridges** | **Connect different blockchains** |
| **DAOs** | Web 3.0's **governing bodies**, with structure and **decentralised governance** |

## 5. Layers of Web 3.0 (lecture)
| Layer | Meaning |
|---|---|
| **Edge computing** | Web 2.0 put computing in **data centres**; Web 3.0 pushes it **out to the edge and into users' hands** |
| **Decentralised data network** | **Users own their data** and can **sell or share it without losing ownership** or using intermediaries |
| **AI and ML** | Algorithms now make **useful predictions and actions** |
| **Blockchain** | Uses **smart contracts** to execute transactions; smart contracts **define the semantics** of a Web 3.0 app; developers must use the **shared state machine** |

## 6. How does Web 3.0 work? (lecture)
| Concept | Explanation |
|---|---|
| **Data ownership** | Your data is stored in **your crypto wallet**, not on Facebook's or YouTube's servers. You interact with apps **through the wallet**, **take your data with you** when you leave, and may **choose to monetise it** |
| **Pseudonymity** | The **wallet is your identity**, which is hard to link to your real identity. Observers can track transactions on privacy-coin blockchains but **can't see the wallets** involved. *"My personal information is hidden, but my behaviour is visible."* (Neuroth) |
| **DAOs** | Decisions are made by **users who own governance tokens** (earned by helping maintain the programs, or bought). Token holders **vote** on changes, and **approved changes go straight into the code through a smart contract** |

## 7. Challenges and considerations (lecture)
1. **Scalability:** blockchain struggles to handle global data volume and transaction throughput.
2. **Complexity:** hard for users to understand and navigate.
3. **Regulation and governance:** who regulates without central authorities?
4. **Security risks:** new vulnerabilities in **dApps and smart contracts**.
5. **Device capabilities** will need to expand.
6. **Web 1.0-based websites will become obsolete** once Web 3.0 is fully implemented.
