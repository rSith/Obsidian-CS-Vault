## What this lesson is about
Where the web is heading:
1. **Web 3.0** in depth;
2. **platform-specific apps vs traditional websites vs Progressive Web Apps (PWAs)**;
3. **blockchain**: what it is, evolution, benefits, features, **how it works**, platforms, security;
4. **AR and VR** for the web.

## Topic structure
```text
Future Trends
├── Web 3.0: definition · projections · characteristics · applications · layers · how it works · challenges
├── Platform-specific apps vs traditional websites
├── Progressive Web Apps: definition · benefits · browser · technical features · SPAs · progressive enhancement
├── Blockchain: definition · evolution · benefits · key features · how it works · protocols/platforms · security
└── AR & VR for the web: definitions · examples · how they change web design
```
