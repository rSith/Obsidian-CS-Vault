# 15.99 · Lesson Summary: Future Trends in Web and E-Commerce

> [!abstract] Back to [[15.00 Future Trends]] · Practice: [[PP 15 - Future Trends]]

## Must know
- **Web 3.0** = third-generation WWW: data ownership, blockchain, cryptocurrencies; open and decentralised. **Projections:** distributed, trustless, open; Zero Trust; DAOs; ledgers; smart contracts; metaverse; NFTs/PII protection. **Characteristics:** semantic web, AI/ML (NLP), trustless data, IoT, 3D graphics, participation without authorisation. **Apps:** NFT, DeFi, crypto, dApps, cross-chain bridges, DAOs. **Layers:** edge computing, decentralised data network, AI/ML, blockchain. **How it works:** wallet data ownership, pseudonymity, DAO governance tokens. **Challenges:** scalability, complexity, regulation, security risks, device capabilities, Web 1.0 obsolete.
- **Platform-specific apps:** per OS, vendor SDK, app store; easy access, offline/background, dedicated UI, OS integration. **Websites:** no device presence, need the browser and network; one codebase, web distribution.
- **PWA:** built with web technologies and gives an app-like UX; the best of both. **Benefits:** single codebase, from the web, installable, offline/background (push, notifications), full screen, device integration, app stores. **Technical:** HTML page + **web app manifest** + **service worker**. Not necessarily an SPA. **Progressive enhancement** + feature detection (Background Sync example).
- **Blockchain:** decentralised distributed database; consensus; blocks linked into a chain; tamper-proof. Bitcoin 2008 (Satoshi Nakamoto); smart contracts 2015. **How it works:** (1) record as blocks + timestamp → (2) link with cryptographic hashes (each includes the previous block's data) → (3) irreversible chain validated by consensus (PoW/PoS) → (4) trust and immutability. **Benefits:** trust, security, traceability, efficiency, automation. **Features:** DLT, immutable records, smart contracts, public-key cryptography. **Platforms:** Hyperledger Fabric, Ethereum, Corda, Quorum.
- **AR** overlays digital content on the real world; **VR** is fully immersive. **Examples:** e-commerce (furniture, try-ons), real estate (3D tours), tourism, education. **Changes:** engagement, real-world integration, immersive storytelling, product development, data insights, cost-effectiveness.

## Important comparisons
| Website | PWA | Native app |
|---|---|---|
| URL, no install, online only | URL + install, offline, push | App store, per OS |

| AR | VR |
|---|---|
| Adds to the real world | Replaces it with a virtual world |

| Secret-key | Public-key |
|---|---|
| One shared key (AES), fast | Key pair; signatures; slower |
