# 00.99 · Summary: HTML and CSS Foundations

> [!abstract] Back to [[00.00 HTML and CSS Foundations]] · Practice: [[PP 00 - HTML and CSS Foundations]]

## Must know
- **Website** = web pages and resources accessed through a browser. **Client:** sends requests, receives responses, displays pages, runs JS. **Server:** stores files, processes requests, runs server-side programs, accesses DBs. **Front-end** = what users see (HTML/CSS/JS); **back-end** = data, authentication, business logic, DB.
- **HTML** = HyperText (text with links) Markup Language (tags label parts); **not a programming language**.
- **Element anatomy:** element, tag, opening tag, closing tag, attribute, content.
- **Document:** `<!DOCTYPE html>` → `<html>` → `<head>` (title, meta, CSS/JS links) + `<body>` (visible content).
- **`<p>` vs `<br>`;** `<strong>`/`<em>` (meaning) vs `<b>`/`<i>` (visual); **entities** by name (`&lt;`) or number (`&#60;`).
- **Lists:** `ol` (order matters), `ul`, `dl/dt/dd`. **Links:** page, `#id`, `mailto:`, `target="_blank"`. **Images:** `src`, `alt`, width only = keeps the ratio. `<pre>` keeps whitespace.
- **Tables:** `tr/th/td`; `<caption>`, `thead/tbody/tfoot`, `colspan`/`rowspan`. **`<figure>` + `<figcaption>`.**
- **Forms:** `action` (where) + `method` (GET = URL query string; POST = request body); `label for` = input `id`; `name` = the submitted key; radio (one per `name` group) vs checkbox (many); `select/option`; `textarea` (rows/cols); `fieldset/legend`; buttons submit/reset/button; validation `required`, `min/max`, `minlength/maxlength`, `pattern`; the **server must validate too**.
- **Semantic HTML:** header, nav, main, section, article, aside, footer.
- **CSS:** external stylesheet; **custom properties** (`--x`, `var(--x)`); reset (`box-sizing: border-box`, `body{margin:0}`); inheritance; `img{max-width:100%;height:auto}`; `min()`, `clamp()`, logical properties, `ch`.
- **Selectors:** type, class, ID, descendant, child `>`, grouping, attribute, multiple classes. **Pseudo-classes** (`:hover`, `:focus`, `:focus-visible`, `:active`, `:visited`, `:nth-child`, `:valid`, `:invalid`, `:checked`, `:has()`) vs **pseudo-elements** (`::after`, `::marker`, `::placeholder`).
- **Cascade:** importance → specificity (ID > class > element) → source order (later wins).
