# 00.04 · Advanced Tables and Figures

> [!info] [[00.00 HTML and CSS Foundations|Foundations]] · Source: Practical 2 (sections 1–2) · Priority 🟢 Low

## 1. Figure and caption
`<figure>` groups **self-contained media** (an image, diagram or code) with its **caption** `<figcaption>`.
```html
<figure>
  <img src="images/blog1.jpg" alt="My first blog post" width="250">
  <figcaption>First Blog Post</figcaption>
</figure>
```
Why use it? It links the caption to the image **semantically** (good for accessibility and SEO), rather than just placing text below the image.

## 2. Advanced tables
```html
<table>
  <caption>My Learning Progress</caption>
  <thead>
    <tr><th>Technology</th><th>Level</th><th>Hours</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML</td><td>Intermediate</td><td rowspan="2">40</td></tr>
    <tr><td>CSS</td><td>Beginner</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="3">Updated June 2026</td></tr>
  </tfoot>
</table>
```
| Element / attribute | Purpose |
|---|---|
| `<caption>` | A **title** for the table (screen readers announce it) |
| `<thead>` / `<tbody>` / `<tfoot>` | **Group** header rows, body rows and footer rows |
| `colspan="3"` | A cell **spans 3 columns** |
| `rowspan="2"` | A cell **spans 2 rows** |

Accessibility link: **"summarise tables and provide headings"** ([[04.04 Functional and Usable Design]]). `<caption>` and `<th>` do exactly that.

## 3. Styling tables (from Practical 3)
```css
table { border-collapse: collapse; width: 100%; }  /* single shared borders */
th, td { border: 1px solid var(--color-border); padding: var(--space-sm); }
tbody tr:nth-child(even) { background-color: #f0f4f8; }   /* zebra stripes */
tbody tr:hover { background-color: #e1e8f0; }             /* row state */
```
- `border-collapse: collapse` merges double cell borders into one (it replaces the old `border="1"` attribute).
- `:nth-child(even)` selects every second row (a pseudo-class: [[00.08 CSS Selectors, Pseudo-classes and the Cascade]]).
- Bootstrap does the same with `.table-striped` and `.table-hover` ([[08.05 Bootstrap Tables, Images and Buttons]]).
