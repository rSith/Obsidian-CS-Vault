# 00.01 · How Websites Work: Client vs Server, Front-End vs Back-End

> [!info] [[00.00 HTML and CSS Foundations|Foundations]] · Source: Practical 01 discussion, slides 1–3 · Priority 🟢 Low (background for Lessons 1–2)

## 1. What is a website? (slide)
**"A website is a collection of web pages and resources that can be accessed through the Internet using a web browser."** Resources include images, stylesheets and scripts.

### What happens when we enter a URL?
The slide asks this question with a diagram. Step by step:
1. The browser asks **DNS** for the server's **IP address**.
2. It sends an **HTTP request** to that server.
3. The server returns **HTML, CSS and JavaScript**.
4. The browser **renders** the page.

Details: [[01.11 Web Browser]] and [[02.04 HTTP Protocol]].

## 2. Client vs server (slides)
| **Client** | **Server** |
|---|---|
| **Normally the user's device and browser** (Chrome, Edge, Firefox, Safari) | **A computer/system that provides resources or services** to clients |
| **Sends requests** | **Stores website files** |
| **Receives responses** | **Processes requests** |
| **Displays web pages** | **Executes server-side programs** (e.g. PHP) |
| **Executes JavaScript** | **Accesses databases** and **returns data** to the client |

## 3. Front-end vs back-end (slides)
| **Front-end** | **Back-end** |
|---|---|
| **What the user sees and interacts with** | **What happens behind the interface** |
| HTML (structure), CSS (presentation), JavaScript (behaviour); frameworks such as Bootstrap and React | **Processing data, user authentication, business logic, database operations, server-side processing** (e.g. PHP + MySQL) |
| Runs in the **browser** | Runs on the **server** |

> [!note]
> The front-end technologies are shown as logos on the slide. The list above is the study guide's reading of it.

## Client/server vs front-end/back-end
These pairs are related but not the same: client/server describes **where code runs** (which machine); front-end/back-end describes **which part of the application** it is (the interface or the logic and data). Front-end code usually runs on the client, and back-end code on the server.
