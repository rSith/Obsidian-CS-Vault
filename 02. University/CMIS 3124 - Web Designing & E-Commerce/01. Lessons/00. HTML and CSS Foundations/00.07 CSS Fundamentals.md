# 00.07 · CSS Fundamentals (Practical 3, Part 1)

> [!info] [[00.00 HTML and CSS Foundations|Foundations]] · Source: Practical 3 (Part 1) · Priority 🟢 Low (supports media-query and Bootstrap answers)

## 1. What is CSS?
**CSS (Cascading Style Sheets)** specifies the **design** of a web page: *"the fonts, colours, positions of different parts of the page"* ([[02.02 Web Languages - HTML CSS JavaScript PHP]]). HTML gives the **structure**; CSS gives the **presentation**.

### A CSS rule
```css
selector   { property: value; }
nav a      { color: #243b53; text-decoration: none; }
```

## 2. Linking an external stylesheet (Practical 3, Step 1)
```html
<head>
  <link rel="stylesheet" href="css/style.css">
</head>
```
Project structure: `index.html`, `css/style.css`, `images/`. **One external stylesheet for all pages** keeps the design consistent (the "repetition" in CARP: [[04.01 Aesthetic Layout and CARP Principles]]). Practical 3 Part 2 says: *"Do not create another stylesheet"*; extend the same one.

The stylesheet is organised into **commented sections**: design tokens, reset, responsive images, typography, header, navigation, main, sections, …, footer.

## 3. Design tokens: CSS custom properties (Step 3)
*"Instead of repeating colours, spacing and sizes throughout the stylesheet, define reusable CSS custom properties."*
```css
:root {
  --color-primary: #243b53;
  --color-secondary: #486581;
  --color-background: #f5f7fa;
  --color-surface: #ffffff;
  --color-text: #1f2933;
  --color-muted: #52606d;
  --color-border: #d9e2ec;
  --space-xs: 0.25rem;  --space-sm: 0.5rem;  --space-md: 1rem;
  --space-lg: 2rem;     --space-xl: 4rem;
  --radius-sm: 0.4rem;  --radius-md: 0.8rem;
  --content-width: 70rem;
}
body { color: var(--color-text); }
```
- Defined with `--name` (usually on `:root`, the `<html>` element) and **used with `var(--name)`**.
- Change one value and the whole site updates. This is a small **design system**.

## 4. Basic CSS reset (Step 4)
```css
*, *::before, *::after { box-sizing: border-box; }
html { scroll-behavior: smooth; }
body {
  margin: 0;
  font-family: Arial, Helvetica, sans-serif;
  line-height: 1.6;
  color: var(--color-text);
  background-color: var(--color-background);
}
```
| Concept (Practical 3 table) | Explanation |
|---|---|
| **`box-sizing`** | Controls how width and height are calculated. With **`border-box`**, **padding and border are included** in the specified width/height |
| **Browser default margins** | Browsers add margins to `<body>`, headings and paragraphs automatically, which can cause unexpected spacing → `body { margin: 0; }` |
| **Inheritance** | Some properties pass **from parent to children**, e.g. `color` and `font-family`: `body { color: blue; }` makes `<p>` text blue too |
| **`line-height`** | Vertical spacing between lines; larger = more space |
| **CSS variables** | Reusable values: `--main-color: blue;` → `color: var(--main-color);` |

### The box model (background)
```text
┌──────────── margin ────────────┐
│ ┌────────── border ──────────┐ │
│ │ ┌──────── padding ───────┐ │ │
│ │ │        content         │ │ │
│ │ └────────────────────────┘ │ │
│ └────────────────────────────┘ │
└────────────────────────────────┘
content-box: width = content only     border-box: width = content + padding + border
```

## 5. Responsive images (Step 5)
```css
img { max-width: 100%; height: auto; }
```
*`max-width: 100%` stops an image from becoming wider than its parent; `height: auto` keeps the aspect ratio.* This is the **flexible images** rule of RWD ([[06.04 Making Pages Responsive]]).

```css
#myself > img {           /* round profile photo */
  width: 100px; height: 100px;
  object-fit: cover;       /* crop instead of stretch */
  border-radius: 50%;      /* circle */
}
```

## 6. Modern layout and typography helpers (Practical 3)
```css
main {
  width: min(90%, var(--content-width));  /* the smaller of the two values */
  margin-inline: auto;                    /* centre horizontally (left + right) */
  padding-block: var(--space-xl);         /* top + bottom */
}
body > header h1 { font-size: clamp(2rem, 5vw, 4rem); }  /* fluid size between a min and a max */
p { max-width: 70ch; }                                     /* about 70 characters per line */
```
| Function / property | Meaning |
|---|---|
| `min(a, b)` | Uses the **smaller** value, so it is fluid but capped |
| `clamp(min, preferred, max)` | **Grows with the screen within limits**: responsive typography |
| `margin-inline` / `padding-block` | **Logical properties**: inline = left/right, block = top/bottom (direction-aware) |
| `ch` unit | About the width of one character, used for readable line length (45–75 characters per line in [[06.06 Designing Responsively and Site Testing]]) |
| `vw` unit | 1% of the viewport width |
