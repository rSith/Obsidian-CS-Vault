## What this section covers
The four lab sheets build **one personal blog website** step by step:
- **Practical 1:** semantic HTML page structure, link types, images, `<pre>`, lists, tables.
- **Practical 2:** figures, advanced tables, a **full registration form** with HTML5 validation.
- **Practical 3 (Part 1):** an **external stylesheet** with a small **design system** (CSS custom properties), reset, typography, navigation states, pseudo-classes and pseudo-elements, table styling, the cascade.
- **Practical 3 Part 2:** **styling the form**: attribute selectors, focus states, `:valid`/`:invalid`, `:checked`/`:has()`, button components, multiple classes.
