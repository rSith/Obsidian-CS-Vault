# 00.06 · Semantic HTML

> [!info] [[00.00 HTML and CSS Foundations|Foundations]] · Source: Practical 01 discussion, slide 9; Practical 1 · Priority 🟡 Medium. It is the "native HTML" behind **ARIA Rule #1** ([[09.04 Introduction to ARIA and the Five Rules]]).

## 1. What is it? (slide)
**Semantic HTML** = **"elements that clearly describe the meaning and purpose of the content they contain."**
Compare `<div>`, which says nothing about its content, with `<nav>`, which says "these are navigation links".

## 2. The semantic layout elements (slide)
| Element | Purpose |
|---|---|
| `<header>` | **Introductory / top content** |
| `<nav>` | **Navigation links** |
| `<main>` | **Main content** (one per page) |
| `<section>` | A **related group of content** (usually with a heading) |
| `<article>` | **Independent, self-contained content** (e.g. **each blog post**, as in Practical 1) |
| `<aside>` | **Related / additional content** (sidebar) |
| `<footer>` | **Bottom / closing information** |

Practical 1 also uses `<blockquote>` (a long quotation), `<figure>`/`<figcaption>`, and `<del>`/`<ins>`.

## 3. Lecture example (simplified)
```html
<!DOCTYPE html>
<html>
<head><title>University Webpage</title></head>
<body>
  <header>
    <h1>ABC University</h1>
    <p>Welcome to our university website</p>
  </header>

  <nav>
    <a href="index.html">Home</a>
    <a href="courses.html">Courses</a>
    <a href="about.html">About Us</a>
    <a href="contact.html">Contact</a>
  </nav>

  <main>
    <section>
      <h2>Our Courses</h2>
      <p>We offer a variety of undergraduate programmes.</p>
      <article>
        <h3>BSc in Data Science</h3>
        <p>This programme provides knowledge and skills in data analysis, programming and machine learning.</p>
      </article>
      <article>
        <h3>BSc in Computer Science</h3>
        <p>This programme covers programming, databases, software engineering and computer systems.</p>
      </article>
    </section>
    <aside>
      <h3>Related Information</h3>
      <p>Applications for the next intake are now open.</p>
      <a href="apply.html">Apply Now</a>
    </aside>
  </main>

  <footer>
    <p>&copy; 2026 ABC University</p>
    <p>Contact: info@abcuniversity.edu</p>
  </footer>
</body>
</html>
```

## 4. Why semantic HTML matters

> [!note]
> These benefits link this practical topic to the theory lessons.

| Benefit | Explanation |
|---|---|
| **Accessibility** | Screen readers announce landmarks ("navigation", "main") so users can jump around. This is **native semantics**, which ARIA tries to imitate (`role="navigation"` ≈ `<nav>`) |
| **SEO** | Search engines understand the page structure better ([[11.06 On-Page SEO]]) |
| **Maintainability** | Code is easier to read than nested `<div>`s |
| **Styling hooks** | CSS selectors such as `body > header` (Practical 3) |

## `<section>` vs `<article>` vs `<div>`
| `<article>` | `<section>` | `<div>` |
|---|---|---|
| Makes sense **on its own** (could be shared or syndicated) | A **thematic group**, part of something bigger | **No meaning**; only for styling and layout |
| A blog post, a news item, a product card | "Our Courses", "Contact" | A wrapper for a CSS grid |
