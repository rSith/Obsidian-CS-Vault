# 00.09 · Styling Forms with CSS (Practical 3 Part 2)

> [!info] [[00.00 HTML and CSS Foundations|Foundations]] · Source: Practical 3 Part 2 · Priority 🟢 Low

## 1. Structure first (recommended HTML changes)
- Wrap the form in a container, e.g. `<main class="form-container">`.
- Group each label and input in a `.form-group`; give fieldsets a class.
- Add **help text** (`<small class="form-help">`) and a **required indicator** (`*`).

```html
<div class="form-group">
  <label for="name">Name <span class="required-indicator">*</span></label>
  <input type="text" id="name" name="name" minlength="3" required>
  <small class="form-help">At least 3 characters.</small>
</div>
```

## 2. Form container
```css
.form-container {
  width: min(100%, 50rem);
  margin-inline: auto;
  padding: var(--space-lg);
  background-color: var(--color-surface);
  border: 1px solid var(--color-border);
  border-radius: var(--radius-md);
  box-shadow: 0 0.5rem 2rem rgb(0 0 0 / 8%);   /* optional */
}
```

## 3. Style all text controls at once: attribute selectors
*"Instead of styling every input separately, use an attribute selector."*
```css
input[type="text"], input[type="email"], input[type="password"],
input[type="number"], input[type="date"], input[type="tel"],
select, textarea {
  width: 100%;
  padding: 0.75rem;
  border: 1px solid var(--color-border);
  border-radius: var(--radius-sm);
  background-color: white;
  font: inherit;
}
```

## 4. Focus, required, valid and invalid states
```css
input:focus, select:focus, textarea:focus {
  outline: 3px solid var(--color-primary);    /* visible focus for keyboard users */
  outline-offset: 3px;
}
input:required, select:required, textarea:required {
  border-inline-start: 3px solid var(--color-primary);   /* marks required fields */
}
input:required:valid, select:required:valid, textarea:required:valid {
  border-color: #2e7d32;                                  /* green when valid */
}
input:required:not(:placeholder-shown):invalid,
textarea:required:not(:placeholder-shown):invalid {
  border-color: #b42318;                                  /* red, only after typing */
}
```
**Why `:not(:placeholder-shown)`?** An empty required field is technically `:invalid` from the start. This trick waits until the user has typed something (the placeholder is gone) before showing red. That is better UX and avoids error messages too early ([[05.08 UI Design Principles]]).

**Validation exercise (38):** "Al" in Name fails `minlength="3"`; "alex" fails `type="email"`; 15 fails `min="18"`; a message shorter than 10 characters fails. This connects **HTML5 validation** with **CSS pseudo-classes**.

## 5. Radio buttons, checkboxes and `:has()`
```css
.choice input { margin-right: var(--space-xs); accent-color: var(--color-primary); }
.choice:has(input:checked) { font-weight: 700; color: var(--color-primary); }
```
- **`accent-color`** recolours native radios and checkboxes **without replacing them**.
- **`:has()`** (an advanced "parent" selector) styles the `.choice` label **if it contains a checked input**, so the chosen option is bolded.

## 6. Textarea and select
```css
textarea { min-height: 10rem; resize: vertical; }   /* taller, no horizontal distortion */
select   { cursor: pointer; }
```

## 7. Button component with states
```css
.button { padding: 0.75rem 1.5rem; border: 0; border-radius: var(--radius-sm); cursor: pointer; }
.button-primary   { background-color: var(--color-primary); color: white; }
.button-secondary { background-color: var(--color-border); color: var(--color-text); }
.button:hover     { filter: brightness(1.1); }
.button:active    { transform: translateY(1px); }
.button:disabled  { opacity: 0.5; cursor: not-allowed; }
```
```html
<button class="button button-primary" type="submit">Register</button>
<button class="button button-secondary" type="reset">Clear</button>
```
> [!note]
> The exact button CSS above is an illustrative reconstruction. The practical introduces the `.button` / `.button-primary` / `.button-secondary` pattern with `:hover`, `:active` and `:disabled` states.

## 8. Developer tools exercise (39)
Inspect an input with the browser's DevTools and check its **width, padding, border, box model, inherited font, focus state, `:valid`, `:invalid`, `:required`**. This is the same tool used for responsive testing ([[06.06 Designing Responsively and Site Testing]]).
