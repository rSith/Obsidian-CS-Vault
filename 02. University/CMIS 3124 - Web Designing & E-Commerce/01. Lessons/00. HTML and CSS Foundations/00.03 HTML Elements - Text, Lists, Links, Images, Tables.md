# 00.03 · HTML Content Elements: Text, Lists, Links, Images, Tables

> [!info] [[00.00 HTML and CSS Foundations|Foundations]] · Source: Practical 01 discussion, slides 5–9; Practical 1 · Priority 🟢 Low

## 1. Headings
`<h1>` is the **most important** heading and `<h6>` the **least important**. Use them in order. They form the page outline that screen readers and search engines use ([[11.06 On-Page SEO]], [[09.03 Applying Accessible Design]]).

## 2. Paragraphs and line breaks (slides)
- `<p>` is a **block-level element**: a paragraph **starts on a new line and takes up the available width**.

| `<p>…</p>` | `<br>` |
|---|---|
| **Creates a paragraph** | **Creates a line break** |
| Used for **separate blocks of text** | Moves text **to the next line** |
| Normally creates **spacing between paragraphs** | **No** paragraph spacing |
| Has **opening and closing tags** | Usually a **single (empty) tag** |

```html
<p>This is the first paragraph.</p>
<p>This is the second paragraph.</p>
Paragraph 1<br>
Paragraph 2
```

## 3. Text formatting (slide)
| Tag | Meaning |
|---|---|
| `<strong>` | **Important** text (semantic) |
| `<em>` | *Emphasised* text (semantic) |
| `<b>` | Bold (visual only) |
| `<i>` | Italic (visual only) |
| `<u>` | Underlined |
| `<mark>` | Highlighted |
| `<small>` | Small text |
| `<sub>` / `<sup>` | Subscript / superscript (e.g. H<sub>2</sub>O, 15<sup>th</sup>) |
| `<ins>` / `<del>` | Inserted / deleted text |
| `<code>` | Computer code |

`<strong>` and `<em>` carry **meaning**, while `<b>` and `<i>` are purely visual. This is repeated in [[04.03 Graphics and Typography]].

## 4. Character entities (slide)
An **HTML entity** is **a special code that represents a character**. You write the entity instead of the character itself, usually because the character would be read as markup.
| Form | Syntax | Example for `<` |
|---|---|---|
| **Entity name** | `&entity_name;` | `&lt;` |
| **Entity number** | `&#entity_number;` | `&#60;` |

```html
<p>5 &lt; 10</p>          <!-- shows: 5 < 10 -->
<p>&copy; 2026 My Blog</p> <!-- shows: © 2026 My Blog (Practical 1 footer) -->
```
Others: `&gt;` (>), `&amp;` (&), `&nbsp;` (non-breaking space).

## 5. Lists (slides)
| List | Tags | Use |
|---|---|---|
| **Ordered** | `<ol>` + `<li>` | **Instructions, procedures, rankings, steps in a process** (order matters) |
| **Unordered** | `<ul>` + `<li>` | Items where **order doesn't matter** |
| **Description** | `<dl>` + `<dt>` (term) + `<dd>` (description) | **Terms and their descriptions** |

```html
<ol><li>Open the browser</li><li>Open the website</li><li>Log in</li></ol>
<ul><li>HTML</li><li>CSS</li><li>JavaScript</li></ul>
<dl>
  <dt>HTML</dt><dd>Used to structure webpages.</dd>
  <dt>CSS</dt><dd>Used to style webpages.</dd>
</dl>
```

## 6. Links (slide + Practical 1)
| Link type | Code |
|---|---|
| External site | `<a href="https://www.google.com">Google</a>` |
| Another page | `<a href="about.html">About Us</a>` |
| Section on the same page | `<a href="#contact">Contact</a>` → jumps to the element with `id="contact"` |
| Email | `<a href="mailto:alex@example.com">Email me</a>` |
| External, new tab | `<a href="https://www.linkedin.com/" target="_blank" rel="noopener" title="My LinkedIn">LinkedIn</a>` |
| Placeholder | `href="#"` |

- `target="_blank"` opens the link in a **new tab**; `rel="noopener"` is a security measure for new tabs; `title` shows a tooltip.

## 7. Images (slide + Practical 1)
```html
<img src="images/logo.png" alt="University Logo" width="150">
```
- `src`: the path, which **must match the file name exactly** (case, extension).
- `alt`: a **text alternative** for screen readers and when the image fails to load ([[09.03 Applying Accessible Design]]).
- `width`/`height`: giving **only width keeps the aspect ratio**.

## 8. The `<pre>` element (Practical 1)
`<pre>` **preserves whitespace and line breaks** exactly as typed (good for code or ASCII diagrams). `<p>` **collapses** multiple spaces and line breaks into one space.

## 9. Basic tables (slide)
```html
<table>
  <tr>
    <th>Name</th>
    <th>Programme</th>
  </tr>
  <tr>
    <td>Kasun</td>
    <td>Data Science</td>
  </tr>
</table>
```
| Tag | Meaning |
|---|---|
| `<table>` | The table |
| `<tr>` | **Table row** |
| `<th>` | **Header cell** (bold and centred by default) |
| `<td>` | **Data cell** |

More: [[00.04 Advanced Tables and Figures]].
