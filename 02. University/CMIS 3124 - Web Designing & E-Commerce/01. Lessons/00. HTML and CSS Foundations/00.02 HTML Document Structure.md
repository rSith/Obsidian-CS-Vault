# 00.02 · HTML Document Structure

> [!info] [[00.00 HTML and CSS Foundations|Foundations]] · Source: Practical 01 discussion, slide 4; Practical 1 · Priority 🟢 Low

## 1. What is HTML? (slide)
**HyperText Markup Language (HTML)** is **"the standard code used to create and structure web pages."**
- **HyperText:** text with links (hyperlinks).
- **Markup language:** a system that uses **tags to label parts** of a document.
- **Not a programming language:** it **cannot perform complex logic or maths**; it only sets up the **layout and structure**.

## 2. Anatomy of an HTML element (slide)
```html
<p class="intro">Welcome to Web Designing!</p>
```
| Part | In the example |
|---|---|
| **HTML element** | The whole thing, from `<p` to `</p>` |
| **HTML tag** | `<p …>` and `</p>` |
| **Opening tag** | `<p class="intro">` |
| **Closing tag** | `</p>` |
| **Attribute** | `class="intro"` (name = `class`, value = `intro`); extra information about the element |
| **Content** | `Welcome to Web Designing!` |

Some elements are **empty (void)**: they have no content and no closing tag, e.g. `<br>`, `<img>`, `<input>`.

## 3. The basic HTML document (slide)
```html
<!DOCTYPE html>
<html>                          <!-- root element -->
<head>                          <!-- information ABOUT the web page -->
  <title>My First Website</title>
</head>
<body>                          <!-- content SHOWN on the web page -->
  <h1>Welcome</h1>
  <p>This is my first webpage.</p>
</body>
</html>
```
| Part | Purpose |
|---|---|
| `<!DOCTYPE html>` | Tells the browser the page uses **HTML5** (Practical 1) |
| `<html>` | The **root element** that contains everything |
| `<head>` | **Information about the page** (not shown in the page body): **title, metadata, CSS references, JS references** |
| `<title>` | The text in the **browser tab** (Practical 1) |
| `<body>` | **Content shown on the page**: headings, paragraphs, images, links, buttons, tables, forms, videos, lists |

### A complete modern `<head>` (beyond the slide)
```html
<head>
  <meta charset="UTF-8">                                                  <!-- character encoding -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">  <!-- responsive (L6) -->
  <title>My Blog</title>
  <link rel="stylesheet" href="css/style.css">                            <!-- external CSS (P3) -->
</head>
```
