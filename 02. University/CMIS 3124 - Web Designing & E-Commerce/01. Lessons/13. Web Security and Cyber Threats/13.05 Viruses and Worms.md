# 13.05 · Viruses and Worms

> [!info] [[13.00 Web Security and Cyber Threats|Lesson 13]] · Lecture ref L13.5 · Priority 🟡 Medium ("threats on a client computer", 2017/18 Q6(a))

## 1. Virus (lecture)
- A type of **malicious software ("malware")**.
- **When executed, it replicates itself by modifying other computer programs and inserting its code.**
- **Spreads** when the software or documents it is attached to are transferred through a **network, a disk, file-sharing methods, or infected email attachments**.
- **Types:** boot sector virus, file virus, email virus, polymorphic virus, macro virus, multipartite virus, encrypted virus, stealth virus, resident virus, direct action virus, browser hijacker virus.

> [!note] Beyond the slides
> Short explanations of the virus types the slide lists.
> | Virus type | Meaning |
> |---|---|
> | Boot sector | Infects the disk's boot area; runs when the computer starts |
> | File | Infects executable program files |
> | Macro | Hides in document macros (e.g. Word/Excel) |
> | Polymorphic | Changes its code each time to avoid antivirus detection |
> | Multipartite | Infects both boot sectors and files |
> | Stealth | Hides its changes from antivirus software |
> | Resident | Lives in memory and infects files as they are opened |
> | Direct action | Runs once when executed, infects, then exits |

## 2. Computer worm (lecture)
- Harmful software that **copies itself and spreads from one computer to another without requiring any user intervention**.
- Spreads through **email attachments** (among other routes).
- Effects: **slows network performance, consumes system resources, steals sensitive information**, or damages and disrupts systems.
- **How it spreads:** once inside, it **starts replicating**; it **searches for other vulnerable systems** on the same network by **scanning IP addresses or probing open ports**, and may **exploit network protocols and services** to reach new targets.
- **Types:** email, network, file-sharing, instant messaging, **Internet** worms (which target vulnerabilities in websites, web servers or web applications).

## 3. Virus vs worm

| Virus | Worm |
|---|---|
| Needs a **host program/file** to attach to | **Standalone**; needs no host |
| Needs **user action** to run (opening the file) | Spreads **without user intervention** |
| Spreads when infected files are **transferred** | Spreads **itself** by scanning networks (IPs, ports) |
| Damages files and programs | Mainly consumes network/system resources (and can also steal or damage) |

## 4. Prevention

> [!note] Beyond the slides
> Standard measures, consistent with the lecture's best practices.

Antivirus and anti-malware (kept updated) · **patch software and OS** (worms exploit vulnerabilities) · don't open unknown attachments or run unknown programs · firewalls · network segmentation (stops worms spreading) · backups.
