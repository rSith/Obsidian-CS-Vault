# 13.06 · Spyware

> [!info] [[13.00 Web Security and Cyber Threats|Lesson 13]] · Lecture ref L13.6 · Priority 🟡 Medium. Nearest topic for old questions on sniffer programs, backdoors, cookie problems and card theft.

## 1. What is spyware? (lecture)
- Gets into the computer **when a user unintentionally clicks a random, unknown link or opens an unknown attachment**.
- **Steals a user's personal or business information and sends it to a third party.**
- **Entry routes:** **phishing, spoofing, free software, misleading software**.

## 2. Types of spyware (lecture)

| Type | What it does |
|---|---|
| **Keyloggers** | **Record keystrokes** typed by the user (passwords, card numbers) |
| **Adware** | **Tracks Internet activity** (to show targeted ads) |
| **Trojans** | **Rogue programs disguised as genuine applications** that steal information |
| **Tracking cookies** | **Track browsing history and preferences** ([[02.05 Sessions and Cookies]]) |
| **System monitors** | **Capture user activity** |
| **Data harvesters** | **Capture and transfer messages or data** (login data, credit-card details) |
| **Browser hijackers** | **Change browser settings** and **forward users to sites that contain malware** |
| **Remote Access Trojans (RATs)** | **Give attackers full control of a device from a distance** |

> [!tip] Memory aid
> "**K**ind **A**dults **T**rust **T**he **S**ystem; **D**on't **B**e **R**eckless" → Keyloggers, Adware, Trojans, Tracking cookies, System monitors, Data harvesters, Browser hijackers, RATs.

## 3. Prevention

> [!note] Beyond the slides
> These measures are not on the slides.

Anti-spyware / anti-malware · download software only from trusted sources (avoid "free" cracked software) · don't click unknown links or attachments (phishing awareness) · block third-party cookies · keep the browser and OS updated · use 2FA so stolen passwords alone aren't enough.
