## What this lesson is about
**Web security** protects data in transit and keeps websites, web apps and servers safe from attacks. The lesson:
1. defines web security and lists **8 major threats**;
2. explains each threat: **how it happens** and **how to prevent it** (SQLi, phishing, viruses and worms, spyware, XSS, code injection, DoS);
3. gives **best practices** for securing a website;
4. covers modern defences: **AI/ML in security**, the **Zero Trust** model, **Secure DevOps (DevSecOps)** and **IoT security**.
