# 13.01 · What is Web Security? The Major Cyber Threats

> [!info] [[13.00 Web Security and Cyber Threats|Lesson 13]] · Lecture ref L13.1–L13.2 · Priority 🔴 High
> **Asked as:** "Describe 3 threats on a client computer." (2017/18 Q6(a)); "possible threats/drawbacks of e-commerce during the pandemic" (2017/18, 2018/19 Q1(b)).

## 1. What is web security? (lecture)
Web security means:
- **protecting data during its transmission** through a network or the Internet, and
- **safeguarding websites, web applications and servers** from **malicious attacks, data breaches and unauthorised access**.

> **"Over 85% of websites are vulnerable to at least one form of attack."**

## 2. Major cyber threats impacting web security (lecture list)

| Threat | One-line meaning | Detail |
|---|---|---|
| **Ransomware** | Malware that **encrypts or locks files** and **demands payment** (ransom) to release them | *(Only named on the slides; this description is from the study guide)* |
| **SQL injection** | Malicious SQL typed into inputs runs on the database | [[13.03 SQL Injection]] |
| **Phishing** | Posing as a trusted party to steal credentials | [[13.04 Phishing]] |
| **Viruses and worms** | Self-replicating malware | [[13.05 Viruses and Worms]] |
| **Spyware** | Secretly steals information | [[13.06 Spyware]] |
| **Cross-site scripting (XSS)** | The attacker's script runs in victims' browsers | [[13.07 Cross-Site Scripting (XSS)]] |
| **Code injection** | Injected code is executed by the app | [[13.08 Code Injection]] |
| **Denial of Service (DoS)** | Overwhelms a server so real users can't get in | [[13.09 Denial of Service]] |

**Malware** (malicious software) is the umbrella term for viruses, worms, spyware, Trojans and ransomware.

### Server-side vs client-side threats

> [!note]
> This grouping is a study aid, not slide content.

| Mainly attack the **server / web app** | Mainly attack the **user / client computer** |
|---|---|
| SQL injection, code injection, DoS | Viruses and worms, spyware, ransomware, phishing |
| XSS (a web-app flaw, but the victim is the user's browser) | |

## 3. Answer pattern: "Describe 3 threats on a client computer"
For each threat give: **what it is → how it gets in → the damage → one prevention**.
1. **Viruses/worms:** replicate by infecting programs (virus) or spreading over networks on their own (worm); slow the system, corrupt or steal data. *Prevent:* antivirus, updates, don't open unknown attachments.
2. **Spyware** (keyloggers, Trojans, tracking cookies, RATs): enters through phishing, free software or unknown links; steals personal and business information. *Prevent:* anti-spyware, download only from trusted sources.
3. **Phishing / ransomware:** tricks users into revealing credentials, or encrypts their files for ransom. *Prevent:* user awareness, check URLs, backups, 2FA.
