# 12.02 · Ethical Practices in Web Development

> [!info] [[12.00 Web Design Ethics and Policies|Lesson 12]] · Lecture ref L12.2 · Priority 🔴 High
> **Asked as:** "Briefly describe ethical practices in web development and their impact on users and businesses." (2023/24 Q7(d), 6 marks). Impact is in [[12.03 Impact on Users and Businesses]].

## The five ethical practices (lecture)

| Practice | Lecture definition | How to do it (web examples) |
|---|---|---|
| **1. Respect for user privacy** | Implement **strong data protection measures** and ensure users' personal information is **collected, stored and processed securely and lawfully** | Collect only needed data (data minimisation); encrypt stored data; follow GDPR ([[10.10 GDPR]]) |
| **2. Transparency and user consent** | Provide **clear, comprehensible information about how user data is used** and **obtain explicit consent before collecting** any personal information | Plain-language privacy policy; unticked opt-in checkboxes; cookie-consent banners ([[02.05 Sessions and Cookies]]) |
| **3. Accessibility and inclusivity** | Design sites **accessible to users with varying abilities**, so the web remains an **inclusive space for everyone** | WCAG: alt text, captions, keyboard access, contrast ([[09.00 Web Accessibility]]) |
| **4. Sustainability** | Consider the **environmental impact**; choose solutions that **minimise carbon footprint and energy consumption** | Lighter pages, optimised images, efficient code, green hosting ([[06.07 Web Performance Optimisation]]) |
| **5. Security** | Adopt **robust security measures** to protect sites from **cyber threats**, safeguarding user data and trust | HTTPS, input validation, 2FA, patching ([[13.10 Best Practices for Securing a Website]]) |

> [!note]
> The "how to do it" column links each practice to other lessons. It is synthesis, not slide text.

> [!tip] Mnemonic
> **"PTASS"**: **P**rivacy, **T**ransparency and consent, **A**ccessibility, **S**ustainability, **S**ecurity.

## Example: an online pharmacy
- **Privacy:** prescriptions stored encrypted, visible only to the pharmacist.
- **Transparency and consent:** "We use your phone number only for delivery updates. ☐ Also send me offers".
- **Accessibility:** screen-reader-friendly search; large text option for elderly users.
- **Sustainability:** compressed images, efficient hosting.
- **Security:** HTTPS, 2FA for pharmacist logins, protection against SQL injection.
