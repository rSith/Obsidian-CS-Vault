# 07.04 · React Component Lifecycle

> [!info] [[07.00 ReactJS|Lesson 7]] · Lecture ref L7.8 · Priority 🟡 Watch. This takes up many slides (19–33), so it is a likely question if React is examined.

## 1. Three phases (lecture)
*"Each component in React has a lifecycle"* with **three phases**:

```text
MOUNTING  ───────────►  UPDATING  ───────────►  UNMOUNTING
(put into the DOM)      (state/props change)     (removed from the DOM)
```

| Phase | Methods called, **in order** |
|---|---|
| **Mounting** (4) | `constructor()` → `getDerivedStateFromProps()` → `render()` → `componentDidMount()` |
| **Updating** (5) | `getDerivedStateFromProps()` → `shouldComponentUpdate()` → `render()` → `getSnapshotBeforeUpdate()` → `componentDidUpdate()` |
| **Unmounting** (1) | `componentWillUnmount()` |

---

## 2. Mounting: putting elements into the DOM
| Method | Purpose (lecture) |
|---|---|
| **`constructor()`** | Called when the component is initiated; **sets up the initial state** and other initial values |
| **`getDerivedStateFromProps()`** | **Sets the state object based on the initial props**; it takes state as an argument and **returns an object with changes to the state** |
| **`render()`** | **Outputs the HTML to the DOM** (required) |
| **`componentDidMount()`** | Runs statements that **require the component to be already placed in the DOM** (e.g. timers, fetching data) |

### Example: `getDerivedStateFromProps` (lecture)
```jsx
class Header extends React.Component {
  constructor(props) {
    super(props);
    this.state = {favoritecolor: "red"};
  }
  static getDerivedStateFromProps(props, state) {
    return {favoritecolor: props.favcol};    // state now taken from the prop
  }
  render() {
    return <h1>My Favorite Color is {this.state.favoritecolor}</h1>;
  }
}
root.render(<Header favcol="yellow" />);     // shows "yellow", not "red"
```
Note that the method is **`static`** and receives `(props, state)`.

### Example: `componentDidMount` (lecture)
```jsx
componentDidMount() {
  setTimeout(() => {
    this.setState({favoritecolor: "yellow"})
  }, 1000)
}
```
The page first shows "red". **After 1 second** the timer runs `setState`, and the page shows "yellow". The timer starts only once the component is in the DOM.

## 3. Updating: when state or props change
*"A component is updated whenever there is a change in the component's state or props."* Five methods run:

| Method | Purpose (lecture) |
|---|---|
| **`getDerivedStateFromProps()`** | Called again first; sets state from props |
| **`shouldComponentUpdate()`** | **Returns a Boolean** that says whether React should **continue with the rendering** or not |
| **`render()`** | Re-renders the HTML with new values |
| **`getSnapshotBeforeUpdate()`** | Gives **access to the props and state before the update**. **An error occurs if `componentDidUpdate()` is not also included.** |
| **`componentDidUpdate()`** | Called **after the component is updated in the DOM** |

### Lecture "gotchas"
1. **`getDerivedStateFromProps` overrides `setState`.** With `favcol="yellow"`, clicking "Change color" (which sets blue) **still shows yellow**, because the method re-applies the prop on every update.
2. **`shouldComponentUpdate()` returning `false`** cancels the update. Clicking "Change color" **still shows red**.

```jsx
shouldComponentUpdate() {
  return false;     // React stops: no re-render
}
```

### Example: `getSnapshotBeforeUpdate` + `componentDidUpdate` (lecture)
```jsx
class Header extends React.Component {
  constructor(props) {
    super(props);
    this.state = {favoritecolor: "red"};
  }
  componentDidMount() {
    setTimeout(() => {this.setState({favoritecolor: "yellow"})}, 1000)
  }
  getSnapshotBeforeUpdate(prevProps, prevState) {
    document.getElementById("div1").innerHTML =
      "Earlier, the favorite was " + prevState.favoritecolor;   // "red"
  }
  componentDidUpdate() {
    document.getElementById("div2").innerHTML =
      "The updated favorite is " + this.state.favoritecolor;    // "yellow"
  }
  render() {
    return (
      <div>
        <h1>My Favorite Color is {this.state.favoritecolor}</h1>
        <div id="div1"></div>
        <div id="div2"></div>
      </div>
    );
  }
}
```
Sequence: mount with "red" → after 1 second the timer changes state → **update phase** → `getSnapshotBeforeUpdate` writes the **old** value into DIV1 → `componentDidUpdate` writes the **new** value into DIV2.

## 4. Unmounting: removing from the DOM
*"`componentWillUnmount()` is called when the component is about to be removed from the DOM."* It is used for **clean-up** (stopping timers, removing listeners).

```jsx
class Container extends React.Component {
  constructor(props) {
    super(props);
    this.state = {show: true};
  }
  delHeader = () => { this.setState({show: false}); }
  render() {
    let myheader;
    if (this.state.show) { myheader = <Child />; }
    return (
      <div>
        {myheader}
        <button type="button" onClick={this.delHeader}>Delete Header</button>
      </div>
    );
  }
}

class Child extends React.Component {
  componentWillUnmount() {
    alert("The component named Header is about to be unmounted.");
  }
  render() { return <h1>Hello World!</h1>; }
}
```
Clicking **Delete Header** sets `show` to `false`, so `<Child />` is no longer rendered. React calls `componentWillUnmount()` (the alert) and then removes it.

## 5. Memory aid
- **Mounting = "C-G-R-D":** Constructor, Get-derived, Render, Did-mount
- **Updating = "G-S-R-S-D":** Get-derived, Should, Render, Snapshot, Did-update
- **Unmounting = "W":** Will-unmount
