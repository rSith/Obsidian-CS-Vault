# 07.99 · Lesson Summary: ReactJS

> [!abstract] Back to [[07.00 ReactJS]] · Practice: [[PP 07 - ReactJS]]

## Must know
- **React:** a simple, feature-rich, **component-based JavaScript UI library** by **Jordan Walke (Facebook)**; first used **2011** for the **News Feed**; React **19.0.0 (Dec 2024)**.
- **Virtual DOM:** changes are made in memory first, diffed, and **only the changed parts** go to the real DOM.
- **Features:** solid base, extensible, component-based, JSX-based, declarative. **Advantages:** easy to learn, fits modern and legacy apps, fast coding, ready-made components, big community.
- **Install:** Node.js → setup tool → project directory → install dependencies → dev server; **or CDN** (React, ReactDOM, **Babel** for JSX/ES6).
- **Components:** independent, reusable; **class or function**; **name starts with an uppercase letter**; render with `root.render(<Employee />)`.
- **constructor()** initialises state; **super()** runs `React.Component`'s constructor; **props** are passed to `constructor(props)` and `super(props)`.
- **Props** = function arguments sent as attributes (read-only). **State** = the component's own data; `this.state`, change only with `this.setState()`; a change triggers a re-render.
- **Lifecycle:**
  - **Mounting:** constructor → getDerivedStateFromProps → render → componentDidMount
  - **Updating:** getDerivedStateFromProps → shouldComponentUpdate → render → getSnapshotBeforeUpdate → componentDidUpdate
  - **Unmounting:** componentWillUnmount
- **Events:** camelCase (`onClick`), handler in `{}`; an **arrow function** passes arguments.
- **Conditional rendering:** `if`, ternary `? :`.
- **Forms:** state + `onChange` (controlled, "single source of truth"); `onSubmit` + `event.preventDefault()`.
- **Router:** `npm i -D react-router-dom`; `BrowserRouter > Routes > Route`; `index` = default child; `*` = 404; Layout uses `<Link>` and `<Outlet>`.
- **Styling:** inline (JS object, camelCase), CSS stylesheet (import), CSS Modules (`.module.css`, `className={styles.x}`).
- **Hooks:** state and lifecycle in function components; **only in function components, top level, not conditional**; `useState`, `useEffect`, `useContext`, custom hooks.

## Important comparisons
| Props | State |
|---|---|
| From the parent, read-only | Owned by the component, changeable |
| Like function arguments | Like private memory |

| Class component | Function component |
|---|---|
| `extends React.Component`, `render()` | A function returning JSX |
| `this.state` / `this.setState` | `useState` |
| Lifecycle methods | `useEffect` |
