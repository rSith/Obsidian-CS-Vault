## What this lesson is about
**React** is a JavaScript library for building user interfaces out of **reusable components**. The deck walks through:
virtual DOM → features and advantages → installation → **components** (class and function) → **props** → **state** → **lifecycle** → **events** → **conditional rendering** → **forms** → **React Router** → **styling** → **hooks**.
Most slides reuse the same **Employee** and **Header** examples, taken from W3Schools (the deck's reference).

> [!warning] Slide inconsistency to be aware of
> Slide 7 says a **component name must start with an uppercase letter**. The event slides (35–36) then define `function handleClick()` and render `<handleClick />` in lowercase. React treats lowercase tags as plain HTML elements, so that example would not render the component. **Follow the uppercase rule** (e.g. `function HandleClick()` → `<HandleClick />`).
