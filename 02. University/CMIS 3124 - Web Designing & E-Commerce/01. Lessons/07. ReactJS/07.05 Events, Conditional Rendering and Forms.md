# 07.05 · React Events, Conditional Rendering and Forms

> [!info] [[07.00 ReactJS|Lesson 7]] · Lecture ref L7.9–L7.11 · Priority 🟡 Watch

## Part A: Events (lecture)
- *React can perform actions based on **user events**.*
- **Same events as HTML:** click, change, mouseover, etc.
- **Written in camelCase:** `onClick` (not `onclick`).
- **Event handlers go inside curly braces:** `onClick={shoot}` (not a string).

```jsx
function HandleClick() {               // uppercase name (see warning below)
  const click = () => {
    alert("Success!");
  }
  return <button onClick={click}>Click the button</button>;
}
```

### Passing an argument: use an arrow function (lecture)
```jsx
function HandleClick() {
  const click = (a) => {
    alert(a);
  }
  return <button onClick={() => click("Success!")}>Click the button</button>;
}
```
Why the arrow? `onClick={click("Success!")}` would **call the function immediately** during rendering. Wrapping it in `() => …` means "call it later, when clicked".

> [!warning] Slide error
> The slides name this component `handleClick` (lowercase) and render `<handleClick />`. Since component names **must start with an uppercase letter**, React would treat it as an unknown HTML tag. The examples here use `HandleClick`.

| HTML event | React event |
|---|---|
| `<button onclick="shoot()">` | `<button onClick={shoot}>` |
| lowercase, string | **camelCase, a function in `{}`** |

## Part B: Conditional rendering (lecture)

```jsx
function Success() { return <h1>Login Success!</h1>; }
function Fail()    { return <h1>Login Failed!</h1>; }
```

### 1. Using `if`
```jsx
function Login(props) {
  const isLoginSuccess = props.isGoal;
  if (isLoginSuccess) {
    return <Success/>;
  }
  return <Fail/>;
}
root.render(<Login isGoal={false} />);   // → "Login Failed!"
```

### 2. Using the ternary operator `condition ? true : false`
```jsx
function Login(props) {
  const isLoginSuccess = props.isGoal;
  return (
    <>
      {isLoginSuccess ? <Success/> : <Fail/>}
    </>
  );
}
```

### 3. Logical `&&` (beyond the slides)
```jsx
{cart.length > 0 && <h2>You have {cart.length} items</h2>}   // render only if true
```

## Part C: Forms (lecture)

### 1. The problem
A plain form inside React **submits and refreshes the page**. *"We want to let React control the form."*

### 2. Handling forms: controlled inputs
- Form data is **usually handled by the components**.
- **All the data is stored in the component state.**
- Control changes with **event handlers in the `onChange` attribute**.
- Use the **`useState` hook** to track each input's value and provide a **"single source of truth"** for the application.

```jsx
import { useState } from 'react';
import ReactDOM from 'react-dom/client';

function MyForm() {
  const [name, setName] = useState("");

  return (
    <form>
      <label>Enter your name:
        <input
          type="text"
          value={name}                                   // value comes FROM state
          onChange={(e) => setName(e.target.value)}      // every keystroke updates state
        />
      </label>
    </form>
  )
}
```

### 3. Submitting forms: `onSubmit`
```jsx
function MyForm() {
  const [name, setName] = useState("");

  const handleSubmit = (event) => {
    event.preventDefault();                          // stop the page refresh
    alert(`The name you entered was: ${name}`)
  }

  return (
    <form onSubmit={handleSubmit}>
      <label>Enter your name:
        <input type="text" value={name}
               onChange={(e) => setName(e.target.value)} />
      </label>
      <input type="submit" />
    </form>
  )
}
```
- `onSubmit` on the `<form>` runs `handleSubmit`.
- `event.preventDefault()` stops the browser's default action (submitting and reloading).
- `` `…${name}` `` is a JavaScript **template literal** that inserts the variable.

### Controlled input vs normal HTML input
| Normal HTML input | React controlled input |
|---|---|
| The browser (DOM) holds the value | **React state** holds the value |
| Read on submit | Always up to date in state |
| Submitting reloads the page | `preventDefault()` + handle in JavaScript |
