# 07.07 · React Hooks

> [!info] [[07.00 ReactJS|Lesson 7]] · Lecture ref L7.14 · Priority 🟡 Watch. "Write a function component with `useState`" is a likely code question if React is examined.

## 1. What are hooks? (lecture)
- Hooks **allow function components to have access to state and other React features**.
- They let you **"hook" into React features such as state and lifecycle methods**.

Before hooks, only **class components** could have state and lifecycle methods. Hooks give the same power to the shorter **function components**.

## 2. Rules of hooks (lecture)
1. **Hooks can only be called inside React function components.**
2. **Hooks can only be called at the top level** of a component (not inside loops or nested functions).
3. **Hooks cannot be conditional** (not inside `if`).

Why? React identifies each hook by the **order** in which it is called on every render. If a hook is skipped sometimes, the order breaks. (This reason is an added explanation.)

## 3. `useState` (lecture example)
```jsx
import React, { useState } from "react";
import ReactDOM from "react-dom/client";

function FavoriteColor() {
  const [color, setColor] = useState("red");   // [current value, setter], initial "red"

  return (
    <>
      <h1>My favorite color is {color}!</h1>
      <button type="button" onClick={() => setColor("blue")}>Blue</button>
      <button type="button" onClick={() => setColor("red")}>Red</button>
    </>
  );
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<FavoriteColor />);
```
**How it works:**
- `useState("red")` creates a state variable with initial value `"red"`.
- It returns an array: **`color`** (the current value) and **`setColor`** (the function to change it). Array destructuring gives them names.
- Clicking **Blue** calls `setColor("blue")`, then React re-renders, and the heading shows "blue".

### Practice: a counter component (study-guide practice question)
```jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);
  return (
    <>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Add 1</button>
    </>
  );
}
```

## 4. Other hooks ("Take a look at these", lecture slide 59)
The slide lists them only. The descriptions below are added explanations.

| Hook | Purpose |
|---|---|
| **`useState`** | Add state to a function component |
| **`useEffect`** | Run **side effects** after render (fetch data, timers, subscriptions); the function-component equivalent of `componentDidMount` / `componentDidUpdate` / `componentWillUnmount` |
| **`useContext`** | Share a value (e.g. theme, logged-in user) with deeply nested components **without passing props through every level** |
| **Custom hooks** | Your own reusable functions that start with `use…` and combine other hooks |

```jsx
import { useState, useEffect } from "react";

function Timer() {
  const [seconds, setSeconds] = useState(0);
  useEffect(() => {
    const id = setInterval(() => setSeconds(s => s + 1), 1000); // like componentDidMount
    return () => clearInterval(id);                              // like componentWillUnmount
  }, []);                                                         // [] = run once after mount
  return <p>{seconds} seconds</p>;
}
```

## 5. Class component vs hooks: the same feature

| Feature | Class component | Function component + hooks |
|---|---|---|
| State | `this.state = {…}` / `this.setState()` | `const [x, setX] = useState()` |
| After mount | `componentDidMount()` | `useEffect(() => {…}, [])` |
| Clean-up | `componentWillUnmount()` | Return a function from `useEffect` |
