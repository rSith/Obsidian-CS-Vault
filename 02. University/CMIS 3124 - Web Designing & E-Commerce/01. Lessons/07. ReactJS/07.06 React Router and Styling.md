# 07.06 · React Router and Styling React

> [!info] [[07.00 ReactJS|Lesson 7]] · Lecture ref L7.12–L7.13 · Priority 🟡 Watch

## Part A: React Router

### 1. What and why
**React Router** adds **page routing**: different URLs show different components, while the app stays a single-page application ([[02.09 SPA, AJAX and Custom Development]]).

**Install** (run in the app's root directory):
```bash
npm i -D react-router-dom
```

### 2. Folder structure (lecture example)
```text
src/pages/
├── Layout.js
├── Home.js
├── Blogs.js
├── Contact.js
└── NoPage.js
```

### 3. Using the router in `index.js` (lecture)
```jsx
import ReactDOM from "react-dom/client";
import { BrowserRouter, Routes, Route } from "react-router-dom";
import Layout from "./pages/Layout";
import Home from "./pages/Home";
import Blogs from "./pages/Blogs";
import Contact from "./pages/Contact";
import NoPage from "./pages/NoPage";

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />
          <Route path="blogs" element={<Blogs />} />
          <Route path="contact" element={<Contact />} />
          <Route path="*" element={<NoPage />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(<App />);
```

**Explanation (lecture points):**
- An app can have **multiple `<Routes>`**; this example uses one.
- The **first `<Route>` has path `/`** and renders the **`Layout`** component.
- **Nested `<Route>`s inherit and add to the parent route**: `blogs` becomes **`/blogs`**.
- The **Home** route has **no path but an `index` attribute**, so it is the **default route for the parent** (`/`).
- **`path="*"`** is a **catch-all for undefined URLs**, which makes a good **404 page**.

### 4. The Layout route (lecture)
- A **shared component** that **inserts common content on all pages**, such as a navigation menu.
- It contains:
  - **`<Outlet>`**, which **renders the currently selected route**;
  - **`<Link>`**, which **sets the URL and keeps track of browsing history** (used instead of `<a href>`, so the page does not reload).

```jsx
import { Outlet, Link } from "react-router-dom";

const Layout = () => {
  return (
    <>
      <nav>
        <ul>
          <li><Link to="/">Home</Link></li>
          <li><Link to="/blogs">Blogs</Link></li>
          <li><Link to="/contact">Contact</Link></li>
        </ul>
      </nav>
      <Outlet />      {/* Home / Blogs / Contact / NoPage appears here */}
    </>
  )
};
export default Layout;
```

### 5. The page components (lecture)
```jsx
const Home    = () => { return <h1>Home</h1>; };           export default Home;
const Blogs   = () => { return <h1>Blog Articles</h1>; };  export default Blogs;
const Contact = () => { return <h1>Contact Me</h1>; };     export default Contact;
const NoPage  = () => { return <h1>404</h1>; };            export default NoPage;
```
(Each is in its own file.)

## Part B: Styling React with CSS (3 ways, lecture)

### 1. Inline styling
*The value of the `style` attribute **must be a JavaScript object**.*
```jsx
const Header = () => {
  return (
    <>
      <h1 style={{backgroundColor: "lightblue"}}>Hello Style!</h1>
      <p>Add a little style!</p>
    </>
  );
}
```
- **Outer `{ }`** = "this is a JavaScript expression"; **inner `{ }`** = the object.
- Properties are **camelCase**: `backgroundColor`, not `background-color`.

**Creating a style object:**
```jsx
const Header = () => {
  const myStyle = {
    color: "white",
    backgroundColor: "DodgerBlue",
    padding: "10px",
    fontFamily: "Sans-Serif"
  };
  return (
    <>
      <h1 style={myStyle}>Hello Style!</h1>
      <p>Add a little style!</p>
    </>
  );
}
```

### 2. CSS stylesheet
Write normal CSS in a file and **import** it:
```css
/* App.css */
body {
  background-color: #282c34;
  color: white;
  padding: 40px;
  font-family: Sans-Serif;
  text-align: center;
}
```
```jsx
// index.js
import './App.css';
```

### 3. CSS Modules
```css
/* my-style.module.css */
.bigblue {
  color: DodgerBlue;
  padding: 40px;
  font-family: Sans-Serif;
  text-align: center;
}
```
```jsx
// Car.js
import styles from './my-style.module.css';

const Car = () => {
  return <h1 className={styles.bigblue}>Hello Car!</h1>;
}
export default Car;
```
The file name must end in **`.module.css`**. Class names are **scoped to the component**, so the same class name in another module won't clash. (The scoping explanation is standard React; the slide shows the code only.)

| Method | Scope | Syntax |
|---|---|---|
| Inline | One element | `style={{…}}` object, camelCase |
| Stylesheet | Global | `import './App.css'` |
| CSS Modules | **Component only** | `import styles from './x.module.css'` → `className={styles.name}` |
