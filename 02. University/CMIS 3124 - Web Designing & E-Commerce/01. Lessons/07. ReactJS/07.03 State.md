# 07.03 · React Class Component State

> [!info] [[07.00 ReactJS|Lesson 7]] · Lecture ref L7.7 · Priority 🟡 Watch

## 1. What is state? (lecture)
- **React class components have a built-in `state` object.**
- The **state object is where you store property values that belong to the component**.
- **The component re-renders when the state object changes.**
- **The state object is initialised in the constructor.**

In simple words, state is the component's **private, changeable memory**: for example a counter value, a form's text or whether a menu is open.

## 2. Creating state (lecture)
```jsx
class Employee extends React.Component {
  constructor(props) {
    super(props);
    this.state = {
      name: "Kevin",
      address: "Kandy"
    };
  }
  render() {
    return (
      <div>
        <h1>I am an Employee</h1>
      </div>
    );
  }
}
```

## 3. Using state: `this.state.propertyname`
*"`this.state.propertyname` can be used to refer to the state object anywhere in the component."*
```jsx
render() {
  return <p>I am {this.state.name}</p>;
}
```

## 4. Changing state: `this.setState()` (lecture)
- **Use `this.setState()` to change a value** in the state object. **Never assign to `this.state` directly** (outside the constructor).
- **The component re-renders when a value in the state changes**, so the output updates to the new value.

```jsx
class Employee extends React.Component {
  constructor(props) {
    super(props);
    this.state = { name: "Kevin" };
  }
  changeName = () => {
    this.setState({name: "Max"});      // update state → re-render
  }
  render() {
    return (
      <div>
        <p>I am {this.state.name}</p>
        <button type="button" onClick={this.changeName}>Change name</button>
      </div>
    );
  }
}
```
**What happens:** the page shows "I am Kevin". Clicking the button calls `changeName`, then `setState({name: "Max"})`, then React re-renders, and the page shows "I am Max".

`changeName = () => {…}` is an **arrow-function class property**, so `this` correctly refers to the component.

## 5. Props vs State

| Props | State |
|---|---|
| **Passed in from the parent** (like function arguments) | **Owned and managed inside** the component |
| **Read-only** for the component | **Changed with `setState()`** (or a hook setter) |
| Configures the component from outside | The component's private memory |
| New props arrive when the parent re-renders | Changing state **triggers a re-render** |

> [!note]
> This table is a synthesis (study guide). The slides define props and state separately.
