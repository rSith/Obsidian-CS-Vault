## What this lesson is about

This is the **"how it is built"** lesson. It moves through three levels:
1. the **languages** of the web (HTML, CSS, JavaScript, PHP);
2. the **plumbing** that carries a request (URLs, HTTP, sessions, cookies);
3. the **architectures** that organise a whole application (client–server, three-tier, web services, architecture components, single-page apps).

It ends with **custom development** and **content management systems (CMS)**.

## The "evolution" of the code (slide 24)

The lecture shows how a page grows from plain HTML into a full web application. Each layer adds **one responsibility**:

```text
HTML (structure, static) → + CSS (presentation) → + JavaScript (client-side behaviour)
      → + PHP (server-side, dynamic pages) → + Database (stored, shared data)
```
