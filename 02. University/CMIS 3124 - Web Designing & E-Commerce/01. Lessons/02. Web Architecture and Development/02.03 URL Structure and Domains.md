# 02.03 · URL Structure and Top-Level Domains

> [!info] [[02.00 Web Architecture and Development|Lesson 2]] · Lecture ref L2.3–L2.4 · Priority 🟢 Low. Not examined yet, but it supports SEO URL structure ([[11.06 On-Page SEO]]) and GET query strings ([[02.04 HTTP Protocol]]).

## 1. What is a URL?
A **Uniform Resource Locator (URL)** is **"an address that indicates where a resource is located on the Internet."** A resource can be a page, an image, a file, and so on.

## 2. Parts of a URL

Example:

```text
https://blog.wyb.ac.lk:443/articles/web.html?id=42&sort=new#comments
└─┬─┘   └┬─┘ └┬┘ └─┬─┘ └┬┘ └───────┬────────┘│└──────┬─────┘└───┬───┘
scheme  sub  dom  TLD  port      path       ?   query string  fragment
```

> [!note]
> In this example `wyb` is the domain name, `.ac.lk` is the domain suffix, and `.lk` is the country-code TLD.

| Part | Lecture definition | Example |
|---|---|---|
| **Scheme / protocol** | The set of **rules that decide the transmission and exchange of data** | `https`, `http`, `ftp` |
| **Subdomain** | **Separates different sections of the website**; specifies the type of resource delivered to the client | `www`, `blog`, `mail` |
| **Domain** | The **organisation or entity** the URL belongs to | `wyb`, `google` |
| **Top-level domain (TLD)** | The **type of organisation** the website is registered to | `.com`, `.lk`, `.edu` |
| **Port number** | The **type of service** requested, since servers often deliver multiple services | `80` (HTTP), `443` (HTTPS) |
| **Path** | The **exact location of the resource** the user wants | `/articles/web.html` |
| **Query string separator** | Tells the browser that **a query is being performed** | `?` |
| **Query string** | The **parameters of the data being queried** from the website's database | `id=42&sort=new` |
| **Fragment** | A **specific location within a page**, such as an element's `id` or `name` | `#comments` |

> [!note] Beyond the slides
> Port numbers 80/443 are standard defaults, not lecture content. When a URL uses the default port, the browser hides it.

## 3. Types of top-level domains (TLDs)

| Type | Meaning | Examples (lecture) |
|---|---|---|
| **gTLD**: Generic | Open, general purpose | `.com`, `.net`, `.org` |
| **geoTLD**: Geographic (a sub-type listed under gTLD on the slide) | A city or region | `.paris` |
| **grTLD**: Generic-restricted | Generic, but registrants must meet criteria | `.biz` |
| **sTLD**: Sponsored | Sponsored by an organisation for a specific community | `.gov`, `.edu` |
| **ccTLD**: Country code | A country | `.ca`, `.uk`, `.lk` |
| **tTLD**: Test | Reserved for testing, never live | `.test`, `.example`, `.localhost` |

## 4. Practical use
- **E-commerce/SEO:** clean, readable paths (`/shoes/running`) help users and search engines ([[11.06 On-Page SEO]]).
- **GET forms** put data in the **query string**, which is why it is visible ([[02.04 HTTP Protocol]]).
- **Fragments** create in-page links, e.g. `<a href="#contact">` ([[00.03 HTML Elements - Text, Lists, Links, Images, Tables]]).
