# 02.10 · Content Management Systems (CMS)

> [!info] [[02.00 Web Architecture and Development|Lesson 2]] · Lecture ref L2.16 · Priority 🔴 High
> **Asked as:** "What is a Content Management System (CMS)? Give two (02) features and two (02) benefits of it." (2023/24 Q7(a), 3 marks)

## 1. What is it?
A **CMS** is **"software that helps users create, manage, store and modify their digital content."**

- *"The system is **already created on the back-end and front-end**, while all the creator sees is a **user-friendly interface** that allows them to make necessary changes in a simplified manner."* In other words, **no coding is needed** to update the site.
- It is built to **enhance the customer experience** for web content viewed online or in a mobile app.
- **APIs allow the system to connect across multiple domains.**

**Examples (lecture):** **WordPress, Drupal, Squarespace, Joomla, Shopify, Adobe Experience Manager, Salesforce CMS, Wix.**

## 2. Why is it used?
Without a CMS, every change to a website (a new blog post, a price update) needs a developer to edit HTML files. With a CMS, **non-technical staff** can update content themselves through a dashboard.

## 3. The two fundamental parts

| Part | Role |
|---|---|
| **CMA: Content Management Application** | Lets the user **add and change content** on the website. It **brings together HTML, CSS and JavaScript** to deliver content. (The "editing" side.) |
| **CDA: Content Delivery Application** | A **back-end process** that **takes the content entered in the CMA, stores it** behind the scenes and makes it **live and visible for all site visitors**. (The "publishing" side.) |

## 4. How it works: flow of content (lecture)

```text
Content creation ──► Publish ──► View published content
(authors update;      (scheduled, or     (visitors see it live and
 preview, review,      goes live          see updates continuously)
 approve in minutes)   automatically)
```

## 5. Key features (lecture)

| Feature | Details |
|---|---|
| **Publishing controls** | Define the **roles and permissions** of multiple authors; **prevent** authors from publishing automatically |
| **Content editing tools** | Add images, videos, **CTAs** (calls to action) and outside forms; **drag-and-drop**; scheduling and updating content |
| **Content staging** | A staging environment lets users **test a new content design without the public seeing it** (needed because the site changes often) |
| **Analytics** | Built-in analytics show how visitors interact with content and on which devices. Otherwise install a tool such as **Google Analytics**, sometimes through a plug-in |
| **Security measures** | **Application firewall**, **CDN** to help prevent **DDoS attacks** |
| **Template and theme offerings** | Ready-made designs |

## 6. Benefits (lecture)

| Benefit | Details |
|---|---|
| **Increased collaboration** | Users across the globe work on the same project **without sending different file versions** to each other |
| **User-friendly** | Easy to use, streamlined workflow; **no coding** or special skills needed |
| **Built-in SEO tools** | SEO features or plug-ins to optimise content ([[11.06 On-Page SEO]]) |
| **Highly scalable** | The CMS **grows with your business** |
| **Consistent branding** | Built-in processes to **categorise content by tagging or labelling** |
| **Organisation** | Content is stored in an organised way; **permissions and scheduling** streamline work |

## 7. Practical example
A small Sri Lankan clothing brand uses **Shopify** (an e-commerce CMS). The owner adds a new dress with photos (editing tools), schedules a sale banner for Friday (publishing controls + scheduling), previews a new homepage layout privately (staging), and checks which products mobile users view most (analytics). Nobody writes HTML. See also [[10.05 E-Commerce Platforms]].

## 8. Exam-relevant points
- 2023/24 Q7(a), 3 marks: **definition (1)** + **two features (1)** + **two benefits (1)**.
- Mention **CMA vs CDA** for a stronger definition.
- Don't mix up **features** (what it *has*) and **benefits** (what you *gain*).
