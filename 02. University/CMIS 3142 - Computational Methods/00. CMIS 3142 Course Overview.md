## Course structure
```text
CMIS 3142 Computational Methods
├── Data representation & computational error
│   ├── 01 Floating Point Numbers ........ binary, IEEE 754 single/double, bias, special values, denormals, over/underflow
│   └── 02 Error Analysis ................ error measures, round-off vs chopping, machine precision, GPA scenario,
│                                          forward/backward error, conditioning, stability
├── Systems of linear equations
│   ├── 03 Matrix Programming ............ row/column vectors, full, symmetric, sparse, sparse symmetric; Java classes
│   ├── Direct methods
│   │   ├── 04 Gaussian Elimination ...... forward elimination, back substitution, algorithm, program
│   │   └── 06 LU & Cholesky ............. A = LU, A = LLᵀ (SPD), algorithm, Java
│   └── Iterative methods
│       ├── 05 Jacobi & Gauss-Seidel ..... formulas, matrix form, algorithms, convergence
│       └── 08 SOR ....................... relaxation parameter ω
├── Non-linear equations
│   └── 07 Fixed-Point Iteration ......... x = g(x), |g'| < 1, Newton–Raphson
└── Differential equations / sequences
    └── 09 Finite Difference Method ...... Taylor series, FD formulas, truncation error, difference tables, Δ operator
```

## Recommended study order
1. **Foundations (needed everywhere):** 01 Floating Point → 02 Error Analysis.
2. **Matrix storage and code:** 03 Matrix Programming (symmetric, sparse symmetric programs).
3. **Direct solvers:** 04 Gaussian Elimination → 06 LU & Cholesky (Cholesky uses symmetric storage from 03).
4. **Iterative solvers:** 05 Jacobi & Gauss-Seidel → 08 SOR (SOR is Gauss-Seidel + ω).
5. **Finite differences:** 09 (Taylor series → formulas → tables → Δ operator).
6. **Non-linear equations:** 07 Fixed-point iteration (lowest exam weight).
7. **Practise:** work the 2026 paper from [[CMIS 3142 Papers by Year]] under timed conditions, then 2025, 2024, 2023; check against the PP notes.
