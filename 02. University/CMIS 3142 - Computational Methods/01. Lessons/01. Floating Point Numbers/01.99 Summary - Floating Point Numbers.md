# 01.99 · Lesson Summary: Floating Point Numbers

> [!info] Hub: [[01.00 Floating Point Numbers]] · Past papers: [[PP 01 - Floating Point Numbers]] · Priority 🔴 (Q1 in **every** paper)

## Must know
- Decimal ↔ binary for **integer** (÷2, remainders bottom-up) and **fraction** (×2, integer parts top-down) parts; 0.1 is a **non-terminating** binary.
- IEEE 754 layouts: **single 1 / 8 / 23, bias 127**; **double 1 / 11 / 52, bias 1023**.
- Normalised value $(-1)^S\times1.F\times2^{E-\text{bias}}$; **hidden 1** is not stored.
- Reserved exponents: $E = 0$ → zero / denormalised; $E$ = all 1s → ∞ / NaN.
- Denormalised: $(-1)^S\times0.F\times2^{-126}$ (single), $2^{-1022}$ (double) → **gradual underflow**.
- Overflow → ±∞; underflow → 0 (via denormals).
- Java program decimal → IEEE double with the 5 labelled steps (+ reverse).

## Important definitions
- **Floating-point representation:** fixed-size binary scientific notation with sign, exponent and mantissa.
- **Biased exponent:** stored exponent $E = e + \text{bias}$; bias ≈ midway in the exponent range (127 / 1023) so negative exponents need no sign bit.
- **Hidden 1:** the always-present leading 1 of a normalised number, not stored, giving 24 / 53 bits of precision.
- **Denormalised number:** $E = 0$, $F \neq 0$; no hidden 1; represents numbers very close to 0.
- **NaN:** $E$ = all 1s, $F \neq 0$; result of undefined operations (0/0, √−1).
- **Overflow:** result magnitude too large → ±∞. **Underflow:** result magnitude smaller than the smallest representable number → 0.

## Important comparisons

| | Single | Double |
|---|---|---|
| Bits S/E/F | 1/8/23 (32) | 1/11/52 (64) |
| Bias | 127 | 1023 |
| Max | $(2-2^{-23})2^{127}\approx3.4\times10^{38}$ | $(2-2^{-52})2^{1023}\approx1.8\times10^{308}$ |
| Min normalised | $2^{-126}\approx1.18\times10^{-38}$ | $2^{-1022}\approx2.2\times10^{-308}$ |
| Min denormalised | $2^{-149}\approx1.4\times10^{-45}$ | $2^{-1074}\approx4.9\times10^{-324}$ |

| | Normalised | Denormalised |
|---|---|---|
| E | 1…254 | 0 |
| Leading bit | 1 | 0 |
| Exponent | $E-127$ | $-126$ fixed |

| E | F | Meaning |
|---|---|---|
| 0 | 0 | ±0 |
| 0 | ≠0 | denormalised |
| 1…254 | any | normalised |
| 255 | 0 | ±∞ |
| 255 | ≠0 | NaN |

## Important formulas / algorithms
**Decimal → IEEE:** sign → binary → normalise $1.F\times2^e$ → $E = e + 127$ (or 1023) → pad F to 23 (or 52) → write S|E|F.

**IEEE → decimal:** split → $e = E - \text{bias}$ → $(-1)^S\times1.F\times2^e$.

**Single ↔ double:** $E_d = E_s - 127 + 1023$; $F_d = F_s + 29$ zeros. Reverse: check overflow ($e > 127$) / underflow ($e < -126$), keep 23 bits.
