# 06.03 · Cholesky Java Programs

> [!info] [[06.00 LU Decomposition and Cholesky|Lesson 6]] · Lecture 06 *Cholesky.java* (Sedgewick & Wayne) · Priority 🔴 High
> **Asked as:** "Write a Java program to solve a system of linear equations using Cholesky method" (2025 Q5(b)) · "Using the above method [symmetric representation], write a Java program to solve a set of linear equations using the Cholesky method" (2026 Q6(b), 15 marks).

## 1. The lecture program (Cholesky.java) explained
```java
public class Cholesky {
    private static final double EPSILON = 1e-10;

    // is symmetric
    public static boolean isSymmetric(double[][] A) {
        int N = A.length;
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < i; j++) {
                if (A[i][j] != A[j][i]) return false;
            }
        }
        return true;
    }

    // is square
    public static boolean isSquare(double[][] A) {
        int N = A.length;
        for (int i = 0; i < N; i++) {
            if (A[i].length != N) return false;
        }
        return true;
    }

    // return Cholesky factor L of psd matrix A = L L^T
    public static double[][] cholesky(double[][] A) {
        if (!isSquare(A)) {
            throw new RuntimeException("Matrix is not square");
        }
        if (!isSymmetric(A)) {
            throw new RuntimeException("Matrix is not symmetric");
        }

        int N = A.length;
        double[][] L = new double[N][N];

        for (int i = 0; i < N; i++) {
            for (int j = 0; j <= i; j++) {
                double sum = 0.0;
                for (int k = 0; k < j; k++) {
                    sum += L[i][k] * L[j][k];
                }
                if (i == j) L[i][i] = Math.sqrt(A[i][i] - sum);
                else        L[i][j] = 1.0 / L[j][j] * (A[i][j] - sum);
            }
            if (L[i][i] <= 0) {
                throw new RuntimeException("Matrix not positive definite");
            }
        }
        return L;
    }

    // sample client
    public static void main(String[] args) {
        int N = 3;
        double[][] A = { { 4, 1, 1 },
                         { 1, 5, 3 },
                         { 1, 3, 15 }
                       };
        double[][] L = cholesky(A);
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < N; j++) {
                StdOut.printf("%8.5f ", L[i][j]);
            }
            StdOut.println();
        }
    }
}
```
*(The handout's comment above `isSquare` says "is symmetric"; it is corrected to "is square" here.)*

| Part | What it does | Theory |
|---|---|---|
| `isSquare`, `isSymmetric` | check conditions 1 and 2 | [[06.02 Cholesky Method]] §2 |
| loops `i` (row), `j ≤ i` (column), `k < j` | build $L$ row by row, lower triangle only | element formulas $\ell_{ij}$ |
| `if (i == j) L[i][i] = Math.sqrt(A[i][i] - sum)` | diagonal $\ell_{ii} = \sqrt{a_{ii} - \sum\ell_{ik}^2}$ | step 1.2 |
| `else L[i][j] = (A[i][j] - sum) / L[j][j]` | off-diagonal $\ell_{ij}$ | step 1.1 (forward substitution) |
| `if (L[i][i] <= 0)` | positive-definite check. A negative argument to `Math.sqrt` gives **NaN**; NaN ≤ 0 is false, so a robust version tests `A[i][i] - sum <= 0` **before** taking the root | theorem: fails iff not SPD |
| `StdOut` | Sedgewick's print library; use `System.out` in your own code | |

The sample prints $L$ for $A = \begin{bmatrix}4&1&1\\1&5&3\\1&3&15\end{bmatrix}$: rows `2.00000 0 0`, `0.50000 2.17945 0`, `0.50000 1.26179 3.62738`.

> [!warning] The lecture program only factorises
> It returns $L$ but does **not** solve $Ax = b$. An exam answer must add **forward substitution** ($Lc = b$) and **back substitution** ($L^Tx = c$), as below.

## 2. Complete solver: factorise + solve (2025 Q5(b)), tested
```java
import java.util.Scanner;

public class CholeskySolver {

    // ---------- Step 1: A = L L^T ----------
    static double[][] cholesky(double[][] A) {
        int n = A.length;
        for (int i = 0; i < n; i++)                         // condition 1: symmetric
            for (int j = 0; j < i; j++)
                if (Math.abs(A[i][j] - A[j][i]) > 1e-12)
                    throw new IllegalArgumentException("Matrix is not symmetric");

        double[][] L = new double[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j <= i; j++) {
                double sum = 0;
                for (int k = 0; k < j; k++) sum += L[i][k] * L[j][k];
                if (i == j) {
                    double d = A[i][i] - sum;
                    if (d <= 0)                             // condition 2: positive definite
                        throw new IllegalArgumentException("Matrix is not positive definite");
                    L[i][i] = Math.sqrt(d);                 // l_ii = sqrt(a_ii - sum l_ik^2)
                } else {
                    L[i][j] = (A[i][j] - sum) / L[j][j];    // l_ij = (a_ij - sum l_ik l_jk) / l_jj
                }
            }
        }
        return L;
    }

    // ---------- Step 2: forward substitution  L c = b ----------
    static double[] forward(double[][] L, double[] b) {
        int n = b.length;
        double[] c = new double[n];
        for (int i = 0; i < n; i++) {
            double sum = b[i];
            for (int k = 0; k < i; k++) sum -= L[i][k] * c[k];
            c[i] = sum / L[i][i];
        }
        return c;
    }

    // ---------- Step 3: back substitution  L^T x = c ----------
    static double[] backward(double[][] L, double[] c) {
        int n = c.length;
        double[] x = new double[n];
        for (int i = n - 1; i >= 0; i--) {
            double sum = c[i];
            for (int k = i + 1; k < n; k++) sum -= L[k][i] * x[k];   // (L^T)[i][k] = L[k][i]
            x[i] = sum / L[i][i];
        }
        return x;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("n: ");
        int n = sc.nextInt();
        double[][] A = new double[n][n];
        double[] b = new double[n];
        System.out.println("Enter A row by row:");
        for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) A[i][j] = sc.nextDouble();
        System.out.println("Enter b:");
        for (int i = 0; i < n; i++) b[i] = sc.nextDouble();

        double[][] L = cholesky(A);
        System.out.println("L =");
        for (double[] row : L) { for (double v : row) System.out.printf("%10.5f", v); System.out.println(); }
        double[] c = forward(L, b);
        double[] x = backward(L, c);
        for (int i = 0; i < n; i++) System.out.printf("c%d = %.5f   x%d = %.5f%n", i + 1, c[i], i + 1, x[i]);
    }
}
```

## 3. Cholesky using symmetric (packed) storage (2026 Q6(b)), tested
2026 Q6(a) asks for a representation of a symmetric matrix and Q6(b) asks to **use it**. Store $A$'s lower triangle in a row vector ([[03.03 Symmetric Matrix Storage]]). Because $L$ is lower triangular, **$L$ fits in the same packed layout**, so the whole method uses $n(n+1)/2$ values for $A$ and the same for $L$.

```java
public class CholeskySymmetric {

    // ---- symmetric matrix stored as its lower triangle in a row vector (Lecture 03) ----
    static int idx(int i, int j) {                  // 0-based packed index, i >= j
        if (j > i) { int t = i; i = j; j = t; }
        return i * (i + 1) / 2 + j;
    }

    // Input : packed A (n(n+1)/2 values), b.  Output: x.
    // L is lower triangular, so it is ALSO stored packed with the same idx() formula.
    static double[] solve(double[] A, double[] b, int n) {
        double[] L = new double[n * (n + 1) / 2];

        // A = L L^T
        for (int i = 0; i < n; i++)
            for (int j = 0; j <= i; j++) {
                double sum = 0;
                for (int k = 0; k < j; k++) sum += L[idx(i, k)] * L[idx(j, k)];
                if (i == j) {
                    double d = A[idx(i, i)] - sum;
                    if (d <= 0) throw new ArithmeticException("Matrix is not positive definite");
                    L[idx(i, i)] = Math.sqrt(d);
                } else {
                    L[idx(i, j)] = (A[idx(i, j)] - sum) / L[idx(j, j)];
                }
            }

        // L c = b   (forward substitution)
        double[] c = new double[n];
        for (int i = 0; i < n; i++) {
            double sum = b[i];
            for (int k = 0; k < i; k++) sum -= L[idx(i, k)] * c[k];
            c[i] = sum / L[idx(i, i)];
        }

        // L^T x = c (back substitution); (L^T)[i][k] = L[k][i] = L[idx(k, i)]
        double[] x = new double[n];
        for (int i = n - 1; i >= 0; i--) {
            double sum = c[i];
            for (int k = i + 1; k < n; k++) sum -= L[idx(k, i)] * x[k];
            x[i] = sum / L[idx(i, i)];
        }
        return x;
    }

    public static void main(String[] args) {
        // 2026 Q6(d): 25x + 15y - 5z = 70, 15x + 18y = 66, -5x + 11z = 12
        double[] A = {25,
                      15, 18,
                      -5,  0, 11};             // lower triangle, row by row
        double[] b = {70, 66, 12};
        double[] x = solve(A, b, 3);
        System.out.printf("x = %.4f, y = %.4f, z = %.4f%n", x[0], x[1], x[2]);
    }
}
```
Output: `x = 2.0000, y = 2.0000, z = 2.0000` (2026 Q6(d) system).

**Changes from the 2-D version:** every `A[i][j]` becomes `A[idx(i, j)]` and every `L[i][j]` becomes `L[idx(i, j)]`; in back substitution $(L^T)_{ik} = L_{ki}$ becomes `L[idx(k, i)]`. Symmetry no longer needs checking, because the storage **cannot** hold a non-symmetric matrix.
