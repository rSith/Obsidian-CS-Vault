# 06.99 · Lesson Summary: LU Decomposition and Cholesky

> [!info] Hub: [[06.00 LU Decomposition and Cholesky]] · Past papers: [[PP 06 - LU and Cholesky]] · Priority 🔴 (4/4 papers)

## Must know
- LU: $A = LU$; solve $LZ = b$ (forward) then $UX = Z$ (back).
- Cholesky: $A = LL^T$ for **symmetric positive definite** $A$; solve $Lc = b$, then $L^Tx = c$.
- Conditions: square, symmetric, positive definite. Theorem: succeeds (non-zero diagonal) **iff** SPD; otherwise a zero diagonal or a square root of a negative number.
- Element formulas, the handout algorithm, the complete algorithm with checks.
- Worked examples: handout 4×4 → $L$ with rows (4), (1, 3), (1, 1, 2), (−1, 1, −1, 1); $c = (8, 6, 3, -1)$; $x = (1, 2, 1, -1)$.
- 25/15/−5 matrix → $L = \begin{bmatrix}5&0&0\\3&3&0\\-1&1&3\end{bmatrix}$.
- Limitations and specialty; Java program (factorise + 2 substitutions), also with packed symmetric storage.

## Important definitions
- **Lower/upper triangular:** zeros above / below the main diagonal.
- **Symmetric positive definite:** $A = A^T$ and $x^TAx > 0$ for all $x \ne 0$.
- **Cholesky factor:** lower triangular $L$ with positive diagonal and $A = LL^T$.

## Important formulas
$$
\ell_{ii} = \sqrt{a_{ii} - \sum_{k<i}\ell_{ik}^2},\qquad \ell_{ij} = \frac{a_{ij} - \sum_{k<j}\ell_{ik}\ell_{jk}}{\ell_{jj}}\ (j<i)
$$
$$
c_i = \frac{b_i - \sum_{k<i}\ell_{ik}c_k}{\ell_{ii}},\qquad x_i = \frac{c_i - \sum_{k>i}\ell_{ki}x_k}{\ell_{ii}}
$$

## Important comparison
| | LU | Cholesky |
|---|---|---|
| form | $LU$ | $LL^T$ |
| matrix | non-singular | SPD |
| cost | ~$2n^3/3$ | ~$n^3/3$ |
| store | $L$, $U$ | $L$ |
| pivoting | may be needed | not needed |

## Limitations (list)
SPD only · breaks down (zero pivot / negative under root) if not SPD · SPD check costly beforehand · square roots · fill-in for sparse matrices · still $O(n^3)$ · accuracy limited by conditioning.

## Specialty (list)
$A = LL^T$ (one factor) · uses symmetry: half work, half storage · no pivoting, stable · tests positive definiteness.
