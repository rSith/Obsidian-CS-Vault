# 02.99 · Lesson Summary: Error Analysis

> [!info] Hub: [[02.00 Error Analysis]] · Past papers: [[PP 02 - Error Analysis]] · Priority 🔴 (every paper, usually as a GPA scenario)

## Must know
- Definitions + formulas: true error, absolute error, true fractional relative error, relative (percent) error, approximate relative error.
- Round-off vs chopping: definitions, the 7-digit example, max error (½ unit vs 1 unit), sign behaviour (cancel vs accumulate).
- Round-off builds up in **large computations**; adding a large and a small number loses the small one.
- The **GPA scenario**: where rounding happens (scaling → marks → grade → GPA → class), impacts with numbers, max/min error, how to minimise (**keep full precision, round once at the end, use rounding not chopping**).
- Java: own `floor`/`ceil`; GPA program with round-off and chopping errors.
- Forward vs backward error with the √2 example.

## Important definitions
- **Accuracy:** closeness of a computed value to the **true** value. **Precision:** closeness of computed values **to each other**.
- **True error:** $E_t = $ true − approximation. **Absolute error:** $|E_t|$.
- **True fractional relative error:** $(\text{true}-\text{approx})/\text{true}$. **Relative error:** same × 100%.
- **Round-off error:** difference between the calculated approximation and the exact value **due to rounding**.
- **Chopping (truncation) error:** difference between a truncated value and the actual value; excess digits are chopped off.
- **Machine precision $\varepsilon_{\text{mach}}$:** $|fl(x)-x|/|x| \le \varepsilon_{\text{mach}}$ for UFL < x < OFL.
- **Well-posed (Hadamard):** solution exists, is unique, depends continuously on the data.
- **Forward error:** $|\hat y - y|$. **Backward error:** smallest $|\Delta x|$ with $\hat y = f(x + \Delta x)$.
- **Well-/ill-conditioned:** small input change → small / possibly large output change.
- **Stable algorithm:** its result is the exact solution of a nearby problem.

## Important comparisons
| Rounding | Chopping |
|---|---|
| nearest value | digits deleted |
| max error ½ unit (0.005 at 2 d.p.) | max error ≈ 1 unit (< 0.01) |
| error ±, tends to cancel | error one sign, adds up |
| more processing | cheaper; "most computers chop" (slide) |

| Forward error | Backward error |
|---|---|
| output space | input space |
| needs true $y$ | needs only "which input gives $\hat y$" |
| accuracy | stability |

| Conditioning | Stability |
|---|---|
| problem | algorithm |
| condition number $\approx \lvert x f'(x)/f(x)\rvert$ | small backward error |

## Important formulas
$$
\varepsilon_t = \frac{T - A}{T}\times100\%,\qquad |\varepsilon_a| = \left|\frac{x^{new}-x^{old}}{x^{new}}\right|\times100\%
$$
$$
\text{cond} = \frac{|\Delta y|/|y|}{|\Delta x|/|x|} \approx \left|\frac{x f'(x)}{f(x)}\right|
$$
$$
\text{GPA} = \frac{\sum \text{credits}\times\text{grade point}}{\sum\text{credits}} \quad(\text{2025: } 32.7/13 = 2.5153846 \to 2.52 \text{ rounded}, 2.51 \text{ chopped})
$$

## Key examples
- 7 digits: 4.2428576428 → chop 4.242857, round 4.242858.
- $0.001 + 4000$ with 4-digit mantissa → $4.000\times10^3$.
- $\sqrt2 \approx 1.4$: forward 0.0142; backward $|2 - 1.96| = 0.04$.
