# 02.05 · Well-Posed Problems, Forward Error and Backward Error

> [!info] [[02.00 Error Analysis|Lesson 2]] · Lecture slides 14–17 · Priority 🟡 Medium
> **Asked as:** "Describe forward error and backward error with suitable examples" (2023 Q3(a), 5 marks).

## 1. Well-posed problems (slide 14)
According to **Hadamard**, a problem is **well-posed** (correctly-set) if:
1. it **has a solution** (existence),
2. the solution is **unique** (uniqueness),
3. the solution **depends continuously on the data and parameters** (small change in input → small change in output).

If any condition fails, the problem is **ill-posed**, and no numerical method can be trusted to solve it reliably.

**Examples**
- $Ax = b$ with $A$ non-singular: well-posed (one solution, continuous in $A$, $b$). This is the assumption behind Gaussian elimination and Jacobi ("the system has a unique solution", [[05.01 Jacobi Method]]).
- $Ax = b$ with $A$ singular: either no solution or infinitely many → ill-posed.

## 2. Forward and backward error (slides 15–16)
Consider computing $y = f(x)$. We only get an approximation $\hat{y}$ (written $\bar y$ on the slides). There are two ways to measure the error.

### 2.1 Forward error
**In simple words:** how far the computed answer is from the true answer.

$$
\text{absolute forward error} = |\hat{y} - y|, \qquad \text{relative forward error} = \frac{|\hat{y} - y|}{|y|}
$$

Slide 15: *the forward error is a natural quantity to measure, but usually (since we don't know the true $y$) we can only get an upper bound on this error. Moreover, it can be very difficult to get tight upper bounds on the forward error.*

### 2.2 Backward error
**In simple words:** for what slightly different input would our computed answer be **exactly correct**?

Slide 16: *"For what set of data have we actually solved the problem?"* Find the smallest $\Delta x$ such that
$$
\hat{y} = f(x + \Delta x)
$$
i.e. $\hat y$ is the **exact** value of $f(x + \Delta x)$. Then

$$
\text{absolute backward error} = |\Delta x|, \qquad \text{relative backward error} = \frac{|\Delta x|}{|x|}
$$

### 2.3 Picture (slide 18)
```text
 x  ───────── f ──────────►  f(x) = y
 │ backward error              │ forward error
 ▼  (|Δx|)                     ▼  (|ŷ − y|)
 x+Δx ──────── f ─────────►  f(x+Δx) = ŷ
```
(The computed result $\hat y$ connects $x$ directly to $f(x+\Delta x)$; that diagonal is what the algorithm actually did.)

## 3. Worked example (slide 17): $y = \sqrt{2}$, computed as $\hat y = 1.4$

**Forward error:**
$$
|\Delta y| = |\hat y - y| = |1.4 - 1.41421\ldots| \approx 0.0142
$$
Relative: $0.0142/1.41421 \approx 0.0100$ (1%).

**Backward error:** $1.4$ is the exact square root of $1.96$ since $\sqrt{1.96} = 1.4$. So we have exactly solved the problem for $x + \Delta x = 1.96$:
$$
|\Delta x| = |2 - 1.96| = 0.04
$$
Relative: $0.04/2 = 0.02$ (2%).

> [!example] A second example you can use in the exam
> Computing $y = \cos(0) = 1$ and getting $\hat y = 0.9998$.
> - Forward error: $|0.9998 - 1| = 0.0002$.
> - Backward error: $\cos(x+\Delta x) = 0.9998 \Rightarrow x + \Delta x = \arccos(0.9998) \approx 0.0200$, so $|\Delta x| \approx 0.02$.
> The forward error is small but the backward error is 100 times larger: near $x = 0$ the cosine is flat, so a large input change makes only a tiny output change.

## 4. Forward vs backward error

| | Forward error | Backward error |
|---|---|---|
| Question asked | How wrong is the **answer**? | For what **input** is the answer exactly right? |
| Measured in | output space: $\lvert\hat y - y\rvert$ | input space: $\lvert\Delta x\rvert$ where $\hat y = f(x+\Delta x)$ |
| Needs the true $y$? | yes (often unknown) | no, only that $\hat y$ solves a nearby problem |
| Easy to bound? | often hard | often easier |
| Linked to | accuracy of result | **stability** of the algorithm |

**Link between them** (see [[02.06 Conditioning and Stability]]):
$$
\text{relative forward error} \lesssim \text{condition number} \times \text{relative backward error}
$$
In the √2 example: $0.01 \approx 0.5 \times 0.02$, and the condition number of $\sqrt{x}$ is exactly $\tfrac12$.

## 5. Practical explanation
- For $Ax = b$ solvers, the **residual** $r = b - A\hat x$ measures backward error (we solved exactly the system $A\hat x = b - r$). A small residual means the algorithm did its job; whether $\hat x$ is close to $x$ then depends on the conditioning of $A$.

## 6. Exam-relevant points (5 marks)
- Define both with formulas (absolute and relative).
- Use the √2 example (both numbers).
- One line on the difference: forward = output space, backward = input space; backward error relates to stability.
