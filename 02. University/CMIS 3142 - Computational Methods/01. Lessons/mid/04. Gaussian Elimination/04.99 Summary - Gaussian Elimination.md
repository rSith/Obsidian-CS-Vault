# 04.99 · Lesson Summary: Gaussian Elimination

> [!info] Hub: [[04.00 Gaussian Elimination]] · Past papers: [[PP 04 - Gaussian Elimination]] · Priority 🔴 (4/4 papers)

## Must know
- Turn a word problem into $Ax = b$: define unknowns, one equation per total, augmented matrix.
- GE = **forward elimination** (zeros below the diagonal using $R_i \leftarrow R_i - m_{ik}R_k$, $m_{ik} = a_{ik}/a_{kk}$) + **back substitution**.
- The lecture pseudocode (loops $k$, $i$, $j$; $b$ as column $n+1$; multipliers stored in the lower triangle; $x_i$ stored in $a_{i,n+1}$).
- A GE program (C from the lecture, or Java) with pivoting / zero-pivot check.
- Parallel GE: for a fixed step $k$, the row updates $E_k^i$ are independent.

## Important definitions
- **Augmented matrix:** $[A\mid b]$, $b$ appended as an extra column.
- **Pivot:** the diagonal element $a_{kk}$ used to eliminate the entries below it.
- **Multiplier:** $m_{ik} = a_{ik}/a_{kk}$.
- **Upper triangular matrix:** all entries below the main diagonal are zero.
- **Partial pivoting:** swapping rows so the pivot has the largest absolute value in its column (beyond slides).

## Important formulas
$$
R_i \leftarrow R_i - \frac{a_{ik}}{a_{kk}}R_k \quad (i > k)
$$
$$
x_n = \frac{b_n}{a_{nn}},\qquad x_i = \frac{1}{a_{ii}}\Big(b_i - \sum_{j=i+1}^{n}a_{ij}x_j\Big)
$$

## Important comparisons
| GE | Gauss-Jordan |
|---|---|
| upper triangular + back substitution | reduced to identity, no back substitution |

| Direct methods | Iterative methods |
|---|---|
| GE, LU, Cholesky | Jacobi, Gauss-Seidel, SOR |
| fixed steps; round-off accumulates | repeat to tolerance; control round-off |
| fill-in destroys sparsity | keep sparsity |
