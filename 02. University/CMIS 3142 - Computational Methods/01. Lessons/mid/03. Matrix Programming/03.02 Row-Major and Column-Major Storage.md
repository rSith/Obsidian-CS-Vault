# 03.02 · Storing a Full Matrix as a Row Vector or Column Vector

> [!info] [[03.00 Matrix Programming|Lesson 3]] · Lecture slides 5–7 · Assignment 03 · Priority 🟢 (not asked directly, but the index idea is used in every storage question)

## 1. What is it?
A 2-D matrix can be stored in a **single 1-D array**:
- **Row vector (row-major):** write row 0, then row 1, then row 2, …
- **Column vector (column-major):** write column 0, then column 1, …

## 2. Why is it used?
Memory is one long line of addresses. A 1-D array is contiguous, simple to pass around and is the basis for the symmetric and sparse schemes (which are row vectors with some elements left out). Libraries such as BLAS/LAPACK (column-major, from Fortran) and C/Java arrays (row-major) depend on this choice.

## 3. How does it work? (slide 5)
$$
A = \begin{bmatrix}12&62&63\\43&58&67\\17&84&69\end{bmatrix}
$$
- Row vector: $B = [12, 62, 63, 43, 58, 67, 17, 84, 69]$
- Column vector: $C = [12, 43, 17, 62, 58, 84, 63, 67, 69]$

**Index formulas (Java, 0-based, $n$ = number of columns for row-major, number of rows for column-major; for a square matrix both are $n$):**
$$
A[i,j] = B[\,i\cdot n + j\,] \qquad\qquad A[i,j] = C[\,j\cdot n + i\,]
$$

> *"It should be noted that in Java the indices of arrays range from 0 to (n−1) instead of (1 to n)."* (slide 5)

For an $m\times n$ (non-square) matrix: row-major $k = i\cdot n + j$ ($n$ = columns); column-major $k = j\cdot m + i$ ($m$ = rows).

### Worked example (slide 7)
$$
A = \begin{bmatrix}1&5&9\\3&5&4\\7&8&2\end{bmatrix},\quad B = [1, 5, 9, 3, 5, 4, 7, 8, 2]
$$
$A[1,2] = 4$ (row 1, column 2, 0-based). With $n = 3$: $k = i\cdot n + j = 1\cdot3 + 2 = 5$, and $B[5] = 4$ ✓.

## 4. Java (Assignment 03)
```java
import java.util.Scanner;

public class MatrixToVectors {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Rows m: ");    int m = sc.nextInt();
        System.out.print("Columns n: "); int n = sc.nextInt();

        double[][] A = new double[m][n];
        System.out.println("Enter the elements row by row:");
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++) A[i][j] = sc.nextDouble();

        double[] B = new double[m * n];   // row vector (row-major)
        double[] C = new double[m * n];   // column vector (column-major)
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++) {
                B[i * n + j] = A[i][j];
                C[j * m + i] = A[i][j];
            }

        System.out.println("Matrix form:");
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) System.out.printf("%8.2f", A[i][j]);
            System.out.println();
        }
        System.out.println("Row vector   : " + java.util.Arrays.toString(B));
        System.out.println("Column vector: " + java.util.Arrays.toString(C));

        System.out.print("Element to locate (i j): ");
        int i = sc.nextInt(), j = sc.nextInt();
        System.out.println("A(" + i + "," + j + ") is B[" + (i * n + j) + "] and C[" + (j * m + i) + "]");
    }
}
```

## 5. Row-major vs column-major

| | Row-major (row vector) | Column-major (column vector) |
|---|---|---|
| Order | row by row | column by column |
| Index (m×n, 0-based) | $i\cdot n + j$ | $j\cdot m + i$ |
| Used by | C, C++, Java 2-D arrays (rows), NumPy default | Fortran, MATLAB, LAPACK |
| Fast loop order | inner loop over $j$ | inner loop over $i$ |

> [!warning] 1-based vs 0-based
> With 1-based indices (maths notation) the row-major formula becomes $k = (i-1)n + j$. Always say which convention you use in an exam answer.
