## 1. What is it?
A **sparse symmetric matrix** is both **symmetric** ($A[i,j] = A[j,i]$) and **sparse** (most elements zero). So we can use **both** savings:
1. store only the **lower triangle** (symmetry, [[03.03 Symmetric Matrix Storage]]), and
2. inside it, store only the **non-zero** values and their positions (sparsity, [[03.05 Sparse Matrices]]).

## 2. The lecture representation (slide 17)
```text
rowVector     a;           // elements
integerVector diagonal;    // location of diagonal elements
integerVector columnNums;  // column number of each element
int           nElements;   // number of elements
```

**How the fields work together** (the slide lists the fields; the following rules are the standard way they fit, as in Jennings' *Matrix Computation*, a course reference):
- Go through the **lower triangle row by row** ($j \le i$). Put each **non-zero** value into `a`, and its column number into `columnNums` at the same position.
- **Always store the diagonal element** of each row (even if zero). It is the **last** stored element of its row, because $j = i$ is the largest column in the lower triangle.
- `diagonal[i]` = the position in `a` of $A[i][i]$. Therefore row $i$ occupies positions `diagonal[i-1] + 1` … `diagonal[i]` (row 0 starts at 0).
- `nElements` = how many values are stored (length of `a`).

> [!warning] Interpretation
> Slide 17 only lists the four fields and asks "how to write method `elementAt(int i, int j)`". The rule "the diagonal is always stored and ends each row" is the interpretation used here because it is what makes `diagonal` useful. If you use a different but consistent rule, explain it in the answer.

### Worked example
$$
A = \begin{bmatrix}5&0&0&1\\0&6&2&0\\0&2&7&0\\1&0&0&8\end{bmatrix}
\quad\text{lower triangle: }
\begin{bmatrix}5&&&\\0&6&&\\0&2&7&\\1&0&0&8\end{bmatrix}
$$

| position $k$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| `a[k]` | 5 | 6 | 2 | 7 | 1 | 8 |
| `columnNums[k]` | 0 | 1 | 1 | 2 | 0 | 3 |
| belongs to row | 0 | 1 | 2 | 2 | 3 | 3 |

`diagonal = [0, 1, 3, 5]`, `nElements = 6`.

Memory: **6 values + 6 column numbers + 4 diagonal positions** instead of 16 values (full) or 10 values (symmetric). For large sparse matrices the saving is enormous.

### `elementAt(i, j)` algorithm
1. If $j > i$, swap $i$ and $j$ (symmetry).
2. `start = (i == 0) ? 0 : diagonal[i-1] + 1`, `end = diagonal[i]`.
3. Search `columnNums[start..end]` for $j$. If found at $k$, return `a[k]`; otherwise return **0**.

**Example:** $A(0,3)$ → swap → $(3,0)$; row 3 is positions $\text{diagonal}[2]+1 = 4$ to $\text{diagonal}[3] = 5$; `columnNums[4] = 0` ✓ → return `a[4] = 1`.
$A(1,0)$: row 1 is positions 1…1; `columnNums[1] = 1`, which is not 0 → not found → **0**.

## 3. Complete Java program (2025 Q3, 2026 Q2(b)), tested
```java
import java.util.Arrays;
import java.util.Scanner;

public class SparseSymmetric {
    // ----- representation from lecture slide 17 -----
    double[] a;          // rowVector a        : stored values (lower triangle, row by row)
    int[] diagonal;      // integerVector      : position in a[] of each diagonal element
    int[] columnNums;    // integerVector      : column number of each stored value
    int nElements;       // number of stored values
    int n;               // matrix size (n x n)

    // (i) read and store: read the lower triangle row by row, keep only non-zeros
    //     (the diagonal element is always kept, so it marks the end of each row)
    void readAndStore(Scanner sc) {
        System.out.print("Size n: ");
        n = sc.nextInt();
        a = new double[n * (n + 1) / 2];          // worst case capacity
        columnNums = new int[n * (n + 1) / 2];
        diagonal = new int[n];
        nElements = 0;
        for (int i = 0; i < n; i++) {
            System.out.print("Row " + i + " (columns 0.." + i + "): ");
            for (int j = 0; j <= i; j++) {
                double value = sc.nextDouble();
                if (value != 0 || j == i) {        // store non-zeros, and always the diagonal
                    a[nElements] = value;
                    columnNums[nElements] = j;
                    if (j == i) diagonal[i] = nElements;
                    nElements++;
                }
            }
        }
        a = Arrays.copyOf(a, nElements);           // shrink to the exact size: minimum memory
        columnNums = Arrays.copyOf(columnNums, nElements);
    }

    // (iii) element at row i, column j
    double elementAt(int i, int j) {
        if (j > i) { int t = i; i = j; j = t; }   // symmetric: A[i][j] = A[j][i]
        int start = (i == 0) ? 0 : diagonal[i - 1] + 1;   // row i starts after previous diagonal
        for (int k = start; k <= diagonal[i]; k++)
            if (columnNums[k] == j) return a[k];
        return 0.0;                                // not stored => zero
    }

    // display only the stored elements with their row and column numbers
    void displayStored() {
        int row = 0;
        for (int k = 0; k < nElements; k++) {
            while (k > diagonal[row]) row++;       // find which row position k belongs to
            System.out.println("(" + row + ", " + columnNums[k] + ") = " + a[k]);
        }
    }

    // (ii) display the full matrix, including zeros
    void displayFull() {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) System.out.printf("%8.2f", elementAt(i, j));
            System.out.println();
        }
    }

    // (iv) multiply two sparse symmetric matrices (result is NOT symmetric in general -> full array)
    double[][] multiply(SparseSymmetric B) {
        double[][] C = new double[n][n];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++) {
                double sum = 0;
                for (int k = 0; k < n; k++) {
                    double aik = elementAt(i, k);
                    if (aik != 0) sum += aik * B.elementAt(k, j);   // skip zero terms
                }
                C[i][j] = sum;
            }
        return C;
    }

    // (v) number of non-zero elements in the FULL matrix
    int countNonZeros() {
        int count = 0;
        for (int k = 0; k < nElements; k++) {
            if (a[k] == 0) continue;                       // a zero diagonal that was stored
            boolean onDiagonal = false;
            for (int i = 0; i < n; i++) if (diagonal[i] == k) onDiagonal = true;
            count += onDiagonal ? 1 : 2;                   // off-diagonal value appears twice
        }
        return count;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        SparseSymmetric A = new SparseSymmetric();
        A.readAndStore(sc);
        System.out.println("Stored elements:"); A.displayStored();
        System.out.println("Full matrix:");     A.displayFull();
        System.out.println("A(0,3) = " + A.elementAt(0, 3));
        System.out.println("Non-zeros = " + A.countNonZeros() + ", stored = " + A.nElements);
        double[][] C = A.multiply(A);
        System.out.println("A x A:");
        for (double[] row : C) { for (double x : row) System.out.printf("%8.2f", x); System.out.println(); }
    }
}
```

### How each exam part maps to the code
| Exam part | Method | Key idea |
|---|---|---|
| Read and store (2025 b, 2026 b-i) | `readAndStore` | read lower triangle only; store non-zeros + diagonal; trim arrays with `Arrays.copyOf` (minimum memory) |
| Element at (row, col) (2025 c, 2026 b-iii) | `elementAt` | swap if $j > i$; search only row $i$'s segment |
| Display stored elements with row & column (2025 d) | `displayStored` | row of position $k$ = first $i$ with $k \le$ `diagonal[i]` |
| Display all incl. zeros (2025 e, 2026 b-ii) | `displayFull` | call `elementAt` for every $(i,j)$ |
| Multiply two (2026 b-iv) | `multiply` | result **not symmetric** in general → full 2-D array; skip zero terms |
| Number of non-zeros (2026 b-v) | `countNonZeros` | off-diagonal values count **twice** (they appear at $(i,j)$ and $(j,i)$); skip a stored zero diagonal |

> [!tip] Why not store the diagonal positions only?
> Without `diagonal`, finding row $i$ would need a scan from the start of `a`. With it, `elementAt` jumps straight to row $i$ and searches only that row: much faster for large matrices.

## 4. Enhancing the symmetric class into a sparse symmetric class (2023 Q4(b): discussion only)
1. Keep the symmetric rule (store only $j \le i$; swap when $j > i$).
2. Replace the full lower-triangle array (size $n(n+1)/2$) by **three arrays**: `a` (non-zero values), `columnNums` (their columns), `diagonal` (position of each row's diagonal, marking row ends), plus `nElements`.
3. `element(i, j)`: swap if needed, then **search** row $i$'s segment; return 0 if absent.
4. `Store_Element(i, j, E)`: swap if needed; if the position exists, overwrite (or delete if $E = 0$); otherwise **insert** into row $i$'s segment and shift later entries, then **update** `diagonal` for rows $\ge i$ and `nElements`. (A linked-list version avoids shifting.)
5. `Multiply`: loop only over stored non-zeros; the product is returned as a full (or general sparse) matrix since it need not be symmetric.
6. Trade-off: much less memory, but $O(\text{row length})$ access instead of $O(1)$.

## 5. Important distinctions
| Symmetric (packed) | Sparse symmetric |
|---|---|
| all $n(n+1)/2$ lower values | only non-zero lower values (+ diagonal) |
| index by formula, $O(1)$ | search in row segment |
| no extra index arrays | `columnNums`, `diagonal` |
| best for dense symmetric (Cholesky) | best for large sparse symmetric (FD grids, structures) |
