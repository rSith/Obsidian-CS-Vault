# 03.04 · Abstract `Matrix` Class, Inheritance and Polymorphism

> [!info] [[03.00 Matrix Programming|Lesson 3]] · Lecture slides 10–11 · Assignment 03 · Priority 🟡 Medium (one paper, but it was a **whole question**)
> **Asked as:** "Using inheritance and polymorphism, write one Java class for each of the following matrix categories: (i) full matrix (ii) symmetric matrix (iii) sparse matrix (iv) sparse symmetric matrix (v) row vector (vi) column vector, with the operations: addition, subtraction, multiplication, row swap, column swap" (2024 Q3).

## 1. What is it?
The lecture gives an **abstract class** `Matrix` (slide 10). Every matrix type extends it and decides **how its elements are stored**, while operations such as add or multiply are written **once** in terms of `elementAt(i, j)`.

```java
public abstract class Matrix            // lecture slide 10
{
    protected int columns;
    protected int rows;

    public int rowSize()    { return rows; }
    public int columnSize() { return columns; }

    public abstract void display();
    public abstract double elementAt(int i, int j);
    public abstract Matrix multiply(double K);
    public abstract Matrix multiply(Matrix B);
    public abstract columnVector multiply(columnVector B);
    public abstract Matrix add(Matrix B);
    public abstract Matrix sub(Matrix B);
    public abstract void swapRows(int i, int j);
    public abstract void swapColumns(int i, int j);
    public abstract Matrix transpose();
    public abstract Matrix inverse();
}
```

## 2. OOP ideas used
| Concept | Meaning here |
|---|---|
| **Abstract class** | `Matrix` cannot be created directly; it defines what every matrix must be able to do. |
| **Abstract method** | `elementAt`, `setElement`: no body in `Matrix`; each subclass must implement them for its own storage. |
| **Inheritance** | `FullMatrix extends Matrix`, `SparseSymmetricMatrix extends SparseMatrix`, … The subclasses **reuse** `add`, `sub`, `multiply`, `display` from the parent. |
| **Polymorphism** | A `Matrix` reference can point to any subclass: `Matrix S = new SymmetricMatrix(3);`. Calling `S.elementAt(i,j)` runs the **symmetric** version at run time (dynamic binding). So `S.add(P)` works even when `P` is a sparse symmetric matrix. |
| **Overriding** | `SymmetricMatrix` overrides `swapRows` because swapping rows alone would destroy symmetry. |

## 3. Design
```text
                    Matrix (abstract)
      rows, columns, elementAt(), setElement()  ← abstract
      add(), sub(), multiply(), multiply(k), swapRows(), swapColumns(), display(), toFull()  ← written once
          │
 ┌────────┼──────────────┬──────────────┬───────────────┐
FullMatrix  RowVector  ColumnVector  SymmetricMatrix   SparseMatrix
double[][]  double[]   double[]      double[] (lower   (row, col, value) lists
                                      triangle)              │
                                                     SparseSymmetricMatrix
                                                     (only i ≥ j stored)
```

**Decisions to explain in the exam:**
- Results of `add`, `sub`, `multiply` are returned as a `FullMatrix`, because the sum/product of two special matrices does not keep the special structure in general (e.g. symmetric × symmetric is not symmetric; sparse × sparse can fill in).
- **Row/column swap** on a symmetric (or sparse symmetric) matrix: swapping only rows makes $A[i,j] \ne A[j,i]$, so the storage scheme can no longer hold it. Here it throws an exception and the user converts with `toFull()` first. (Alternative answer: swap row $i$/$j$ **and** column $i$/$j$ together, which keeps symmetry; this is a symmetric permutation.)
- Sparse classes never store zeros: setting an element to 0 removes it.

## 4. Complete, tested Java code (2024 Q3)
```java
import java.util.ArrayList;

// ===================== abstract base class (lecture slide 10, completed) =====================
abstract class Matrix {
    protected int rows;
    protected int columns;

    public int rowSize()    { return rows; }
    public int columnSize() { return columns; }

    // each subclass decides HOW elements are stored
    public abstract double elementAt(int i, int j);
    public abstract void setElement(int i, int j, double value);

    // ---------- operations written ONCE, inherited by every subclass ----------
    public void display() {
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < columns; j++) System.out.printf("%8.2f", elementAt(i, j));
            System.out.println();
        }
    }

    public Matrix add(Matrix B) {
        if (rows != B.rows || columns != B.columns) throw new IllegalArgumentException("Size mismatch");
        FullMatrix C = new FullMatrix(rows, columns);
        for (int i = 0; i < rows; i++)
            for (int j = 0; j < columns; j++)
                C.setElement(i, j, elementAt(i, j) + B.elementAt(i, j));
        return C;
    }

    public Matrix sub(Matrix B) {
        if (rows != B.rows || columns != B.columns) throw new IllegalArgumentException("Size mismatch");
        FullMatrix C = new FullMatrix(rows, columns);
        for (int i = 0; i < rows; i++)
            for (int j = 0; j < columns; j++)
                C.setElement(i, j, elementAt(i, j) - B.elementAt(i, j));
        return C;
    }

    public Matrix multiply(Matrix B) {
        if (columns != B.rows) throw new IllegalArgumentException("Columns of A must equal rows of B");
        FullMatrix C = new FullMatrix(rows, B.columns);
        for (int i = 0; i < rows; i++)
            for (int j = 0; j < B.columns; j++) {
                double sum = 0;
                for (int k = 0; k < columns; k++) sum += elementAt(i, k) * B.elementAt(k, j);
                C.setElement(i, j, sum);
            }
        return C;
    }

    public Matrix multiply(double k) {
        FullMatrix C = new FullMatrix(rows, columns);
        for (int i = 0; i < rows; i++)
            for (int j = 0; j < columns; j++) C.setElement(i, j, k * elementAt(i, j));
        return C;
    }

    public void swapRows(int r1, int r2) {
        for (int j = 0; j < columns; j++) {
            double t = elementAt(r1, j);
            setElement(r1, j, elementAt(r2, j));
            setElement(r2, j, t);
        }
    }

    public void swapColumns(int c1, int c2) {
        for (int i = 0; i < rows; i++) {
            double t = elementAt(i, c1);
            setElement(i, c1, elementAt(i, c2));
            setElement(i, c2, t);
        }
    }

    public FullMatrix toFull() {
        FullMatrix F = new FullMatrix(rows, columns);
        for (int i = 0; i < rows; i++)
            for (int j = 0; j < columns; j++) F.setElement(i, j, elementAt(i, j));
        return F;
    }
}

// ===================== (i) full matrix: every element stored =====================
class FullMatrix extends Matrix {
    private double[][] a;
    public FullMatrix(int m, int n) { rows = m; columns = n; a = new double[m][n]; }
    public double elementAt(int i, int j)            { return a[i][j]; }
    public void setElement(int i, int j, double v)    { a[i][j] = v; }
}

// ===================== (v) row vector: 1 x n =====================
class RowVector extends Matrix {
    private double[] a;
    public RowVector(int n) { rows = 1; columns = n; a = new double[n]; }
    public double elementAt(int i, int j)         { return a[j]; }      // i is always 0
    public void setElement(int i, int j, double v) { a[j] = v; }
}

// ===================== (vi) column vector: n x 1 =====================
class ColumnVector extends Matrix {
    private double[] a;
    public ColumnVector(int n) { rows = n; columns = 1; a = new double[n]; }
    public double elementAt(int i, int j)         { return a[i]; }      // j is always 0
    public void setElement(int i, int j, double v) { a[i] = v; }
}

// ===================== (ii) symmetric matrix: lower triangle in a row vector =====================
class SymmetricMatrix extends Matrix {
    private double[] a;                                   // n(n+1)/2 elements
    public SymmetricMatrix(int n) { rows = columns = n; a = new double[n * (n + 1) / 2]; }
    private int index(int i, int j) {                     // 0-based, lower triangle row by row
        if (j > i) { int t = i; i = j; j = t; }           // A[i][j] = A[j][i]
        return i * (i + 1) / 2 + j;
    }
    public double elementAt(int i, int j)         { return a[index(i, j)]; }
    public void setElement(int i, int j, double v) { a[index(i, j)] = v; }  // sets both (i,j) and (j,i)

    // swapping rows (or columns) alone destroys symmetry, so it is not allowed in place
    public void swapRows(int r1, int r2) {
        throw new UnsupportedOperationException("Row swap breaks symmetry: use toFull().swapRows()");
    }
    public void swapColumns(int c1, int c2) {
        throw new UnsupportedOperationException("Column swap breaks symmetry: use toFull().swapColumns()");
    }
}

// ===================== (iii) sparse matrix: only non-zeros as (row, column, value) =====================
class SparseMatrix extends Matrix {
    protected ArrayList<Integer> r = new ArrayList<>();
    protected ArrayList<Integer> c = new ArrayList<>();
    protected ArrayList<Double>  v = new ArrayList<>();

    public SparseMatrix(int m, int n) { rows = m; columns = n; }

    protected int find(int i, int j) {
        for (int k = 0; k < v.size(); k++) if (r.get(k) == i && c.get(k) == j) return k;
        return -1;
    }
    public double elementAt(int i, int j) {
        int k = find(i, j);
        return (k < 0) ? 0.0 : v.get(k);                 // anything not stored is zero
    }
    public void setElement(int i, int j, double value) {
        int k = find(i, j);
        if (value == 0) { if (k >= 0) { r.remove(k); c.remove(k); v.remove(k); } }   // keep zeros out
        else if (k >= 0) v.set(k, value);
        else { r.add(i); c.add(j); v.add(value); }
    }
    public int nonZeros() { return v.size(); }
}

// ===================== (iv) sparse symmetric: sparse + only lower triangle stored =====================
class SparseSymmetricMatrix extends SparseMatrix {
    public SparseSymmetricMatrix(int n) { super(n, n); }
    public double elementAt(int i, int j)             { return (j > i) ? super.elementAt(j, i) : super.elementAt(i, j); }
    public void setElement(int i, int j, double value) { if (j > i) super.setElement(j, i, value); else super.setElement(i, j, value); }
    public void swapRows(int r1, int r2) {
        throw new UnsupportedOperationException("Row swap breaks symmetry: use toFull().swapRows()");
    }
    public void swapColumns(int c1, int c2) {
        throw new UnsupportedOperationException("Column swap breaks symmetry: use toFull().swapColumns()");
    }
}

public class MatrixDemo {
    public static void main(String[] args) {
        Matrix S = new SymmetricMatrix(3);           // polymorphism: a Matrix reference
        S.setElement(0, 0, 3); S.setElement(1, 0, 4); S.setElement(1, 1, 15);
        S.setElement(2, 0, 5); S.setElement(2, 1, 7); S.setElement(2, 2, 3);

        Matrix P = new SparseSymmetricMatrix(3);
        P.setElement(0, 0, 2); P.setElement(2, 1, 1);

        Matrix F = new FullMatrix(3, 3);
        for (int i = 0; i < 3; i++) F.setElement(i, i, 1);   // identity

        System.out.println("S + P ="); S.add(P).display();
        System.out.println("S * F ="); S.multiply(F).display();
        System.out.println("S - P ="); S.sub(P).display();

        Matrix R = new RowVector(3), C = new ColumnVector(3);
        for (int k = 0; k < 3; k++) { R.setElement(0, k, k + 1); C.setElement(k, 0, k + 4); }
        System.out.println("R * C ="); R.multiply(C).display();   // 1x1 (inner product)
        System.out.println("C * R ="); C.multiply(R).display();   // 3x3 (outer product)

        Matrix G = S.toFull(); G.swapRows(0, 2); System.out.println("rows 0,2 swapped (full copy):"); G.display();
        try { S.swapRows(0, 1); } catch (UnsupportedOperationException e) { System.out.println(e.getMessage()); }
        System.out.println("Sparse symmetric stores " + ((SparseMatrix) P).nonZeros() + " values");
    }
}
```

### How polymorphism appears in the output
- `S.add(P)` adds a `SymmetricMatrix` and a `SparseSymmetricMatrix` with **one** `add` method from the abstract class; each object supplies its own `elementAt`.
- `R.multiply(C)` gives the 1×1 inner product (32) and `C.multiply(R)` the 3×3 outer product ([[03.01 Matrix Types and Vector Products]]): the same inherited `multiply`.
