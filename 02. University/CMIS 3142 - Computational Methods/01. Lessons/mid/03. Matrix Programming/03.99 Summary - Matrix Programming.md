# 03.99 · Lesson Summary: Programming Aspects of Matrices

> [!info] Hub: [[03.00 Matrix Programming]] · Past papers: [[PP 03 - Matrix Programming]] · Priority 🔴 (4/4 papers, mostly Java code)

## Must know
- The six types: row vector, column vector, full, symmetric, sparse, sparse symmetric; what each stores.
- Row-major $A[i,j] = B[i\cdot n + j]$, column-major $A[i,j] = C[j\cdot n + i]$ (0-based).
- **Symmetric:** lower triangle in a row vector, $k = \frac{i(i+1)}{2} + j$ for $i \ge j$ (swap if $j > i$); class with `element`, `Store_Element`, `Multiply` (result may not be symmetric).
- **Sparse:** most elements zero; linked list (header/element nodes, `down`/`right` links) or arrays (triplets, compressed rows).
- **Sparse symmetric:** `a`, `diagonal`, `columnNums`, `nElements`; full program: read/store, `elementAt`, display stored, display full, multiply, count non-zeros.
- Abstract `Matrix` class + 6 subclasses: inheritance (operations written once) and polymorphism (`Matrix S = new SymmetricMatrix(3)`).
- Row vector × column vector = scalar; column × row = $n\times n$ matrix.

## Important definitions
- **Symmetric matrix:** $A[i,j] = A[j,i]$ for all $i, j$ ($A = A^T$).
- **Sparse matrix:** a matrix in which most of the elements are zero.
- **Abstract class:** a class that cannot be instantiated and declares methods subclasses must implement.
- **Polymorphism:** the same call (`elementAt`, `add`) runs the subclass's own version at run time.

## Important comparisons
| Storage | Values stored | Access |
|---|---|---|
| Full | $n^2$ | `a[i][j]` |
| Symmetric | $n(n+1)/2$ | formula, $O(1)$ |
| Sparse symmetric | non-zeros of lower triangle (+ diagonal) | search row segment |
| General sparse | all non-zeros | search row segment (no swap) |

| Sparse symmetric → general sparse: what changes |
|---|
| store whole rows (both triangles), $m\times n$ |
| `rowStart[]` (size $m+1$) replaces `diagonal[]` |
| no $i \leftrightarrow j$ swap in `elementAt` |
| non-zero count = `nElements` (no doubling) |

## Key formulas / code skeletons
```java
int index(int i, int j) {            // symmetric packed storage, 0-based
    if (j > i) { int t = i; i = j; j = t; }
    return i * (i + 1) / 2 + j;
}

double elementAt(int i, int j) {     // sparse symmetric (a, diagonal, columnNums)
    if (j > i) { int t = i; i = j; j = t; }
    int start = (i == 0) ? 0 : diagonal[i - 1] + 1;
    for (int k = start; k <= diagonal[i]; k++)
        if (columnNums[k] == j) return a[k];
    return 0.0;
}
```
