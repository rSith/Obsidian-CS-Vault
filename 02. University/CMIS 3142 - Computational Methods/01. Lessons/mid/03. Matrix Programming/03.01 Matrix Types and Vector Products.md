# 03.01 · Matrix Types and Row × Column Vector Products

> [!info] [[03.00 Matrix Programming|Lesson 3]] · Lecture slides 3–4, 8, 12, 14 · Priority 🟡 Medium
> **Asked as:** "Let A be a row vector and B be a column vector. Write a separate Java method to perform each of: (i) A\*B (ii) B\*A" (2023 Q4(c), 8 marks).

## 1. The six matrix types (slide 4)

| Type | Shape | Definition | What to store |
|---|---|---|---|
| **Row vector** | $1\times n$ | one row | $n$ values |
| **Column vector** | $n\times1$ | one column | $n$ values |
| **Full matrix** | $m\times n$ | no special structure | all $m\cdot n$ values |
| **Symmetric matrix** | $n\times n$ | $A[i,j] = A[j,i]$ for all $i, j$ (slide 12) | lower (or upper) triangle: $\frac{n(n+1)}{2}$ values |
| **Sparse matrix** | $m\times n$ | **most of the elements are zero** (slide 14) | only the non-zeros + their positions |
| **Sparse symmetric matrix** | $n\times n$ | symmetric **and** sparse | non-zeros of one triangle + positions |

### Examples
$$
\text{Symmetric: } B = \begin{bmatrix}3&4&5\\4&15&7\\5&7&3\end{bmatrix}
\qquad
\text{not symmetric: } A = \begin{bmatrix}3&4&5\\6&5&4\\9&7&3\end{bmatrix},\; A^T = \begin{bmatrix}3&6&9\\4&5&7\\5&4&3\end{bmatrix}
$$
(slide 8: a matrix is symmetric exactly when $A = A^T$.)

$$
\text{Sparse symmetric: } \begin{bmatrix}5&0&0&1\\0&6&2&0\\0&2&7&0\\1&0&0&8\end{bmatrix}
$$

## 2. Why the type matters
| Type | Memory for $n = 1000$ (`double`, 8 bytes) |
|---|---|
| Full | $10^6\times8$ B = 8 MB |
| Symmetric | $500\,500\times8$ B ≈ 4 MB (half) |
| Sparse with 5 000 non-zeros | ≈ 5 000 × (8 + 4 + 4) B ≈ 80 KB |

Choosing the right type saves memory **and** time (no multiplications by zero).

## 3. Row vector × column vector (2023 Q4(c))
Let $A = [a_1\ a_2\ \dots\ a_n]$ (row, $1\times n$) and $B = [b_1\ b_2\ \dots\ b_n]^T$ (column, $n\times1$).

### 3.1 $A\cdot B$ is a **scalar** (inner / dot product)
$(1\times n)(n\times1) = 1\times1$:
$$
A B = \sum_{k=1}^{n} a_k b_k
$$

### 3.2 $B\cdot A$ is an **$n\times n$ matrix** (outer product)
$(n\times1)(1\times n) = n\times n$:
$$
(BA)_{ij} = b_i\,a_j
$$

### Worked example
$A = [1\ 2\ 3]$, $B = [4\ 5\ 6]^T$:
$$
AB = 1\cdot4 + 2\cdot5 + 3\cdot6 = 32, \qquad
BA = \begin{bmatrix}4&8&12\\5&10&15\\6&12&18\end{bmatrix}
$$

### 3.3 Java methods
```java
public class VectorProducts {

    // (i) A * B : row vector (1 x n) times column vector (n x 1) -> scalar
    static double rowTimesColumn(double[] A, double[] B) {
        if (A.length != B.length) throw new IllegalArgumentException("Lengths must match");
        double sum = 0;
        for (int k = 0; k < A.length; k++)
            sum += A[k] * B[k];
        return sum;
    }

    // (ii) B * A : column vector (n x 1) times row vector (1 x m) -> n x m matrix
    static double[][] columnTimesRow(double[] B, double[] A) {
        double[][] C = new double[B.length][A.length];
        for (int i = 0; i < B.length; i++)
            for (int j = 0; j < A.length; j++)
                C[i][j] = B[i] * A[j];
        return C;
    }

    public static void main(String[] args) {
        double[] A = {1, 2, 3};          // row vector
        double[] B = {4, 5, 6};          // column vector
        System.out.println("A*B = " + rowTimesColumn(A, B));   // 32.0
        for (double[] row : columnTimesRow(B, A)) {
            for (double x : row) System.out.print(x + " ");
            System.out.println();
        }
    }
}
```

**Explanation:**
- Both vectors are stored as 1-D arrays; the "row" or "column" meaning is in how we multiply them.
- `rowTimesColumn` needs equal lengths (inner dimensions must match). One loop, $n$ multiplications.
- `columnTimesRow` works for any lengths; two nested loops fill $n\times m$ entries. Note $AB \neq BA$: **matrix multiplication is not commutative**, and here the results do not even have the same size.

In the inheritance design ([[03.04 Abstract Matrix Class and Inheritance]]) the same results come from `R.multiply(C)` (1×1 matrix) and `C.multiply(R)` (3×3 matrix).
