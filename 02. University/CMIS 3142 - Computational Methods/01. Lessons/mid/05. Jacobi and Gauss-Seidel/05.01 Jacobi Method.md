# 05.01 · The Jacobi Method

> [!info] [[05.00 Iterative Methods - Jacobi and Gauss-Seidel|Lesson 5]] · Lecture 05_A pp. 1–4 · Priority 🟡 Medium
> **Asked as:** "Write a numerical algorithm for Jacobi method" (2024 Q4(a)) · "Solve the following equations using Jacobi method" (2024 Q4(c)) · fruit scenario by Jacobi, initial (1, 1, 2), max 10 iterations (2025 Q4(b)(ii)).

## 1. What is it?
The **Jacobi method** solves $Ax = b$ by **rewriting each equation for its own diagonal unknown** and then repeatedly substituting the **previous** approximation into the right-hand sides until the values stop changing.

### Two assumptions (lecture)
1. The system $Ax = b$ **has a unique solution**.
2. The coefficient matrix has **no zeros on its main diagonal** ($a_{11}, a_{22}, \dots, a_{nn} \neq 0$), because we divide by them.

## 2. Main idea (lecture)
1. Solve the 1st equation for $x_1$, the 2nd for $x_2$, and so on.
2. Make an **initial guess** $x^{(0)} = (x_1^{(0)}, \dots, x_n^{(0)})$ (often all zeros).
3. Substitute it into the right-hand sides → **first approximation** $x^{(1)}$. That is **one iteration**.
4. Substitute $x^{(1)}$ → $x^{(2)}$, and so on, forming a sequence $x^{(1)}, x^{(2)}, x^{(3)}, \dots$ that (hopefully) converges to the solution.

All new values in iteration $k$ are computed from the **old** values of iteration $k-1$ only.

## 3. Component formula
For each $k \ge 1$:
$$
x_i^{(k)} = \frac{1}{a_{ii}}\left[\sum_{\substack{j=1\\j\neq i}}^{n}\left(-a_{ij}\,x_j^{(k-1)}\right) + b_i\right],\qquad i = 1, 2, \dots, n
$$

## 4. Worked example (lecture)
$$
\begin{aligned}
5x_1 - 2x_2 + 3x_3 &= -1\\
-3x_1 + 9x_2 + x_3 &= 2\\
2x_1 - x_2 - 7x_3 &= 3
\end{aligned}
$$
*Continue iterations until two successive approximations are identical when rounded to three significant digits.*

> [!note] Slide typo
> The handout writes the unknown in each equation's last term as $x_n$; for this 3×3 system it means $x_3$.

**Rewrite:**
$$
x_1 = -\frac15 + \frac25x_2 - \frac35x_3,\qquad
x_2 = \frac29 + \frac39x_1 - \frac19x_3,\qquad
x_3 = -\frac37 + \frac27x_1 - \frac17x_2
$$

**Initial guess** $x^{(0)} = (0, 0, 0)$. **First approximation:**
$$
x_1^{(1)} = -\tfrac15 = -0.200,\quad x_2^{(1)} = \tfrac29 = 0.222,\quad x_3^{(1)} = -\tfrac37 = -0.429
$$

**Second approximation** (uses only $x^{(1)}$):
$$
x_1^{(2)} = -0.2 + 0.4(0.222) - 0.6(-0.429) = 0.146
$$
$$
x_2^{(2)} = 0.222 + 0.333(-0.200) - 0.111(-0.429) = 0.203
$$
$$
x_3^{(2)} = -0.429 + 0.286(-0.200) - 0.143(0.222) = -0.517
$$

**Table** (the lecture filled $k = 0$–$3$; $k = 4$–$7$ completed here and checked by program):

| | $k=0$ | $k=1$ | $k=2$ | $k=3$ | $k=4$ | $k=5$ | $k=6$ | $k=7$ |
|---|---|---|---|---|---|---|---|---|
| $x_1^{(k)}$ | 0.000 | −0.200 | 0.146 | 0.192 | 0.181 | 0.185 | 0.186 | 0.186 |
| $x_2^{(k)}$ | 0.000 | 0.222 | 0.203 | 0.328 | 0.332 | 0.329 | 0.331 | 0.331 |
| $x_3^{(k)}$ | 0.000 | −0.429 | −0.517 | −0.416 | −0.421 | −0.424 | −0.423 | −0.423 |

$x^{(6)}$ and $x^{(7)}$ agree to 3 significant digits, so **$x \approx (0.186,\ 0.331,\ -0.423)$** (exact: $0.18612, 0.33123, -0.42271$).

## 5. Matrix form (lecture p. 3–4)
Split $A$ into its diagonal, strictly lower and strictly upper parts:
$$
A = D - L - U
$$
For a 3×3 matrix:
$$
\underbrace{\begin{bmatrix}a_{11}&0&0\\0&a_{22}&0\\0&0&a_{33}\end{bmatrix}}_{D}
-
\underbrace{\begin{bmatrix}0&0&0\\-a_{21}&0&0\\-a_{31}&-a_{32}&0\end{bmatrix}}_{L}
-
\underbrace{\begin{bmatrix}0&-a_{12}&-a_{13}\\0&0&-a_{23}\\0&0&0\end{bmatrix}}_{U}
$$
(note the minus signs: $L$ and $U$ hold the **negatives** of the off-diagonal entries).

Then $Ax = b$ becomes $(D - L - U)x = b \Rightarrow Dx = (L+U)x + b$. If $D^{-1}$ exists ($D^{-1} = \text{diag}(1/a_{11}, \dots, 1/a_{nn})$):
$$
x^{(k)} = D^{-1}(L+U)\,x^{(k-1)} + D^{-1}b
$$
Define $T_j = D^{-1}(L+U)$ and $c_j = D^{-1}b$:
$$
\boxed{x^{(k)} = T_j\,x^{(k-1)} + c_j,\qquad k = 1, 2, 3, \dots}
$$
$T_j$ is the **Jacobi iteration matrix**; its spectral radius decides convergence ([[05.03 Convergence of Iterative Methods]]).

## 6. Numerical algorithm (lecture p. 4), the answer to 2024 Q4(a)
**Input:** $A = [a_{ij}]$, $b$, $XO = x^{(0)}$, tolerance $TOL$, maximum number of iterations $N$.
**Output:** approximate solution $x_1, \dots, x_n$ or a failure message.

```text
Step 1  Set k = 1
Step 2  While (k <= N) do Steps 3–6
    Step 3  For i = 1, 2, ..., n
                x_i = (1 / a_ii) * [ Σ_{j=1, j≠i}^{n} ( −a_ij * XO_j ) + b_i ]
    Step 4  If ||x − XO|| < TOL then OUTPUT (x_1, x_2, ..., x_n); STOP.   [success]
    Step 5  Set k = k + 1
    Step 6  For i = 1, 2, ..., n  set XO_i = x_i
Step 7  OUTPUT ('Maximum number of iterations exceeded'); STOP.          [failure]
```
Another stopping criterion in Step 4 (relative): $\dfrac{\|x^{(k)} - x^{(k-1)}\|}{\|x^{(k)}\|} < TOL$.

> [!note] Step 7 wording
> The handout's Step 7 prints $(x_1, \dots, x_n)$ again. The textbook version (Burden & Faires) prints "maximum number of iterations exceeded", which is the clearer exam answer.

## 7. Java method (Assignment 06 Q1(c) style), tested
```java
public class JacobiMethod {

    // ---------------- Jacobi ----------------
    static double[] jacobi(double[][] A, double[] b, double[] x0, double tol, int maxIter) {
        int n = b.length;
        double[] xOld = x0.clone();
        double[] x = new double[n];
        for (int k = 1; k <= maxIter; k++) {
            for (int i = 0; i < n; i++) {
                double sum = b[i];
                for (int j = 0; j < n; j++)
                    if (j != i) sum -= A[i][j] * xOld[j];   // ONLY old values are used
                x[i] = sum / A[i][i];
            }
            print(k, x);
            if (maxDiff(x, xOld) < tol) return x;          // ||x - XO|| < TOL
            xOld = x.clone();                               // XO = x  (Step 6)
        }
        System.out.println("Maximum number of iterations exceeded");
        return x;
    }

    static double maxDiff(double[] a, double[] b) {         // infinity norm of (a - b)
        double m = 0;
        for (int i = 0; i < a.length; i++) m = Math.max(m, Math.abs(a[i] - b[i]));
        return m;
    }

    static void print(int k, double[] x) {
        System.out.printf("k=%2d :", k);
        for (double v : x) System.out.printf(" %10.5f", v);
        System.out.println();
    }

    public static void main(String[] args) {
        double[][] A = {{5, -2, 3}, {-3, 9, 1}, {2, -1, -7}};   // lecture example
        double[] b = {-1, 2, 3};
        double[] x = jacobi(A, b, new double[]{0, 0, 0}, 0.0005, 50);
    }
}
```
Running it on the lecture example prints iterations 1–7 shown in the table above (tolerance 0.0005).

## 8. Exam-relevant points
- Always **rewrite** the equations first (one line per unknown), then tabulate iterations to 4 d.p.
- Use **only old values** in each iteration. Mixing in new values is Gauss-Seidel.
- **Check convergence first** (diagonal dominance); if it fails, say so and show 2–3 diverging iterations (2024 Q4(c)).
- Know the algorithm steps 1–7 for an "algorithm" question.
