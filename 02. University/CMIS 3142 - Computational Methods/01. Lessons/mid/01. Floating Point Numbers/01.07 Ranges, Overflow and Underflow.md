# 01.07 · Ranges, Overflow and Underflow

> [!info] [[01.00 Floating Point Numbers|Lesson 1]] · Lecture slides 29–35 · Priority 🟡 Medium
> **Asked as:** "Summarize the range of numbers that can be represented by the IEEE 754 single precision and double precision" (2024 Q1(a)) · "Describe overflow and underflow when representing a floating point number using IEEE 754 format" (2025 Q1(a)).

## 1. Ranges (slide 30)

| | Denormalised | Normalised |
|---|---|---|
| **Single precision** | $\pm\,2^{-149}$ to $(1-2^{-23})\times2^{-126}$ | $\pm\,2^{-126}$ to $(2-2^{-23})\times2^{127}$ |
| **Double precision** | $\pm\,2^{-1074}$ to $(1-2^{-52})\times2^{-1022}$ | $\pm\,2^{-1022}$ to $(2-2^{-52})\times2^{1023}$ |

### Where the formulas come from
- **Largest normalised (single):** $E = 11111110 = 254 \Rightarrow e = 127$; $F$ = all 1s $\Rightarrow 1.F = 1.111\ldots1 = 2 - 2^{-23}$. Value $= (2-2^{-23})\times2^{127}$.
- **Smallest normalised:** $E = 00000001 \Rightarrow e = -126$; $F = 0 \Rightarrow 1.0\times2^{-126}$.
- **Largest denormalised:** $E = 0$, $F$ = all 1s $\Rightarrow 0.111\ldots1 = 1-2^{-23}$; value $(1-2^{-23})\times2^{-126}$.
- **Smallest denormalised:** $E = 0$, $F = 00\ldots01 \Rightarrow 2^{-23}\times2^{-126} = 2^{-149}$.

### "Interesting numbers" in decimal (slide 32)

| Description | exp | frac | Single | Double |
|---|---|---|---|---|
| Zero | 00…00 | 00…00 | 0.0 | 0.0 |
| Smallest positive denormalised | 00…00 | 00…01 | $\approx1.4\times10^{-45}$ | $\approx4.9\times10^{-324}$ |
| Largest denormalised | 00…00 | 11…11 | $\approx1.18\times10^{-38}$ | $\approx2.2\times10^{-308}$ |
| Smallest positive normalised | 00…01 | 00…00 | $\approx1.18\times10^{-38}$ (just larger than largest denorm.) | $\approx2.2\times10^{-308}$ |
| One | 01…11 | 00…00 | 1.0 | 1.0 |
| Largest normalised | 11…10 | 11…11 | $\approx3.4\times10^{38}$ | $\approx1.8\times10^{308}$ |

### The number line (slide 31)
```text
 NaN  -∞ ── -Normalized ── -Denorm ── -0 | +0 ── +Denorm ── +Normalized ── +∞  NaN
```
Positive and negative ranges are **symmetric** because only the sign bit changes.

## 2. Overflow

**Definition (slide 35):** *"When the absolute value of a result becomes too large for the floating point standard, overflow occurs."* The result becomes **+∞ or −∞** (the special bit pattern $E$ = all 1s, $F = 0$).

- Single precision overflows above about $3.4\times10^{38}$; double above about $1.8\times10^{308}$.
- **What it tells you:** seeing ∞ usually means a programming error or an algorithm error (for example a diverging iterative method; see [[05.03 Convergence of Iterative Methods]]).

## 3. Underflow

**Definition (slide 34):** *"Underflow occurs when a positive result becomes smaller than the smallest representable, positive number; the result is then set to 0. This also happens with negative numbers with small magnitude. In most environments you will get a warning, but otherwise the calculations will continue."*

- With denormalised numbers, values between $2^{-149}$ and $2^{-126}$ are still kept (with reduced precision): **gradual underflow**. Below $2^{-149}$ the result becomes ±0.
- Usually harmless, but dangerous if you later **divide by** the underflowed value (division by zero → ∞) or compare it with zero.

## 4. Java demonstration
(Class practical code, *AB.java*, in your CMIS 3142 folder.)

```java
public class OverUnderflow {
    public static void main(String[] args) {
        float a = 3.4e38f;      // close to the largest float
        float b = a * 10;       // exceeds the float range
        System.out.println(b);  // prints Infinity  -> overflow

        float c = 1.0e-45f;     // smallest denormalised float (about 1.4e-45)
        float d = c / 10;       // smaller than anything representable
        System.out.println(d);  // prints 0.0       -> underflow
    }
}
```

## 5. Overflow vs underflow

| | Overflow | Underflow |
|---|---|---|
| Cause | magnitude **too large** | magnitude **too small** (too close to 0) |
| Single limit | $> (2-2^{-23})\times2^{127}\approx3.4\times10^{38}$ | $< 2^{-149}\approx1.4\times10^{-45}$ (or $<2^{-126}$ for normalised) |
| Result | ±∞ | denormalised, then ±0 |
| Seriousness | usually a bug; result is useless | usually harmless, but watch division |
| Example | `3.4e38f * 10` | `1e-45f / 10` |
