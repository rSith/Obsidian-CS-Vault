## 1. What is it?
For values $y_0, y_1, y_2, \dots$ at equally spaced points $x_0, x_0 + h, x_0 + 2h, \dots$, the **forward differences** are
$$
\Delta y_i = y_{i+1} - y_i,\qquad \Delta^2y_i = \Delta y_{i+1} - \Delta y_i,\qquad \Delta^ky_i = \Delta^{k-1}y_{i+1} - \Delta^{k-1}y_i
$$
A **forward difference table** lists $x$, $y$, then each order of difference in the next column, each entry written between the two entries it came from.

## 2. Why is it used?
- **Detect polynomial behaviour:** for a polynomial of degree $n$ (equal steps), the **$n$-th differences are constant** and the $(n+1)$-th are zero.
- **Find missing or next terms** of a sequence (Example 5.3).
- **Interpolation** (Newton's forward formula) and **numerical differentiation**: $\Delta y_i/h \approx f'(x_i)$ is exactly the forward difference of [[09.02 First Derivative Differences and Truncation Error]].
- **Discrete models** (difference equations) such as compound interest.

## 4. Algorithm for $x = 1, 2, \dots, 25$ (2023 Q2(d))
```text
INPUT  f(x) = x^3 + 2x + 1,  n = 25
1  For i = 1 to n:  D[i][0] = f(i)                         // column 0 = y values
2  For k = 1 to n−1:                                       // k-th differences
       For i = 1 to n−k:
           D[i][k] = D[i+1][k−1] − D[i][k−1]
3  For i = 1 to n:                                         // print row i
       print i, D[i][0], D[i][1], ..., D[i][n−i]
       (or only up to the order needed, e.g. Δ^4)
STOP
```
Optional improvement: stop computing new columns once a column is all zeros (for this cubic, $\Delta^4 = 0$, so only 4 difference columns are needed).

```java
public class ForwardDifferenceTable {

    static double f(double x) { return x * x * x + 2 * x + 1; }     // y = x^3 + 2x + 1

    public static void main(String[] args) {
        int n = 25;                                   // x = 1, 2, ..., 25
        double[][] d = new double[n][n];              // d[i][k] = Δ^k y_i

        for (int i = 0; i < n; i++) d[i][0] = f(i + 1);              // column 0: y values
        for (int k = 1; k < n; k++)                                  // column k: k-th differences
            for (int i = 0; i < n - k; i++)
                d[i][k] = d[i + 1][k - 1] - d[i][k - 1];             // Δ^k y_i = Δ^{k-1} y_{i+1} - Δ^{k-1} y_i

        int show = 5;                                 // print y, Δy, Δ²y, Δ³y, Δ⁴y
        System.out.printf("%4s %10s %10s %10s %10s %10s%n", "x", "y", "Dy", "D2y", "D3y", "D4y");
        for (int i = 0; i < n; i++) {
            System.out.printf("%4d", i + 1);
            for (int k = 0; k < show && k < n - i; k++) System.out.printf(" %10.0f", d[i][k]);
            System.out.println();
        }
    }
}
```

## 5. Compound interest as a finite difference model (2026 Q3)

### 5.1 Deriving the difference equation (2026 Q3(b))
Let $A_n$ = amount after $n$ years, $P$ = principal, $r$ = annual interest rate (as a decimal), compounded yearly. **Compound interest is interest on the principal and on the interest already added**, so the interest in year $n+1$ is $r$ times the **current** amount $A_n$:
$$
A_{n+1} = A_n + rA_n\qquad\Longleftrightarrow\qquad \Delta A_n = A_{n+1} - A_n = rA_n,\qquad A_0 = P
$$
That is the **finite difference equation**: $\Delta A_n = rA_n$, or $A_{n+1} = (1 + r)A_n$. Solving it step by step:
$$
A_n = P(1 + r)^n
$$
Further differences: $\Delta A_n = rP(1+r)^n$, $\Delta^2A_n = r^2P(1+r)^n = r\,\Delta A_n$, so **every difference column grows by the same factor $(1 + r)$**. (Compare the continuous model $\frac{dA}{dt} = rA$: replacing the derivative by a forward difference with step 1 gives exactly $\Delta A_n = rA_n$.)

### 5.3 Java program (2026 Q3(d)), tested
```java
import java.util.Scanner;

public class CompoundInterestTable {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Principal: ");               double P = sc.nextDouble();
        System.out.print("Annual interest rate (%): "); double r = sc.nextDouble() / 100.0;
        System.out.print("Duration (years): ");         int N = sc.nextInt();

        // finite difference model: A(n+1) = A(n) + r*A(n) = (1 + r) A(n),  A(0) = P
        double[] A = new double[N + 1];
        A[0] = P;
        for (int n = 0; n < N; n++) A[n + 1] = (1 + r) * A[n];

        // first and second forward differences
        double[] d1 = new double[N];          // ΔA_n  = A_{n+1} - A_n  (interest earned in year n+1)
        double[] d2 = new double[N - 1];      // Δ²A_n = ΔA_{n+1} - ΔA_n
        for (int n = 0; n < N; n++)     d1[n] = A[n + 1] - A[n];
        for (int n = 0; n < N - 1; n++) d2[n] = d1[n + 1] - d1[n];

        System.out.printf("%5s %14s %12s %12s%n", "Year", "Amount A", "Delta A", "Delta^2 A");
        for (int n = 0; n <= N; n++) {
            System.out.printf("%5d %14.2f", n, A[n]);
            if (n < N)     System.out.printf(" %12.2f", d1[n]);
            if (n < N - 1) System.out.printf(" %12.2f", d2[n]);
            System.out.println();
        }
    }
}
```
Running it with `5000`, `7.5`, `10` prints exactly the table above.
