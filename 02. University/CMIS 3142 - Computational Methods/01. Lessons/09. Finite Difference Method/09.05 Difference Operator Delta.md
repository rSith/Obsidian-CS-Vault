# 09.05 · The Forward Difference Operator Δ

> [!info] [[09.00 Finite Difference Method|Lesson 9]] · Lecture 09 Example PDF, Examples 5.4–5.5 · Priority 🟡 Medium
> **Asked as:** "Find (i) $\Delta e^{ax}$ (ii) $\Delta^2e^x$ (iii) $\Delta\log(x)$" (2024 Q2(c), **identical to Example 5.4**) · "Evaluate $\Delta^2\frac1x$ by taking '1' as the interval of differencing" (2024 Q2(d), same technique as Example 5.5).

## 1. Definition
With **interval of differencing** (step) $h$:
$$
\Delta f(x) = f(x + h) - f(x),\qquad \Delta^2f(x) = \Delta[\Delta f(x)] = f(x + 2h) - 2f(x + h) + f(x)
$$
In general $\Delta^k f = \Delta(\Delta^{k-1}f)$.

**Useful rules** (follow directly from the definition):
- $\Delta c = 0$ for a constant $c$
- $\Delta[c\,f(x)] = c\,\Delta f(x)$
- $\Delta[f(x) \pm g(x)] = \Delta f(x) \pm \Delta g(x)$ (Δ is **linear**)
- A constant factor that does not depend on $x$ can be taken outside Δ.

> [!note] Beyond the handout
> The handout links to a page on "relations between the operators Δ, ∇ and E", which is not included. For reference: the shift operator $Ef(x) = f(x+h)$ gives $\Delta = E - 1$; the backward difference is $\nabla f(x) = f(x) - f(x - h)$.

## 2. Example 5.4 (= 2024 Q2(c))

### (i) $\Delta e^{ax}$
$$
\Delta e^{ax} = e^{a(x+h)} - e^{ax} = e^{ax}e^{ah} - e^{ax} = e^{ax}\left(e^{ah} - 1\right)
$$
(using $a^{m+n} = a^m a^n$).

> [!warning] Typo in the handout
> The handout's first line reads $e^{a(x+h)} - e^{x}$ and the next lines write $e^{ax}\cdot e^{h} - e^{ax} = e^{ax}[e^h - 1]$. With the definition $\Delta f(x) = f(x+h) - f(x)$ and $f(x) = e^{ax}$, the correct result is $e^{ax}(e^{ah} - 1)$. The handout's version is only right for $a = 1$. Use the corrected form.

### (ii) $\Delta^2e^x$
$$
\Delta e^x = e^{x+h} - e^x = e^x(e^h - 1)
$$
$$
\Delta^2e^x = \Delta\big[e^x(e^h - 1)\big] = (e^h - 1)\,\Delta e^x = (e^h - 1)(e^h - 1)e^x = \left(e^h - 1\right)^2e^x
$$
($e^h - 1$ is a constant, so it comes outside Δ.) In general $\Delta^ne^x = (e^h - 1)^ne^x$.

### (iii) $\Delta\log x$
$$
\Delta\log x = \log(x + h) - \log x = \log\frac{x + h}{x} = \log\left(\frac xx + \frac hx\right) = \log\left(1 + \frac hx\right)
$$

## 3. Example 5.5: rational function by partial fractions
Evaluate $\Delta\left[\dfrac{5x + 12}{x^2 + 5x + 6}\right]$ with $h = 1$.

1. **Partial fractions:** $x^2 + 5x + 6 = (x+2)(x+3)$.
$$
\frac{5x+12}{(x+3)(x+2)} = \frac{A}{x+3} + \frac{B}{x+2},\quad A = \frac{5x+12}{x+2}\Big|_{x=-3} = \frac{-3}{-1} = 3,\quad B = \frac{5x+12}{x+3}\Big|_{x=-2} = \frac{2}{1} = 2
$$
2. **Apply Δ to each part** (Δ is linear):
$$
\Delta\left[\frac{3}{x+3} + \frac{2}{x+2}\right] = 3\left[\frac{1}{x+4} - \frac{1}{x+3}\right] + 2\left[\frac{1}{x+3} - \frac{1}{x+2}\right]
$$
3. **Simplify:** $\frac{1}{x+4} - \frac{1}{x+3} = \frac{-1}{(x+4)(x+3)}$ and $\frac{1}{x+3} - \frac{1}{x+2} = \frac{-1}{(x+3)(x+2)}$:
$$
= \frac{-3}{(x+4)(x+3)} - \frac{2}{(x+3)(x+2)} = \frac{-3(x+2) - 2(x+4)}{(x+2)(x+3)(x+4)} = \frac{-5x - 14}{(x+2)(x+3)(x+4)}
$$

## 4. $\Delta^2\dfrac1x$ with interval 1 (2024 Q2(d))
**First difference:**
$$
\Delta\frac1x = \frac{1}{x+1} - \frac1x = \frac{x - (x+1)}{x(x+1)} = \frac{-1}{x(x+1)}
$$
**Second difference:**
$$
\Delta^2\frac1x = \Delta\left[\frac{-1}{x(x+1)}\right] = \frac{-1}{(x+1)(x+2)} - \frac{-1}{x(x+1)} = \frac{-x + (x+2)}{x(x+1)(x+2)}
$$
$$
\boxed{\Delta^2\frac1x = \frac{2}{x(x+1)(x+2)}}
$$
**Check** with the direct formula $\Delta^2f(x) = f(x+2) - 2f(x+1) + f(x)$ at $x = 1$: $\frac13 - 2\cdot\frac12 + 1 = \frac13$, and $\frac{2}{1\cdot2\cdot3} = \frac13$ ✓.

(Alternative route: $\frac{-1}{x(x+1)} = \frac{1}{x+1} - \frac1x$ by partial fractions, then difference each term.)

General interval $h$: $\Delta\frac1x = \frac{-h}{x(x+h)}$ and $\Delta^2\frac1x = \frac{2h^2}{x(x+h)(x+2h)}$.

## 5. Summary of results
| $f(x)$ | $\Delta f(x)$ | $\Delta^2f(x)$ |
|---|---|---|
| $e^{ax}$ | $e^{ax}(e^{ah}-1)$ | $e^{ax}(e^{ah}-1)^2$ |
| $e^x$ | $e^x(e^h-1)$ | $e^x(e^h-1)^2$ |
| $\log x$ | $\log(1 + h/x)$ | — |
| $1/x$ ($h=1$) | $-\dfrac{1}{x(x+1)}$ | $\dfrac{2}{x(x+1)(x+2)}$ |
| $\dfrac{5x+12}{x^2+5x+6}$ ($h=1$) | $\dfrac{-5x-14}{(x+2)(x+3)(x+4)}$ | — |

## 6. Exam-relevant points
- Start every answer from the definition $\Delta f(x) = f(x+h) - f(x)$.
- Take constants (like $e^h - 1$) **outside** Δ, and show the exponent law step.
- For rational functions use **partial fractions** first; check the result at one $x$ value.
