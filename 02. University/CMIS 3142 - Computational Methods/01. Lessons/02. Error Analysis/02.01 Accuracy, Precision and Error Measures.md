# 02.01 · Accuracy, Precision and Error Measures

> [!info] [[02.00 Error Analysis|Lesson 2]] · Lecture slides 4–6 · Priority 🟡 Medium
> **Asked as:** "Describe the relative error and true fractional relative error" (2024 Q2(a)).

## 1. Accuracy vs precision (slide 4)
> **Accuracy** refers to how closely a computed or measured value agrees with the **true value**, while **precision** refers to how closely individual computed or measured values agree **with each other**.

| | Accurate | Inaccurate |
|---|---|---|
| **Precise** | values close together **and** close to the truth | values close together but all **off** the truth (systematic error) |
| **Imprecise** | values scattered but **centred** on the truth | values scattered and off the truth |

**Computing example:** a `float` stores about 7 digits (its precision). If a buggy formula always gives 3.1428571 for π, the result is **precise** (7 digits, repeatable) but **inaccurate** (wrong after the 3rd digit).

## 2. Error measures (slides 5–6)

### 2.1 True error $E_t$
The **difference between the true value and the approximation**:
$$
E_t = \text{true value} - \text{approximation}
$$
It has a sign: positive means the approximation is too small.

### 2.2 Absolute error $|E_t|$
The **absolute difference** between the true value and the approximation:
$$
|E_t| = |\text{true value} - \text{approximation}|
$$

### 2.3 True fractional relative error
The **true error divided by the true value**:
$$
\text{True fractional relative error} = \frac{\text{true value} - \text{approximation}}{\text{true value}}
$$
It has no units. It says how big the error is **compared with the size of the quantity**.

### 2.4 (True percent) relative error $\varepsilon_t$
The **true fractional relative error expressed as a percentage**:
$$
\varepsilon_t = \frac{\text{true value} - \text{approximation}}{\text{true value}}\times100\%
$$

### 2.5 Approximate relative error $\varepsilon_a$ (used in iterative methods)
In real problems the true value is **unknown**, so we compare the current and previous approximations instead (Lecture 05_B, Gauss-Seidel):
$$
|\varepsilon_a| = \left|\frac{x^{\text{new}} - x^{\text{old}}}{x^{\text{new}}}\right|\times100\%
$$
Iteration stops when $|\varepsilon_a|$ is below a pre-set tolerance for every unknown. See [[05.02 Gauss-Seidel Method]].

## 3. Why relative error matters (worked example)
Two measurements, each with a true error of 1 cm:

| Quantity | True value | Approximation | $E_t$ | $\varepsilon_t$ |
|---|---|---|---|---|
| Bridge length | 10 000 cm | 9 999 cm | 1 cm | $\frac{1}{10000}\times100 = 0.01\%$ |
| Rivet length | 10 cm | 9 cm | 1 cm | $\frac{1}{10}\times100 = 10\%$ |

The **same** true error is negligible for the bridge but terrible for the rivet. Relative error captures this; true error does not.

**GPA example** (2025 paper data): exact GPA $= 32.7/13 = 2.5153846\ldots$, rounded GPA $= 2.52$.
- $E_t = 2.5153846 - 2.52 = -0.0046154$
- True fractional relative error $= -0.0046154/2.5153846 = -0.001835$
- $\varepsilon_t = -0.1835\%$

## 4. Important distinctions
| Measure | Formula | Needs true value? | Units |
|---|---|---|---|
| True error | $T - A$ | yes | same as data |
| Absolute error | $\lvert T - A\rvert$ | yes | same as data |
| True fractional relative error | $(T - A)/T$ | yes | none |
| Relative (percent) error $\varepsilon_t$ | $(T-A)/T\times100\%$ | yes | % |
| Approximate relative error $\varepsilon_a$ | $(x_{new}-x_{old})/x_{new}\times100\%$ | **no** | % |

> [!note] "Relative error" vs "true fractional relative error"
> The slides use the two terms for the same idea: true fractional relative error is the fraction, relative error $\varepsilon_t$ is the same fraction as a percentage. In 2024 Q2(a), describe both, give both formulas and show the ×100% link with a numeric example.
