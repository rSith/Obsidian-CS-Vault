# 07.02 · Newton–Raphson Method

> [!info] [[07.00 Non-linear Equations - Fixed Point Iteration|Lesson 7]] · Lecture 07 slide 5 ("Book – 801"), Kreyszig pp. 801–803 · Priority 🟢 Low (**never examined** in 2023–2026)

## 1. What is it?
**Newton's method** (Newton–Raphson) solves $f(x) = 0$, where $f$ has a continuous derivative $f'$, by repeatedly replacing the curve with its **tangent line** and taking the point where the tangent crosses the x-axis as the next approximation. *"The method is commonly used because of its simplicity and great speed."*

## 2. Derivation (tangent idea)
At $x_0$ the tangent has slope $f'(x_0)$. If it meets the x-axis at $x_1$:
$$
\tan\beta = f'(x_0) = \frac{f(x_0)}{x_0 - x_1}\quad\Rightarrow\quad x_1 = x_0 - \frac{f(x_0)}{f'(x_0)}
$$
Repeating gives
$$
\boxed{x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}}
$$
The same formula comes from Taylor's formula: $f(x_{n+1}) \approx f(x_n) + (x_{n+1} - x_n)f'(x_n) = 0$.

Newton's method is a fixed-point iteration with $g(x) = x - f(x)/f'(x)$ ([[07.01 Fixed-Point Iteration]]).

## 3. Algorithm (Kreyszig Table 19.1)
```text
ALGORITHM NEWTON (f, f', x0, ε, N)
INPUT  f, f', initial approximation x0, tolerance ε > 0, maximum iterations N
OUTPUT approximate solution x_n (n ≤ N) or message of failure
For n = 0, 1, 2, ..., N − 1 do:
    1  Compute f'(x_n)
    2  If f'(x_n) = 0 then OUTPUT "Failure". Stop.          [unsuccessful]
    3  Else compute  x_{n+1} = x_n − f(x_n) / f'(x_n)
    4  If |x_{n+1} − x_n| ≤ ε |x_{n+1}| then OUTPUT x_{n+1}. Stop.   [successful]
End
5  OUTPUT "Failure". Stop.                                   [no convergence after N iterations]
```
- Line 2: if $f'(x_n) = 0$ (horizontal tangent), try another $x_0$.
- Line 4 is a **relative error test**: it guarantees the desired number of significant digits. **Warning:** the test alone does not prove convergence (the harmonic series diverges although its partial-sum differences go to 0).
- Line 5 is needed because Newton's method may **diverge** or converge too slowly from a poor $x_0$; with several roots, different $x_0$ may give different roots.

## 4. Worked examples (Kreyszig)
**Example 3, square root.** $x = \sqrt c \Rightarrow f(x) = x^2 - c$, $f'(x) = 2x$:
$$
x_{n+1} = x_n - \frac{x_n^2 - c}{2x_n} = \frac12\left(x_n + \frac{c}{x_n}\right)
$$
$c = 2$, $x_0 = 1$: $x_1 = 1.500000$, $x_2 = 1.416667$, $x_3 = 1.414216$, $x_4 = 1.414214$ (exact to 6D).

**Example 4, transcendental.** Positive solution of $2\sin x = x$. $f(x) = x - 2\sin x$, $f'(x) = 1 - 2\cos x$:
$$
x_{n+1} = \frac{2(\sin x_n - x_n\cos x_n)}{1 - 2\cos x_n}
$$
$x_0 = 2$: 1.90100, 1.89552, 1.89550, $x_4 = 1.89549$ (exact to 5D; solution 1.895494).

**Example 5, algebraic.** $f(x) = x^3 + x - 1$:
$$
x_{n+1} = x_n - \frac{x_n^3 + x_n - 1}{3x_n^2 + 1} = \frac{2x_n^3 + 1}{3x_n^2 + 1}
$$
$x_0 = 1$: 0.750000, 0.686047, 0.682340, 0.682328 (error $-1\times10^{-6}$). Compare fixed-point iteration on the same equation (Example 2: still 0.701 after 6 steps): **Newton converges much faster**.

**Bonus (same equation as 2025 Q6(c)):** $f(x) = 4x^3 - 3x^2 - 5x - 10$, $f'(x) = 12x^2 - 6x - 5$, $x_0 = 1.5$: 2.326923, 2.054853, 2.001935, 2.000003, 2.000000 (5 steps, against about 13 for the fixed-point version to the same tolerance).

## 5. Fixed-point vs Newton
| | Fixed-point iteration | Newton–Raphson |
|---|---|---|
| Formula | $x_{n+1} = g(x_n)$ | $x_{n+1} = x_n - f(x_n)/f'(x_n)$ |
| Needs | a good rearrangement $x = g(x)$ | the derivative $f'(x)$ |
| Convergence condition | $\lvert g'(x)\rvert \le K < 1$ near the root | good $x_0$, $f'(\text{root}) \ne 0$ |
| Speed | linear (error × K each step) | quadratic near the root (correct digits roughly double each step) |
| Failure | divergence if $\lvert g'\rvert > 1$ | $f'(x_n) = 0$, poor $x_0$, divergence |

> [!note] Beyond the slides
> "Linear" and "quadratic" convergence are terms from the next section of Kreyszig (order of an iteration process), which is not included in the provided pages. The provided text only says Newton converges "much more rapid[ly]".

## 6. Java
```java
import java.util.function.DoubleUnaryOperator;

public class NewtonRaphson {
    static double newton(DoubleUnaryOperator f, DoubleUnaryOperator df, double x0, double eps, int N) {
        double x = x0;
        for (int n = 0; n < N; n++) {
            double d = df.applyAsDouble(x);
            if (d == 0) throw new ArithmeticException("Failure: f'(x) = 0");        // line 2
            double xNew = x - f.applyAsDouble(x) / d;                               // line 3
            if (Math.abs(xNew - x) <= eps * Math.abs(xNew)) return xNew;           // line 4
            x = xNew;
        }
        throw new ArithmeticException("Failure after " + N + " iterations");       // line 5
    }

    public static void main(String[] args) {
        System.out.println(newton(x -> x * x - 2, x -> 2 * x, 1, 1e-10, 50));     // sqrt(2)
    }
}
```
