# 07.01 · Fixed-Point Iteration

> [!info] [[07.00 Non-linear Equations - Fixed Point Iteration|Lesson 7]] · Kreyszig §19.2 pp. 798–801 · Priority 🟡 Medium
> **Asked as:** "Find the solution to $f(x) = 4x^3 - 3x^2 - 5x - 10$ using the fixed iteration method" (2025 Q6(c)).

## 1. What is it?
To solve $f(x) = 0$:
1. By some algebraic steps, **rewrite** it as
$$
x = g(x)
$$
2. Choose a starting value $x_0$ and compute
$$
x_1 = g(x_0),\quad x_2 = g(x_1),\quad\dots,\quad x_{n+1} = g(x_n)\quad(n = 0, 1, \dots)
$$

A solution of $x = g(x)$ is called a **fixed point** of $g$ (applying $g$ leaves it unchanged), hence the name. A fixed point of $g$ is a solution of $f(x) = 0$, because we got $x = g(x)$ from $f(x) = 0$ by valid algebra.

## 2. Why the choice of $g$ matters (Kreyszig Example 1)
One $f$ can be rewritten in many ways, and **some converge, some do not**.

$f(x) = x^2 - 3x + 1 = 0$, exact roots $1.5 \pm\sqrt{1.25}$: $2.618034$ and $0.381966$.

**(a)** $x = g_1(x) = \frac13(x^2 + 1)$, so $x_{n+1} = \frac13(x_n^2 + 1)$
- $x_0 = 1$: 1.000, 0.667, 0.481, 0.411, 0.390, … → approaches the **smaller** root.
- $x_0 = 3$: 3.000, 3.333, 4.037, 5.766, 11.415, … → **diverges**.

**(b)** $x = g_2(x) = 3 - \frac1x$, so $x_{n+1} = 3 - \frac{1}{x_n}$
- $x_0 = 1$: 1.000, 2.000, 2.500, 2.600, 2.615, … → **larger** root.
- $x_0 = 3$: 3.000, 2.667, 2.625, 2.619, 2.618, … → larger root.

**Graphical reason:** near the smaller root the curve $y = g_1(x)$ is **less steep** than $y = x$ (slope 1), i.e. $|g_1'(x)| < 1$, and the iteration converges. Near 2.618, $g_1$ is steeper ($g_1'(x) > 1$) and the iteration runs away. Convergence depends on **$|g'(x)| < 1$ near the solution**.

## 3. Convergence theorem (Kreyszig Theorem 1)
> Let $x = s$ be a solution of $x = g(x)$ and suppose that $g$ has a continuous derivative in some interval $J$ containing $s$. Then, if $|g'(x)| \le K < 1$ in $J$, the iteration process $x_{n+1} = g(x_n)$ **converges for any $x_0$ in $J$**, and the limit of the sequence $\{x_n\}$ is $s$.

**Proof (mean value theorem):** there is a $t$ between $x$ and $s$ with $g(x) - g(s) = g'(t)(x - s)$. Since $g(s) = s$ and $x_n = g(x_{n-1})$:
$$
|x_n - s| = |g(x_{n-1}) - g(s)| = |g'(t)|\,|x_{n-1} - s| \le K|x_{n-1} - s|
$$
Applying this $n$ times: $|x_n - s| \le K^n|x_0 - s|$. Since $K < 1$, $K^n \to 0$, so $x_n \to s$. ∎

- A $g$ with $|g(x) - g(v)| \le K|x - v|$, $K < 1$, is called a **contraction**.
- $K$ tells the **speed**: e.g. $K = 0.5$ gives at least 2 more correct digits every 7 steps, since $0.5^7 < 0.01$.
- The condition is **sufficient**, not necessary.

## 4. Kreyszig Example 2: $f(x) = x^3 + x - 1 = 0$ (the slide's "example (Book)")
A sketch shows a root near $x = 1$.

**(a)** $x(x^2 + 1) = 1 \Rightarrow x = g_1(x) = \dfrac{1}{1 + x^2}$, with $|g_1'(x)| = \dfrac{2|x|}{(1+x^2)^2} < 1$ for all $x$ → converges for any $x_0$.
From $x_0 = 1$: $x_1 = 0.500$, $x_2 = 0.800$, $x_3 = 0.610$, $x_4 = 0.729$, $x_5 = 0.653$, $x_6 = 0.701$, … (exact $s = 0.682328$). Note the **oscillation** around $s$, typical when $g' < 0$.

**(b)** $x = g_2(x) = 1 - x^3$, $|g_2'(x)| = 3x^2 > 1$ near the solution → the theorem cannot guarantee convergence (try it: it fails).

*"The transformation of a given $f(x) = 0$ into the form $x = g(x)$ with $g$ satisfying $|g'(x)| \le K < 1$ may need some experimentation."*

## 5. Worked exam example: $f(x) = 4x^3 - 3x^2 - 5x - 10 = 0$ (2025 Q6(c))

**Step 1: locate the root.** $f(1) = 4 - 3 - 5 - 10 = -14 < 0$; $f(2) = 32 - 12 - 10 - 10 = 0$. So $x = 2$ is a root (exactly). In an exam you would see the sign change between 1 and 2 (or around 2) and iterate.

**Step 2: choose $g$ with $|g'| < 1$ near the root.**

| Rearrangement | $g'(x)$ | $\lvert g'(2)\rvert$ | Verdict |
|---|---|---|---|
| $x = \dfrac{4x^3 - 3x^2 - 10}{5}$ | $\dfrac{12x^2 - 6x}{5}$ | 7.2 | ❌ diverges |
| $x = \sqrt[3]{\dfrac{3x^2 + 5x + 10}{4}}$ | $\dfrac{6x + 5}{12}\left(\dfrac{3x^2 + 5x + 10}{4}\right)^{-2/3}$ | **0.354** | ✅ converges |

($4x^3 = 3x^2 + 5x + 10 \Rightarrow x^3 = \frac{3x^2 + 5x + 10}{4}$.) On $J = [1.5, 2.5]$, $|g'(x)| \le 0.36 < 1$, so by Theorem 1 the iteration converges for any $x_0$ in $J$.

**Step 3: iterate** $x_{n+1} = \sqrt[3]{(3x_n^2 + 5x_n + 10)/4}$ from $x_0 = 1.5$:

| $n$ | $x_n$ |
|---|---|
| 0 | 1.500000 |
| 1 | 1.823408 |
| 2 | 1.937472 |
| 3 | 1.977855 |
| 4 | 1.992157 |
| 5 | 1.997222 |
| 6 | 1.999016 |
| 7 | 1.999652 |
| 8 | 1.999877 |
| 9 | 1.999956 |
| 10 | 1.999985 |

$x_n \to$ **2.0000** (error shrinks by about $K \approx 0.35$ each step). Check: $f(2) = 0$ ✓.

Example check of step 1: $x_1 = \sqrt[3]{(3(2.25) + 7.5 + 10)/4} = \sqrt[3]{24.25/4} = \sqrt[3]{6.0625} = 1.8234$.

## 6. Algorithm and Java
```text
INPUT g, x0, tolerance ε, max iterations N
for n = 0, 1, ..., N−1
    x_{n+1} = g(x_n)
    if |x_{n+1} − x_n| ≤ ε |x_{n+1}| then OUTPUT x_{n+1}; STOP
OUTPUT "no convergence"; STOP
```

```java
import java.util.function.DoubleUnaryOperator;

public class FixedPointIteration {

    // x_{n+1} = g(x_n) until |x_{n+1} - x_n| <= eps*|x_{n+1}| or N iterations
    static double fixedPoint(DoubleUnaryOperator g, double x0, double eps, int N) {
        double x = x0;
        for (int n = 0; n < N; n++) {
            double xNew = g.applyAsDouble(x);
            System.out.printf("x%-2d = %.6f%n", n + 1, xNew);
            if (Math.abs(xNew - x) <= eps * Math.abs(xNew)) return xNew;   // relative test
            x = xNew;
        }
        throw new ArithmeticException("No convergence in " + N + " iterations");
    }

    public static void main(String[] args) {
        // 2025 Q6(c): x = cbrt((3x^2 + 5x + 10) / 4)
        double r = fixedPoint(x -> Math.cbrt((3 * x * x + 5 * x + 10) / 4), 1.5, 1e-6, 100);
        System.out.println("root = " + r);      // about 2.0
    }
}
```
