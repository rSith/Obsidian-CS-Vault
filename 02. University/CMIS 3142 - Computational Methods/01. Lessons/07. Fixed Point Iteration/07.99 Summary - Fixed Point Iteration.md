# 07.99 · Lesson Summary: Fixed-Point Iteration and Newton–Raphson

> [!info] Hub: [[07.00 Non-linear Equations - Fixed Point Iteration]] · Past papers: [[PP 07 - Fixed Point Iteration]] · Priority 🟡 (1/4 papers)

## Must know
- Rewrite $f(x) = 0$ as $x = g(x)$; iterate $x_{n+1} = g(x_n)$.
- **Convergence theorem:** $|g'(x)| \le K < 1$ on an interval $J$ containing the root ⇒ converges for any $x_0 \in J$; proof by the mean value theorem: $|x_n - s| \le K^n|x_0 - s|$.
- Different rearrangements behave differently (Example 1: $x^2 - 3x + 1$; Example 2: $x^3 + x - 1$).
- Newton: $x_{n+1} = x_n - f(x_n)/f'(x_n)$; algorithm with failure checks and relative stopping test.

## Important definitions
- **Fixed point of $g$:** a value $s$ with $g(s) = s$.
- **Algebraic vs transcendental equation:** polynomial $f$ vs $f$ with sin, cos, exp, log…
- **Contraction:** $|g(x) - g(v)| \le K|x - v|$ with $K < 1$.

## Important formulas
$$
x_{n+1} = g(x_n),\qquad |x_n - s| \le K^n|x_0 - s|
$$
$$
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)},\qquad \text{stop if } |x_{n+1} - x_n| \le \varepsilon|x_{n+1}|
$$

## Important comparison
| Fixed-point | Newton |
|---|---|
| needs $g$ with $\lvert g'\rvert < 1$ | needs $f'$ |
| slow (linear) | fast near root |
| simple | fails if $f'(x_n) = 0$ |

## Key answer (2025 Q6(c))
$4x^3 - 3x^2 - 5x - 10 = 0$ → $x = \sqrt[3]{(3x^2 + 5x + 10)/4}$, $|g'(2)| \approx 0.35 < 1$; from $x_0 = 1.5$: 1.8234, 1.9375, 1.9779, 1.9922, 1.9972, … → **2**. (The rearrangement $x = (4x^3 - 3x^2 - 10)/5$ diverges: $|g'(2)| = 7.2$.)
