# 08.01 · The SOR (Successive Over-Relaxation) Method

> [!info] [[08.00 Successive Over-Relaxation|Lesson 8]] · Lecture 08 slides 3–4 + linked example page · Priority 🔴 High
> **Asked as:** "Solve the following equations using SOR (Successive over-relaxation) method (with initial guess (0,0,0) and w = 1.25)" (2024 Q5(b), 2025 Q5(a), 2026 Q4(a) 10 marks).

## 1. What is it?
**SOR** is Gauss-Seidel with a **relaxation parameter $\omega$** (omega). For each unknown, first compute the ordinary Gauss-Seidel value, then take a **weighted combination** of that value and the old value:
$$
\boxed{x_i^{(k)} = (1 - \omega)\,x_i^{(k-1)} + \omega\,\underbrace{\frac{1}{a_{ii}}\left[b_i - \sum_{j<i}a_{ij}x_j^{(k)} - \sum_{j>i}a_{ij}x_j^{(k-1)}\right]}_{\text{Gauss-Seidel value}}}
$$

The linked example page puts it in three steps:
1. *"First write down the equations for Gauss Seidel method."*
2. *"Now multiply the right hand side by the parameter $w$ and add to it the vector $x^k$ from the previous iteration multiplied by the factor of $(1 - w)$."*
3. Start from the initial guess and iterate, always using the newest values (as in Gauss-Seidel).

Equivalent form: $x_i^{(k)} = x_i^{(k-1)} + \omega\big(x_i^{GS} - x_i^{(k-1)}\big)$, i.e. **move $\omega$ times as far** as Gauss-Seidel would.

## 2. The relaxation parameter $\omega$
| $\omega$ | Name | Effect |
|---|---|---|
| $0 < \omega < 1$ | **under-relaxation** | smaller, damped steps; can make a diverging iteration converge |
| $\omega = 1$ | Gauss-Seidel | SOR reduces exactly to Gauss-Seidel |
| $1 < \omega < 2$ | **over-relaxation** (the "O" in SOR) | bigger steps; speeds up slow convergence |
| $\omega \le 0$ or $\omega \ge 2$ | — | SOR diverges |

- From the example page: *"for symmetric positive definite matrix the SOR method converges for values of the relaxation parameter $w$ from the interval $0 < w < 2$."*
- The best $\omega$ depends on the matrix; values around 1.2–1.5 are common. **All exams used $\omega = 1.25$.**
- Too large an $\omega$ makes the iterates **overshoot and oscillate**.

> [!note] Beyond the slides
> The under/over-relaxation names, the "$\omega \notin (0, 2)$ diverges" statement (Kahan's theorem) and the matrix form $x^{(k)} = (D - \omega L)^{-1}\big[(1-\omega)D + \omega U\big]x^{(k-1)} + \omega(D - \omega L)^{-1}b$ are standard results not stated in the lecture material.

## 3. Worked example (linked lecture example): $3x - y + z = -1$, $-x + 3y - z = 7$, $x - y + 3z = -7$, $\omega = 1.25$, start $(0, 0, 0)$

**Gauss-Seidel equations:**
$$
x^{k+1} = \tfrac13(-1 + y^k - z^k),\quad
y^{k+1} = \tfrac13(7 + x^{k+1} + z^k),\quad
z^{k+1} = \tfrac13(-7 - x^{k+1} + y^{k+1})
$$
**SOR equations:**
$$
x^{k+1} = (1 - 1.25)x^k + 1.25\cdot\tfrac13(-1 + y^k - z^k)
$$
$$
y^{k+1} = (1 - 1.25)y^k + 1.25\cdot\tfrac13(7 + x^{k+1} + z^k)
$$
$$
z^{k+1} = (1 - 1.25)z^k + 1.25\cdot\tfrac13(-7 - x^{k+1} + y^{k+1})
$$

**1st approximation:**
- $x^1 = (-0.25)(0) + 1.25\cdot\frac13[-1 + 0 - 0] = -0.41667$
- $y^1 = (-0.25)(0) + 1.25\cdot\frac13[7 + (-0.41667) + 0] = 1.25\cdot\frac{6.58333}{3} = 2.74306$
- $z^1 = (-0.25)(0) + 1.25\cdot\frac13[-7 - (-0.41667) + 2.74306] = 1.25\cdot\frac{-3.84028}{3} = -1.60012$

**2nd approximation:**
- $x^2 = (-0.25)(-0.41667) + 1.25\cdot\frac13[-1 + 2.74306 + 1.60012] = 0.10417 + 1.39299 = 1.49715$
- $y^2 = (-0.25)(2.74306) + 1.25\cdot\frac13[7 + 1.49715 - 1.60012] = -0.68576 + 2.87377 = 2.18800$
- $z^2 = (-0.25)(-1.60012) + 1.25\cdot\frac13[-7 - 1.49715 + 2.18800] = 0.40003 - 2.62881 = -2.22878$

| Iteration | $x$ | $y$ | $z$ |
|---|---|---|---|
| 1 | −0.41667 | 2.74306 | −1.60012 |
| 2 | 1.49715 | 2.18800 | −2.22878 |
| 3 | 1.04937 | 1.87824 | −2.01411 |
| 4 | 0.94280 | 2.00073 | −1.97234 |
| 5 | 1.00308 | 2.01263 | −2.00294 |
| 6 | 1.00572 | 1.99800 | −2.00248 |
| 7 | 0.99877 | 1.99895 | −1.99930 |
| 8 | 0.99958 | 2.00038 | −1.99984 |
| 9 | 1.00020 | 2.00005 | −2.00010 |

Solution $x \approx 1$, $y \approx 2$, $z \approx -2$. Note the **overshoot** in iteration 2 ($x = 1.497$ jumps past 1): that is over-relaxation at work.

## 5. SOR algorithm (in the style of the lecture's Gauss-Seidel algorithm)
**Input:** $A$, $b$, $XO = x^{(0)}$, $\omega$, $TOL$, $N$.
```text
Step 1  Set k = 1
Step 2  While (k <= N) do Steps 3–6
    Step 3  For i = 1, ..., n
                x_i = (1 − ω) XO_i + (ω / a_ii) [ − Σ_{j<i} a_ij x_j − Σ_{j>i} a_ij XO_j + b_i ]
    Step 4  If ||x − XO|| < TOL then OUTPUT (x_1, ..., x_n); STOP.
    Step 5  Set k = k + 1
    Step 6  For i = 1, ..., n set XO_i = x_i
Step 7  OUTPUT ('Maximum number of iterations exceeded'); STOP.
```

## 6. How to lay out an SOR answer in the exam
1. Check the diagonal is non-zero (and ideally diagonally dominant).
2. Write the **Gauss-Seidel** rearrangement for each unknown.
3. Write the **SOR** equations with $(1 - \omega)$ and $\omega$ substituted: $(1 - 1.25) = -0.25$.
4. Show iteration 1 in full (every substitution), iteration 2 in full, then a **table** for further iterations (3–5 iterations usually suffice).
5. State the converged answer and check it in one original equation.

All three exam systems are worked in [[PP 08 - Successive Over-Relaxation]].

## 7. Important distinctions
| | Jacobi | Gauss-Seidel | SOR |
|---|---|---|---|
| Uses new values immediately | no | yes | yes |
| Extra parameter | none | none | $\omega$ ($0 < \omega < 2$) |
| Update | $x_i^{J}$ | $x_i^{GS}$ | $(1-\omega)x_i^{old} + \omega x_i^{GS}$ |
| Speed | slowest | faster | fastest with a good $\omega$ |
| Special case | — | SOR with $\omega = 1$ | — |
