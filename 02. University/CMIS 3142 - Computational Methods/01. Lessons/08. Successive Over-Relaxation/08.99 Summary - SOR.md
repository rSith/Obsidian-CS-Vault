# 08.99 · Lesson Summary: Successive Over-Relaxation (SOR)

> [!info] Hub: [[08.00 Successive Over-Relaxation]] · Past papers: [[PP 08 - Successive Over-Relaxation]] · Priority 🔴 (3/4 papers, always ω = 1.25 from (0, 0, 0))

## Must know
- SOR = Gauss-Seidel value blended with the old value:
$$
x_i^{(k)} = (1-\omega)x_i^{(k-1)} + \frac{\omega}{a_{ii}}\Big[b_i - \sum_{j<i}a_{ij}x_j^{(k)} - \sum_{j>i}a_{ij}x_j^{(k-1)}\Big]
$$
- With $\omega = 1.25$: $1 - \omega = -0.25$.
- $\omega = 1$ → Gauss-Seidel; $1 < \omega < 2$ over-relaxation; $0 < \omega < 1$ under-relaxation; SPD ⇒ converges for $0 < \omega < 2$.
- Layout: GS equations → SOR equations → iteration 1 and 2 in full → table → answer + check.
- Java: one extra line compared with Gauss-Seidel.

## Important definitions
- **Relaxation parameter $\omega$:** weight given to the Gauss-Seidel update relative to the old value.
- **Over-relaxation:** $\omega > 1$, step beyond the GS value to speed up convergence.
