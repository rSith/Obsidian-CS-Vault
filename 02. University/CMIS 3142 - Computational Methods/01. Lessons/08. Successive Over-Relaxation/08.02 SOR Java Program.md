# 08.02 · SOR Java Program

> [!info] [[08.00 Successive Over-Relaxation|Lesson 8]] · Priority 🟡 Medium
> **Asked as:** "Write a Java program to solve a set of linear equations using the SOR method" (2026 Q4(b), 15 marks).

## 1. Program (tested)
```java
import java.util.Scanner;

public class SOR {

    // Successive Over-Relaxation: Gauss-Seidel value blended with the old value by omega
    static double[] sor(double[][] A, double[] b, double[] x0, double omega, double tol, int maxIter) {
        int n = b.length;
        double[] x = x0.clone();
        for (int k = 1; k <= maxIter; k++) {
            double maxChange = 0;
            for (int i = 0; i < n; i++) {
                double sum = b[i];
                for (int j = 0; j < n; j++)
                    if (j != i) sum -= A[i][j] * x[j];       // newest values (as in Gauss-Seidel)
                double gs = sum / A[i][i];                   // Gauss-Seidel value
                double xNew = (1 - omega) * x[i] + omega * gs; // relaxation step
                maxChange = Math.max(maxChange, Math.abs(xNew - x[i]));
                x[i] = xNew;
            }
            System.out.printf("k=%2d :", k);
            for (double v : x) System.out.printf(" %10.5f", v);
            System.out.println();
            if (maxChange < tol) return x;                   // converged
        }
        System.out.println("Maximum number of iterations exceeded");
        return x;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Number of equations n: ");
        int n = sc.nextInt();
        double[][] A = new double[n][n];
        double[] b = new double[n];
        System.out.println("Enter each row: coefficients then right-hand side");
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) A[i][j] = sc.nextDouble();
            b[i] = sc.nextDouble();
        }
        System.out.print("omega: ");
        double omega = sc.nextDouble();
        if (omega <= 0 || omega >= 2) System.out.println("Warning: SOR needs 0 < omega < 2");
        for (int i = 0; i < n; i++)
            if (A[i][i] == 0) { System.out.println("Zero on the diagonal: reorder the equations"); return; }

        double[] x = sor(A, b, new double[n], omega, 1e-4, 100);     // initial guess = 0
        for (int i = 0; i < n; i++) System.out.printf("x%d = %.4f%n", i + 1, x[i]);
    }
}
```

## 2. How it works
| Part | Code | Theory |
|---|---|---|
| Input | augmented rows, then $\omega$ | $Ax = b$, relaxation parameter |
| Checks | $0 < \omega < 2$; non-zero diagonal | convergence range; division by $a_{ii}$ |
| Gauss-Seidel value | `sum -= A[i][j] * x[j]` over $j \ne i$, then `gs = sum / A[i][i]` | uses newest $x_j$ because `x[]` is updated in place |
| Relaxation | `xNew = (1 - omega) * x[i] + omega * gs` | $x_i^{(k)} = (1-\omega)x_i^{(k-1)} + \omega x_i^{GS}$ |
| Stopping | largest change in a sweep `< tol`, or `maxIter` reached | $\|x^{(k)} - x^{(k-1)}\|_\infty < TOL$ |

**From Gauss-Seidel to SOR:** a Gauss-Seidel program becomes SOR by adding the parameter `omega` and changing **one line** (`x[i] = gs` → `x[i] = (1 - omega) * x[i] + omega * gs`). With `omega = 1` the program **is** Gauss-Seidel ([[05.02 Gauss-Seidel Method]]).
