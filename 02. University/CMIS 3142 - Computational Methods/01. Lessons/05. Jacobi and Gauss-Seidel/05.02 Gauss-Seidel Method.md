# 05.02 · The Gauss-Seidel Method

> [!info] [[05.00 Iterative Methods - Jacobi and Gauss-Seidel|Lesson 5]] · Lecture 05_A pp. 5–6, Lecture 05_B (all) · Priority 🔴 High
> **Asked as:** numerical algorithm for Gauss-Seidel (2024 Q4(b); 2026 Q4(d), 10 marks) · solve by Gauss-Seidel (2024 Q4(d); 2025 Q4(b)(iii) from (1, 1, 2), max 6 iterations; 2026 Q4(c) from (1, 2, 3), 15 marks) · "main difference between Jacobi and Gauss-Seidel" (2025 Q4(a)) · "Describe the way to modify the [Jacobi] computer program for … Gauss Seidel" (2025 Q4(c)).

## 1. What is it?
**Gauss-Seidel** is an iterative method like Jacobi, with one change:

> **Main idea (lecture):** With the Jacobi method, the values of $x_i^{(k)}$ obtained in the $k$-th iteration remain unchanged until the entire $(k+1)$-th iteration has been calculated. With the Gauss-Seidel method, we **use the new values $x_i^{(k+1)}$ as soon as they are known.** For example, once we have computed $x_1^{(k+1)}$ from the first equation, its value is then used in the second equation to obtain the new $x_2^{(k+1)}$, and so on.

### Why use it? (Lecture 05_B)
- *"The Gauss-Seidel method allows the user to control round-off error."* Elimination methods such as Gaussian elimination and LU decomposition are prone to round-off error.
- *"If the physics of the problem are understood, a close initial guess can be made, decreasing the number of iterations needed."*
- It usually converges **faster** than Jacobi (uses better values sooner) and needs only **one** solution vector.

## 2. Basic procedure (Lecture 05_B)
1. Algebraically solve each linear equation for $x_i$ (diagonal elements must be non-zero).
2. Assume an initial guess solution array.
3. Solve for each $x_i$ and repeat, **always using the most recent values**.
4. Use the **absolute relative approximate error** after each iteration to check if the error is within a pre-specified tolerance:
$$
|\varepsilon_a|_i = \left|\frac{x_i^{\text{new}} - x_i^{\text{old}}}{x_i^{\text{new}}}\right|\times100
$$
Stop when $|\varepsilon_a|_i$ is below the tolerance **for all unknowns**.

## 3. Component formula (Lecture 05_A)
$$
x_i^{(k)} = \frac{1}{a_{ii}}\left[-\sum_{j=1}^{i-1}a_{ij}\,x_j^{(k)} \;-\; \sum_{j=i+1}^{n}a_{ij}\,x_j^{(k-1)} \;+\; b_i\right],\qquad i = 1, \dots, n
$$
- $j < i$: unknowns **already updated** in this sweep → new values $x_j^{(k)}$.
- $j > i$: unknowns **not yet updated** → old values $x_j^{(k-1)}$.

General form for any row (Lecture 05_B): $x_i = \dfrac{b_i - \sum_{j\ne i}a_{ij}x_j}{a_{ii}}$ **using the most recent value of each $x_j$**.

## 4. Matrix form (Lecture 05_A)
With $A = D - L - U$ ([[05.01 Jacobi Method]]):
$$
(D - L)\,x^{(k)} = U\,x^{(k-1)} + b
\quad\Rightarrow\quad
x^{(k)} = (D-L)^{-1}U\,x^{(k-1)} + (D-L)^{-1}b
$$
Define $T_g = (D-L)^{-1}U$, $c_g = (D-L)^{-1}b$:
$$
\boxed{x^{(k)} = T_g\,x^{(k-1)} + c_g}
$$

## 5. Worked example 1 (Lecture 05_A system, Gauss-Seidel version)
$5x_1 - 2x_2 + 3x_3 = -1,\quad -3x_1 + 9x_2 + x_3 = 2,\quad 2x_1 - x_2 - 7x_3 = 3$

**Iteration equations:**
$$
x_1^{(k)} = -\tfrac15 + \tfrac25x_2^{(k-1)} - \tfrac35x_3^{(k-1)}
$$
$$
x_2^{(k)} = \tfrac29 + \tfrac39x_1^{(k)} - \tfrac19x_3^{(k-1)}
$$
$$
x_3^{(k)} = -\tfrac37 + \tfrac27x_1^{(k)} - \tfrac17x_2^{(k)}
$$

From $x^{(0)} = (0, 0, 0)$:
- $x_1^{(1)} = -0.2$
- $x_2^{(1)} = 0.2222 + 0.3333(-0.2) - 0 = 0.1556$ ← uses the **new** $x_1$
- $x_3^{(1)} = -0.4286 + 0.2857(-0.2) - 0.1429(0.1556) = -0.5079$ ← uses new $x_1$ and $x_2$

| $k$ | $x_1$ | $x_2$ | $x_3$ |
|---|---|---|---|
| 1 | −0.2000 | 0.1556 | −0.5079 |

## 6. Worked example 2 (Lecture 05_B, "Example 2")
$$
12x_1 + 3x_2 - 5x_3 = 1,\qquad x_1 + 5x_2 + 3x_3 = 28,\qquad 3x_1 + 7x_2 + 13x_3 = 76,\qquad x^{(0)} = (1, 0, 1)
$$
**Convergence check (diagonal dominance):** $|12| \ge |3| + |-5| = 8$; $|5| \ge |1| + |3| = 4$; $|13| \ge |3| + |7| = 10$. All true, at least one strictly → the solution should converge.

**Rewrite:** $x_1 = \dfrac{1 - 3x_2 + 5x_3}{12}$, $x_2 = \dfrac{28 - x_1 - 3x_3}{5}$, $x_3 = \dfrac{76 - 3x_1 - 7x_2}{13}$

**Iteration 1:** $x_1 = \frac{1 - 0 + 5}{12} = 0.50000$; $x_2 = \frac{28 - 0.5 - 3}{5} = 4.9000$; $x_3 = \frac{76 - 1.5 - 34.3}{13} = 3.0923$.

## 7. Numerical algorithm (Lecture 05_A p. 6), the answer to 2024 Q4(b), 2026 Q4(d)
**Input:** $A = [a_{ij}]$, $b$, $XO = x^{(0)}$, tolerance $TOL$, maximum iterations $N$.

```text
Step 1  Set k = 1
Step 2  While (k <= N) do Steps 3–6
    Step 3  For i = 1, 2, ..., n
                x_i = (1 / a_ii) * [ − Σ_{j=1}^{i−1} a_ij * x_j  −  Σ_{j=i+1}^{n} a_ij * XO_j  +  b_i ]
    Step 4  If ||x − XO|| < TOL then OUTPUT (x_1, ..., x_n); STOP.        [success]
    Step 5  Set k = k + 1
    Step 6  For i = 1, ..., n  set XO_i = x_i
Step 7  OUTPUT ('Maximum number of iterations exceeded'); STOP.         [failure]
```
The **only** difference from Jacobi is Step 3: the first sum uses the **new** $x_j$ ($j < i$).

## 8. Java method, tested
```java
public class GaussSeidelMethod {

    // ---------------- Gauss-Seidel ----------------
    static double[] gaussSeidel(double[][] A, double[] b, double[] x0, double tol, int maxIter) {
        int n = b.length;
        double[] x = x0.clone();                            // ONE vector: updated in place
        for (int k = 1; k <= maxIter; k++) {
            double[] xOld = x.clone();                      // kept only for the stopping test
            for (int i = 0; i < n; i++) {
                double sum = b[i];
                for (int j = 0; j < n; j++)
                    if (j != i) sum -= A[i][j] * x[j];      // x[j] is already NEW for j < i
                x[i] = sum / A[i][i];
            }
            print(k, x);
            if (maxDiff(x, xOld) < tol) return x;
        }
        System.out.println("Maximum number of iterations exceeded");
        return x;
    }

    static double maxDiff(double[] a, double[] b) {         // infinity norm of (a - b)
        double m = 0;
        for (int i = 0; i < a.length; i++) m = Math.max(m, Math.abs(a[i] - b[i]));
        return m;
    }

    static void print(int k, double[] x) {
        System.out.printf("k=%2d :", k);
        for (double v : x) System.out.printf(" %10.5f", v);
        System.out.println();
    }

    public static void main(String[] args) {
        double[][] A = {{6, 2, 1}, {2, 8, 1}, {1, 2, 10}};      // 2026 Q4(c)
        double[] b = {22, 32, 48};
        double[] x = gaussSeidel(A, b, new double[]{1, 2, 3}, 0.0001, 100);
    }
}
```

## 9. Modifying a Jacobi program into Gauss-Seidel (2025 Q4(c))
1. **Use one solution array.** In Jacobi the new values go into `x[]` while the sums read `xOld[]`. In Gauss-Seidel, read **and** write the same array `x[]`, so `x[j]` for $j < i$ is already the new value when row $i$ is computed.
2. In the inner sum change `A[i][j] * xOld[j]` to `A[i][j] * x[j]`.
3. Keep a copy `xOld = x.clone()` **only at the start of each iteration**, for the stopping test $\|x - x_{old}\| < TOL$ (or the relative error test).
4. Remove the separate "copy new into old after the sweep" step (Step 6), because values are already updated in place.
5. Everything else (input, max iterations, output) stays the same.

```java
// Jacobi inner loop                        // Gauss-Seidel inner loop
sum -= A[i][j] * xOld[j];                   sum -= A[i][j] * x[j];
x[i] = sum / A[i][i];                       x[i] = sum / A[i][i];   // overwrites at once
```

## 10. Exam-relevant points
- State the **main difference** in one sentence: Gauss-Seidel uses each newly computed value immediately in the same iteration; Jacobi waits until the next iteration.
- When solving by hand: write the iteration equations showing **which values are new** (superscript $k$) and which are old ($k-1$).
- Check **diagonal dominance** first and mention it.
- If the question gives a starting vector (e.g. $(1, 2, 3)$ in 2026), **use it**, not zeros.
