# 05.99 · Lesson Summary: Jacobi and Gauss-Seidel

> [!info] Hub: [[05.00 Iterative Methods - Jacobi and Gauss-Seidel]] · Past papers: [[PP 05 - Jacobi and Gauss-Seidel]] · Priority 🔴 (3/4 papers)

## Must know
- Assumptions: unique solution; non-zero diagonal.
- Jacobi: rewrite each equation for its diagonal unknown; use **only old values** each iteration.
- Gauss-Seidel: same, but **use new values immediately**.
- Component formulas, matrix forms ($A = D - L - U$; $T_j = D^{-1}(L+U)$, $T_g = (D-L)^{-1}U$), and the 7-step numerical algorithms.
- Stopping: $\|x - XO\| < TOL$, relative $\|x^{(k)}-x^{(k-1)}\|/\|x^{(k)}\|$, or $|\varepsilon_a| < $ tolerance for all unknowns; plus max iterations $N$.
- Convergence: iff $\rho(T) < 1$; strict diagonal dominance ⇒ both converge; Stein–Rosenberg ⇒ GS faster for the right class of matrices.
- How to change a Jacobi program into Gauss-Seidel.

## Important definitions
- **Iterative method:** starts from an initial guess and repeatedly improves it until a stopping criterion is met.
- **Spectral radius $\rho(T)$:** largest absolute eigenvalue of $T$.
- **Strictly diagonally dominant:** $|a_{ii}| > \sum_{j\ne i}|a_{ij}|$ for every row.
- **Absolute relative approximate error:** $|\varepsilon_a| = |(x^{new}-x^{old})/x^{new}|\times100$.

## Important formulas
$$
\text{Jacobi: } x_i^{(k)} = \frac{1}{a_{ii}}\Big[b_i - \sum_{j\ne i}a_{ij}x_j^{(k-1)}\Big]
$$
$$
\text{Gauss-Seidel: } x_i^{(k)} = \frac{1}{a_{ii}}\Big[b_i - \sum_{j<i}a_{ij}x_j^{(k)} - \sum_{j>i}a_{ij}x_j^{(k-1)}\Big]
$$
$$
x^{(k)} = Tx^{(k-1)} + c,\qquad \|x - x^{(k)}\| \approx \rho(T)^k\|x^{(0)} - x\|
$$

## Important comparison
| Jacobi | Gauss-Seidel |
|---|---|
| old values only | newest values |
| two vectors | one vector |
| slower | faster (usually) |
| parallel-friendly | sequential |
| $T_j = D^{-1}(L+U)$ | $T_g = (D-L)^{-1}U$ |

## Key worked answers
| System | Method | Result |
|---|---|---|
| Lecture $5x_1-2x_2+3x_3=-1$ … | Jacobi | 7 iterations → $(0.186, 0.331, -0.423)$ |
| same | GS | 5 iterations → same |
| Lecture 05_B $12x_1+3x_2-5x_3=1$ … from $(1,0,1)$ | GS | → $(1, 3, 4)$ |
| 2024 $x+y+z=3$ … | both | **diverge** (not diagonally dominant); exact $(2, -3, 4)$ |
| 2025 fruits from $(1,1,2)$ | Jacobi 10 it. / GS 6 it. | $(1, 2, 3)$; GS much faster |
| 2026 $6x+2y+z=22$ … from $(1,2,3)$ | GS | $(2, 3, 4)$ in ~5 iterations |
