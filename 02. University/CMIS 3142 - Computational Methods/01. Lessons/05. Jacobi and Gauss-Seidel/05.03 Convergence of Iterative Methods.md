# 05.03 · Convergence of Iterative Methods, and Jacobi vs Gauss-Seidel

> [!info] [[05.00 Iterative Methods - Jacobi and Gauss-Seidel|Lesson 5]] · Lecture 05_A pp. 6–7, Lecture 05_B slides 11–12 · Priority 🟡 Medium
> **Asked as:** "Compare and contrast Jacobi and Gauss-Seidel method" (2024 Q4(e)) · "What is the main difference between Jacobi method and Gauss-Seidel method?" (2025 Q4(a)) · "Comment on the performance of both of those methods" (2025 Q4(b)(iv)).

## 1. The general iteration
Both methods have the form
$$
x^{(k)} = T\,x^{(k-1)} + c,\qquad k = 1, 2, \dots
$$
with $T_j = D^{-1}(L+U)$ (Jacobi) or $T_g = (D-L)^{-1}U$ (Gauss-Seidel). Whether the sequence converges depends **only on $T$**.

## 2. Spectral radius
**In simple words:** the spectral radius $\rho(T)$ is the **size of the largest eigenvalue** of $T$ (largest absolute value). It measures how much the iteration matrix can stretch an error vector in the long run.
$$
\rho(T) = \max_i |\lambda_i(T)|
$$

## 3. The convergence results (Lecture 05_A)
- **Lemma 7.18:** if $\rho(T) < 1$, then $(I - T)^{-1}$ exists and $(I - T)^{-1} = I + T + T^2 + \dots = \sum_{j=0}^{\infty}T^j$.
- **Theorem 7.19:** for **any** $x^{(0)} \in \mathbb{R}^n$, the sequence $x^{(k)} = Tx^{(k-1)} + c$ converges to the unique solution of $x = Tx + c$ **if and only if $\rho(T) < 1$**.
  *Proof of sufficiency (lecture):* $x^{(k)} = T^kx^{(0)} + (T^{k-1} + \dots + T + I)c$. Since $\rho(T) < 1$, $T^kx^{(0)} \to 0$, so $\lim x^{(k)} = 0 + \left(\sum_{j=0}^{\infty}T^j\right)c = (I - T)^{-1}c$.
- **Corollary 7.20:** if $\|T\| < 1$ for any natural matrix norm, the sequence converges for any $x^{(0)}$ to $x$ with $x = Tx + c$, and
  1. $\|x - x^{(k)}\| \le \|T\|^k\,\|x^{(0)} - x\|$
  2. $\|x - x^{(k)}\| \le \dfrac{\|T\|^k}{1 - \|T\|}\,\|x^{(1)} - x^{(0)}\|$
- **Theorem 7.21:** if $A$ is **strictly diagonally dominant**, then for **any** $x^{(0)}$ both Jacobi and Gauss-Seidel converge to the unique solution of $Ax = b$.

### Rate of convergence
From Corollary 7.20(i): $\|x - x^{(k)}\| \approx \rho(T)^k\,\|x^{(0)} - x\|$. **The smaller $\rho(T)$, the faster** the error shrinks: each iteration multiplies it by about $\rho(T)$.

- **Theorem 7.22 (Stein–Rosenberg):** if $a_{ij} \le 0$ for each $i \ne j$ and $a_{ii} > 0$ for each $i$, then **exactly one** of these holds:
  1. $0 \le \rho(T_g) < \rho(T_j) < 1$ (both converge, Gauss-Seidel faster),
  2. $1 < \rho(T_j) < \rho(T_g)$ (both diverge, Gauss-Seidel faster),
  3. $\rho(T_j) = \rho(T_g) = 0$,
  4. $\rho(T_j) = \rho(T_g) = 1$.

  Meaning: for this class of matrices, **when one method converges so does the other, and Gauss-Seidel is faster**.

## 4. The practical test: strict diagonal dominance
A matrix is **strictly diagonally dominant** if, in **every row**, the absolute value of the diagonal entry is **greater than** the sum of the absolute values of the other entries:
$$
|a_{ii}| > \sum_{j\ne i}|a_{ij}|\quad\text{for every } i
$$
It is a **sufficient** condition (not necessary): a system may converge without it, but with it convergence is guaranteed (Theorem 7.21). Lecture 05_B states the slightly weaker version: $|a_{ii}| \ge \sum_{j\ne i}|a_{ij}|$ for all rows, with **strict** inequality in at least one row.

> [!tip] Rearranging can help
> If a system is not diagonally dominant, try **reordering the equations** (swapping rows) so the largest coefficient of each unknown lands on the diagonal.

## 5. Jacobi vs Gauss-Seidel (2024 Q4(e), 2025 Q4(a))

**Main difference (one sentence):** Jacobi computes every new component **only from the previous iteration's values**, while Gauss-Seidel **uses each new component as soon as it is computed** within the same iteration.

| Feature | Jacobi | Gauss-Seidel |
|---|---|---|
| Values used in iteration $k$ | only $x^{(k-1)}$ | new $x_j^{(k)}$ for $j < i$, old $x_j^{(k-1)}$ for $j > i$ |
| Formula | $x_i^{(k)} = \frac{1}{a_{ii}}\big[b_i - \sum_{j\ne i}a_{ij}x_j^{(k-1)}\big]$ | $x_i^{(k)} = \frac{1}{a_{ii}}\big[b_i - \sum_{j<i}a_{ij}x_j^{(k)} - \sum_{j>i}a_{ij}x_j^{(k-1)}\big]$ |
| Iteration matrix | $T_j = D^{-1}(L+U)$ | $T_g = (D-L)^{-1}U$ |
| Storage | two vectors (old and new) | one vector (overwrite in place) |
| Speed of convergence | slower | usually faster (often about twice; Stein–Rosenberg) |
| Order of equations | does not matter | result of each sweep depends on the order |
| Parallel computing | easy: all components independent | hard: each component waits for the previous |
| Convergence guaranteed if | strictly diagonally dominant ($\rho(T_j) < 1$) | strictly diagonally dominant ($\rho(T_g) < 1$); also for symmetric positive definite $A$ |
| Similarities | both iterative, both need non-zero diagonal, both start from a guess, both stop on a tolerance or max iterations, both converge under diagonal dominance | |

> [!note] Beyond the slides
> "Easy to parallelise", "order matters" and "GS converges for SPD matrices" are standard facts not written in the lecture notes. They are useful in a "compare and contrast" answer.

## 6. Commenting on performance (2025 Q4(b)(iv))
For the fruit system from $(1, 1, 2)$:
- **Jacobi** after 10 iterations: $(0.9997, 1.9996, 2.9997)$, still oscillating around $(1, 2, 3)$, about 3 correct decimals.
- **Gauss-Seidel** after 6 iterations: $(1.0000, 2.0000, 3.0000)$, correct to 4 d.p. after about 5 iterations.
- Comment: both converge because the matrix is strictly diagonally dominant; Gauss-Seidel converges **much faster** (fewer iterations for higher accuracy) because it uses updated values immediately ($\rho_{GS} \approx 0.11$ vs $\rho_J \approx 0.48$). Jacobi's iterates **oscillate** above and below the solution while GS approaches it smoothly.

## 7. What divergence looks like (2024 Q4(c)(d))
Jacobi from $(0, 0, 0)$ on $x+y+z=3,\ 2x-y-z=3,\ x-y+z=9$:
$(3, -3, 9) \to (-3, -6, 3) \to (6, -12, 6) \to (9, 3, -9) \to (9, 24, 3) \dots$, growing without settling. Gauss-Seidel blows up even faster: $(3, 3, 9) \to (-9, -30, -12) \to (45, 99, 63) \dots$. The exact solution (by elimination) is $(2, -3, 4)$. Full answer in [[PP 05 - Jacobi and Gauss-Seidel]].
