# 04.02 · Forward Elimination and Back Substitution (GE by hand)

> [!info] [[04.00 Gaussian Elimination|Lesson 4]] · Lecture 04 slides 5–10, Lecture 4_1 · Priority 🔴 High
> **Asked as:** "Describe the Gaussian elimination method to solve a given system of linear equations" (2023 Q6(a) 8 marks; 2024 Q6(a); 2025 Q6(a)) · solve by GE (2023/2024 Q6(b)(ii) 9 marks; 2026 Q5(b) 20 marks).

## 1. What is it?
**Gaussian elimination** is a direct method that solves $Ax = b$ ($A$ square $n\times n$) by:
1. **Forward elimination:** use row operations to reduce $[A\mid b]$ to an **upper triangular** system $Ux = y$ (zeros below the diagonal).
2. **Back (backward) substitution:** solve the triangular system from the last equation upwards.

(Lecture 4_0: *"the system of equations $Ax = b$ is reduced (by Gaussian elimination) to an upper triangular system $Ux = y$ to be solved through backward substitution."*)

## 2. Why does it work?
These **elementary row operations** do not change the solution of the system:
- add a multiple of one row to another row,
- swap two rows,
- multiply a row by a non-zero constant.

An upper triangular system is easy: the last equation has one unknown, the one before has two (one already known), and so on.

## 3. How it works: the algorithm in words
For an $n\times n$ system:

**Forward elimination.** For each pivot column $k = 1, \dots, n-1$:
- the **pivot** is $a_{kk}$ (must be non-zero; swap rows if it is 0);
- for each row $i$ below it ($i = k+1, \dots, n$): compute the **multiplier** $m_{ik} = a_{ik}/a_{kk}$ and do
$$
R_i \leftarrow R_i - m_{ik}\,R_k
$$
so that $a_{ik}$ becomes 0.

**Back substitution.**
$$
x_n = \frac{b_n}{a_{nn}}, \qquad x_i = \frac{1}{a_{ii}}\left(b_i - \sum_{j=i+1}^{n} a_{ij}x_j\right),\quad i = n-1, \dots, 1
$$
(here $a$ and $b$ are the values **after** elimination).

### Goal of forward elimination (slide 7)
$$
\begin{bmatrix}a_{11}&a_{12}&a_{13}\\0&a_{22}&a_{23}\\0&0&a_{33}\end{bmatrix}
\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix} = \begin{bmatrix}b_1\\b_2\\b_3\end{bmatrix}
$$

## 4. Worked example 1 (lecture slides 2–10)
$$
\left[\begin{array}{ccc|c}-3&2&-1&-1\\6&-6&7&-7\\3&-4&4&-6\end{array}\right]
$$

**Step 1 (pivot $a_{11} = -3$):** multipliers $m_{21} = 6/(-3) = -2$, $m_{31} = 3/(-3) = -1$.
$R_2 \leftarrow R_2 + 2R_1$, $R_3 \leftarrow R_3 + R_1$:
$$
\left[\begin{array}{ccc|c}-3&2&-1&-1\\0&-2&5&-9\\0&-2&3&-7\end{array}\right]
$$

**Step 2 (pivot $a_{22} = -2$):** $m_{32} = (-2)/(-2) = 1$. $R_3 \leftarrow R_3 - R_2$:
$$
\left[\begin{array}{ccc|c}-3&2&-1&-1\\0&-2&5&-9\\0&0&-2&2\end{array}\right]
$$

The equations now look like (slide 9):
$$
-3x_1 + 2x_2 - x_3 = -1,\qquad -2x_2 + 5x_3 = -9,\qquad -2x_3 = 2
$$

**Back substitution (slide 10):**
$$
x_3 = \frac{2}{-2} = -1,\qquad
x_2 = \frac{1}{-2}(-9 - 5x_3) = \frac{-9+5}{-2} = 2,\qquad
x_1 = \frac{1}{-3}(-1 - 2x_2 + x_3) = \frac{-1-4-1}{-3} = 2
$$

$$
\boxed{x = (2,\ 2,\ -1)}
$$
Check in equation 2: $6(2) - 6(2) + 7(-1) = -7$ ✓.

## 5. Worked example 2 (Lecture 4_1): leading-ones variant
$$
2x - 3y + 3z = 7,\quad 3x + y - 2z = -11,\quad 5x - 2y + 4z = 11
$$
The blog example also **divides each pivot row by its pivot** so the diagonal becomes 1 ("Gauss form": *ones on the diagonal and zeroes below*):
1. $R_1/2$: $x - 1.5y + 1.5z = 3.5$
2. $R_2 - 3R_1$, $R_3 - 5R_1$: $5.5y - 6.5z = -21.5$; $5.5y - 3.5z = -6.5$
3. $R_2/5.5$: $y - 1.18z = -3.91$ (rounded)
4. $R_3 - 5.5R_2$: $3z = 15$; $R_3/3$: $z = 5$
5. Back substitution: $z = 5$, $y = -3.91 + 1.18(5) = 2.0$, $x = 1.5(2) - 1.5(5) + 3.5 = -1$

$$
\boxed{(x, y, z) = (-1,\ 2,\ 5)}
$$

> [!note] Two equivalent styles
> The lecture slides do **not** normalise rows (they keep −3, −2, −2 on the diagonal); the blog example does. Both are Gaussian elimination and give the same answer. Normalising is not needed, and rounding there (e.g. 1.18, 3.91) introduces round-off error. Keeping **fractions** gives exact answers when calculators are not allowed (2024).

## 6. Worked example 3: 4×4 (2026 Q5(b)) at a glance
$$
\begin{aligned}
x + 2y + z + w &= 8\\ 2x + 3y + 2z + w &= 12\\ x + y + 3z + 2w &= 10\\ 3x + 4y + z + 2w &= 16
\end{aligned}
$$
After elimination ($R_2-2R_1$, $R_3-R_1$, $R_4-3R_1$; then $R_3-R_2$, $R_4-2R_2$; then $R_4+R_3$):
$$
\left[\begin{array}{cccc|c}1&2&1&1&8\\0&-1&0&-1&-4\\0&0&2&2&6\\0&0&0&3&6\end{array}\right]
\Rightarrow w = 2,\ z = 1,\ y = 2,\ x = 1
$$

## 7. Model answer: "Describe the Gaussian elimination method" (8 marks)
1. **Purpose:** direct method for solving $n$ linear equations in $n$ unknowns, $Ax = b$, with $A$ non-singular.
2. **Augmented matrix:** write $[A \mid b]$.
3. **Forward elimination:** for $k = 1 \dots n-1$, use pivot $a_{kk}$; for each lower row $i$, multiplier $m_{ik} = a_{ik}/a_{kk}$, $R_i \leftarrow R_i - m_{ik}R_k$; this creates zeros below the diagonal → upper triangular $U$.
4. **Back substitution:** $x_n = b_n/a_{nn}$, then $x_i = (b_i - \sum_{j>i}a_{ij}x_j)/a_{ii}$ upwards.
5. **Pivot problem:** if $a_{kk} = 0$ (or very small), swap with a lower row (partial pivoting) to avoid division by zero and reduce round-off.
6. **Cost:** about $\frac{2}{3}n^3$ operations for elimination, $n^2$ for back substitution (beyond the slides).
7. **Short 3×3 example** (lecture example above).

## 8. Important distinctions
| Gaussian elimination | Gauss-Jordan elimination |
|---|---|
| zeros **below** the diagonal (upper triangular) | zeros **above and below** (identity) |
| needs back substitution | answer read directly |
| fewer operations | about 50% more work |

| Direct (GE, LU, Cholesky) | Iterative (Jacobi, GS, SOR) |
|---|---|
| fixed number of steps, exact in exact arithmetic | repeat until converged |
| round-off accumulates; fill-in destroys sparsity | uses only $A\times$vector; good for large sparse |
| any non-singular $A$ (with pivoting) | needs convergence condition (e.g. diagonal dominance) |
