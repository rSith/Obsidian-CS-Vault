# 04.03 · Gaussian Elimination: Algorithm and Program

> [!info] [[04.00 Gaussian Elimination|Lesson 4]] · Lecture 4_0 (algorithm), Lecture 4_2 (C program), Lecture 04 slide 12 (Java exercise) · Priority 🔴 High
> **Asked as:** "Develop an algorithm to solve a given system of linear equation" (2024 Q5(a)) · "Write program in any programming language to solve a system of linear equations using Gaussian elimination" (2025 Q6(b); 2026 Q5(a), 15 marks).

## 1. The sequential algorithm (Lecture 4_0)
Assumptions: $A$ is $n\times n$, $x$ and $b$ are $n$-vectors. **$b$ is stored as the $(n+1)$-th column of $A$.** Loop $k$ controls the elimination step, loop $i$ the row, loop $j$ the column.

**Forward elimination**
```text
for k = 1 to n-1
    for i = k+1 to n
        a(i,k) = a(i,k) / a(k,k)                 // multiplier, stored in place
        for j = k+1 to n+1
            a(i,j) = a(i,j) - a(i,k) * a(k,j)
        endfor
    endfor
endfor
```
*Note: since the entries in the lower triangular part vanish after elimination, their space is used to store the multipliers $a_{ik} = a_{ik}/a_{kk}$.* (These multipliers are exactly the $L$ of the LU decomposition, see [[06.01 LU Decomposition]].)

**Backward substitution**
```text
for i = n to 1
    for j = i+1 to n
        x(i) = x(i) - a(i,j) * x(j)
    endfor
    x(i) = x(i) / a(i,i)
endfor
```
*Note: $x_i$ is stored in the space of $a_{i,n+1}$* (i.e. $x(i)$ starts as $a(i, n+1) = b_i$ and is overwritten by the answer).

### Parallel Gaussian elimination (Lecture 4_0, brief)
In forward elimination, the work for **different rows $i$ within the same step $k$** (the task called $E_k^i$: compute the multiplier for row $i$ and update row $i$) is **independent**: each row only reads the pivot row $k$. So for a fixed $k$, the rows $k+1 \dots n$ can be updated **in parallel** on different processors; the steps $k$ themselves must run in order. (The handout stops after introducing $E_k^i$.)

## 2. The C program from the lecture (Lecture 4_2)
```c
#include<stdio.h>
int main()
{
    int i,j,k,n;
    float A[20][20],c,x[10],sum=0.0;
    printf("\nEnter the order of matrix: ");
    scanf("%d",&n);
    printf("\nEnter the elements of augmented matrix row-wise:\n\n");
    for(i=1; i<=n; i++)
    {
        for(j=1; j<=(n+1); j++)
        {
            printf("A[%d][%d] : ", i,j);
            scanf("%f",&A[i][j]);
        }
    }
    for(j=1; j<=n; j++) /* loop for the generation of upper triangular matrix*/
    {
        for(i=1; i<=n; i++)
        {
            if(i>j)
            {
                c=A[i][j]/A[j][j];
                for(k=1; k<=n+1; k++)
                {
                    A[i][k]=A[i][k]-c*A[j][k];
                }
            }
        }
    }
    x[n]=A[n][n+1]/A[n][n];
    /* this loop is for backward substitution*/
    for(i=n-1; i>=1; i--)
    {
        sum=0;
        for(j=i+1; j<=n; j++)
        {
            sum=sum+A[i][j]*x[j];
        }
        x[i]=(A[i][n+1]-sum)/A[i][i];
    }
    printf("\nThe solution is: \n");
    for(i=1; i<=n; i++)
    {
        printf("\nx%d=%f\t",i,x[i]); /* x1, x2, x3 are the required solutions*/
    }
    return(0);
}
```

**How it maps to the algorithm:**

| C code | Algorithm |
|---|---|
| outer `j` loop = pivot column, `if(i>j)` = rows below the pivot | loops $k$ and $i$ |
| `c = A[i][j]/A[j][j]` | multiplier $m_{ij}$ |
| `A[i][k] = A[i][k] - c*A[j][k]` for all columns up to $n+1$ | row operation $R_i \leftarrow R_i - mR_j$ (also updates $b$) |
| `x[n] = A[n][n+1]/A[n][n]` then the `sum` loop | back substitution |

> [!warning] Limitations of the lecture C program (worth mentioning if asked to improve it)
> - **No pivoting:** if a pivot `A[j][j]` is 0 it divides by zero; small pivots amplify round-off.
> - Uses 1-based indexing inside arrays declared from 0, and `x[10]` only allows $n \le 9$ (while `A` allows up to 19).
> - `float` (single precision) gives only about 7 digits; `double` is safer ([[01.05 IEEE 754 Double Precision]]).

## 3. Java program (Lecture 04 slide 12 exercise; 2025 Q6(b), 2026 Q5(a)), tested
```java
import java.util.Scanner;

public class GaussianElimination {

    // Solves Ax = b. The augmented matrix a has n rows and n+1 columns (column n holds b).
    static double[] solve(double[][] a) {
        int n = a.length;

        // ---------- forward elimination ----------
        for (int k = 0; k < n - 1; k++) {                 // k = pivot (elimination step)
            // partial pivoting: bring the row with the largest |a[i][k]| to row k
            int max = k;
            for (int i = k + 1; i < n; i++)
                if (Math.abs(a[i][k]) > Math.abs(a[max][k])) max = i;
            double[] tmp = a[k]; a[k] = a[max]; a[max] = tmp;
            if (Math.abs(a[k][k]) < 1e-12) throw new ArithmeticException("Matrix is singular");

            for (int i = k + 1; i < n; i++) {             // rows below the pivot
                double m = a[i][k] / a[k][k];             // multiplier
                for (int j = k; j <= n; j++)              // columns k..n (n = b column)
                    a[i][j] = a[i][j] - m * a[k][j];
            }
        }

        // ---------- back substitution ----------
        double[] x = new double[n];
        for (int i = n - 1; i >= 0; i--) {
            double sum = a[i][n];                         // start from b_i
            for (int j = i + 1; j < n; j++)
                sum = sum - a[i][j] * x[j];               // subtract the known terms
            x[i] = sum / a[i][i];
        }
        return x;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Number of equations n: ");
        int n = sc.nextInt();
        double[][] a = new double[n][n + 1];
        System.out.println("Enter the augmented matrix row by row (n coefficients, then b):");
        for (int i = 0; i < n; i++)
            for (int j = 0; j <= n; j++) a[i][j] = sc.nextDouble();

        double[] x = solve(a);
        for (int i = 0; i < n; i++) System.out.printf("x%d = %.4f%n", i + 1, x[i]);
    }
}
```

```text
Lecture 04 system:                     x1 = 2.0000   x2 = 2.0000   x3 = -1.0000
```

### What each part does
1. **Input:** the augmented matrix, $n$ rows × $(n+1)$ columns (column $n$ = $b$), exactly as in the C program.
2. **Partial pivoting** (an improvement over the lecture code): before eliminating column $k$, swap in the row with the largest $|a_{ik}|$. This avoids division by zero and reduces round-off. If even the largest is ~0, the matrix is singular.
3. **Elimination:** multiplier `m = a[i][k] / a[k][k]`, then `a[i][j] -= m * a[k][j]` for $j = k \dots n$ (including the $b$ column).
4. **Back substitution:** from the last row up, subtract known terms and divide by the diagonal.

> [!note] Beyond the slides
> Partial pivoting is not in the lecture materials. It is standard practice and worth one or two sentences in a "describe" or "program" answer. Without it the program is identical in logic to the lecture C code.

## 4. Operation count (beyond the slides)
| Phase | Approximate operations |
|---|---|
| Forward elimination | $\frac{2}{3}n^3$ |
| Back substitution | $n^2$ |
So doubling $n$ makes GE about 8 times slower, which is why iterative methods are used for very large sparse systems.
