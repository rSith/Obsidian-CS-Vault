# 03.03 · Symmetric Matrix Storage (and the Symmetric Matrix Class)

> [!info] [[03.00 Matrix Programming|Lesson 3]] · Lecture slides 8–9, 12–13 · Assignment 04 · Priority 🔴 High
> **Asked as:**
> - "Write an efficient Java class for a symmetric matrix with methods: `element(i,j)`, `Store_Element(i,j,E)`, `Multiply(A)` … Note that the matrix returned may not be symmetric" (2023 Q4(a), 12 marks)
> - "Describe a suitable method to represent the symmetric matrix" (2026 Q6(a), 10 marks), then use it for Cholesky (2026 Q6(b))
> - symmetric class in the inheritance hierarchy (2024 Q3)

## 1. What is it?
A **symmetric matrix** is a square matrix where $A[i,j] = A[j,i]$ for all $i$ and $j$ (slide 12):
$$
A = \begin{bmatrix}a&b&c\\b&d&e\\c&e&f\end{bmatrix}
$$
Equivalently, $A = A^T$.

## 2. Why special storage?
The elements above the diagonal are copies of those below it. Storing both wastes memory. If we store only the **lower triangle (including the diagonal)** we need
$$
1 + 2 + \dots + n = \frac{n(n+1)}{2} \text{ values instead of } n^2
$$
which is **about half** the memory for large $n$ (for $n = 1000$: 500 500 instead of 1 000 000).

Symmetric matrices are very common: stiffness matrices in structural engineering, covariance matrices in statistics/ML, and the matrices used by **Cholesky** ([[06.02 Cholesky Method]]).

## 3. How does it work?

### 3.1 Representation (slide 13: "row vector + number of elements")
- a **row vector** `a[]` holding the lower triangle **row by row**,
- the **matrix size** $n$ (so the number of elements is $n(n+1)/2$).

For $A = \begin{bmatrix}3&4&5\\4&15&7\\5&7&3\end{bmatrix}$ (slide 8 matrix $B$):
$$
a = [\underbrace{3}_{\text{row }0},\ \underbrace{4,\ 15}_{\text{row }1},\ \underbrace{5,\ 7,\ 3}_{\text{row }2}]
$$

### 3.2 The index formula
To find $A[i,j]$ with $i \ge j$: rows $0 \dots i-1$ are stored before row $i$, and they contain $1 + 2 + \dots + i = \frac{i(i+1)}{2}$ values. Then move $j$ places along row $i$:

$$
\boxed{\;k = \frac{i(i+1)}{2} + j \quad (0\text{-based}, i \ge j)\;}
\qquad\text{or}\qquad
k = \frac{(i-1)\,i}{2} + j \quad (1\text{-based})
$$

If $j > i$, **swap $i$ and $j$** first (use the mirror element).

> [!warning] Conflict with slide 9
> Slide 9 writes the formula as $(i-1)(i)/2 + i + j$. With **0-based** $i, j$ this simplifies to $\frac{i(i-1)}{2} + i + j = \frac{i(i+1)}{2} + j$, the same as the boxed formula. With **1-based** indices the correct formula is $\frac{(i-1)i}{2} + j$. The slide's own check pairs work with the 0-based reading. Use the boxed form and **state the index base** in the exam.

**Check (slide 9 pairs, 0-based, $n = 3$):**

| $(i,j)$ | $k = i(i+1)/2 + j$ | $a[k]$ |
|---|---|---|
| (0,0) | 0 | 3 |
| (1,0) | 1 | 4 |
| (1,1) | 2 | 15 |
| (2,0) | 3 | 5 |
| (2,1) | 4 | 7 |
| (2,2) | 5 | 3 |
| (0,2) → swap → (2,0) | 3 | 5 ✓ |

### 3.3 Constructors suggested on slide 13
`symmetricMatrix(int Matsize)`, `symmetricMatrix(rowVector A, int Matsize)`, `symmetricMatrix(double[] A, int Matsize)`, `symmetricMatrix(String datafile, int Matsize)`, `symmetricMatrix(Matrix A)`. The class below implements the first one plus a "from a full 2-D array" version.

> [!note] Assignment 04: "using column vector"
> Storing the **upper** triangle column by column gives exactly the same array and the same formula with $i$ and $j$ exchanged: $k = \frac{j(j+1)}{2} + i$ for $i \le j$.

## 4. Java class (2023 Q4(a))
```java
public class SymmetricMatrix {
    private int n;          // matrix size (n x n)
    private double[] a;     // lower triangle stored row by row: n(n+1)/2 values

    public SymmetricMatrix(int n) {
        this.n = n;
        a = new double[n * (n + 1) / 2];
    }

    public SymmetricMatrix(double[][] full) {       // build from a full symmetric 2-D array
        this(full.length);
        for (int i = 0; i < n; i++)
            for (int j = 0; j <= i; j++) Store_Element(i, j, full[i][j]);
    }

    // position of A[i][j] (0-based) inside the row vector a
    private int index(int i, int j) {
        if (j > i) { int t = i; i = j; j = t; }    // upper triangle -> use the mirror element
        return i * (i + 1) / 2 + j;                // rows 0..i-1 hold 1+2+...+i = i(i+1)/2 values
    }

    // (i) element at row i, column j
    public double element(int i, int j) { return a[index(i, j)]; }

    // (ii) store E at row i, column j (automatically also at j, i)
    public void Store_Element(int i, int j, double E) { a[index(i, j)] = E; }

    // (iii) this * A  -- the product of two symmetric matrices is NOT always symmetric,
    //                   so the result is returned as a full 2-D array
    public double[][] Multiply(SymmetricMatrix A) {
        if (A.n != n) throw new IllegalArgumentException("Sizes differ");
        double[][] C = new double[n][n];
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++) {
                double sum = 0;
                for (int k = 0; k < n; k++) sum += element(i, k) * A.element(k, j);
                C[i][j] = sum;
            }
        return C;
    }

    public void display() {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) System.out.printf("%8.2f", element(i, j));
            System.out.println();
        }
    }

    public static void main(String[] args) {
        SymmetricMatrix S = new SymmetricMatrix(new double[][]{{3, 4, 5}, {4, 15, 7}, {5, 7, 3}});
        SymmetricMatrix T = new SymmetricMatrix(new double[][]{{1, 2, 0}, {2, 1, 0}, {0, 0, 1}});
        S.display();
        double[][] P = S.Multiply(T);
        System.out.println("S x T:");
        for (double[] row : P) { for (double x : row) System.out.printf("%8.2f", x); System.out.println(); }
    }
}
```

Output (tested). Notice $S\times T$ is **not symmetric** (34 ≠ 10), which is why `Multiply` returns a full array:
```text
S x T:
   11.00   10.00    5.00
   34.00   23.00    7.00
   19.00   17.00    3.00
```

### Why this is "efficient"
- Memory: $n(n+1)/2$ doubles instead of $n^2$.
- `element` and `Store_Element` are $O(1)$: one formula, no search.
- Storing at $(i,j)$ automatically updates $(j,i)$, so symmetry can never be broken by mistake.

## 5. Important distinctions
| Full storage | Symmetric (packed) storage |
|---|---|
| $n^2$ values | $n(n+1)/2$ values |
| `a[i][j]` direct | `a[i(i+1)/2 + j]` after swapping so $i \ge j$ |
| any matrix | only $A = A^T$ |
| row/column swap allowed | swapping rows alone breaks symmetry (must convert to full) |
