# 06.01 · LU Decomposition

> [!info] [[06.00 LU Decomposition and Cholesky|Lesson 6]] · Lecture 06 slides 2–4 · Priority 🟢 Low (never asked on its own, but it is the idea behind Cholesky)

## 1. What is it?
> *For most non-singular matrix $[A]$ that one could conduct Naïve Gauss Elimination forward elimination steps, one can always write it as*
> $$[A] = [L][U]$$
> *where $[L]$ = lower triangular matrix and $[U]$ = upper triangular matrix.* (slide 3)

- **Lower triangular:** all entries **above** the diagonal are zero.
- **Upper triangular:** all entries **below** the diagonal are zero.
- In the usual (Doolittle) form, $L$ has **1s on its diagonal**, $L$'s entries below the diagonal are the **Gaussian elimination multipliers**, and $U$ is the upper triangular matrix that forward elimination produces.

## 2. How can this be used? (slide 4)
Given $[A][X] = [b]$:
1. Decompose $[A]$ into $[L]$ and $[U]$ such that $[A] = [L][U]$. That is, $[L][U][X] = [b]$.
2. Let $[U][X] = [Z]$. **Solve $[L][Z] = [b]$ for $[Z]$** (forward substitution, top to bottom).
3. **Solve $[U][X] = [Z]$ for $[X]$** (back substitution, bottom to top).

## 3. Why is it used?
- The expensive part (factorising, about $\frac23n^3$ operations) is done **once**. Each extra right-hand side $b$ costs only two triangular solves (about $2n^2$).
- Useful for many load cases in engineering, for computing $A^{-1}$ column by column, and for determinants ($\det A = \det U = \prod u_{ii}$).

## 4. Worked example (using the Lecture 04 GE example)
$$
A = \begin{bmatrix}-3&2&-1\\6&-6&7\\3&-4&4\end{bmatrix},\qquad b = \begin{bmatrix}-1\\-7\\-6\end{bmatrix}
$$
Gaussian elimination ([[04.02 Forward Elimination and Back Substitution]]) used multipliers $m_{21} = -2$, $m_{31} = -1$, $m_{32} = 1$ and produced $U$:
$$
L = \begin{bmatrix}1&0&0\\-2&1&0\\-1&1&1\end{bmatrix},\qquad
U = \begin{bmatrix}-3&2&-1\\0&-2&5\\0&0&-2\end{bmatrix}
$$
Check row 2 of $LU$: $-2(-3, 2, -1) + (0, -2, 5) = (6, -6, 7)$ ✓.

**Solve $LZ = b$ (forward):** $z_1 = -1$; $z_2 = -7 - (-2)(-1) = -9$; $z_3 = -6 - (-1)(-1) - (1)(-9) = 2$.

**Solve $UX = Z$ (back):** $x_3 = 2/(-2) = -1$; $x_2 = (-9 - 5(-1))/(-2) = 2$; $x_1 = (-1 - 2(2) + (-1))/(-3) = 2$.

$X = (2, 2, -1)$, the same as by Gaussian elimination.

## 5. LU vs Cholesky
| | LU | Cholesky |
|---|---|---|
| Factorisation | $A = LU$ | $A = LL^T$ (so $U = L^T$) |
| Matrix required | non-singular (pivoting may be needed) | **symmetric positive definite** |
| Factors to store | $L$ and $U$ | only $L$ |
| Work | about $\frac23n^3$ | about $\frac13n^3$ (half) |
| Square roots | none | $n$ square roots |

## 6. Exam-relevant points
- Not examined directly, but the two-step solve **$LZ = b$ then $UX = Z$** is exactly the second half of every Cholesky question ($Lc = b$, then $L^Tx = c$).
