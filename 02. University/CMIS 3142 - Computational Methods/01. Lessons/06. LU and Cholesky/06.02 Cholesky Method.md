# 06.02 · The Cholesky Method (A = LLᵀ)

## 1. What is it?
The **Cholesky method** factorises a **symmetric positive definite (SPD)** matrix $A$ as
$$
A = LL^T
$$
where $L$ is **lower triangular** with **positive diagonal entries**, and $L^T$ (its transpose) is upper triangular. Then $Ax = b$ becomes $LL^Tx = b$, which is solved by two triangular solves:
$$
Lc = b \;(\text{forward substitution}),\qquad L^Tx = c\;(\text{back substitution})
$$

## 2. Essential conditions (2025 Q5(b))
1. $A$ is **square** ($n\times n$).
2. $A$ is **symmetric**: $a_{ij} = a_{ji}$ ($A = A^T$).
3. $A$ is **positive definite**: $x^TAx > 0$ for every non-zero vector $x$.

Ways to recognise positive definiteness (beyond the slides):
- all eigenvalues of $A$ are positive;
- all leading principal minors are positive ($a_{11} > 0$, $\det\begin{bmatrix}a_{11}&a_{12}\\a_{21}&a_{22}\end{bmatrix} > 0$, …, $\det A > 0$);
- in practice: **the Cholesky algorithm itself succeeds** (every number under a square root is positive).

**Theorem (handout):** *For a symmetric matrix $A$, the Cholesky algorithm will succeed with non-zero diagonal entries in $L$ **if and only if $A$ is SPD**. If $A$ is not SPD then the algorithm will either have a zero entry in the diagonal of some $L_k$ (making $L_k$ singular) or will require complex numbers in step 0 or step 1.2.*

> [!example] Quick check: 2024/2026 matrix
> $A = \begin{bmatrix}25&15&-5\\15&18&0\\-5&0&11\end{bmatrix}$: symmetric ✓; leading minors $25 > 0$, $25\cdot18 - 15^2 = 225 > 0$, $\det A = 2025 > 0$ ✓ → SPD.

## 3. The algorithm (handout version)
**Input:** an $n\times n$ SPD matrix $A$. **Output:** the Cholesky factor $L$ (lower triangular) with $A = LL^T$.

**Notation:** $L_{k-1}$ = the $(k-1)\times(k-1)$ upper-left corner of $L$; $a_k$ = the first $k-1$ entries in column $k$ of $A$; $\ell_k$ = the first $k-1$ entries in column $k$ of $L^T$ (= row $k$ of $L$); $a_{kk}$, $\ell_{kk}$ = the $(k,k)$ entries of $A$ and $L$.

```text
0)  Initialise  L_1 = sqrt(a_11)
1)  For k = 2, ..., n
      1.1  Solve  L_{k-1} ℓ_k = a_k  for ℓ_k      (forward substitution; for k = 2 a scalar equation)
      1.2  ℓ_kk = sqrt( a_kk − ℓ_kᵀ ℓ_k )
      1.3  L_k = [ L_{k-1}   0   ]
                 [ ℓ_kᵀ     ℓ_kk ]
```
Each step adds one new row to $L$.

## 4. Element-by-element formulas (the form used in the Java program)
Comparing entries of $A = LL^T$ gives, for $i = 1, \dots, n$ and $j < i$:
$$
\ell_{ii} = \sqrt{a_{ii} - \sum_{k=1}^{i-1}\ell_{ik}^2},
\qquad
\ell_{ij} = \frac{1}{\ell_{jj}}\left(a_{ij} - \sum_{k=1}^{j-1}\ell_{ik}\ell_{jk}\right)
$$
In particular: $\ell_{11} = \sqrt{a_{11}}$, $\ell_{i1} = a_{i1}/\ell_{11}$.

Then
$$
c_i = \frac{1}{\ell_{ii}}\Big(b_i - \sum_{k<i}\ell_{ik}c_k\Big)\ (i = 1\ldots n),
\qquad
x_i = \frac{1}{\ell_{ii}}\Big(c_i - \sum_{k>i}\ell_{ki}x_k\Big)\ (i = n\ldots1)
$$

## 5. Complete algorithm for $AX = B$ (model answer to 2023 Q5(a))
```text
INPUT  n, A (n×n symmetric), B (n×1)
STEP 1  Check A is symmetric: if a_ij ≠ a_ji for some i, j → OUTPUT "not symmetric", STOP
STEP 2  (Factorise A = L Lᵀ)
        for i = 1 to n
            for j = 1 to i
                s = Σ_{k=1}^{j-1} l_ik * l_jk
                if i = j then
                    d = a_ii − s
                    if d ≤ 0 → OUTPUT "A is not positive definite", STOP
                    l_ii = sqrt(d)
                else
                    l_ij = (a_ij − s) / l_jj
STEP 3  (Forward substitution, L C = B)
        for i = 1 to n:   c_i = ( b_i − Σ_{k=1}^{i-1} l_ik c_k ) / l_ii
STEP 4  (Back substitution, Lᵀ X = C)
        for i = n down to 1:   x_i = ( c_i − Σ_{k=i+1}^{n} l_ki x_k ) / l_ii
OUTPUT  X
```

## 6. Worked example 1: the handout 4×4 (= 2023 Q5(b))
$$
A = \begin{bmatrix}16&4&4&-4\\4&10&4&2\\4&4&6&-2\\-4&2&-2&4\end{bmatrix},\qquad b = \begin{bmatrix}32\\26\\20\\-6\end{bmatrix}
$$

**k = 1:** $L_1 = \sqrt{16} = 4$.

**k = 2:** $a_2 = 4$, $a_{22} = 10$. Solve $4\ell_2 = 4 \Rightarrow \ell_2 = 1$. $\ell_{22} = \sqrt{10 - 1^2} = 3$.
$L_2 = \begin{bmatrix}4&0\\1&3\end{bmatrix}$

**k = 3:** $a_3 = (4, 4)^T$, $a_{33} = 6$. Solve $\begin{bmatrix}4&0\\1&3\end{bmatrix}\ell_3 = \begin{bmatrix}4\\4\end{bmatrix}$: $\ell_{31} = 1$, $\ell_{32} = (4 - 1)/3 = 1$. $\ell_{33} = \sqrt{6 - (1^2 + 1^2)} = 2$.
$L_3 = \begin{bmatrix}4&0&0\\1&3&0\\1&1&2\end{bmatrix}$

**k = 4:** $a_4 = (-4, 2, -2)^T$, $a_{44} = 4$. Solve $L_3\ell_4 = a_4$: $\ell_{41} = -4/4 = -1$; $\ell_{42} = (2 - (1)(-1))/3 = 1$; $\ell_{43} = (-2 - (1)(-1) - (1)(1))/2 = -1$. $\ell_{44} = \sqrt{4 - (1 + 1 + 1)} = 1$.
$$
L = \begin{bmatrix}4&0&0&0\\1&3&0&0\\1&1&2&0\\-1&1&-1&1\end{bmatrix}
$$

**Forward $Lc = b$:**
$4c_1 = 32 \Rightarrow c_1 = 8$;
$c_1 + 3c_2 = 26 \Rightarrow c_2 = 6$;
$c_1 + c_2 + 2c_3 = 20 \Rightarrow c_3 = 3$;
$-c_1 + c_2 - c_3 + c_4 = -6 \Rightarrow -8 + 6 - 3 + c_4 = -6 \Rightarrow c_4 = -1$.

**Back $L^Tx = c$** with $L^T = \begin{bmatrix}4&1&1&-1\\0&3&1&1\\0&0&2&-1\\0&0&0&1\end{bmatrix}$:
$x_4 = -1$;
$2x_3 - x_4 = 3 \Rightarrow x_3 = 1$;
$3x_2 + x_3 + x_4 = 6 \Rightarrow x_2 = 2$;
$4x_1 + x_2 + x_3 - x_4 = 8 \Rightarrow 4x_1 + 4 = 8 \Rightarrow x_1 = 1$.

$$
\boxed{x = (1,\ 2,\ 1,\ -1)}
$$

## 7. Worked example 2: 3×3 (2024 Q5(c))
$25x + 15y - 5z = 35$, $15x + 18y = 33$, $-5x + 11z = 6$
$$
\ell_{11} = \sqrt{25} = 5,\quad \ell_{21} = \tfrac{15}{5} = 3,\quad \ell_{31} = \tfrac{-5}{5} = -1
$$
$$
\ell_{22} = \sqrt{18 - 3^2} = 3,\quad \ell_{32} = \tfrac{0 - (-1)(3)}{3} = 1,\quad \ell_{33} = \sqrt{11 - (-1)^2 - 1^2} = 3
$$
$$
L = \begin{bmatrix}5&0&0\\3&3&0\\-1&1&3\end{bmatrix}
$$
$Lc = b$: $c_1 = 35/5 = 7$; $c_2 = (33 - 3\cdot7)/3 = 4$; $c_3 = (6 + 7 - 4)/3 = 3$.
$L^Tx = c$: $z = 3/3 = 1$; $y = (4 - z)/3 = 1$; $x = (7 - 3y + z)/5 = 1$.

$$
\boxed{(x, y, z) = (1, 1, 1)}
$$
(2026 Q6(d) has the same $A$ with $b = (70, 66, 12)$ → $c = (14, 8, 6)$, $x = y = z = 2$; see [[PP 06 - LU and Cholesky]].)

## 8. Limitations (2023 Q5(c), 6 marks)
1. **Only for symmetric positive definite matrices.** Non-symmetric, indefinite or singular matrices cannot be factorised (use LU/Gaussian elimination instead).
2. **Breakdown if not PD:** a zero diagonal $\ell_{kk}$ (division by zero) or a **negative number under the square root** (complex numbers / NaN), as stated in the handout theorem.
3. **Checking SPD in advance is expensive**; in practice you only find out by attempting the factorisation.
4. **Square roots:** $n$ square-root evaluations, which are slower than other operations and add round-off.
5. **Fill-in for sparse matrices:** $L$ can have many non-zeros where $A$ had zeros, losing the memory advantage of sparse storage (the reason ICCG, incomplete Cholesky, exists; named in the syllabus but not covered).
6. **Round-off for ill-conditioned matrices** (nearly singular SPD matrices): stable, but accuracy still depends on conditioning ([[02.06 Conditioning and Stability]]).
7. Still a direct method costing $O(n^3)$, too slow for very large systems compared with iterative methods.

## 9. Specialty of the Cholesky method (2026 Q6(c), 5 marks)
- It factorises $A$ into a **lower triangular matrix and its own transpose**, $A = LL^T$: only **one** factor has to be computed and stored.
- It **exploits symmetry**: about **half the operations** ($\approx n^3/3$) and **half the storage** of LU; $A$ and $L$ both fit in packed lower-triangular storage ([[03.03 Symmetric Matrix Storage]]).
- **No pivoting is needed** for SPD matrices, and the method is **numerically stable**.
- It doubles as a **test for positive definiteness** (it succeeds iff $A$ is SPD).

## 10. Important distinctions
| Cholesky | LU | Gaussian elimination |
|---|---|---|
| $A = LL^T$ | $A = LU$ | reduce to $U$ |
| SPD only | any non-singular (with pivoting) | any non-singular (with pivoting) |
| ~$n^3/3$ operations | ~$2n^3/3$ | ~$2n^3/3$ |
| store $L$ only | store $L$ and $U$ | store $U$ (multipliers optional) |
| reuse for many $b$ | reuse for many $b$ | redo for each $b$ |
