## Course structure
```text
CMIS 3153 Advanced Database Systems
├── Physical level: where and how data is stored
│   ├── 01 Data Storage & File Organization ... memory hierarchy, disk mechanics, access time, buffering,
│   │                                            records & blocking, heap / sorted / hashed files, RAID, SAN/NAS
│   └── 02 Indexing Structures ................. primary / clustering / secondary, dense vs sparse,
│                                                multilevel, B-trees, B+-trees, index maintenance
├── Processing level: how queries are answered
│   ├── 03 Query Processing & Relational Algebra  stages, σ π ∪ − × ρ ⋈ ÷ γ, writing RA queries, pipelining
│   └── 04 Query Optimization .................. execution, cost, logical vs physical plans, CBO vs RBO,
│                                                query trees & graphs, heuristics, transformation rules
├── Architecture level: beyond one machine and flat tables
│   ├── 05 Distributed Databases ............... CAP, transparency, fragmentation, replication,
│   │                                            distributed query processing, 2PC, fault tolerance
│   └── 06 Object-Relational Databases ......... OO vs relational, ORDB features, ORM, SQL3 types, OIDs
├── Analytical level
│   └── 07 Data Warehousing & OLAP ............. Inmon, OLTP vs OLAP, cubes, star/snowflake, ETL
└── 08 Supporting topics (not in notes) ⚠️ ..... three-schema architecture, NoSQL vs relational
```

## High-priority topics (strongest evidence)
1. **Query evaluation steps** (3 papers) + **logical vs physical optimization** (2) + **CBO vs heuristic** (2).
2. **Query trees**: draw from SQL and optimize with heuristics (3 papers) + **trees vs graphs** (2).
3. **Relational algebra queries** and interpreting RA (every paper).
4. **B+-tree** insert/delete drawing, properties, utilization (2 recent papers, full question).
5. **Indexing**: purpose, clustered vs non-clustered, maintenance cost, B-tree range query (every paper).
6. **Disk**: access-time calculation, buffering, performance factors, sequential vs indexed (every recent Q1).
7. **Distributed DBs**: CAP, fragmentation/replication strategy, DDB vs centralized, distributed query processing (rising).
8. **OIDs vs primary keys** and ORDB features.

## Recommended study order
1. **Foundations:** 01 Storage → 02 Indexing (needed for optimization).
2. **Queries:** 03 Relational algebra (practise Tutorials 3 and 5) → 04 Optimization (practise the three query-tree questions).
3. **Architectures:** 05 Distributed DBs (practise scenario answers) → 06 ORDBMS.
4. **Analytics:** 07 Data warehousing (OLTP vs OLAP at minimum).
5. **Gaps:** 08 (three-schema architecture, NoSQL).
6. **Practise:** the 2023/24 paper under timed conditions (5 questions in 150 minutes = 30 min each), then 2022/23, 2021/22, 2020/21; check against the PP notes.
