## 2021/22 · Q2(d) [25 marks]
> **Question:** Discuss RAID architecture. Your answer should cover the objective of RAID, the key techniques used, and a brief description of the types of RAID.

### Expected answer
**RAID (Redundant Array of Independent Disks)** combines several physical disks into **one logical unit** to improve **performance**, **reliability/redundancy**, or both.

**Objective.** Processor and memory speeds improved much faster than disk speeds. RAID aims to **even out this gap** by using **a large array of small independent disks acting as a single higher-performance logical disk**, and to provide **fault tolerance** so that a disk failure does not lose data.

**Key techniques**
1. **Data striping:** split data into equal blocks spread across disks → disks work **in parallel** → higher transfer rates.
2. **Mirroring (shadowing):** keep identical copies on two or more disks → redundancy, faster reads.
3. **Parity:** store computed redundancy (e.g. XOR) so lost data on a failed disk can be **reconstructed** with less overhead than mirroring.

**Types of RAID**
| Level | Technique | Fault tolerance | Performance | Usable capacity | Use |
|---|---|---|---|---|---|
| RAID 0 | striping | none | highest read/write | 100% | temporary data, video editing |
| RAID 1 | mirroring | 1 disk (per mirror) | better reads; writes = single disk | 50% | OS drives, critical DBs |
| RAID 5 | striping + **distributed parity** | 1 disk | good reads; slower writes (parity) | n − 1 disks | file/web servers |
| RAID 6 | striping + **double parity** | 2 disks | good reads; slower writes than RAID 5 | n − 2 disks | enterprise storage |
| RAID 10 | mirror + stripe | 1 per mirrored pair | high reads and writes | 50% | high-performance databases |

Brief trade-off: RAID 0 = speed only; RAID 1 = safety, costly capacity; RAID 5/6 = balance with write penalty; RAID 10 = speed + safety at 50% capacity.

All three parts the question names (objective, techniques, types); a diagram of striping/mirroring/parity earns marks.
