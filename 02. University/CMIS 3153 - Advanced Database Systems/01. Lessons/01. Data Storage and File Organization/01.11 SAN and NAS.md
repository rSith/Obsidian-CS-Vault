# 01.11 · New Storage Systems: SAN and NAS

> [!info] [[01.00 Data Storage and File Organization|Lesson 1]] · Lecture L1 §9 · Priority 🟢 Low (not examined so far)

## 1. Storage Area Network (SAN)
**What:** a **specialized high-speed network** that gives servers **block-level** access to shared storage devices (disk arrays, tape libraries) as if they were **local disks**.

> [!tip] Analogy
> Instead of every office keeping its own filing cabinet, all files are in a central warehouse connected by a private express road. Each office still feels like the cabinet is in its own room.

**Key characteristics (lecture):**
1. **Block-level storage**: servers see raw blocks, like a local disk → flexible and fast.
2. **Storage separated from servers**: unlike direct-attached storage (DAS), storage is pooled and shared.
3. **High-speed network**: Fibre Channel, iSCSI or Fibre Channel over Ethernet (FCoE); low latency, high throughput.
4. **Centralized management**: easier to scale, back up and maintain; better utilization.
5. **Redundancy and fault tolerance**: multiple paths, replication and mirroring.
6. **Scalability**: add storage or servers without disruption.

## 2. Network-Attached Storage (NAS)
**What:** a storage device on the ordinary network that acts as a **file server**; clients access **files** (not blocks) using protocols such as **NFS** or **SMB/CIFS**.

> [!warning] Lecture copy-paste
> Lecture §9.2 repeats the SAN definition paragraph under the NAS heading. Use the NAS features list and the SAN vs NAS comparison (below) for NAS.

**Key features (lecture):** centralized storage accessible from any network device; file sharing across operating systems (NFS, SMB); scalable; easy setup and web-based management; built-in data protection (often RAID).

## 3. SAN vs NAS
| | SAN | NAS |
|---|---|---|
| Access level | **block-level** (looks like a local disk) | **file-level** (looks like a shared folder) |
| Network | dedicated high-speed (Fibre Channel, iSCSI) | standard Ethernet |
| Protocols | FC, iSCSI, FCoE | NFS, SMB, CIFS |
| Complexity / cost | higher | lower, easy to deploy |
| Typical use | **databases**, virtualization, high-performance enterprise apps | file sharing, backups, less performance-critical apps |
