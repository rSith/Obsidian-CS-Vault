> [!abstract] What it is about
> Pretrain an LLM: data preparation, model configuration/initialization, training run and evaluation.

> [!important] What I'll learn
> - The full pretraining workflow and its cost levers
> - **Afterwards I can:** Run continued or from-scratch pretraining of a small model
> - **Main output:** Small pretrained model and evaluation results
>
> **Covers:** When pretraining is worth it; base vs fine-tuned vs continued-pretrained outputs; building a quality dataset from web text; packaging data for Hugging Face; configuring and initializing Llama-style models (resize, random vs reused weights, depth upscaling); running training; benchmark evaluation
> **Tech:** Python, Hugging Face Transformers/Datasets, Llama architecture, PyTorch
