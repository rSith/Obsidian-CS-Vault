> [!abstract] What it is about
> A systematic loop of evaluation, prompting, self-reflection and fine-tuning (LoRA, memory tuning) to raise LLM app accuracy.

> [!important] What I'll learn
> - An accuracy-improvement workflow grounded in evaluation
> - **Afterwards I can:** Measure and raise the factual accuracy of a narrow LLM app
> - **Main output:** Evaluated and fine-tuned text-to-SQL agent
>
> **Covers:** Text-to-SQL agent with Llama 3 8B and hallucination cases; building an evaluation framework and score; instruction vs memory fine-tuning; PEFT/LoRA and Mixture of Memory Experts; iterative synthetic data generation, filtering and fine-tuning
> **Tech:** Python, Llama 3-8B, Lamini (now AMD), SQL, LoRA

## Before I start
- **Stated prerequisites:** Intermediate Python and LLM familiarity
- **What I actually need:** SQL basics; fine-tuning concepts
- **Take these first:** [[Finetuning Large Language Models]] · [[Evaluating and Debugging Generative AI]]
- **Overlaps with:** [[Finetuning Large Language Models]] (fine-tuning), [[Building Your Own Database Agent]] (SQL agent)
- **Why it sits here:** Evaluation-led accuracy improvement with LoRA and memory tuning; applies [[Finetuning Large Language Models]].
