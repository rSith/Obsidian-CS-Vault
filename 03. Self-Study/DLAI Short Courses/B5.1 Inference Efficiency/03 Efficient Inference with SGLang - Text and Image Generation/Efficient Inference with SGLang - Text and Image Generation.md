> [!abstract] What it is about
> Cut inference cost by reusing computation with SGLang's KV and radix caching, for text and image models.

> [!important] What I'll learn
> - Where inference cost comes from and how caching removes redundant work
> - **Afterwards I can:** Explain and apply KV/prefix caching optimizations and measure speedups
> - **Main output:** From-scratch KV cache plus SGLang-accelerated text and image generation
>
> **Covers:** Token-by-token inference cost; attention and KV cache implemented from scratch; RadixAttention (radix-tree prefix sharing across requests); caching and multi-GPU parallelism for diffusion models; future inference trends
> **Tech:** Python, SGLang, RadixAttention, diffusion models, multi-GPU
