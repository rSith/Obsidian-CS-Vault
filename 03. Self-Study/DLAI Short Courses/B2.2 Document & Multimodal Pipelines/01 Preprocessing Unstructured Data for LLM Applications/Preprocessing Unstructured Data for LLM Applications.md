> [!abstract] What it is about
> Preprocess diverse unstructured files (PDF, PPT, Word, HTML, images, tables) into clean, chunked JSON for RAG.

> [!important] What I'll learn
> - Data preparation that improves RAG quality

> **Tech:** Python, Unstructured library/API, layout and table transformers, vector store
