> [!abstract] What it is about
> Build a multi-agent data agent and evaluate both its answers and its goal-plan-action alignment.

> [!important] What I'll learn
> - How to trace and score an agent's output and process, then improve it
> - **Afterwards I can:** Build, trace, evaluate and iteratively improve a data-analysis agent
> - **Main output:** Multi-agent data agent with tracing, GPA evals and inline evaluation
>
> **Covers:** Data agents and trust via goal/plan/action (GPA) alignment; planner + executor + specialised sub-agents in LangGraph; Snowflake Cortex sub-agent over structured and unstructured data; tracing; LLM-as-judge for context relevance, groundedness, answer relevance; GPA metrics (plan quality, adherence, consistency, efficiency); inline runtime evaluations
> **Tech:** Python (OOP), LangGraph, Snowflake Cortex, web search, tracing, LLM-as-judge (TruLens-style RAG triad)

## Before I start
- **Stated prerequisites:** Basic Python and object-oriented programming
- **What I actually need:** LangGraph basics; RAG evaluation concepts
