> [!abstract] What it is about
> Cut agent latency and cost by caching responses based on meaning (semantic caching).

> [!important] What I'll learn
> - Designing and measuring a semantic cache
> - **Afterwards I can:** Add a measured semantic cache to an LLM app or agent
> - **Main output:** Agent with semantic cache that speeds up as it warms
>
> **Covers:** Semantic cache built from scratch then with Redis; metrics (hit rate, precision, recall, latency); threshold tuning, cross-encoders, LLM validation, fuzzy matching; integrating cache into an agent
> **Tech:** Python, Redis (RedisVL), embeddings, cross-encoders
