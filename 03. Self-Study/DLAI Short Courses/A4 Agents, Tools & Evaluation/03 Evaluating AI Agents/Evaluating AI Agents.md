> [!abstract] What it is about
> Systematically trace, evaluate and improve AI agents component by component.

> [!important] What I'll learn
> - An evaluation-driven development process for agents
> - **Afterwards I can:** Instrument and evaluate any agent and run experiments to improve it
> - **Main output:** Traced agent with component and trajectory evals and experiments
>
> **Covers:** LLM evals vs software testing; agent anatomy (router, skills, memory) built from scratch; tracing; code-based vs LLM-as-judge vs human evaluators; router and skill evals; trajectory/convergence evaluation; structured experiments; improving judges; production monitoring
> **Tech:** Python, Arize Phoenix, OpenTelemetry tracing, LLM-as-judge
