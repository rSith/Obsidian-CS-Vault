> [!abstract] What it is about
> Learn the Model Context Protocol and build MCP servers and clients to give apps rich external context.

> [!important] What I'll learn
> - Core MCP concepts and implementation on both sides
> - **Afterwards I can:** Build, test and deploy MCP servers and connect apps to the MCP ecosystem
> - **Main output:** Research-paper chatbot with its own MCP server and client, deployed remotely
>
> **Covers:** Why MCP; client-server architecture and transport; chatbot with arXiv search tools made MCP-compatible; FastMCP server exposing tools, resources and prompt templates; MCP Inspector; MCP client in the chatbot; reference servers (filesystem, fetch); Claude Desktop configuration; remote deployment; roadmap (registry, auth)
> **Tech:** Python, MCP, FastMCP, MCP Inspector, Claude Desktop, Anthropic API
