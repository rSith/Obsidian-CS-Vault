> [!abstract] What it is about
> Use the open A2A protocol so agents built in different frameworks can discover and call each other.

> [!important] What I'll learn
> - How A2A standardizes inter-agent communication and complements MCP
> - **Afterwards I can:** Connect heterogeneous agents into one multi-agent system
> - **Main output:** Healthcare multi-agent system of three A2A agents
>
> **Covers:** A2A client-server architecture, agent cards, lifecycle; wrapping agents as A2A servers; A2A clients; sequential (ADK) and hierarchical/dynamic (BeeAI) orchestration; A2A + MCP; deployment on Agent Stack; extensions and security
> **Tech:** Python, A2A Python SDK, Claude Haiku 4.5 on Vertex AI, Google ADK, Gemini 3 Pro, LangGraph, MCP, Microsoft Agent Framework, BeeAI
