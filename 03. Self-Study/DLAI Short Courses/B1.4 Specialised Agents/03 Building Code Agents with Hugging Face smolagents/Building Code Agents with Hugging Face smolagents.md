> [!abstract] What it is about
> Build code agents (that act by writing code) with Hugging Face smolagents, run them safely and evaluate them.

> [!important] What I'll learn
> - Why and when code-as-action agents outperform function calling
> - **Afterwards I can:** Build, sandbox and evaluate a code agent and a research multi-agent system
> - **Main output:** Deep-research multi-agent system producing a report
>
> **Covers:** Evolution of agency; code agents vs tool-calling agents and benchmarks; constrained Python interpreter and E2B sandboxing; tracing/monitoring and evaluation; multi-agent deep-research system with interactive report
> **Tech:** Python, smolagents, E2B, tracing (OpenTelemetry/Phoenix-style)
