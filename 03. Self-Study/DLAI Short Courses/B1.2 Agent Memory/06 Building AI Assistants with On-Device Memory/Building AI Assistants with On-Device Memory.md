> [!abstract] What it is about
> Give an assistant a local, offline memory of text, voice and images using on-device vector search.

> [!important] What I'll learn
> - Local vector memory design and multimodal recall without retraining
> - **Afterwards I can:** Build an offline assistant that remembers and recalls across modalities and learns new objects from examples
> - **Main output:** Offline multimodal memory assistant
>
> **Covers:** On-device memory flow (capture, store, recall, forget); storing experiences as vectors; filtering/deleting memories; multimodal (voice, image) memory; few-shot object recognition by similarity threshold; running on Mac/Windows/Linux
> **Tech:** Python, Qdrant (local/edge vector DB), embeddings, speech and image models

## Before I start
