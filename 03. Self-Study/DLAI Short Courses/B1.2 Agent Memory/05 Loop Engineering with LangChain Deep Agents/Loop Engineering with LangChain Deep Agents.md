> [!abstract] What it is about
> Engineering the loops around an agent (verification, event-driven, hill-climbing) so it works reliably on long tasks.

> [!important] What I'll learn
> - How each loop extends an agent and how to implement it
> - **Afterwards I can:** Wrap an existing agent with self-checking, automatic triggering and run-over-run improvement
> - **Main output:** Requirements-review agent with verification, event-trigger and learning loops
>
> **Covers:** Four-loop framework (agent, verification, event-driven, hill-climbing); LangChain Deep Agents filesystem/instructions/skills; rubric-based evaluator feedback; triggering runs from Slack/Jira events; trace analysis across runs to improve the harness
> **Tech:** Python, LangChain Deep Agents, LLM evaluator/rubrics, Slack/Jira event triggers, traces

## Before I start
- **Stated prerequisites:** Python familiarity recommended
- **What I actually need:** Agent basics (tool calling, agent loop); LLM-as-judge evaluation; LangChain/LangGraph basics helpful
- **Take these first:** [[AI Agents in LangGraph]] · [[Evaluating AI Agents]]
