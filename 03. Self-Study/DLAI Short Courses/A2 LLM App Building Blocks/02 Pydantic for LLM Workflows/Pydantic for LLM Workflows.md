> [!abstract] What it is about
> Use Pydantic to validate data and get reliable structured outputs and tool calls from LLMs.

> [!important] What I'll learn
> - Data validation at every stage of an LLM system
> - **Afterwards I can:** Build an LLM app whose inputs, outputs and tool parameters are validated
> - **Main output:** Customer-support assistant producing validated tickets/tool calls
>
> **Covers:** Pydantic model basics; validating user input; validating LLM responses and retrying; passing Pydantic models to LLM provider/agent-framework APIs; combining structured output with tool calling
> **Tech:** Python, Pydantic, LLM provider APIs, agent frameworks

- **What I actually need:** Calling an LLM API
