> [!abstract] What it is about
> Compare three ways to get structured LLM output: provider APIs, re-prompting libraries, and constrained decoding.

> [!important] What I'll learn
> - How structured generation works under the hood
> - **Afterwards I can:** Reliably produce schema-valid output and pick the right method
> - **Main output:** Social-media analysis agent with structured outputs
>
> **Covers:** Why structured output matters; OpenAI structured-output API with Pydantic; pandas use of outputs; instructor (validate-and-retry) and its limits; constrained decoding with outlines (logit masking); regex as finite-state machines for formats beyond JSON
> **Tech:** Python, OpenAI API, Pydantic, instructor, outlines, pandas
