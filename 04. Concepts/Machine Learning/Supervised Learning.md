# Supervised Learning
>[!note] 
>Algorithm learns to map input data to known, labeled output responses.
>- Each input has a known output
>- Adjusts itself to reduce prediction errors
>- Make accurate predictions on new data

## Types of Supervised Learning
1. [[Classification]] : Output is a categorical variable. *(spam vs non-spam emails)*
2. [[Regression]]: Output is a continuous variable. *(predicting house price)*
