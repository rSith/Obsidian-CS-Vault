# Unsupervised Learning
>[!note] 
>Unsupervised Learning is a type of machine learning that **finds hidden patterns** or structures **in raw, unlabeled data** without human intervention.

How It Works:
- **Input Data:** Feed the model *raw data* that has no tags, labels, or correct answers
- **Processing:** The system studies the data on its own to *spot* *Similarities, differences, or grouping.*
- **Output:** It *organizes the data into clusters* or simplified structures for a human to interpret

## Unsupervised Learning Algorithms
1. [[Clustering]] : Group similar data points together.
2. [[Association Rule]] : Finds "if-then" relationships and item connection
3. [[Dimensionality Reduction]] : Simplifies complex data by reducing variables while keeping core information
