# Glossary

Back to [[00. Computational Psychiatry - Research Home|Home]]

## Psychiatry words
| Term | Simple meaning |
|---|---|
| Psychiatry | Medicine for mental disorders |
| Psychopathology | Mental disorders, and the study of them |
| Symptom | Something a patient feels or shows (e.g. low mood) |
| Diagnosis / prognosis | Naming the condition / predicting how it will develop |
| DSM-5 / ICD-11 | The two main manuals for classifying mental disorders |
| RDoC | US research framework that studies brain functions instead of diagnostic labels |
| Biomarker | A measurable sign of a condition |
| Depression | Long-lasting low mood, loss of interest, hopelessness |
| Anhedonia | Reduced ability to feel pleasure or reward |
| Schizophrenia | Severe disorder with hallucinations, delusions and confused thinking |
| Bipolar disorder | Mood swings between depression and very high mood |
| Psychosis | Losing touch with reality |
| Hallucination / delusion | Perceiving things that aren't there / a fixed false belief |
| Panic disorder | Repeated sudden attacks of intense fear |
| Relapse | Symptoms coming back |
| CBT | Cognitive-behavioural therapy, a talking therapy |
| Precision psychiatry | Treatment chosen to fit each individual |

## Brain words
| Term | Simple meaning |
|---|---|
| fMRI / EEG | Brain scan of blood flow / recording of brain electrical activity |
| Dopamine | Brain chemical linked to reward |
| Neuron firing | A brain cell sending an electrical signal |

## Modelling words
| Term | Simple meaning |
|---|---|
| Model | A simplified representation of something complex |
| Latent | Hidden; can't be measured directly |
| Parameter | A number in a model that describes a hidden process |
| Error | Gap between prediction and real data |
| Overfitting | Model memorises old data and fails on new data |
| Equifinality / multifinality | Different causes → same result / same cause → different results |
| Generative model | A model that can simulate realistic data |
| Prediction error | Actual result minus expected result |
| Learning rate (α) | How fast expectations change |
| Reward sensitivity (β) | How strongly rewards affect choices |
| Prior / posterior | Belief before / after new evidence |
| Drift rate | Strength of evidence in a decision |

## AI words
| Term | Simple meaning |
|---|---|
| Machine learning | Computers learning patterns from data |
| Supervised / unsupervised | Learning with labels / finding groups without labels |
| CNN / RNN / Transformer | Neural networks for images / sequences / long text |
| LLM | Large language model (e.g. chatbots) |
| Black box | A model whose decisions can't be explained |
| XAI | Explainable AI |
