🚀 Kicked off my Machine Learning journey — Week 1 done!

I just wrapped up "Supervised Machine Learning: Regression and Classification," the first course in Andrew Ng's Machine Learning Specialization (DeepLearning.AI), and I wanted to share a quick recap of what I learned in Week 1: Introduction to Machine Learning.

Here's what stood out to me 👇

🔹 Supervised vs. Unsupervised Learning The foundation of it all — supervised learning maps inputs to known outputs (labeled data), while unsupervised learning finds hidden structure in data with no labels at all.

🔹 The Regression Model Built my first linear regression model from scratch: f(w,b)(x) = wx + b. It's simple, but it's the building block for understanding how a model actually "learns" from data — in my case, predicting house prices from square footage.

🔹 The Cost Function Learned how the squared error cost function measures how far off predictions are from reality, and why that "bowl-shaped" convex cost surface is exactly what makes optimization possible.

🔹 Gradient Descent The real "aha" moment — watching an algorithm iteratively adjust w and b, step by step, to minimize the cost function and converge on the best-fit line. Implementing it in Python and actually seeing it predict house prices made the math click in a way lectures alone hadn't.

📓 All my notes and code are up on GitHub as I work through the specialization: https://github.com/rSith/machine-learning-specialization

On to Week 2: Regression with multiple input variables! Excited to keep building toward my goal of becoming an AI/ML Engineer. 💡
