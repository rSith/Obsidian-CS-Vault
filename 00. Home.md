# 🏠 CS Vault

> [!abstract] How this vault works
> 1. **Capture:** every new note lands in `01. Inbox`. Don't worry about where it goes yet.
> 2. **Use a template** (command palette → *Templates: Insert template*): Lecture Note, Concept Note, Course Home, Project Home, Weekly Review.
> 3. **Set `status`** on every note: `stub` → `draft` → `done`. Anything not `done` shows up in **Still to finish** below.
> 4. **Weekly review (20 min, e.g. Sunday):** empty the Inbox, tick progress, pick 2–3 stubs for next week.
