> a type of **artificial intelligence model designed to process sequential data**, like words in a sentence, stock prices, or audio—by using internal memory to remember past information in the sequence.


- Unlike regular neural networks, an [[RNN]] has loops that let information pass from one step of the network to the next.
- The model keeps a "Hidden state" that acts as a short-term memory, updateing itself as each new piece of data arrives.
- Data is processed one item at a time while keeping track of the context from all previous items.

**Common uses :**
- Language Translation
- Generating Text and Speech
- Use in Time Series data.
