>[!note] 
>- Supervised machine learning technique used to **predict labels or categories from input data.** It assigns each data point to a predefined class based on learned patterns.

- **Uses labeled data:** Trained on datasets where the correct class in known.
- **Predict categories:** Determines the class of new data points.

>[!quote] Example : Cat-Dog Classification
>![[Pasted image 20260903183539.png]]
>A classification model might be trained on dataset of images labeled as either dogs or cats and it can be used to predict the class of new and unseen images as dogs or cats based on their features such as color, texture or shape.
